# 📖 阅读理解词汇积累 (1) — 精读 / 课外阅读

> 来源：阅读理解与课外阅读中积累的生词，按语义场景分组，服务六级阅读与写译
> 排版：每条 2-4 行解析，按优先级排列：核心 → 搭配 → 辨析 → 词根/记忆
> 标注：`⚠️` = 易错点/原文修正 | **加粗** = 核心要点

## 一、社会与制度

### 1. **feudal society** — 封建社会
**核心**：⚠️ 拼写：**feudal society**（原文 fedual 错误）；以土地分封与等级制度为基础的社会
**搭配**：in feudal society 在封建社会 / the feudal system 封建制度
**词根**：feud-（封地，采邑）+ -al；同根 feudalism 封建主义

### 2. **primitive society** — 原始社会
**核心**：**史前、尚未开化**的社会形态
**搭配**：in primitive society 在原始社会 / primitive tribes 原始部落
**词根**：prim- = first（第一，最初）+ -itive；同根 primary 首要的, prime 首要的

### 3. **monarch** — 君主，帝王
**核心**：**世袭**的国王/女王等最高统治者
**搭配**：an absolute monarch 专制君主 / a constitutional monarch 立宪君主
**词根**：mono-（单一）+ arch-（统治）→ 一人统治；同根 monarchy 君主制, anarchy 无政府状态

### 4. **incumbent** — 现任的，在职的；负有职责的
**核心**：**在任**的（官员/总统）；n. 现任者
**搭配**：the incumbent president 现任总统 / be incumbent on/upon sb to do sth 某人有责任做某事（⚠️ 写作正式表达）
**辨析**：⚠️ incumbent（现任/在职）≠ occupant（占用人/居住者）≠ officeholder（官员，中性）
**词根**：in-（在…上）+ cumb- = lie（躺）+ -ent → 躺在职位上 → 在职的；同根 recumbent 躺卧的, succumb 屈服

### 5. **prescript** — 命令，法规，规定
**核心**：⚠️ 罕见书面词（= a rule/dictate）；阅读中更常用 decree 法令 / ordinance 条例
**搭配**：follow the prescript 遵守规定 / by the prescript of law 依法律规定
**词根**：pre-（在前）+ script- = write（写）→ 预先写下的规则；同根 prescribe 开处方/规定, inscription 铭文

## 二、文艺与创作

### 6. **poetry** — 诗歌（总称）；诗集
**核心**：⚠️ 拼写：**poetry**（原文 poety 错误）；不可数名词，表"诗歌"总称
**搭配**：write poetry 写诗 / a poetry collection 诗集 / epic poetry 史诗
**辨析**：⚠️ poetry（诗歌总称，不可数）≠ poem（一首诗，可数）≠ poet（诗人）
**词根**：poet-（诗人）+ -ry；同根 poem 诗, poetic 富有诗意的

### 7. **troupe** — 剧团，戏班子，表演团
**核心**：**巡回演出**的演员团体
**搭配**：a dance troupe 舞蹈团 / a theater troupe 剧团
**辨析**：⚠️ 形近：troupe（演员/表演团）≠ troop（军队/人群，troops 部队）
**记忆**：troupe 与 troop 形近：演员"团" vs 军队"队"

### 8. **immersive** — 沉浸式的
**核心**：让人**身临其境**的（体验/技术）
**搭配**：immersive virtual reality 沉浸式虚拟现实 / an immersive experience 沉浸式体验
**词根**：im-（进入）+ mers- = sink（沉入）+ -ive → 沉入其中；同根 immerse 使沉浸, submersion 沉浸

### 9. **groundbreaking** — 开创性的，突破性的
**核心**：**前所未有**、开辟新领域的
**搭配**：groundbreaking research 开创性研究 / a groundbreaking discovery 突破性发现
**记忆**：ground（地面）+ breaking（打破）→ 破土动工 → 开辟新领域

### 10. **distinctive** — 独特的，与众不同的，独具特色的
**核心**：**区别于他者**的显著特征
**搭配**：a distinctive feature 显著特征 / a distinctive style 独特风格
**辨析**：⚠️ distinctive（独特的，中性偏褒）≠ distinct（清晰的，截然不同的）≠ distinguished（杰出的，褒义）
**词根**：dis-（分开）+ stinct- = prick（刺）+ -ive → 与…分开 → 有区别的；同根 distinct 清晰的, distinguish 区分

## 三、生态与生物

### 11. **predator** — 捕食者，肉食动物；掠夺者
**核心**：**捕食**其他动物的生物；引申"掠夺者"
**搭配**：natural predators 天敌 / a top predator 顶级掠食者
**辨析**：⚠️ predator（捕食者）≠ prey（猎物）—— 两者相对
**词根**：pred- = prey（猎物）+ -ator（施动者）；同根 prey 猎物, predation 捕食

### 12. **marine** — 海洋的，海生的；海军陆战队士兵
**核心**：与**海洋**有关的
**搭配**：marine life 海洋生物 / marine ecosystem 海洋生态系统 / marine biologist 海洋生物学家
**辨析**：⚠️ marine（海洋的，侧重生物/生态）≠ maritime（海事的，侧重航运/法律）
**词根**：mar- = sea（海）+ -ine；同根 maritime 海事的, submarine 潜水艇

### 13. **infant** — 婴儿；初期的，初创的
**核心**：n. **婴儿**；adj. **初期的**（原文 infants 为复数）
**搭配**：infant mortality 婴儿死亡率 / infant industry 新兴产业
**辨析**：⚠️ 形近：infant（婴儿）≠ infirm（体弱的，虚弱的）
**词根**：in-（不）+ fant- = speak（说）→ 还不会说话 → 婴儿；同根 infantile 婴儿的/幼稚的

## 四、动作与状态

### 14. **identify** — 识别，查明；认同
**核心**：**认出/确定**（人、物、问题）
**搭配**：identify the cause 查明原因 / identify with sb 与某人产生共鸣 / identify A with B 把 A 等同于 B
**词根**：ident- = same（相同）+ -ify（使…）；同根 identity 身份, identical 完全相同的

### 15. **devour** — 吞食，吞噬；贪婪地读
**核心**：**狼吞虎咽**地吃；（火）吞噬；（喻）贪婪地阅读
**搭配**：devour the food 狼吞虎咽 / be devoured by fire 被大火吞噬 / devour a book 如饥似渴地读书
**辨析**：⚠️ devour（急切地吞）≠ consume（消耗，中性）≠ swallow（吞咽，指动作）
**词根**：de-（完全）+ vour- = eat（吃）；同根 voracious 贪吃的/求知若渴的

### 16. **prevail** — 盛行，流行；获胜，占上风
**核心**：**普遍存在**（风气/观念）；战胜（prevail over）
**搭配**：prevailing winds 盛行风 / prevail over difficulties 战胜困难 / reason prevails 理智占上风
**辨析**：⚠️ prevail（占上风/盛行）≠ dominate（主导，支配）≠ predominate（占优势，正式）
**词根**：pre-（在前）+ vail- = strong（强）→ 强者在前 → 占上风；同根 valiant 勇敢的, valid 有效的

### 17. **formulated** — 制定，构想；系统阐述
**核心**：**系统地制定/表达**（政策、计划、理论）；原形 **formulate**
**搭配**：formulate a plan 制定计划 / formulate a policy 制定政策 / formulate an idea 阐述想法
**词根**：form- = shape（形状）+ -ulate（使…）→ 使成形 → 制定；同根 formula 公式, formation 形成

### 18. **characterized** — 以…为特征的
**核心**：⚠️ 用法：**be characterized by** 以…为特征（写译高频）；原形 **characterize**
**搭配**：be characterized by rapid growth 以快速增长为特点 / characterize the era 标志这个时代
**辨析**：⚠️ be characterized by（以…为特征，被动）≠ be characteristic of（是…的特征，主动用法）
**词根**：character（特征）+ -ize + -ed；同根 characteristic 特征, character 性格/角色

### 19. **prompt** — 促进，推动；迅速的；提示
**核心**：v. **促使/推动**（某人做某事）；adj. **迅速的**；n. 提示符
**搭配**：prompt sb to do sth 促使某人做某事 / a prompt reply 迅速的回复 / on-screen prompt 屏幕提示
**辨析**：⚠️ prompt（促使，指引发反应）≠ urge（敦促，语气更强）≠ motivate（激励，侧重内在动力）
**记忆**：pro-（向前）+ mpt → 推一把向前 → 促使

### 20. **defray** — 支付，承担（费用）
**核心**：**支付**费用（正式书面词）
**搭配**：defray the cost/expenses 支付费用 / defray the costs of travel 承担差旅费
**辨析**：⚠️ defray（支付费用，正式）≠ pay（支付，通用）≠ cover（承担费用，覆盖）
**词根**：de-（分开）+ fray-（花费）；近义 reimburse 报销, disburse 支付（正式）

### 21. **strapping on** — 系上，绑上
**核心**：⚠️ 拼写：**strapping on**（原文 stropping 错误）；用带子**系牢**
**搭配**：strap on a backpack 背上背包 / strap on your seatbelt 系好安全带
**辨析**：⚠️ strap on（用带子系上）≠ tie on（系上，通用）≠ buckle up（系安全带，口语）
**词根**：strap 带子；同根 strapless 无肩带的

### 22. **be referred to** — 被称为，被称作
**核心**：⚠️ 拼写：**be referred to**（原文 refereed 错误）；refer to ... as ... 的被动形式
**搭配**：be referred to as ... 被称为… / refer to 提及，查阅 / refer A to B 把 A 提交给 B
**辨析**：⚠️ be referred to as（被称为）≠ be referred to（被提交/被提及）—— 有无 as 意思不同
**词根**：re-（回）+ fer- = carry（拿）+ -ed；同根 refer 提及, reference 参考, transfer 转移

## 五、品质与能力

### 23. **dexterity** — 灵巧，熟练，敏捷
**核心**：⚠️ 名词（原释义误为形容词）；尤指**手部**的灵巧
**搭配**：manual dexterity 手部灵巧 / mental dexterity 思维敏捷
**辨析**：⚠️ dexterity（手部/技巧性灵巧）≠ agility（身体敏捷）≠ fluency（流畅）
**词根**：dextr- = right（右手）+ -ity；同根 dexterous 灵巧的, ambidextrous 双手都灵巧的

### 24. **mobility** — 流动性，机动性，移动性
**核心**：**移动/流动**的能力（原释义"机动率"有误）
**搭配**：social mobility 社会流动性 / upward mobility 向上流动 / mobility scooter 电动代步车
**辨析**：⚠️ mobility（流动性/机动性）≠ motility（运动能力，生物学术语）≠ movement（移动，一般）
**词根**：mob-/mov- = move（移动）+ -ility；同根 mobile 可移动的, automobile 汽车

### 25. **scantiness** — 缺乏，不足，稀少
**核心**：**数量不足**的状态（书面词）
**搭配**：the scantiness of resources 资源匮乏 / scantiness of evidence 证据不足
**辨析**：⚠️ scantiness（缺乏，书面）≠ shortage（短缺，通用）≠ scarcity（稀缺，正式）
**词根**：scant（不足的）+ -iness；同根 scant 缺乏的, scanty 少量的

### 26. **infirm** — 体弱的，虚弱的；不牢靠的
**核心**：**年老/体弱**；引申"不坚定的"
**搭配**：infirm with age 因年老而体弱 / an infirm argument 站不住脚的论点
**辨析**：⚠️ 形近：infirm（虚弱的）≠ infant（婴儿）；近义 feeble 虚弱的, frail 脆弱的
**词根**：in-（不）+ firm- = strong（坚固）→ 不坚固 → 虚弱的；同根 firm 坚定的, confirm 确认

### 27. **frugal** — 节俭的，节约的
**核心**：**节省**的（尤其指吃穿用度）
**搭配**：a frugal life 节俭的生活 / be frugal with money 用钱节俭
**辨析**：⚠️ frugal（节俭，中性偏褒）≠ economical（经济划算，客观）≠ stingy（吝啬，贬义）
**词根**：frug- = fruit（果实）+ -al → 只享果实 → 节俭；同根 frugality 节俭

### 28. **tolerably** — 还算可以地；可容忍地
**核心**：副词，**尚可/过得去**
**搭配**：tolerably well 还算不错 / tolerably clean 还算干净
**辨析**：⚠️ tolerably（尚可，指程度）≠ tolerantly（宽容地，副词，来自 tolerant）
**词根**：toler- = bear（容忍）+ -ably；同根 tolerate 容忍, tolerance 容忍, tolerable 可容忍的

### 29. **impartially** — 公正地，不偏不倚地
**核心**：副词，**不带偏见**地
**搭配**：judge impartially 公正地评判 / act impartially 秉公行事
**辨析**：⚠️ impartially（公正地）≠ partially（部分地；偏袒地）—— 差一个前缀意思相反
**词根**：im-（不）+ partial（偏袒的）+ -ly；同根 partial 偏袒的, impartial 公正的

### 30. **upbringing** — 抚育，教养
**核心**：⚠️ 拼写：**upbringing**（原文 upbring 错误）；**成长过程中所受的抚养/教育**
**搭配**：a good upbringing 良好的教养 / religious upbringing 宗教教育背景
**辨析**：⚠️ upbringing（教养，侧重家庭）≠ education（教育，侧重学校）
**记忆**：up（向上）+ bringing（带来）→ 把孩子带大 → 教养；同源 bring up 抚养

## 六、器物与生活

### 31. **tractor** — 拖拉机
**核心**：**农用**牵引机械
**搭配**：drive a tractor 开拖拉机 / farm tractor 农用拖拉机
**词根**：tract- = pull（拉）+ -or（表机器）→ 拉东西的机器；同根 attract 吸引, traction 牵引

### 32. **specification** — 规格，规范；说明书
**核心**：**技术指标/规格要求**
**搭配**：technical specifications 技术规格 / meet the specifications 符合规格 / specification sheet 规格说明书
**词根**：spec- = see/look（看）+ -ific + -ation → 看得清 → 明确说明；同根 specific 具体的, specify 明确规定

### 33. **project** — 项目，工程；投射，投影；展现
**核心**：n. **项目/工程**；v. **投射**（光/影）、**展现**（形象/自信）
**搭配**：a research project 研究项目 / project an image onto the screen 把图像投影到屏幕 / project confidence 展现自信
**辨析**：⚠️ project（项目/投射）≠ program（计划/节目，范围更广）≠ scheme（方案，偏贬"计谋"）
**词根**：pro-（向前）+ ject- = throw（扔）→ 向前扔出 → 投射；同根 inject 注射, reject 拒绝, subject 主题

### 34. **allotment** — 分配，份额；配给地
**核心**：**分给**（时间/资源/份额）；英式另指"租种的小块菜地"（原释义"拨款"有误）
**搭配**：the allotment of funds 资金分配 / time allotment 时间分配 / an allotment garden 配给地菜园
**辨析**：⚠️ allotment（分配/份额）≠ allocation（拨款/分配，正式）≠ appropriation（拨款，法律用语）
**词根**：al-（向）+ lot-（份额）+ -ment；同根 lot 份额, lottery 彩票

### 35. **pirate** — 海盗；盗版者；盗版的
**核心**：n. **海盗**/盗版者；adj. **盗版的**
**搭配**：a pirate ship 海盗船 / pirate software 盗版软件 / software piracy 软件盗版
**辨析**：⚠️ pirate（海盗/盗版）≠ robber（抢劫犯）≠ bandit（土匪，山贼）
**词根**：pir- = attempt（尝试）+ -ate；同根 piracy 盗版/海盗行为

### 36. **supplementary** — 补充的，增补的，附加的
**核心**：⚠️ 拼写：**supplementary**（原文 supplymentary 错误）；在原有基础上**额外添加**
**搭配**：supplementary reading 补充阅读 / supplementary income 额外收入 / supplementary materials 补充材料
**辨析**：⚠️ supplementary（补充的，额外附加）≠ complementary（互补的，相互配合）
**词根**：supple- = fill（填满）+ -ment + -ary；同根 supplement 补充, supply 供给

### 37. **high-end** — 高端的，高档的
**核心**：**高档/昂贵**的（产品或服务）
**搭配**：high-end products 高端产品 / high-end restaurants 高档餐厅
**辨析**：⚠️ high-end（高端，产品/服务）≠ upscale（高档，消费场所）≠ top-of-the-line（顶级）
**记忆**：high（高）+ end（一端）→ 处于高端的一端

### 38. **brand-new** — 崭新的，全新的
**核心**：**全新未用**的
**搭配**：a brand-new car 崭新的汽车 / brand-new ideas 全新的想法
**辨析**：⚠️ brand-new（全新的）≠ pristine（崭新完好的，书面）
**记忆**：brand（烙印）+ new → 刚打上新烙印的 → 崭新的

## 📌 词根小结

| 词根 | 含义 | 例词 |
|------|------|------|
| **soci-** | 社会 | feudal society, primitive society |
| **pre-** | 在前 | prescript, prevail |
| **-ive** | 形容词后缀 | primitive, immersive, distinctive |
| **-ity** | 名词后缀 | dexterity, mobility |
| **-ly** | 副词后缀 | tolerably, impartially |

## ⚠️ 形近词 / 近义词辨析（含场景偏好）

| 词对 | 区别（含使用场景偏好） |
|------|------|
| **infirm** vs **infant** | 形近：infirm = 体弱的（指人/论点，书面）；infant = 婴儿/初期的（指人或产业） |
| **frugal** vs **economical** vs **stingy** | frugal = 节俭（中性偏褒，指生活方式）；economical = 经济的（客观划算）；stingy = 吝啬（贬义，指抠门） |
| **supplementary** vs **complementary** | supplementary = 补充的（额外附加，如 supplementary reading）；complementary = 互补的（相互配合，如 complementary skills） |
| **dexterity** vs **agility** | dexterity = 手部/技巧性灵巧；agility = 身体/动作敏捷 |
| **allotment** vs **allocation** | allotment = 分配/份额（具体分给）；allocation = 拨款/分配（正式，资源统筹） |
| **marine** vs **maritime** | marine = 海洋的（生物/生态）；maritime = 海事的（航运/贸易/法律） |
| **troupe** vs **troop** | 形近：troupe = 剧团/表演团；troop = 军队/一群人（troops 部队） |
| **poetry** vs **poem** | poetry = 诗歌总称（不可数）；poem = 一首诗（可数） |

## 🎯 高频考点速记

| 考点 | 说明 |
|------|------|
| **be characterized by** | 以…为特征，六级写译高频被动结构；主动形式 characterize sth |
| **be referred to as** | 被称为（refer to ... as 的被动）；省略 as 则为"被提交/被提及" |
| **prompt 一词多义** | v. 促使（prompt sb to do）/ adj. 迅速的 / n. 提示符，阅读常考词性转换 |
| **prevail over** | 战胜、胜过；prevailing 意为"盛行的"（prevailing wind 盛行风） |
| **be incumbent on/upon sb** | 某人有责任做某事（正式表达，写译加分项） |
| **infant industry** | "新兴产业"（经济学名词），infant 作形容词"初期的" |
