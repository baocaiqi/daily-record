## 一、修饰与外观

### 1. **cosmetic** — 化妆用的，美容的；⭐️ 表面的，装点门面的
**核心**：⚠️ 拼写：**cosmetic**（原文 cometic 漏 s）；本义"**美容/化妆**的"，⭐️ 引申"**表面的、做样子的**"
**搭配**：cosmetic products 化妆品 / cosmetic surgery 整容手术 / a cosmetic measure 装点门面的举措
**辨析**：⚠️ cosmetic（化妆的/表面的）≠ cosmetology（美容学）≠ beautifying（美化的，一般）
**词根**：cosm- = order/adorn（秩序、装饰，希腊语 kosmos）+ -etic → 整理修饰；同根 cosmic 宇宙的, cosmonaut 宇航员
**例句**：The reforms were merely cosmetic. 这些改革不过是做做样子。

## 二、态度与作风

### 2. **meticulous** — 极仔细的，一丝不苟的
**核心**：**对细节极为讲究**（褒义，程度远超 careful）
**搭配**：meticulous attention to detail 对细节的一丝不苟 / meticulous planning 周密的计划 / be meticulous about 对…极为细致
**辨析**：⚠️ meticulous（细致，褒义）≠ careful（小心，通用）≠ fastidious（过分讲究/挑剔，偏贬）≠ fussy（爱挑剔，贬义）
**词根**：拉丁语 metus = fear（恐惧）→ 原义"因害怕出错而谨慎"→ 谨小慎微 → 一丝不苟
**例句**：She kept meticulous records of every experiment. 她对每次实验都做了详尽细致的记录。

## ⚠️ 形近词 / 近义词辨析（含场景偏好）

| 词对 | 区别（含使用场景偏好） |
|------|------|
| **cosmetic** vs **cosmetology** | cosmetic = 化妆用的/表面的（形容词常用）；cosmetology = 美容学（学科名词） |
| **meticulous** vs **careful** vs **fastidious** | meticulous = 一丝不苟（褒义，程度强）；careful = 小心（通用）；fastidious = 过分讲究（偏贬） |

## 🎯 高频考点速记

| 考点 | 说明 |
|------|------|
| **拼写修正** | cometic → **cosmetic**（漏 s，注意 cos- 开头） |
| **cosmetic 熟词僻义** | ⭐️ cosmetic changes/measures = "表面上的改动/装点门面的举措"，阅读贬义语境高频 |
| **meticulous about** | 固定搭配，be meticulous about sth 对某事务求细致 |
| **meticulous 语气** | 程度远强于 careful，常用于褒扬严谨的工作态度（写作可替换 careful） |
