# 📚 CET-6 单词本 (26)

> 排版：每条单词 2-4 行解析，按优先级排列：核心 → 搭配 → 辨析 → 词根/记忆
> 标注：`⚠️` = 易混点/重点 | `⭐️` = 六级熟词僻义（配例句）| **加粗** = 核心要点

## 一、变化与趋势

### 1. **escalate** — （使）升级，加剧；（价格）上涨
**核心**：⚠️ 动词（原释义"逐步上升的"为形容词形式 escalating）；事态**逐步恶化/升级**
**搭配**：escalate into 升级为 / escalate the conflict 使冲突升级 / prices escalate 物价上涨
**辨析**：⚠️ escalate（升级，程度加重）≠ increase（增加，中性）≠ intensify（加强，强度）
**词根**：e-（出）+ scal- = ladder（梯子）→ 沿梯子向上 → 升级；同根 escalator 自动扶梯, scale 刻度/规模

### 2. **recede** — 后退，退缩；（水）退去；（记忆）淡化
**核心**：**向后退/逐渐远去**
**搭配**：the floodwaters recede 洪水退去 / recede from view 渐渐从视野中消失 / memories recede 记忆淡去
**辨析**：⚠️ recede（后退/退去，自然发生）≠ retreat（撤退，主动行动）≠ withdraw（撤回，正式）
**词根**：re-（向后）+ ced- = go（走）→ 向后走；同根 proceed 前进, concede 让步, precede 先于

### 3. **reversal** — 逆转，反转；撤销
**核心**：**彻底的翻转**（局面/决定/趋势）
**搭配**：a reversal of fortune 命运的逆转 / a reversal of policy 政策的逆转 / a dramatic reversal 戏剧性反转
**辨析**：⚠️ reversal（逆转，名词）≠ reverse（反转，动词/形容词）≠ setback（挫折，暂时后退）
**词根**：re-（向后）+ vers- = turn（转）+ -al → 转回来；同根 reverse 反转, convert 转换, versatile 多才的

### 4. **deviate** — 偏离，背离（常指脱离常规）
**核心**：⚠️ 不及物，固定搭配 **deviate from** 偏离…
**搭配**：deviate from the plan 偏离计划 / deviate from the norm 背离常规 / deviate from the truth 偏离事实
**辨析**：⚠️ deviate（偏离，中性）≠ diverge（分岔，路线/观点分歧）≠ stray（走失，走偏）
**词根**：de-（离开）+ vi- = way（路）+ -ate → 离开道路；同根 deviate, viaduct 高架桥

### 5. **cascade** — 小瀑布；倾泻而下；层叠
**核心**：n. **小瀑布**；v. **倾泻/层层传递**（信息、效应）
**搭配**：a cascade of water 倾泻的水流 / a cascade of events 连锁事件 / cascade down 倾泻而下
**辨析**：⚠️ cascade（小瀑布/层层传递）≠ waterfall（瀑布，泛指）≠ torrent（急流，量大）
**词根**：casc- = fall（落下）+ -ade；同根 cataract 大瀑布/白内障

### 6. **sustainable** — 可持续的，能维持的
**核心**：能**长期维持**而不耗尽资源的（发展/模式/做法）
**搭配**：sustainable development 可持续发展 / sustainable growth 可持续增长 / environmentally sustainable 环保可持续的
**辨析**：⚠️ sustainable（可持续，侧重长期）≠ maintainable（可维持，侧重可行）≠ viable（可行的，商业）
**词根**：sus-（在下）+ tain- = hold（握住）+ -able → 能从下面撑住；同根 sustain 维持, contain 包含, retain 保留

## 二、群体与社会

### 7. **clannish** — 排外的，抱团的；宗派的
**核心**：⚠️ 抱团**排外**的（多含贬义）；（原释义"党派的"不够准确）
**搭配**：a clannish community 抱团的社群 / be clannish about 对…抱团排外
**辨析**：⚠️ clannish（抱团排外，贬义）≠ loyal（忠诚，褒义）≠ exclusive（排他的，中性/商业）
**词根**：clan（氏族，苏格兰高地部族）+ -nish；同根 clan 部族/家族

### 8. **league** — 联盟，同盟；结盟；联赛
**核心**：**为共同利益结成的团体**；⭐️ 习语 **in league with 与…勾结**
**搭配**：the League of Nations 国际联盟 / league together 结盟 / in league with 与…勾结 / football league 足球联赛
**辨析**：⚠️ league（联盟，可含贬义勾结）≠ alliance（同盟，正式/政治）≠ union（联合，组织性强）
**词根**：lig- = bind（捆绑）→ 绑在一起；同根 ligament 韧带, oblige 使有义务

### 9. **populous** — 人口稠密的，人口众多的
**核心**：⚠️ 形容**地区人口多**（不是"稠密"的泛义）；原释义易与 dense 混
**搭配**：the most populous city 人口最多的城市 / a populous nation 人口大国
**辨析**：⚠️ populous（人口多，形容地区）≠ populated（有人居住的）≠ crowded（拥挤的，形容空间）≠ dense（稠密的，形容密度）
**词根**：popul- = people（人民）+ -ous；同根 popular 流行的, population 人口, populate 居住于

### 10. **culprit** — 罪犯，肇事者；问题的根源
**核心**：**犯错/肇事**的人；⭐️ 引申"（问题的）罪魁祸首"
**搭配**：the main culprit 主要肇事者 / find the culprit 找出元凶 / the culprit behind 背后的元凶
**辨析**：⚠️ culprit（肇事者/元凶，可指事）≠ criminal（罪犯，法律意义）≠ offender（违法者，正式）
**词根**：culp- = fault/blame（过错，拉丁 culpa）；同根 culpable 有罪的, exculpate 开脱罪责

### 11. **honourable** — 正直的，高尚的；尊敬的（英式拼写）
**核心**：**品德高尚、值得尊敬**的；⚠️ 英式 **honourable** = 美式 honorable
**搭配**：an honourable man 正直的人 / honourable conduct 光明磊落的行为 / the Honourable Mr. 尊敬的…先生（英式头衔）
**辨析**：⚠️ honourable（正直/高尚，褒义）≠ honest（诚实的）≠ respectable（体面的，外表）
**词根**：honour（荣誉）+ -able；同根 honour 荣誉, honorary 荣誉的

## 三、语言与表达

### 12. **vowel** — 元音，元音字母
**核心**：a e i o u 五个**元音字母**及其发音
**搭配**：vowel sound 元音音素 / vowel letters 元音字母 / a long vowel 长元音
**辨析**：⚠️ vowel（元音）≠ consonant（辅音）—— 两者相对
**词根**：源自拉丁 vocalis（发声的）→ 声带振动发出的音；同根 vocal 嗓音的, voice 声音

### 13. **clause** — 从句；（法律）条款
**核心**：语法上**含主谓的从句**；法律/合同中**条款**
**搭配**：a relative clause 定语从句 / a contract clause 合同条款 / an escape clause 免责条款
**辨析**：⚠️ clause（从句，含主谓）≠ phrase（短语，不含主谓）≠ sentence（句子，完整）
**词根**：claus- = close（关闭）→ 收尾的完整单位；同根 close, conclusion 结论, include 包含

### 14. **keynote** — 主旨，基调；主题演讲
**核心**：⚠️ 原释义"住址"完全错误；指会议的**核心基调**；**keynote speech 主题演讲**
**搭配**：deliver the keynote 发表主题演讲 / a keynote address 主题演讲 / set the keynote 定下基调
**辨析**：⚠️ keynote（主旨/主题演讲）≠ key point（要点）≠ address（演讲，泛指）
**记忆**：key（关键）+ note（音符）→ 定调的关键音 → 主旨/基调

### 15. **correspondent** — 记者，通讯员；通信者
**核心**：⚠️ 拼写：**correspondent**（原文 correspondant 错误）；派驻某地的**通讯记者**
**搭配**：a war correspondent 战地记者 / a foreign correspondent 驻外记者 / our correspondent reports 本台记者报道
**辨析**：⚠️ correspondent（记者/通信者）≠ reporter（记者，通用）≠ journalist（新闻工作者，职业）
**词根**：cor-（共同）+ respond- = answer（回应）+ -ent → 相互通信的人；同根 correspond 通信/符合, response 回应

### 16. **nerdy** — 书呆子气的，学究式的
**核心**：**沉迷知识/技术、不通世故**的（常带调侃，非恶毒）
**搭配**：a nerdy kid 书呆子气的孩子 / nerdy hobbies 极客爱好 / look nerdy 一副书呆子样
**辨析**：⚠️ nerdy（书呆子气，调侃）≠ geeky（极客范，偏褒）≠ dorky（呆笨，贬义）
**词根**：nerd（书呆子）+ -y；同根 nerd 书呆子

### 17. **grumble** — 嘟囔，抱怨，发牢骚
**核心**：**低声不满地抱怨**（连续、含混）
**搭配**：grumble about the food 抱怨伙食 / grumble at sb 对某人发牢骚 / grumble that... 嘟囔说…
**辨析**：⚠️ grumble（低声抱怨，持续）≠ complain（抱怨，通用正式）≠ mutter（嘟囔，未必抱怨）
**记忆**：拟声词，模仿肚子"咕噜"或低声嘟囔的声音

## 四、模拟与态度

### 18. **mock** — 嘲笑，讥讽；模拟的；使挫败
**核心**：v. **嘲笑/模仿取笑**；adj. **模拟的**（非真实的）
**搭配**：mock at sb 嘲笑某人 / mock exams 模拟考试 / a mock trial 模拟审判 / mock sb's accent 模仿取笑口音
**辨析**：⚠️ mock（嘲笑/模拟，含戏弄）≠ imitate（模仿，中性）≠ laugh at（嘲笑，动词短语）
**词根**：源自拉丁 mocquer（嘲弄）；同根 mockery 嘲弄, mockingbird 模仿鸟（嘲鸫）

### 19. **a mock interview** — 模拟面试
**核心**：**为练习而进行的**模拟面试（非正式面试）
**搭配**：conduct a mock interview 进行模拟面试 / a mock interview session 模拟面试环节
**记忆**：mock（模拟的）+ interview（面试）→ 模拟面试

### 20. **tentative** — 暂时的，试探性的，初步的
**核心**：**尚未最终确定**的（计划/结论/安排）
**搭配**：a tentative plan 暂定计划 / tentative conclusion 初步结论 / a tentative agreement 初步协议
**辨析**：⚠️ tentative（暂时/试探性）≠ temporary（临时的，时间短暂）≠ provisional（暂定的，正式）
**词根**：tent- = try（尝试）+ -ative → 尝试性的；同根 tempt 诱惑, attempt 尝试

### 21. **charged** — 带电的；气氛紧张的；充满感情的
**核心**：⭐️ 熟词僻义：**气氛紧张/情绪激昂**的（非仅"带电"）
**搭配**：a charged atmosphere 紧张的气氛 / emotionally charged 情绪激动的 / a charged debate 火药味十足的辩论
**辨析**：⚠️ charged（紧张/激昂，形容气氛）≠ tense（紧张的，形容局势或人）≠ electric（带电的，本义）
**词根**：charge（装载/充电）+ -ed → 已装满情绪/电荷；同根 charge 收费/指控/充电

## 五、逻辑与前提

### 22. **premise** — 前提，假设
**核心**：⚠️ 拼写：**premise**（原文 permise 错误）；推理的**出发点/前提**
**搭配**：on the premise that... 以…为前提 / a false premise 错误的前提 / the basic premise 基本前提
**辨析**：⚠️ premise（前提，逻辑）≠ precondition（先决条件）≠ hypothesis（假设，待验证）
**词根**：pre-（在前）+ mis- = send（送）+ -e → 预先送出 → 前提；同根 mission 使命, submit 提交

### 23. **business premises** — 营业场所，办公场所
**核心**：⚠️ 拼写：**premises**（原文 permise 错误）；⚠️ 作"场所"义时**必用复数 premises**
**搭配**：business premises 营业场所 / on the premises 在场所内 / licensed premises 持牌经营场所
**辨析**：⚠️ premises（场所/房产，复数）≠ premise（前提，单数）—— 同形不同义
**词根**：pre-（在前）+ mis- = send → 前述的（房产）；同根 premise 前提

### 24. **pertain** — 关于，与…有关；适合
**核心**：⚠️ 不及物，固定搭配 **pertain to** 与…有关
**搭配**：pertain to the matter 与此事有关 / documents pertaining to the case 与案件有关的文件
**辨析**：⚠️ pertain to（与…有关，正式书面）≠ relate to（相关，通用）≠ concern（涉及，通用）
**词根**：per-（贯穿）+ tain- = hold（握）→ 一直连着 → 相关；同根 contain 包含, maintain 维持

### 25. **pertinent** — 相关的，切题的
**核心**：**与主题直接相关**的（正式，强调贴题）
**搭配**：pertinent information 相关信息 / pertinent to the discussion 与讨论相关 / pertinent questions 切题的问题
**辨析**：⚠️ pertinent（切题的，正式）≠ relevant（相关的，通用）≠ applicable（适用的）
**词根**：per-（贯穿）+ tin- = hold（握）+ -ent → 握得住主题；同根 pertain 关于

### 26. **impertinent** — 不切题的；粗鲁的，无礼的
**核心**：⚠️ 两义：**不相关**的（本义）／**唐突无礼**的（引申，更常用）
**搭配**：an impertinent question 不切题/唐突的问题 / impertinent remarks 无礼的言论 / be impertinent to sb 对某人无礼
**辨析**：⚠️ impertinent（不切题/无礼）≠ irrelevant（不相关的，无"无礼"义）≠ impudent（厚颜无耻，贬义更重）
**词根**：im-（不）+ pertinent（切题的）→ 不切题的，再引申无礼

### 27. **comprise** — 包括，由…组成
**核心**：⚠️ **整体包含部分**（不用被动，不用 of）；主动用法 comprise = consist of
**搭配**：The team comprises five members. 该队由五人组成 / be comprised of 由…组成（⚠️ 用被动须加 -d）
**辨析**：⚠️ comprise（整体含部分，无被动）= consist of = be composed of；≠ compose（be composed of，须被动）
**词根**：com-（一起）+ pris- = take（拿）+ -e → 一起拿住；同根 prison 监狱, enterprise 事业

### 28. **be comprised of** — 由…组成
**核心**：⚠️ 拼写：**be comprised of**（原文 comprise 漏 -d 且缺 be）；⚠️ 是 comprise 的被动式
**搭配**：The committee is comprised of ten experts. 委员会由十名专家组成
**辨析**：⚠️ be comprised of（被动，需 -d）≠ comprise（主动，不加 of）≠ be composed of（同义）
**记忆**：comprise 主动 + 被动式 be comprised of 表示"由…构成"

## 六、自然与生物

### 29. **embryo** — 胚胎；萌芽期
**核心**：n. **胚胎**（生物）；引申"**初期/萌芽**"
**搭配**：a human embryo 人类胚胎 / in embryo 在萌芽阶段 / embryo development 胚胎发育
**辨析**：⚠️ embryo（胚胎，动物/植物早期）≠ fetus（胎儿，后期）≠ germ（胚芽/细菌）
**词根**：em-（在内）+ bry- = swell（膨胀）+ -o → 内部生长；同根 embryonic 胚胎的

### 30. **embryonic** — 胚胎的；初期的，萌芽的
**核心**：**处于萌芽阶段**的（发展初期）
**搭配**：embryonic stage 萌芽阶段 / an embryonic industry 萌芽产业 / embryonic cells 胚胎细胞
**辨析**：⚠️ embryonic（萌芽/初期的）≠ embryo（胚胎，名词）≠ infant（初期的，可指产业）
**词根**：embryo（胚胎）+ -nic；同根 embryo 胚胎

### 31. **germ** — 细菌，病菌；胚芽；萌芽
**核心**：**致病微生物**；⭐️ 引申"**萌芽/开端**"（the germ of an idea）
**搭配**：the germ of an idea 想法的萌芽 / germ theory 细菌学说 / wheat germ 麦芽
**辨析**：⚠️ germ（细菌，日常）≠ bacterium（细菌，学术单数）≠ virus（病毒）≠ microbe（微生物）
**词根**：germ- = sprout（芽，拉丁 germen）；同根 germinate 发芽, germination 萌发

### 32. **specimen** — 样本，标本；（化验）试样
**核心**：⚠️ 拼写：**specimen**（原文 speciman 错误）；供**检验/研究的样本**
**搭配**：a blood specimen 血液样本 / a specimen of rock 岩石标本 / collect specimens 采集标本
**辨析**：⚠️ specimen（样本/标本，科研）≠ sample（样品，通用/抽样）≠ example（例子）
**词根**：spec- = look（看）+ -men → 供查看之物；同根 inspect 检查, aspect 方面, speculate 推测

### 33. **whale** — 鲸鱼；⭐️ 大力拍打，猛击
**核心**：n. **鲸**；⭐️ 动词"**猛击/痛打**"；习语 **a whale of a 极好的/巨大的**
**搭配**：a blue whale 蓝鲸 / whale watching 观鲸 / a whale of a time 玩得极开心
**辨析**：⚠️ whale（鲸，哺乳动物）≠ shark（鲨鱼，鱼）≠ dolphin（海豚）
**记忆**：习语 a whale of a... = 了不得的…（a whale of a good time）

### 34. **toxin** — 毒素
**核心**：⚠️ 名词（原释义"有毒素的"为形容词 toxic）；生物产生的**毒素**
**搭配**：release toxins 释放毒素 / a bacterial toxin 细菌毒素 / toxin levels 毒素含量
**辨析**：⚠️ toxin（毒素，名词）≠ toxic（有毒的，形容词）≠ venom（毒液，动物分泌）
**词根**：tox- = poison（毒）+ -in（表物质）；同根 toxic 有毒的, detox 排毒

### 35. **impurity** — 杂质；不纯，不洁
**核心**：⚠️ 名词（原释义"不纯的"为形容词 impure）；混入的**杂质**
**搭配**：remove impurities 去除杂质 / chemical impurities 化学杂质 / a trace of impurity 微量杂质
**辨析**：⚠️ impurity（杂质，名词）≠ impure（不纯的，形容词）≠ pollution（污染）
**词根**：im-（不）+ pur- = pure（纯）+ -ity；同根 pure 纯的, purify 净化

### 36. **terrain** — 地形，地势；领域
**核心**：一片土地的**地形地貌**；引申"（竞争的）领域"
**搭配**：rough terrain 崎岖地形 / mountainous terrain 山地地形 / familiar terrain 熟悉的领域
**辨析**：⚠️ terrain（地形，地表特征）≠ territory（领土，政治范围）≠ landscape（景观，视觉）
**词根**：terr- = earth（土地）+ -ain；同根 territory 领土, terrace 梯田/露台

### 37. **fairy** — 小精灵，仙子；仙女般的
**核心**：民间传说中的**仙子/精灵**
**搭配**：fairy tale 童话 / a fairy godmother 仙女教母 / fairy lights 装饰小彩灯
**辨析**：⚠️ fairy（仙子，西方传说）≠ elf（精灵，北欧传说）≠ angel（天使，宗教）
**词根**：源自拉丁 fata（命运女神）→ fate 命运；同根 fate 命运, fable 寓言

### 38. **hedge** — 树篱；防范手段；避免正面回答
**核心**：n. **树篱**/防范手段（**a hedge against** 防范…的对策）；v. 设篱/规避/闪烁其词
**搭配**：a hedge against inflation 防通胀手段 / hedge fund 对冲基金 / hedge one's bets 两面下注
**辨析**：⚠️ hedge（防范/对冲，金融+日常）≠ shield（保护屏障）≠ fence（栅栏，实物）
**词根**：古英语 hecg（篱笆）；同根 hedgehog 刺猬

## 七、状态与困境

### 39. **reserve** — 保留，预订；储备（物）；保护区
**核心**：⚠️ 动词/名词（原释义"存储"偏 storage）；**留出备用**或**预订**
**搭配**：reserve a table 预订餐桌 / reserve the right 保留权利 / foreign reserves 外汇储备 / nature reserve 自然保护区
**辨析**：⚠️ reserve（保留/预订/储备）≠ store（储存，侧重存放）≠ book（预订，通用）
**词根**：re-（回）+ serv- = keep（保存）→ 留着；同根 preserve 保存, conserve 保护

### 40. **turmoil** — 混乱，动荡，骚动
**核心**：**剧烈的混乱/动荡**（局势或内心）
**搭配**：in turmoil 处于动荡中 / political turmoil 政治动荡 / emotional turmoil 内心煎熬
**辨析**：⚠️ turmoil（动荡，局势/内心）≠ chaos（彻底混乱）≠ unrest（不安，社会/政治）
**记忆**：起源不明，常与 in turmoil 连用表"一团乱"

### 41. **refuge** — 避难所，庇护所；庇护
**核心**：⚠️ **避难处/庇护**（不是"难民"！）；⭐️ 短语 **take refuge in 躲进…**
**搭配**：take refuge in 躲进/求助于 / a wildlife refuge 野生动物保护区 / seek refuge 寻求庇护
**辨析**：⚠️ refuge（避难所，地方/行为）≠ refugee（难民，人）—— 一字之差！
**词根**：re-（回）+ fug- = flee（逃）+ -e → 逃回去的地方；同根 refugee 难民, fugitive 逃亡者

### 42. **refugee** — 难民
**核心**：⚠️ 原文误写作 refuge；因战乱/迫害**逃离家园的人**
**搭配**：a refugee camp 难民营 / political refugees 政治难民 / refugee crisis 难民危机
**辨析**：⚠️ refugee（难民，人）≠ refuge（避难所，地方）—— 形近必辨
**词根**：refuge（避难）+ -ee（表"被…的人"）；同根 employee 雇员, trainee 受训者

### 43. **ordeal** — 折磨，严峻考验，痛苦经历
**核心**：**漫长而痛苦的考验**
**搭配**：go through an ordeal 经历磨难 / a terrifying ordeal 可怕的折磨 / survive the ordeal 挺过磨难
**辨析**：⚠️ ordeal（痛苦的考验，经历）≠ trial（审判/考验，中性）≠ misery（痛苦，状态）
**词根**：古英语 ordal（审判）→ 古代"神裁法"的残酷考验 → 折磨

### 44. **backlog** — 积压的工作，待办事项；积压订单
**核心**：⚠️ 拼写/释义：**backlog**（原文"代办事项"应作"待办"）；**积压未完成的事**
**搭配**：a backlog of work 积压的工作 / clear the backlog 清理积压 / a backlog of orders 积压订单
**辨析**：⚠️ backlog（积压，含"该做未完"）≠ to-do list（待办清单，计划性）≠ arrears（欠款，欠账）
**词根**：back（后面）+ log（原指壁炉中垫底的大木柴）→ 压着的大事 → 积压；同根 log 原木/记录

### 45. **mighty** — 强大的，巨大的；⭐️ 极其，非常
**核心**：adj. **强大/巨大**的；⭐️ adv.（口语）**非常**
**搭配**：a mighty empire 强大的帝国 / mighty efforts 巨大的努力 / mighty fine 好极了（口语）
**辨析**：⚠️ mighty（强大/巨大，可作副词）≠ powerful（强大的，通用）≠ strong（强壮的）
**词根**：might（力量）+ -y；同根 might 力量/可能, almighty 全能的

### 46. **metaphysical** — 形而上学的，玄学的
**核心**：**超越物质经验、探讨本体**的（哲学）；引申"抽象难懂的"
**搭配**：metaphysical questions 形而上学问题 / a metaphysical poet 玄学派诗人 / metaphysical speculation 玄思
**辨析**：⚠️ metaphysical（形而上的，哲学）≠ physical（物质的，物理的）—— meta- 前缀相对
**词根**：meta-（超越）+ phys- = nature（自然）+ -ical → 在自然之上；同根 physics 物理, physician 内科医生

### 47. **scarcely** — 几乎不；刚刚，勉强
**核心**：**几乎不**（否定副词）⭐️ 置于句首**须倒装**：Scarcely had he left...
**搭配**：scarcely any 几乎没有 / scarcely ever 极少 / Scarcely had...when... 刚…就…
**辨析**：⚠️ scarcely（几乎不）≈ hardly（几乎不）≠ barely（仅仅，勉强）≠ rarely（很少，频率）
**词根**：scarce（稀少的）+ -ly；同根 scarce 稀缺的, scarcity 稀缺

## 八、动作与器物

### 48. **scoop** — 舀，铲；⭐️ 抢先报道；独家新闻；铲子
**核心**：v. **舀/铲**；⭐️ **抢先获得/独家报道**；n. 勺铲、独家新闻
**搭配**：scoop up 舀起 / scoop the story 抢先报道 / a front-page scoop 头版独家
**辨析**：⚠️ scoop（勺/独家新闻）≠ spoon（调羹，餐具）≠ shovel（铲子，更大）
**记忆**：scoop 本义"舀取"→ 媒体抢先"捞"到新闻 → 独家新闻

### 49. **lamp** — 灯，台灯
**核心**：**灯具**（台灯/路灯等照明器具）
**搭配**：turn on the lamp 开灯 / a desk lamp 台灯 / a street lamp 路灯
**辨析**：⚠️ lamp（灯，灯具）≠ light（光/灯，可指光源）≠ lamp 一般指带罩的固定灯
**词根**：源自希腊 lampas（火炬）；同根 lantern 灯笼

### 50. **persevere** — 坚持不懈，锲而不舍
**核心**：⚠️ 拼写：**persevere**（原文 perservere 错误）；不及物，坚持做下去
**搭配**：persevere with/in sth 对…坚持不懈 / persevere against difficulties 顶着困难坚持
**辨析**：⚠️ persevere（坚持，褒义，有韧性）≠ persist（坚持，中性；persist in 固执）≠ endure（忍耐）
**词根**：per-（贯穿）+ sever- = strict（严格）→ 一直严格对待自己 → 坚持；同根 severe 严厉的

### 51. **persevere in sth** — 对…坚持不懈
**核心**：⚠️ 拼写：**persevere in sth**（原文 persecere 错误）；固定搭配 persevere in/with
**搭配**：persevere in one's efforts 坚持不懈地努力 / persevere in the study 坚持钻研
**辨析**：⚠️ persevere in（坚持，褒义）≠ persist in（执意，常含贬义"固执"，如 persist in error）
**记忆**：persevere in/with + 名词/动名词 → 在…上坚持不懈

### 52. **mansion** — 大厦，宅邸，豪宅
**核心**：**宏伟的大宅**（尤指富人的宅邸）
**搭配**：a luxury mansion 豪华宅邸 / a country mansion 乡间大宅 / a mansion block 公寓大楼（英式）
**辨析**：⚠️ mansion（宅邸，私人/宏大）≠ villa（别墅，度假）≠ building（建筑，通用）≠ skyscraper（摩天楼）
**词根**：man- = stay（停留，拉丁 manere）→ 居住之所；同根 remain 保持, permanent 永久的

### 53. **a big mansion** — 一栋大豪宅
**核心**：**一栋大宅邸**（口语化说法）
**搭配**：live in a big mansion 住在大宅里 / own a big mansion 拥有一栋豪宅
**记忆**：big（大的）+ mansion（宅邸）→ 一栋大豪宅

| 词根 | 含义 | 例词 |
|------|------|------|

## ⚠️ 形近词 / 近义词辨析（含场景偏好）

| 词对 | 区别（含使用场景偏好） |
|------|------|
| **refuge** vs **refugee** | refuge = 避难所/庇护（地方、行为）；refugee = 难民（人）⚠️ 一字之差 |
| **premise** vs **premises** | premise = 前提（逻辑，单数）；premises = 场所/房产（复数）⚠️ 同形不同义 |
| **comprise** vs **be comprised of** vs **compose** | comprise = 整体含部分（主动，不加 of）；be comprised of = 由…组成（被动须 -d）；compose 用 be composed of |
| **pertinent** vs **pertain** | pertinent = 切题的（形容词）；pertain = 与…有关（动词，接 to） |
| **refuge** vs **shelter** | refuge = 躲避危险的地方（正式）；shelter = 庇护所/遮盖（通用，也指遮蔽物） |
| **escalate** vs **increase** vs **intensify** | escalate = 升级/恶化（局势、冲突）；increase = 增加（中性）；intensify = 加强（强度） |
| **recede** vs **retreat** vs **withdraw** | recede = 后退/退去（自然、被动的渐退）；retreat = 撤退（主动）；withdraw = 撤回（正式） |
| **tentative** vs **temporary** vs **provisional** | tentative = 试探性/暂定的；temporary = 临时的（时间短）；provisional = 暂定的（正式，待批准） |
| **populous** vs **populated** vs **dense** | populous = 人口多的（形容地区）；populated = 有人居住的；dense = 稠密的（密度） |
| **culprit** vs **criminal** vs **offender** | culprit = 肇事者/元凶（可指事）；criminal = 罪犯（法律）；offender = 违法者（正式） |
| **specimen** vs **sample** | specimen = 标本/样本（科研、检验）；sample = 样品（通用、抽样） |
| **toxin** vs **toxic** vs **venom** | toxin = 毒素（名词）；toxic = 有毒的（形容词）；venom = 毒液（动物分泌） |
| **impurity** vs **impure** | impurity = 杂质（名词）；impure = 不纯的（形容词）⚠️ 词性易混 |
| **terrain** vs **territory** vs **landscape** | terrain = 地形（地表特征）；territory = 领土（政治）；landscape = 景观（视觉） |
| **germ** vs **bacterium** vs **virus** | germ = 细菌（日常）；bacterium = 细菌（学术单数）；virus = 病毒 |
| **persevere** vs **persist** | persevere in = 坚持（褒义，有韧性）；persist in = 执意（常含贬义，如 persist in error） |
| **scarcely** vs **hardly** vs **barely** | scarcely = 几乎不（≈hardly，可倒装）；hardly = 几乎不；barely = 仅仅/勉强 |
| **nerdy** vs **geeky** vs **dorky** | nerdy = 书呆子气（调侃）；geeky = 极客范（偏褒）；dorky = 呆笨（贬义） |
| **mock** vs **imitate** | mock = 嘲笑/模拟（含戏弄）；imitate = 模仿（中性） |
| **hedge** vs **shield** vs **fence** | hedge = 防范/对冲（金融+日常）；shield = 保护屏障；fence = 栅栏（实物） |
| **mansion** vs **villa** | mansion = 大宅邸（私人、宏伟）；villa = 别墅（度假、带花园） |

## 🎯 高频考点速记

| 考点 | 说明 |
|------|------|
| **拼写修正汇总** | correspondant → **correspondent**；perservere/persecere → **persevere**；speciman → **specimen**；permise → **premise**；comprise of → **be comprised of** |
| **释义修正汇总** | keynote"住址"→ **主旨/基调**；refuge"难民"→ **refugee**；backlog"代办"→ **待办/积压**；toxin/impurity 原标形容词 → 实为**名词**；escalate 原标形容词 → 实为**动词** |
| **deviate from** | 固定接 from（偏离），勿用 to/in |
| **pertain to** | 固定接 to（与…有关），不及物 |
| **comprise 用法** | 主动 comprise 不加 of；被动须 be comprised of |
| **premises 复数义** | 作"场所/房产"时常以复数 premises 出现（on the premises） |
| **take refuge in** | "躲进…/求助于…"，阅读高频 |
| **scarcely 倒装** | 置于句首须部分倒装：Scarcely had he left when... 刚…就… |
| **in league with** | "与…勾结"（含贬义），勿理解为"与…结盟（褒）" |
| **a whale of a** | "极好的/巨大的"，口语习语 |
| **hedge against** | "防范…"，金融语境 hedge fund 对冲基金 |
| **charged 熟词僻义** | charged atmosphere = 紧张/激昂的气氛 |
| **be composed of / consist of / comprise** | 三者均表"由…组成"，被动形式各有讲究 |
