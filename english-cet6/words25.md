# 📚 CET-6 单词本 (25)

> 排版：每条单词 2-4 行解析，按优先级排列：核心 → 搭配 → 辨析 → 词根/记忆
> 标注：`⚠️` = 易混点/重点 | **加粗** = 核心要点

## 一、性格与情绪

### 1. **self-assured** — 自信的，胸有成竹的
**核心**：对自己能力有**充分信心**（褒义）
**搭配**：a self-assured young man 自信的年轻人 / appear self-assured 显得自信 / speak in a self-assured tone 语气自信
**辨析**：⚠️ self-assured（自信，褒义，靠实力）≠ self-confident（自信，中性）≠ arrogant（傲慢，贬义）≠ conceited（自负，贬义）
**词根**：self-（自我）+ assure（使确信）+ -ed → 自己确信自己；同根 assure 保证, assurance 信心/保险

### 2. **grounded** — 脚踏实地的，务实的；有根据的
**核心**：**踏实、不浮躁**；也指（论点）**有依据**
**搭配**：a grounded person 务实的人 / be well-grounded in 在…方面根基扎实 / be grounded in reality 立足于现实
**辨析**：⚠️ grounded（务实/有根据）≠ realistic（现实的）≠ practical（实用的）
**词根**：ground（地面/理由）+ -ed → 站在地面上 → 脚踏实地；同根 ground 基础

### 3. **heated** — 激烈的，激动的，动怒的
**核心**：⚠️ **情绪升温**的（多修饰争论/气氛），非"加热的"
**搭配**：a heated debate 激烈的辩论 / a heated argument 激烈争吵 / get heated 变得激动
**辨析**：⚠️ heated（激烈的，修饰讨论/气氛）≠ hot（热的，本义）≠ angry（生气的，修饰人）
**词根**：heat（热）+ -ed → 加热了的 → 情绪升温；同根 heat 热度

### 4. **frantically** — 疯狂地，拼命地；手忙脚乱地
**核心**：副词，因**焦虑或紧急**而拼命地（原形 **frantic**）
**搭配**：search frantically for 拼命寻找 / work frantically 疯狂工作 / frantically try to 拼命试图
**辨析**：⚠️ frantic（疯狂的，形容词）≠ frenetic（狂热繁忙的，形容活动）≠ crazy（疯狂的，口语）
**词根**：fren- = mind（心智）→ 源自"精神错乱"；同根 frenzy 狂乱

## 二、特征与程度

### 5. **formidable** — 强大的，令人敬畏的；艰巨的
**核心**：**令人望而生畏**的（对手/任务）—— 比 difficult 语气强得多
**搭配**：a formidable opponent 强大的对手 / a formidable task 艰巨的任务 / formidable challenges 严峻挑战
**辨析**：⚠️ formidable（令人生畏，褒/中性）≠ difficult（困难的，通用）≠ intimidating（吓人的，贬）
**词根**：formid- = fear（恐惧）+ -able → 令人害怕的；同根 formidably 强大地

### 6. **predominantly** — 主要地，大多；占主导地位地
**核心**：副词，在**数量/程度上占优势**（原形 **predominant**）
**搭配**：predominantly male 以男性为主 / predominantly rural 以农村为主 / consist predominantly of 主要由…构成
**辨析**：⚠️ predominantly（占主导地，正式）≠ mostly（大多，口语）≠ mainly（主要，通用）
**词根**：pre-（在前）+ domin- = rule（统治）→ 占统治地位；同根 dominate 支配, dominant 占主导的, predominant 主要的

### 7. **sensational** — 轰动的，耸人听闻的；极好的
**核心**：**引发轰动**的（新闻/事件）；口语也指"**极棒的**"
**搭配**：a sensational story 耸人听闻的报道 / sensational news 轰动的消息 / a sensational victory 惊人的胜利
**辨析**：⚠️ 形近三胞胎：sensational（轰动的）≠ sensitive（敏感的）≠ sensible（明智的）
**词根**：sens- = feel（感觉）+ -ation + -al → 引发强烈感觉的；同根 sensation 感觉/轰动, sense 感觉

## 三、改变与增强

### 8. **bolster** — 增强，支持，改善
**核心**：**提振/支撑**（信心、经济、论点）；本义"长枕"
**搭配**：bolster confidence 提振信心 / bolster the economy 支撑经济 / bolster one's argument 支持论点
**辨析**：⚠️ bolster（提振/支持，可指信心或论点）≠ boost（提升，侧重增长幅度）≠ reinforce（加强，侧重结构/观念）
**记忆**：bolster 本义"垫子"→ 垫高、支撑 → 增强

### 9. **conversion** — 转化，转换，改变
**核心**：**由一种形式变为另一种**（性质/用途/信仰）
**搭配**：the conversion of A into B 把 A 转化为 B / currency conversion 货币兑换 / conversion rate 转化率
**辨析**：⚠️ conversion（转换，侧重形式/用途改变）≠ transformation（转变，更彻底）≠ change（改变，通用）
**词根**：con-（完全）+ vers- = turn（转）+ -ion → 完全转变；同根 convert 转换, reverse 反转, versatile 多才的

### 10. **compose** — 撰写，创作；组成；使平静
**核心**：**创作**（音乐/诗歌/文章）；⚠️ 被动 **be composed of = 由…组成**
**搭配**：compose a poem 作诗 / compose an email 写邮件 / be composed of 由…组成 / compose oneself 镇定下来
**辨析**：⚠️ compose（创作/构成，be composed of）≠ comprise（包含，整体含部分，不用被动）≠ consist of（由…组成，无被动）
**词根**：com-（一起）+ pos- = put（放）→ 放在一起 → 组成/创作；同根 composition 作文/构成, composite 合成的

### 11. **renovation** — 翻新，整修，翻修
**核心**：⚠️ 拼写：**renovation**（原文 renonvation 错误）；**整修旧建筑**使其焕新
**搭配**：the renovation of the old house 旧房翻新 / under renovation 正在整修 / renovation work 翻修工程
**辨析**：⚠️ renovation（翻新改造）≠ restoration（修复，复原原貌）≠ decoration（装修装饰）
**词根**：re-（再）+ nov- = new（新）+ -ation → 使再新；同根 novel 新奇的, innovate 创新

### 12. **defrost** — 解冻，除霜
**核心**：使（食物）**解冻**；给（冰箱/车窗）**除霜**
**搭配**：defrost the chicken 解冻鸡肉 / defrost the fridge 给冰箱除霜 / defrost the windshield 给挡风玻璃除霜
**辨析**：⚠️ defrost（除霜/解冻，人为）≠ thaw（解冻，天然融化）≠ melt（融化，变成液体）
**词根**：de-（去除）+ frost（霜）→ 去霜；同根 frost 霜, frozen 冰冻的

## 四、品质与适用

### 13. **versatile** — 多才多艺的；多功能的，通用的
**核心**：**能适应多种用途/角色**的（人/工具）
**搭配**：a versatile actor 多才多艺的演员 / a versatile tool 多用途工具 / versatile skills 多方面技能
**辨析**：⚠️ versatile（多才/多用途）≠ capable（有能力的）≠ flexible（灵活的，侧重可变通）
**词根**：vers- = turn（转）+ -atile → 能转向多处的；同根 convert 转换, reverse 反转, version 版本

### 14. **indigenous** — 本土的，土生土长的；原住民的
**核心**：某地**原产/原住**的；⚠️ 固定搭配 **indigenous to** 原产于…
**搭配**：indigenous people 原住民 / indigenous species 本地物种 / be indigenous to 原产于…
**辨析**：⚠️ indigenous（原产/原住民，正式）≠ native（本地的，中性）≠ local（当地的，泛指）≠ endemic（某地特有的，疾病/物种）
**词根**：indi-（在内）+ gen- = birth（出生）+ -ous → 生于其中；同根 generate 产生, gene 基因

### 15. **therapeutic** — 治疗的，有疗效的；使人放松的
**核心**：有助**治疗或放松身心**的
**搭配**：therapeutic effects 疗效 / a therapeutic massage 理疗按摩 / therapeutic value 治疗价值
**辨析**：⚠️ therapeutic（疗愈的/放松的）≠ medicinal（药用的，指药物）≠ medical（医学的，泛指）
**词根**：therap- = heal（治疗）+ -eutic；同根 therapy 治疗, therapist 治疗师

### 16. **perishable** — 易腐烂的，易变质的
**核心**：**易腐坏**的（食品）；⚠️ 名词复数 **perishables = 生鲜**
**搭配**：perishable goods 易腐货物 / perishable food 易变质食品 / perishables 生鲜食品
**辨析**：⚠️ perishable（易腐烂，指食品）≠ fragile（易碎的，指物品）≠ vulnerable（易受伤害的，指人/系统）
**词根**：per-（彻底）+ ish- = go（走）→ 彻底消亡 + -able；同根 perish 死亡/毁灭

## 五、礼节与货币

### 17. **courtesy** — 礼貌，谦恭；好意，恩惠
**核心**：**彬彬有礼**的行为；⭐️ 短语 **by courtesy of = 承蒙…好意/由…提供**
**搭配**：show courtesy to 对…有礼貌 / a courtesy call 礼节性拜访 / by courtesy of 承蒙…提供 / common courtesy 基本礼节
**辨析**：⚠️ courtesy（礼貌，可指行为）≠ politeness（礼貌，不可数）≠ manners（举止，复数）
**词根**：court（宫廷）+ -esy → 宫廷礼仪；同根 courteous 有礼貌的

### 18. **penny** — 便士；一小笔钱
**核心**：英国最小货币单位；⭐️ 习语 **not a penny / cost a pretty penny**
**搭配**：not a penny 一分钱也没有 / cost a pretty penny 花一大笔钱 / penny-pinching 吝啬的
**辨析**：⚠️ penny（便士，英）≠ cent（美分，美）—— 别与美币混用
**词根**：古英语 penig；同根 penniless 身无分文的

### 19. **nickel** — 镍；五分硬币（美/加）
**核心**：⚠️ 拼写：**nickel**（原文 nickle 错误）；金属"镍"；美国/加拿大**五分硬币**
**搭配**：a nickel 一枚五分硬币 / nickel plating 镀镍 / nickel-and-dime 微不足道的；斤斤计较地省钱
**辨析**：⚠️ 美币体系：penny(1¢) < nickel(5¢) < dime(10¢) < quarter(25¢)
**词根**：源自德语 Kupfernickel（假铜）→ 镍矿常被误认成铜矿

## ⚠️ 形近词 / 近义词辨析（含场景偏好）

| 词对 | 区别（含使用场景偏好） |
|------|------|
| **self-assured** vs **self-confident** vs **arrogant** | self-assured = 自信（褒义，靠实力）；self-confident = 自信（中性）；arrogant = 傲慢（贬义） |
| **sensational** vs **sensitive** vs **sensible** | 形近：sensational = 轰动的/耸人听闻；sensitive = 敏感的；sensible = 明智的 |
| **formidable** vs **difficult** | formidable = 令人生畏的（任务/对手，语气强）；difficult = 困难的（通用） |
| **bolster** vs **boost** vs **reinforce** | bolster = 提振/支持（信心、论点）；boost = 提升（增长幅度）；reinforce = 加强（结构、观念） |
| **conversion** vs **transformation** | conversion = 转换（形式/用途/信仰）；transformation = 彻底转变 |
| **compose** vs **comprise** vs **consist of** | compose = 创作/组成（be composed of）；comprise = 包含（整体含部分，不用被动）；consist of = 由…组成（无被动） |
| **renovation** vs **restoration** | renovation = 翻新改造；restoration = 修复（复原原貌） |
| **defrost** vs **thaw** vs **melt** | defrost = 除霜/解冻（人为）；thaw = 解冻（天然）；melt = 融化（变液体） |
| **indigenous** vs **native** vs **endemic** | indigenous = 原产/原住民（正式）；native = 本地的（中性）；endemic = 某地特有的（疾病/物种） |
| **therapeutic** vs **medicinal** vs **medical** | therapeutic = 疗愈的/放松的；medicinal = 药用的（指药物）；medical = 医学的（泛指） |
| **perishable** vs **fragile** vs **vulnerable** | perishable = 易腐烂（食品）；fragile = 易碎（物品）；vulnerable = 易受伤害（人/系统） |
| **frantic** vs **frenetic** | frantic = 因焦虑手忙脚乱；frenetic = 狂热繁忙的（形容活动） |
| **predominantly** vs **mostly** vs **mainly** | predominantly = 占主导地（正式）；mostly = 大多（口语）；mainly = 主要（通用） |
| **grounded** vs **realistic** vs **practical** | grounded = 务实/有根据；realistic = 现实的；practical = 实用的 |

## 🎯 高频考点速记

| 考点 | 说明 |
|------|------|
| **拼写修正汇总** | renonvation → renovation（漏 n）；nickle → nickel（应为 -kel） |
| **be composed of** | 由…组成（compose 的被动）；与 comprise / consist of 用法区分 |
| **by courtesy of** | 承蒙…提供/由…惠允 —— 图片、资料出处常用，阅读高频 |
| **indigenous to** | 原产于…（固定接 to，不接 in） |
| **perishable 名词化** | perishables = 生鲜食品（商务/物流阅读） |
| **cost a pretty penny** | "花一大笔钱"（习语）；not a penny 一分钱也没有 |
| **nickel-and-dime** | adj. 微不足道的；v. 斤斤计较地省钱（美式习语） |
| **heated debate** | "激烈的辩论"（不是"加热的"）—— heated 形容词义 |
| **defrost 双语境** | 食物解冻 / 车窗与冰箱除霜 —— 一词两场景 |
| **predominantly 位置** | 副词修饰形容词/动词，常置于被修饰词前 |
| **formidable 程度** | 强调"令人望而生畏"，非普通"困难"；a formidable task 艰巨任务 |
