## 📌 词根小结

| 词根 | 含义 | 例词 |
|------|------|------|
| **com-** | 共同，一起 | composure, commencement |
| **de-** | 向下/加强/完全 | defer, decree, decimation, desolate |
| **ex-** | 向外，出 | exterminate, elude（e- = ex-） |
| **pro-** | 向前 | propel, procreation |
| **-ment** | 名词后缀（结果/状态） | commencement |
| **-ive** | 形容词后缀（…的） | elusive, desolate |
| **-ate** | 动词后缀（使…） | facilitate, situate, exterminate |
| **lev-** | 举起，抬起 | levy, elevator, relieve |
| **sol-/-sir-** | 独自/渴望 | desolate, desirable |
| **lud-/lus-** | 玩，游戏 | elude, elusive, allusion |

## ⚠️ 形近词 / 近义词辨析

| 词对 | 区别 |
|------|------|
| **persecute** vs **prosecute** | persecute = 迫害（因身份/信仰，非法律）；prosecute = 起诉（违法行为，法律）⚠️ 考研形近必考 |
| **elusive** vs **illusive** | elusive = 难以捉摸的（抓不到）；illusive = 虚幻的（是假的，←illusion） |
| **defer** vs **differ** | defer = 推迟（de- 往后带）；differ = 不同（dis- 分开）⚠️ 形近 |
| **decimation** vs **extermination** | decimation = 大批毁灭（毁掉大部分，非全灭）；extermination = 彻底灭绝（赶尽杀绝） |
| **economical** vs **economic** | economical = 节约的/划算的（省钱）；economic = 经济上的（宏观） |
| **veto** vs **vote** | veto = 否决（一票否决权）；vote = 投票（选举/表决） |
| **futile** vs **fertile** | futile = 徒劳的；fertile = 肥沃的/多产的 ⚠️ 形近 |
| **summon** vs **summit** | summon = 召唤/传唤；summit = 顶峰/峰会 ⚠️ 形近 |
| **treaty** vs **treat** | treaty = 条约（名词）；treat = 对待/款待（动词） |
| **desirable** vs **desirous** | desirable = 值得拥有的（物作主语）；desirous = 渴望的（人作主语） |
| **cricket** vs **racket** | cricket = 板球/蟋蟀；racket = 球拍/喧闹（make a racket 制造噪音） |

## 🎯 考研高频考点速记

| 考点 | 说明 |
|------|------|
| **cardinal vs ordinal** | cardinal numbers 基数词（1,2,3）≠ ordinal numbers 序数词（第一、第二） |
| **persecute vs prosecute** | 完形/阅读高频形近词对：迫害 vs 起诉 |
| **economical vs economic** | economical 省钱/划算；economic 经济的——形容词辨析必考 |
| **lay siege to** | 围攻（注意 siege 拼写，非 seige） |
| **veto 否决权** | 政治制度阅读：Congress can override a presidential veto（议会可推翻总统否决） |
| **allegiance** | 宣誓效忠：swear/pledge allegiance to（注意拼写，非 alligence） |
| **watershed 比喻义** | a watershed moment 转折点——阅读中常考比喻用法 |
| **fauna/flora 成对** | flora and fauna 动植物——固定搭配 |
| **make a racket** | 制造噪音——口语高频，注意与 cricket 区分 |
| **-ize 动词后缀** | hospitalize 使住院、facilitate 促进——动词化构词法 |
