# 📖 阅读理解词汇积累 (4) — 精读 / 课外阅读

> 来源：阅读理解与课外阅读中积累的生词，按语义场景分组，服务六级阅读与写译
> 排版：每条 2-4 行解析，按优先级排列：核心 → 搭配 → 辨析 → 词根/记忆
> 标注：`⚠️` = 易错点/原文修正 | **加粗** = 核心要点

## 一、身份与年代

### 1. **aristocrat** — 贵族
**核心**：n. 拥有**世袭头衔/显赫出身**的贵族（可指男女）
**搭配**：a wealthy aristocrat 富有的贵族 / born an aristocrat 生而为贵族
**辨析**：aristocrat（贵族成员，通用、不分性别）vs nobleman（特指**男性**贵族）
**词根**：希腊 aristos（最优秀）+ -crat（统治者）→ 由"最优秀者"统治；同根 democracy 民主, bureaucracy 官僚体制

### 2. **nobleman** — 贵族（男性）
**核心**：n. 复数 **noblemen**；出身高贵的**男子**，贵族
**搭配**：a nobleman's estate 贵族庄园 / of noble birth 出身高贵
**辨析**：nobleman（男性贵族）↔ noblewoman（女性贵族）；较 aristocrat 更直白通用
**词根**：noble（高贵的、贵族的）+ man；同根 nobility 贵族阶层, noble 高贵的

### 3. **barbarous** — 野蛮的，粗俗的，残暴的
**核心**：⚠️ 拼写：**barbarous**（原文 bararous 漏一个 b）；**野蛮残暴、未开化**的（贬义）
**搭配**：barbarous acts 野蛮行径 / barbarous cruelty 惨无人道的残忍
**辨析**：barbarous（adj. 残暴野蛮的）vs barbarian（n. 野蛮人 / adj. 未开化的）——名词形式更常见
**词根**：barbar-（希腊语拟声：异邦人讲话听来像"bar-bar"）+ -ous；同根 barbarian 野蛮人, barbaric 野蛮的

### 4. **antiquity** — 古代；古迹，古物；古老
**核心**：n. **古代**（尤指古希腊罗马）；可数 **antiquities** = 古迹/古物
**搭配**：in antiquity 在古代 / Roman antiquities 古罗马文物 / of great antiquity 年代久远的
**辨析**：antiquity（古代/古迹，名词）≠ antique（n. 古董；adj. 古老的，指器物）≠ ancient（adj. 古代的）
**词根**：antiqu- = old（古老，拉丁 antiquus）+ -ity；同根 ancient 古代的, antique 古董

## 二、处境与心境

### 5. **arduous** — 艰巨的，费力的
**核心**：**极其艰难、需长期坚持**的（任务/旅程/训练）
**搭配**：an arduous journey 艰苦的旅程 / arduous training 高强度的训练
**辨析**：arduous（艰巨持久，正式书面）vs hard（难，口语通用）vs laborious（费时费力的苦差）
**词根**：ard- = burn（燃烧，拉丁 ardere）+ -uous → 像被火烧灼般辛苦；同根 ardor 热情

### 6. **jeopardize** — 危及，损害
**核心**：**使…陷入危险/有失败风险**（危及事业、计划、关系）
**搭配**：jeopardize one's health/career 危及健康/事业 / jeopardize the peace talks 危及和谈
**辨析**：⚠️ jeopardize（v.）≠ jeopardy（n.：in jeopardy 处于危险中）≈ endanger（危及，常用）
**词根**：源自古法语 jeu parti（胜负未卜的棋局）→"危险"；名词 jeopardy 危险

### 7. **frustrated** — 挫败的，失意的
**核心**：因**想做却做不成**而沮丧的；动词 frustrate 使受挫
**搭配**：feel frustrated with/at sth 对…感到沮丧 / a frustrated attempt 受挫的尝试
**辨析**：frustrated（因受阻而憋屈，事与愿违）vs disappointed（失望，未达预期）——前者更强烈
**词根**：frustra = in vain（徒劳，拉丁）+ -ate + -ed；同根 frustration 挫折

### 8. **outdone** — 被超越，被胜过
**核心**：⚠️ **outdo**（胜过）的过去分词；**be outdone** = 被超过、落了下风
**搭配**：not to be outdone 不甘示弱（习语）/ outdo sb in sth 在某方面胜过某人
**辨析**：outdo（凭本事胜过对手/业绩）vs surpass（超越纪录/成就，正式）vs exceed（超过，数量/限度）
**词根**：out-（超过）+ do（做）→ 做得更好；同类 outrun 跑赢, outshine 使黯然失色

## 三、环境与气息

### 9. **dwell** — 居住；细想，详述
**核心**：v. **居住**（正式/文学语体 = live）；⚠️ 六级更常考 **dwell on/upon**（老是想着；详述）
**搭配**：dwell in the countryside 住在乡下 / dwell on the past 沉湎于过去 / dwell on details 详述细节
**辨析**：dwell（居住，书面/文学）vs live（住，通用）vs inhabit（栖息，正式，生物占据某地）
**记忆**：过去式/分词 **dwelt** 或 dwelled；dweller 居民（city dwellers 城市居民）

### 10. **navigable** — 可航行的
**核心**：⚠️ 原文释义"可操纵的、可驾驶的"有误——那是 **maneuverable/drivable**；**navigable** =（水域）**可通航的**
**搭配**：a navigable river 可通航的河流 / navigable waters 可通航水域
**辨析**：navigable（水域可通航 / 网页可导航）vs navigational（导航的：navigational system）
**词根**：navig- = 航行（拉丁 navis 船）+ -able（可…的）；同根 navigate 航行, navigation 导航, navy 海军

### 11. **boisterous** — 喧闹的，欢腾的；狂暴的
**核心**：**喧闹欢腾**的（人群/聚会）；也可形容**狂风大浪**
**搭配**：a boisterous crowd 喧闹的人群 / boisterous laughter 纵情的笑声 / boisterous seas 汹涌的海面
**辨析**：boisterous（热闹欢快，多含褒义）vs noisy（吵闹，贬义为主）vs turbulent（动荡：政局/气流，正式）
**记忆**：词源难考；联想"party 上纵情喧嚣"→ 喧闹（常与欢笑/人群连用）

### 12. **allure** — 诱惑，吸引；魅力
**核心**：v./n. **强烈吸引**；不可数名词 = **魅力、诱惑力**
**搭配**：the allure of success 成功的诱惑 / be allured into a trap 被诱入圈套 / sexual allure 性感魅力
**辨析**：allure（迷人魅力，文学色彩，中性偏褒）vs attract（吸引，通用中性）vs tempt（引诱作恶，贬义）
**记忆**：al-（向）+ lure（诱饵）→ 撒饵引人上钩；lure 本身即"诱惑"

### 13. **breathing** — 呼吸（n.）；活的（adj.）
**核心**：⚠️ 原文"可呼吸的"应为 **breathable**；**breathing** = 呼吸（名词）/ **活的、有生命的**（形容词）
**搭配**：heavy breathing 沉重的呼吸声 / a breathing space 喘息之机 / breathing exercises 呼吸练习
**辨析**：breathing（活的/呼吸的）vs breathable（可呼吸的、透气的：breathable fabric）vs breath（名词：take a deep breath）
**记忆**：breath（气息，名词）+ -ing；表示"可…的"应加 -able

## 📌 词根小结

| 词根 | 含义 | 例词 |
|------|------|------|
| **-ous** | "…的"形容词后缀 | barbarous, arduous, boisterous |
| **out-** | 超过、胜过 | outdo (outdone) |

## ⚠️ 形近词 / 近义词辨析（含场景偏好）

| 词对 | 区别（含使用场景偏好） |
|------|------|
| **aristocrat** vs **nobleman** | 都指贵族：aristocrat = 贵族成员（可指男女，强调阶层/头衔）；nobleman = 男性贵族（noble birth 出身高贵），对应 noblewoman |
| **barbarous** vs **barbarian** | barbarous = 残暴野蛮的（adj.，贬义，形容行为/风俗）；barbarian = 野蛮人（n.）/未开化的（adj.） |
| **antiquity** vs **antique** | antiquity = 古代/古迹（时间与遗址概念）；antique = 古董/古董的（器物，如 antique furniture） |
| **arduous** vs **laborious** vs **hard** | arduous = 艰巨持久（正式书面）；laborious = 费时费力的苦差（重复劳作）；hard = 难（口语通用） |
| **jeopardize** vs **endanger** | jeopardize = 危及成败/前途（抽象，正式）；endanger = 危及生命/物种（具体，新闻常用）；名词 in jeopardy 处于危险中 |
| **frustrated** vs **disappointed** | frustrated = 挫败（想做却受阻，憋屈、强烈）；disappointed = 失望（未达预期，温和） |
| **outdo** vs **surpass** vs **exceed** | outdo = 胜过对手/业绩；surpass = 超越（成就/纪录，正式）；exceed = 超过（数量/限度，客观） |
| **dwell** vs **live** vs **inhabit** | dwell = 居住（书面/文学，正式）；live = 住（口语通用）；inhabit = 栖息（生物占据，正式） |
| **boisterous** vs **noisy** vs **turbulent** | boisterous = 喧闹欢腾（人/派对，偏褒）或狂暴（风浪）；noisy = 吵闹（贬义为主）；turbulent = 动荡（政局/气流，正式） |
| **allure** vs **attract** vs **tempt** | allure = 迷人魅力/诱惑（n./v.，文学性，偏褒）；attract = 吸引（通用中性）；tempt = 引诱（做坏事，贬义） |
| **breathing** vs **breathable** vs **breath** | breathing = 活的/呼吸的（adj./n.）；breathable = 可呼吸的/透气的（-able 表"可…"）；breath = 气息（名词） |

## 🎯 高频考点速记

| 考点 | 说明 |
|------|------|
| **not to be outdone** | "不甘示弱"，习语考点（outdo 的过去分词）；outdo sb in sth 在某方面胜过某人 |
| **dwell on/upon sth** | "老是想着/详述"，六级高频；dwell 过去式 dwelt（居住义少见，dwell on 常考） |
| **in jeopardy / jeopardize** | in jeopardy = 处于危险中（名词）；jeopardize = 危及（动词）——词性辨析 |
| **be/feel frustrated with/at sth** | "对…感到沮丧"，介词搭配 with/at |
| **navigable ≠ maneuverable** | navigable 形容"水域可通航"；"可操纵的"是 maneuverable（形近易混） |
| **a breathing space** | "喘息之机/缓冲时间"（breathing 名词化搭配，阅读高频） |
| **be allured into doing sth** | "被引诱做某事"，allure 的被动用法（be allured into 结构） |
