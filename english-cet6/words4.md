# 📚 CET-6 单词本 (4)

> 排版：每条单词 2-4 行解析，按优先级排列：核心 → 搭配 → 辨析 → 词根/记忆
> 标注：`⚠️` = 易混点/重点 | **加粗** = 核心要点

## 一、工具·器物·艺术

### 1. **rake** — n. 耙子 / v. 耙平；搜寻
**核心**：名词**耙子**；动词**耙/搜寻**
**搭配**：rake up 翻出（旧事），重提 / rake in 大量敛财 / rake through sth 仔细搜寻某物 / as thin as a rake 骨瘦如柴

### 2. **comb** — n. 梳子 / v. 梳理；仔细搜寻
**核心**：名词**梳子**；动词**梳理/仔细搜索**
**搭配**：comb one's hair 梳头发 / comb the area 仔细搜索该区域 / comb through documents 仔细翻阅文件 / fine-tooth comb 细齿梳（比喻仔细检查）

### 3. **ribbon** — 丝带，缎带；带状物
**核心**：**丝带/缎带**；引申"带状物"
**搭配**：a piece of ribbon 一条丝带 / cut the ribbon 剪彩 / ribbon cable 带状电缆 / tear sth to ribbons 把…撕成碎片

### 4. **lantern** — 灯笼，提灯
**核心**：**灯笼/提灯**（可提可挂的灯）
**搭配**：lantern festival 元宵节，灯会 / Chinese lantern 中国灯笼 / magic lantern 幻灯机（早期的）/ a lantern in the dark 黑暗中的灯笼（比喻希望之光）

### 5. **vase** — 花瓶
**核心**：**花瓶**（装饰用，细颈）
**搭配**：a vase of flowers 一瓶花 / flower vase 花瓶 / put flowers in a vase 把花插进花瓶
**辨析**：⚠️ vase（花瓶，装饰用）≠ jar（罐子，储物用）

### 6. **jar** — n. 罐子，广口瓶 / v. 震动，冲突
**核心**：名词**广口罐**；动词**震动/使不快**
**搭配**：cookie jar 饼干罐 / glass jar 玻璃罐 / jar on sb 使某人不快 / jarring sound 刺耳的声音 / a jar of jam 一罐果酱

### 7. **mosaic** — 马赛克；镶嵌图案；拼合物
**核心**：**马赛克/镶嵌图案**；比喻"多元融合"
**搭配**：mosaic floor 马赛克地板 / a mosaic of cultures 多元文化的融合 / genetic mosaic 遗传镶嵌体
**词根**：源自希腊语 mouseios（缪斯女神之作）

## 二、身体与健康

### 8. **dental** — 牙科的，牙齿的
**核心**：**牙齿的/牙科的**
**搭配**：dental care 牙齿护理 / dental floss 牙线 / dental check-up 牙科检查
**词根**：dent- = tooth（牙齿）→ dentist, denture, dentition, indent

### 9. **gum** — n. 口香糖；牙龈；树胶
**核心**：一词多义：**牙龈/口香糖/树胶**
**搭配**：chewing gum 口香糖 / gum disease 牙龈病 / bubble gum 泡泡糖
**辨析**：⚠️ gum（牙龈，解剖术语）≠ teeth（牙齿）≠ lip（嘴唇）

### 10. **waist** — 腰，腰部
**核心**：**腰部**（身体部位）
**搭配**：waist size 腰围 / around the waist 在腰部 / waist-high 齐腰高的
**辨析**：⚠️ waist（腰部）≠ waste（浪费/废弃，同音词）

### 11. **lick** — v. 舔 / n. 少量；击打
**核心**：动词**舔**；名词**少量**（a lick of）
**搭配**：lick one's lips 舔嘴唇（期待/满意）/ lick one's wounds 舔舐伤口（恢复元气）/ a lick of paint 薄薄一层漆 / at a great lick 飞快地

### 12. **frown** — v. 皱眉 / n. 皱眉
**核心**：**皱眉**；frown on/upon 表示"不赞成"
**搭配**：frown at sb 对某人皱眉 / frown on/upon sth 反对，不赞成某事 / a deep frown 紧皱的眉头 / frown in concentration 专注地皱眉

## 三、契约·武器·犯罪

### 13. **pact** — 协议，条约，契约
**核心**：**正式协议/条约**（国家或个人之间）
**搭配**：a pact with sb to do sth 与某人达成协议做某事 / make a pact 立约 / suicide pact 自杀协议 / non-aggression pact 互不侵犯条约
**词根**：pact- = agree（同意，固定）→ compact, impact

### 14. **pistol** — 手枪
**核心**：**手枪**（单手使用）
**搭配**：automatic pistol 自动手枪 / hold a pistol to sb's head 威胁某人（比喻义）/ starting pistol 发令枪

### 15. **bribe** — v. 贿赂 / n. 贿赂物
**核心**：**贿赂**（给钱/物让人办事）
**搭配**：bribe sb to do sth 贿赂某人做某事 / accept/take a bribe 受贿 / offer a bribe 行贿 / bribery and corruption 贪污腐败

### 16. **get the nod** — 得到肯定/批准/点头
**核心**：**获得首肯/开绿灯**（商务/新闻口语）
**搭配**：get the nod from sb 获得某人的首肯 / give sb the nod 给某人开绿灯

## 四、信仰·话语·阅读

### 17. **faith** — 信仰，信任，虔诚
**核心**：**信仰/信任**（常含超越理性的成分）
**搭配**：have faith in sb/sth 对…有信心 / lose faith 失去信心 / in good faith 真诚地，善意地 / blind faith 盲目信仰
**辨析**：⚠️ faith（信仰，超理性）≠ belief（相信，基于经验）≠ trust（信任，侧重可靠性）

### 18. **discourse** — n. 话语，论述，语篇 / v. 讲述
**核心**：**话语/论述**（学术、政治语境）
**搭配**：political discourse 政治话语 / academic discourse 学术论述 / discourse on sth 就某事进行论述 / public discourse 公共讨论
**词根**：dis-（分离）+ cours-（跑）→ 跑来跑去地讲 → 论述

### 19. **arbitrary** — 武断的，专横的；任意的
**核心**：**主观武断/任意**的（决定、逮捕）
**搭配**：arbitrary decision 武断的决定 / arbitrary arrest 任意逮捕 / an arbitrary number 任意数字
**辨析**：⚠️ arbitrary（主观随意）≠ random（数学上的随机）
**词根**：arbitr- = judge（裁决）→ 源自拉丁语 arbiter

### 20. **skim** — 撇去（浮沫）；略读，浏览
**核心**：**撇去浮沫** + **快速浏览**（抓重点）
**搭配**：skim off 撇去，捞走（精华/利润）/ skim through a book 浏览一本书 / skim milk 脱脂牛奶 / skim the surface 浅尝辄止
**辨析**：⚠️ skim（快速浏览，抓大意）≠ scan（快速扫视，寻找特定信息）

## 五、治理·工程·外交

### 21. **govern** — 统治，管理，支配
**核心**：**统治/治理**（国家、规则）
**搭配**：govern a country 治理国家 / rules governing sth 支配某事的规则 / govern oneself 自治，自律
**词根**：gubern-/govern- = steer（掌舵，管理）→ governor, government, governance

### 22. **overpass** — 高架桥，立交桥，天桥
**核心**：**跨越道路/铁路的桥**（美式常用）
**辨析**：⚠️ overpass（跨越道路/铁路的桥）≠ flyover（英式：高架道路/立交桥）≠ underpass（地下通道）≠ bridge（通用桥）
**词根**：over-（在上方）+ pass（通过）→ 从上方通过的路

### 23. **dam** — n. 水坝，大坝 / v. 阻止，抑制
**核心**：名词**水坝**；动词**拦截/压抑**
**搭配**：dam a river 筑坝拦截河流 / dam up one's emotions 压抑情感 / hydropower dam 水电站大坝
**辨析**：⚠️ dam（大坝）≠ damn（该死的，同音词）

### 24. **reclaim** — 收回，取回；开垦（荒地）；回收利用
**核心**：**要回来/收回**；开垦荒地；回收
**搭配**：reclaim one's luggage 取回行李 / reclaim land from the sea 填海造地 / reclaimed materials 回收材料 / reclaim one's throne 夺回王位
**词根**：re-（回）+ claim（声称，要求）→ 要回来

### 25. **embassy** — 大使馆
**核心**：**大使馆**（机构/建筑）
**搭配**：the Chinese Embassy 中国大使馆 / embassy staff 使馆工作人员
**辨析**：⚠️ embassy（机构）≠ ambassador（大使，人员）
**词根**：emb-（里面）+ assy（= send，派）→ 派驻机构

## 六、农事·能源·生活

### 26. **sow** — v. 播种 / n. 母猪
**核心**：动词**播种**；名词**母猪**
**搭配**：sow seeds 播种 / sow doubt 撒播怀疑的种子 / reap what you sow 种瓜得瓜，种豆得豆 / You reap what you sow. 善有善报，恶有恶报
**辨析**：⚠️ sow（播种，过去式 sowed，过去分词 sown/sowed）≠ sew（缝纫，同音词）

### 27. **petroleum** — 石油
**核心**：**石油**（原油 crude petroleum）
**搭配**：crude petroleum 原油 / petroleum industry 石油工业 / petroleum jelly 凡士林
**词根**：petr-（岩石）+ oleum（油）→ 石油；同根 petrify（石化）, petroglyph（岩石雕刻）

### 28. **vacuum** — n. 真空 / v. 用吸尘器打扫
**核心**：**真空**（物理/比喻）；动词**吸尘**
**搭配**：vacuum cleaner 吸尘器 / in a vacuum 在真空中（比喻脱离现实环境）/ power vacuum 权力真空 / vacuum-packed 真空包装的
**词根**：vacu- = empty（空的）→ vacuous, evacuate, vacation

### 29. **ort** — 剩饭，残羹碎屑
**核心**：**吃剩的碎屑**（通常用复数 orts）
**搭配**：kitchen orts 厨房剩饭 / literary orts 文学碎片/断章
**辨析**：⚠️ ort（残羹剩饭，小而碎）≠ leftover（剩菜，通用词）

## 七、人物·动物

### 30. **pilgrim** — 朝圣者，香客
**核心**：**朝圣者**；the Pilgrims 特指清教徒前辈移民
**搭配**：pilgrim route 朝圣路线 / the Pilgrims（1620 年乘"五月花号"抵达美洲）/ pilgrim's progress 天路历程
**词根**：源自拉丁语 peregrinus（外来的，旅行者）

### 31. **donkey** — 驴
**核心**：**驴**；常象征固执（stubborn as a donkey）
**搭配**：donkey's years 很久很久 / talk the hind legs off a donkey 唠叨个没完 / donkey work 苦活累活

## ⚠️ 形近词 / 近义词辨析（含场景偏好）

| 词对 | 区别（含使用场景偏好） |
|------|------|
| **embassy** vs **ambassador** | embassy = 大使馆（建筑物/机构）；ambassador = 大使（人） |
| **waist** vs **waste** | waist = 腰（身体部位）；waste = 浪费/废弃（同音词，拼写不同） |
| **dam** vs **damn** | dam = 水坝；damn = 该死的，诅咒（同音词） |
| **sow** vs **sew** | sow = 播种（过去式 sowed，过去分词 sown）；sew = 缝纫（同音词，过去式 sewed，过去分词 sewn/sewed） |
| **skim** vs **scan** | skim = 快速浏览，了解大意；scan = 快速扫视，寻找特定信息 |
| **vase** vs **jar** | vase = 花瓶（细颈，装饰用）；jar = 广口罐（储物用） |
| **gum** vs **teeth** vs **lip** | gum = 牙龈；teeth = 牙齿；lip = 嘴唇 |
| **faith** vs **belief** vs **trust** | faith = 信仰/信任（可超越理性）；belief = 相信（基于经验/推理）；trust = 信任（可靠性导向） |
| **overpass** vs **flyover** vs **underpass** | overpass = 跨越道路的天桥（美式）；flyover = 高架道路（英式）；underpass = 地下通道 |
| **arbitrary** vs **random** | arbitrary = 主观武断/任意；random = 数学上的随机/无规律 |
| **ort** vs **leftover** | ort = 残羹碎屑（小而碎的剩饭，通常复数）；leftover = 剩饭剩菜（通用词） |

## 🎯 高频考点速记

| 考点 | 说明 |
|------|------|
| **三组同音词** | waist/waste、dam/damn、sow/sew，听力与写作易错 |
| **skim vs scan** | skim 抓大意 / scan 找特定信息，阅读技巧题常考 |
| **get the nod** | "获得首肯/开绿灯"，新闻商务固定搭配 |
| **faith/belief/trust** | 超理性信仰 / 经验相信 / 可靠性信任，完型常考 |
| **arbitrary vs random** | 主观任意（arbitrary decision）vs 数学随机（random number） |
| **vase vs jar** | 装饰细颈瓶 vs 储物广口罐 |
| **overpass/flyover/underpass** | 美式天桥 / 英式高架 / 地下通道，交通类阅读 |
