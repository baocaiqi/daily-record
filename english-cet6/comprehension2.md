# 📖 阅读理解词汇积累 (2) — 精读 / 课外阅读

> 来源：阅读理解与课外阅读中积累的生词，按语义场景分组，服务六级阅读与写译
> 排版：每条 2-4 行解析，按优先级排列：核心 → 搭配 → 辨析 → 词根/记忆
> 标注：`⚠️` = 易错点/原文修正 | **加粗** = 核心要点

## 一、言语与表达

### 1. **uttering** — 说出，发出（utter 的 -ing 形式）
**核心**：还原原形 **utter**：v. **说出/发出**（话语、声音）；⚠️ 另义 adj. **完全的**（熟词僻义）
**搭配**：not utter a word 一言不发 / utter a sigh of relief 如释重负地叹口气 / utter nonsense 一派胡言
**辨析**：utter（郑重地说出/发声，正式）vs speak/say（通用）——utter 常见于否定句或"发出声音"语境
**记忆**：形容词 utter 义项 → **utterly**（adv. 完全地）：utterly different 完全不同

### 2. **bellow** — 吼叫，咆哮；怒吼
**核心**：v./n. **低沉洪亮地吼叫**（像公牛；人或机器轰鸣）
**搭配**：bellow at sb 冲某人大吼 / bellow with pain 疼得吼叫 / a bellow of rage 愤怒的吼声
**辨析**：bellow（低沉洪亮，公牛般）vs roar（狮吼/引擎轰鸣，范围更广）vs shout（喊叫，通用）
**记忆**：⚠️ 形近 **below**（在…下方）：bellow 多一个 l，像张大嘴在吼

### 3. **saunter** — 漫步，闲逛
**核心**：⚠️ 拼写：**saunter**（原文 saunte 拼写错误）；**不慌不忙**地散步
**搭配**：saunter along the street 沿街漫步 / saunter into the room 悠哉地走进房间
**辨析**：saunter（悠闲从容）≈ stroll（散步）——都比 wander（漫无目的地游荡）更显"轻松随意"

### 4. **abridge** — 删节，缩短（书籍、文章）
**核心**：**删减压缩**（书/文，保留原意）
**搭配**：an abridged edition 节选本/简写本 / abridge a novel 删节小说
**辨析**：abridge（删节文章/书）vs abbreviate（缩写单词，如 approx.）vs condense（浓缩、凝练）
**词根**：与 **abbreviate** 同源（拉丁 brevis = 短）；同根 brief 简短的, brevity 简洁

### 5. **bestow** — 授予，赠予（正式）
**核心**：**正式地给予**（荣誉、称号、恩惠）；用法 **bestow sth on/upon sb**
**搭配**：bestow an honour/a title on sb 授予某人荣誉/头衔 / bestow favours upon sb 施恩于某人
**辨析**：bestow（赐予，庄重，隐含"恩赐"）vs award（因成绩颁奖）vs grant（准予，法律/行政）vs confer（授予学位/头衔）
**词根**：be-（使）+ stow（装载、放置）→ 放到（某人手中）→ 授予；⚠️ 原注释"留宿、使用"为陈旧义项，现代英语几乎不用

### 6. **dedicate** — 致力于，献身；题献
**核心**：v. **把（时间/精力/一生）奉献给**；dedicated adj. **敬业的**
**搭配**：dedicate oneself to sth/doing 献身于 / be dedicated to 致力于 / dedicate a book to sb 把书题献给某人
**辨析**：dedicate（献身于事业/理想）≈ devote（投入时间精力）vs commit（承诺，较抽象）
**词根**：de-（加强）+ dic- = proclaim（宣告）+ -ate → 郑重宣告献出；同根 dictate 口述, predict 预言

## 二、生存与状态

### 7. **sprawl** — 蔓延，无序扩张；伸开四肢
**核心**：v./n.（城市、建筑）**无序蔓延**；也指伸开四肢懒散地躺
**搭配**：urban sprawl 城市无序扩张 / sprawl over the hillside 在山坡上蔓延开来 / sprawl on the sofa 瘫在沙发上
**辨析**：sprawl（无序扩张，常含贬义）vs spread（扩散，中性）vs expand（有计划地扩大）
**记忆**：与 **crawl**（爬）形近——像爬一样无规则地铺开

### 8. **subsist** — 维持生存，勉强生活
**核心**：**靠极少资源活下去**；用法 **subsist on sth**
**搭配**：subsist on bread and water 靠面包和水维持生存 / subsist on a small income 靠微薄收入过活
**辨析**：subsist（勉强维持，书面）vs survive（存活，通用）vs exist（存在，中性）
**词根**：sub-（在下）+ sist- = stand（站立）→ 下方立住 → 得以维持；同根 persist 坚持, consist 由…组成

### 9. **indolent** — 懒散的，怠惰的（正式）
**核心**：**好逸恶劳、懒得活动**的（书面/正式）
**搭配**：an indolent lifestyle 懒散的生活方式 / indolent youth 好逸恶劳的年轻人
**辨析**：indolent（懒散，书面贬义）vs lazy（懒惰，口语通用）vs idle（闲着的，中性：机器闲置/无事可做）
**词根**：in-（不）+ dol- = feel pain（疼痛）+ -ent → 一动就怕疼 → 怠惰；同根 indolence 懒散（名词）

### 10. **dissipated** — 放荡的，挥霍享乐的；分散的
**核心**：⚠️ 阅读常考 adj. **放荡的、沉迷享乐的**（原文只注"分散的"）；原形动词 **dissipate** = 驱散/消散/挥霍
**搭配**：a dissipated life 放荡的生活 / dissipate the fog 驱散雾气 / dissipate one's fortune 挥霍家产
**辨析**：dissipated（放荡，贬义）vs dispersed（散开的，中性：人群/雾气被驱散）
**记忆**：dis-（散开）+ sip（小口喝）→ 把家产一口口"喝"光 → 挥霍；由此引申"放荡"

## 三、产业与分工（农牧·纺织）

### 11. **grazier** — 牧场主，放牧人
**核心**：**经营牧场**的人（养牛/养羊），英澳常用
**搭配**：a sheep/cattle grazier 牧羊/牧牛场主
**辨析**：grazier（英澳用词）vs rancher（美式大牧场主）——同一职业的地域用词差异
**词根**：graze（吃草、放牧）+ -(i)er → 放牧的人；同根 graze 放牧

### 12. **spinner** — 纺纱工人；纺纱机
**核心**：**纺纱的人/机器**（纺织业分工中的角色）
**搭配**：a cotton spinner 棉纺工人 / spinning wheel 纺车
**辨析**：spinner（纺纱）vs weaver（织布）vs dyer（染色）——纺织产业链上不同工序的从业者
**词根**：spin（纺纱；旋转）+ -er（…的人/机）；同根 spin 旋转, spinning 纺纱

### 13. **bleacher** — 漂白工人；漂白器
**核心**：⚠️ 原文释义"漂白剂"应为 **bleach**；**bleacher**（-er 表人或工具）= 漂白工人/漂白装置
**搭配**：a textile bleacher 纺织漂白工 / the bleachers（美式）露天看台
**辨析**：bleacher（人/装置）vs bleach（n. 漂白剂；v. 漂白）——词形相近、词义不同
**词根**：bleach（漂白）+ -er；同根 bleach 漂白剂/漂白

### 14. **smoother** — 平整机，压光机；更光滑的
**核心**：n.（使表面光滑的）**平整机/压光机**（原文"路面平整机"是道路场景的叫法）；⚠️ 阅读中更常见作 smooth 的**比较级**
**搭配**：a road smoother 路面平整机 / a smoother ride 更平稳的行驶（比较级）
**辨析**：⚠️ 一词两性——作名词="机器/工具"，作形容词=smooth 比较级，阅读时先判断词性
**词根**：smooth（光滑的）+ -er（表"…的工具"或比较级）

### 15. **subdivide** — 细分，再分
**核心**：**在已划分的基础上进一步细分**
**搭配**：subdivide ... into ... 把…再细分为 / subdivide the land into lots 把土地再分割成小块
**辨析**：divide（分成若干份）vs subdivide（再分/细分，含 sub- "进一步"之意）
**词根**：sub-（再、在下）+ divide（分）→ 再分；同根 divide 划分, division 部门/除法

## 四、性状与评价

### 16. **appetising** — 开胃的，诱人的
**核心**：**勾起食欲**的；⚠️ 英式拼写 **appetising** = 美式 **appetizing**
**搭配**：an appetising smell 诱人的香味 / appetising food 令人垂涎的食物
**辨析**：appetising（勾起食欲，吃之前）vs delicious（好吃，吃之后的评价）
**词根**：appetite（食欲/欲望）+ -ise/-ize；同根 appetite 食欲, appetiser 开胃菜（美式 appetizer）

### 17. **proportionable** — 成比例的（罕见书面词）
**核心**：⚠️ 罕见词；现代英语多用 **proportional / proportionate**
**搭配**：proportionable to 与…成比例（罕见，书面）/ proportional to 与…成正比（常用）
**辨析**：proportionable（古旧书面，阅读偶见）→ 写作用 proportional/proportionate；名词 proportion 比例
**词根**：proportion（比例）+ -able（可…的）；同根 proportion 比例, portion 部分

### 18. **inferiority** — 劣势，下等；自卑（感）
**核心**：n. **较低的地位/劣势**；引申"自卑感"
**搭配**：a sense of inferiority 自卑感 / inferiority complex 自卑情结 / social inferiority 社会地位低下
**辨析**：inferiority（劣势/自卑）↔ superiority（优势/优越）——反义词对；inferior 较差的 vs superior 优越的
**词根**：inferior（较低的）+ -ity（名词后缀）；同根 inferior 较差的

### 19. **nothing but** — 只有，仅仅
**核心**：**仅仅、只不过**（= only）；⚠️ 原文释义"绝不"有误——"绝不"对应的是 **anything but**
**搭配**：nothing but the truth 只要真相 / do nothing but complain 只会抱怨
**辨析**：⚠️ nothing but（只有）≠ anything but（绝不：anything but lazy 一点也不懒）≠ all but（几乎）
**记忆**：nothing but = 除了…什么都没有 → 只有；anything but = 除了…什么都行 → 绝不

## 📌 词根小结

| 词根 | 含义 | 例词 |
|------|------|------|
| **sub-** | 在…之下；再、进一步 | subdivide, subsist |
| **-er / -ier** | …的人 / 工具（从业者、机器） | spinner, bleacher, smoother, grazier |

## ⚠️ 形近词 / 近义词辨析（含场景偏好）

| 词对 | 区别（含使用场景偏好） |
|------|------|
| **nothing but** vs **anything but** | nothing but = 只有/仅仅（陈述事实，中性）；anything but = 绝不/一点也不（强调否定，口语常用） |
| **bleacher** vs **bleach** | bleacher = 漂白工人/漂白器（-er 表人或工具）；bleach = 漂白剂/漂白（名词/动词） |
| **bellow** vs **below** | 形近：bellow = 低沉吼叫（v./n.，公牛般）；below = 在…下方（介词/副词） |
| **saunter** vs **stroll** | 近义：都指悠闲步行；saunter 更强调"不慌不忙、从容"；口语中 stroll 散步更常用 |
| **abridge** vs **abbreviate** vs **condense** | abridge = 删节（文章/书）；abbreviate = 缩写（单词，如 approx.）；condense = 浓缩（凝练内容） |
| **bestow** vs **confer** vs **grant** | bestow = 赐予（庄重，含恩赐意味）；confer = 授予（学位/头衔，正式）；grant = 准予（法律/行政，中性） |
| **dedicate** vs **devote** | 都接 to：dedicate 侧重献身于事业/理想（也可"题献"书）；devote 侧重投入时间精力 |
| **indolent** vs **lazy** vs **idle** | indolent = 懒散（正式/书面，贬）；lazy = 懒惰（口语通用，贬）；idle = 闲着的（中性，机器闲置/无事可做） |
| **inferiority** vs **superiority** | 反义词对：inferiority = 劣势/自卑（inferiority complex 自卑情结）；superiority = 优势/优越 |
| **sprawl** vs **spread** vs **expand** | sprawl = 无序蔓延（贬，urban sprawl）；spread = 扩散（中性）；expand = 有计划地扩大（中性偏褒） |

## 🎯 高频考点速记

| 考点 | 说明 |
|------|------|
| **anything but ≠ nothing but** | anything but = 绝不；nothing but = 只有；all but = 几乎（写译高频易混） |
| **utter 一词多义** | v. 说出（not utter a word 一言不发）/ adj. 完全的（utter nonsense）→ 副词 utterly 完全地 |
| **be dedicated to sth/doing** | "致力于"六级写作高频；dedicate oneself to ... 同义 |
| **bestow sth on/upon sb** | 正式"授予"，必须用 on/upon 接人，不可直接跟双宾语 |
| **subsist on sth** | 靠…勉强维持生存；名词 subsistence 生计/最低生活 |
| **urban sprawl** | "城市无序扩张"，新闻阅读高频搭配，sprawl 含贬义 |
| **-er/-ier 职业后缀猜词** | spinner/bleacher/grazier/smoother → 阅读中凭后缀判断"从业者或工具" |
| **英美拼写 -ise/-ize** | appetising（英式）= appetizing（美式）；名词 appetite 食欲 |
| **inferiority complex** | 自卑情结（心理学名词，阅读/听力常考） |
