# 📚 CET-6 单词本 (14)

> 排版：每条单词 2-4 行解析，按优先级排列：核心 → 搭配 → 辨析 → 词根/记忆
> 标注：`⚠️` = 易混点/重点 | **加粗** = 核心要点

## 一、武器与攻击

### 1. **spear** — 矛，长矛；（植物的）嫩芽
**核心**：**长矛** + 熟词僻义"**嫩芽**"（a spear of asparagus 一根芦笋嫩茎）
**搭配**：a spear of asparagus 芦笋嫩茎 / spear fishing 用矛捕鱼 / spearhead 矛头，先锋
**辨析**：⚠️ spear（长矛/嫩芽）≠ lance（骑士长枪）≠ javelin（标枪，田径）≠ shoot（嫩芽，更泛）
**记忆**：音近"撕破"→ 长矛撕破敌人 → 矛

### 2. **snatch** — 一把抓起，抢夺；片段
**核心**：**突然抢夺**（一把抓走）
**搭配**：snatch sth from sb 从某人手中抢走 / snatch at 试图抓住 / a snatch of conversation 谈话的片段 / snatch victory 险胜
**辨析**：⚠️ snatch（突然抢夺）≠ grab（急切抓取）≠ seize（用力抓住）≠ steal（秘密偷）
**记忆**：音近"死抓"→ 一把抓住

### 3. **brutal** — 残忍的，野蛮的；严酷的
**核心**：**残忍粗暴、毫无怜悯**（brutal truth 残酷的事实）
**搭配**：a brutal attack 残忍的袭击 / brutal truth 残酷的事实 / brutal winter 严酷的冬天
**辨析**：⚠️ brutal（残忍粗暴）≈ cruel（残忍，通用）≈ savage（野蛮残暴）≠ humane（人道的，反义）
**词根**：brut- = 粗野；同根 brute 野兽, brutish 兽性的；brutal honesty 不留情面的诚实

### 4. **a brutal attack** — 残忍的袭击，野蛮攻击
**核心**：**强调暴力残忍**的袭击（≈ a vicious attack 恶毒攻击）
**搭配**：a brutal attack on civilians 对平民的残忍袭击 / survive a brutal attack 在残忍袭击中幸存

## 二、物理与化学

### 5. **absorption** — 吸收；专心，全神贯注
**核心**：⚠️ 拼写 **absorption**（原文 aborption 漏 -s-）；吸收/专注
**搭配**：absorption of nutrients 营养吸收 / absorption in one's work 对工作全神贯注 / water absorption 吸水
**辨析**：⚠️ absorption（吸收，吸入内部）≠ adsorption（吸附，表面附着）形近一字之差
**词根**：ab-（离开）+ sorpt-（吸）+ -ion → 吸走；同根 absorb, absorbent

### 6. **distill** — 蒸馏；提炼
**核心**：**蒸馏/提炼**；⚠️ 美式 **distill**（双 l），英式拼写 distil
**搭配**：distilled water 蒸馏水 / distill from 从…中提炼 / distill one's ideas 提炼观点
**辨析**：⚠️ distill（蒸馏/提炼）≠ distil（英式单 l 变体）≠ condense（冷凝/浓缩）
**词根**：di-（向下）+ still-（滴）→ 使滴下 → 蒸馏

### 7. **atom** — 原子；极少量
**核心**：**不可再分割**的微粒；not an atom of 一点…也没有
**搭配**：a hydrogen atom 氢原子 / atom bomb 原子弹 / not an atom of 一点…也没有
**辨析**：⚠️ atom（原子，不可分）≠ molecule（分子，多原子组成）≠ particle（粒子，泛称）
**词根**：a-（不）+ tom-（切）→ 不可再切分 → 原子；同根 atomic, anatomy

## 三、丑闻与同意

### 8. **scandal** — 丑闻；愤慨
**核心**：**社会性丑闻**（让人跌倒的事）
**搭配**：a political scandal 政治丑闻 / cause a scandal 引起丑闻 / be involved in a scandal 卷入丑闻 / scandal sheet 八卦小报
**辨析**：⚠️ scandal（丑闻，社会性）≠ gossip（流言蜚语，日常）≠ rumour（谣言，未经证实）
**记忆**：谐音"死干得"→ 干坏事被曝光 → 丑闻

### 9. **consent** — 同意，准许
**核心**：**同意/准许**（正式，名词/动词两用）
**搭配**：consent to sth 同意某事 / give one's consent 表示同意 / age of consent 法定同意年龄 / by mutual consent 经双方同意
**辨析**：⚠️ consent（同意/准许，正式）≠ agree（同意，通用）≠ approve（批准，官方）≠ assent（正式点头同意）
**词根**：con-（共同）+ sent-（感觉）→ 感觉一致 → 同意；同根 consensus 共识, dissent 异议

## 四、飞行与傀儡

### 10. **parachute** — 降落伞；跳伞；空投
**核心**：**抵御下坠之物** → 降落伞（名词/动词）
**搭配**：parachute jump 跳伞 / parachute into 空降到 / parachute troops 伞兵
**词根**：para-（抵御）+ chute-（落下）→ 防坠落 → 降落伞；≠ glider 滑翔机

### 11. **puppet** — 木偶；傀儡
**核心**：**受控制的人**，比喻"傀儡"（政治阅读）
**搭配**：a puppet government 傀儡政府 / puppet show 木偶戏 / be a puppet of sb 是某人的傀儡
**辨析**：⚠️ puppet（木偶/傀儡，比喻受控者）≠ doll（玩具娃娃）≠ marionette（提线木偶）
**词根**：拉丁语 pupa（娃娃）→ 木偶；puppet regime 傀儡政权

## 五、罪责与毁灭

### 12. **culprit** — 罪犯，肇事者；问题的根源
**核心**：**肇事者/元凶**，比喻义"**问题根源**"阅读高频
**搭配**：the main culprit 罪魁祸首 / catch the culprit 抓住罪犯 / the culprit behind the failure 失败的根源
**辨析**：⚠️ culprit（肇事者/元凶）≠ criminal（罪犯，法律）≠ offender（违法者）≠ suspect（嫌疑人，未定罪）
**词根**：culp- = 罪 + -rit → 有罪的人；同根 culpable 有罪的, exculpate 开脱

### 13. **the main culprit** — 罪魁祸首，主要原因
**核心**：**主要根源/元凶**（科普/健康阅读高频；≈ the main cause 中性说法）
**搭配**：the main culprit behind the crisis 危机的罪魁祸首 / identify the main culprit 找出元凶

### 14. **decimation** — 大规模削减，大量毁灭
**核心**：**大规模毁灭/削减**；⚠️ 词源"古罗马十抽一杀"
**搭配**：the decimation of the population 人口的锐减 / decimation of the forest 森林的大面积破坏
**辨析**：⚠️ decimation（大规模削减）≠ destruction（破坏，通用）≠ annihilation（彻底消灭）
**词根**：deci- = 十 → 每十人杀一人 → 大规模削减；同根 decimal, decade

## 六、神学与职业

### 15. **theological** — 神学的
**核心**：**研究神的** → 神学的
**搭配**：theological debate 神学辩论 / theological seminary 神学院 / theological differences 神学分歧
**辨析**：⚠️ theological（神学）≠ religious（宗教，泛）≠ spiritual（精神，灵性）
**词根**：theo- = 神 + -logy（学科）+ -ical；同根 theology 神学, atheist 无神论者

### 16. **blacksmith** — 铁匠
**核心**：**打铁的匠人**（铁烧黑 → black）
**搭配**：a village blacksmith 乡村铁匠 / blacksmith's forge 铁匠铺
**辨析**：⚠️ blacksmith（铁匠，打铁）≠ farrier（蹄铁匠，钉马掌）≠ smith（工匠，泛称）
**词根**：black（黑）+ smith（工匠）；同根 goldsmith 金匠, silversmith 银匠

## 七、比较与现状

### 17. **overshadow** — 使黯然失色；使蒙上阴影
**核心**：⚠️ 拼写 **overshadow**（原文 overshawdow 有误）；阴影盖过 → 使逊色
**搭配**：be overshadowed by 被…比下去 / overshadow the achievement 使成就黯然失色 / overshadowed by grief 被悲伤笼罩
**辨析**：⚠️ overshadow（使逊色/蒙阴影）≠ outshine（更亮眼）≠ eclipse（日食隐喻，使黯然）
**词根**：over-（在…上）+ shadow（阴影）→ 阴影压过

### 18. **be overshadowed by sb** — 与某人相比相形见绌
**核心**：**被动结构"相形见绌"**（阅读高频；≈ be outshone by）
**搭配**：be overshadowed by a more talented colleague 在更有才华的同事面前相形见绌 / feel overshadowed by one's sibling 在兄弟姐妹面前黯然失色

### 19. **status quo** — 现状，原有状态
**核心**：**拉丁语外来语"现状"**，固定搭配
**搭配**：maintain the status quo 维持现状 / challenge the status quo 挑战现状 / the status quo ante 原状
**辨析**：⚠️ status quo（现状）≠ status（地位/状态）≠ state（状态，通用）
**词根**：拉丁语 status（状态）+ quo（在此）→ 现状

## 八、语言与法律

### 20. **language-acquisition** — 语言习得
**核心**：**自然获得语言**（语言学）；Chomsky 的 LAD 语言习得机制
**搭配**：language-acquisition device 语言习得机制 / second-language acquisition 第二语言习得 / language-acquisition research 语言习得研究
**辨析**：⚠️ language acquisition（自然习得）≠ language learning（有意识学习）≠ first-language acquisition（母语习得）
**词根**：language + ac-（向）+ quisit-（寻求）→ 习得；同根 acquire, acquisition

### 21. **ruling** — 裁决，裁定；统治的
**核心**：**法院/机构的裁定**（名词）；adj. 统治的、现行的
**搭配**：issue a ruling 作出裁决 / a court ruling 法院裁定 / the ruling party 执政党 / the ruling class 统治阶级
**辨析**：⚠️ ruling（裁定，机构）≠ verdict（判决，陪审团）≠ judgement（判决，法官）≠ sentence（量刑）
**词根**：rule（规则）+ -ing → 定下的规则 → 裁决

### 22. **issue a ruling** — 作出裁决
**核心**：**发布裁定**（法律用语；美式 hand down a ruling）
**搭配**：issue a ruling on the case 对该案作出裁决 / the court issued its ruling yesterday 法院昨天作出裁定

## 九、火候与威胁

### 23. **simmer** — 煨，炖；（怒火）酝酿
**核心**：⚠️ **动词**"文火慢炖/酝酿"（原文"即将爆发"是形容词 simmering）
**搭配**：simmer the soup 把汤文火慢炖 / bring to a simmer 煮到将沸未沸 / simmer with anger 怒火中烧
**辨析**：⚠️ simmer（煨/酝酿）≠ boil（沸腾）≠ stew（炖，加料慢煮）
**记忆**：小火"嘶嘶"（拟声）→ 文火慢炖

### 24. **simmering** — 一触即发的，即将爆发的
**核心**：**正在酝酿的** → 一触即发（新闻阅读）
**搭配**：simmering anger 郁积的怒火 / simmering tensions 一触即发的紧张局势 / a simmering conflict 蓄势待发的冲突
**辨析**：⚠️ simmering（酝酿中）≠ boiling（爆发中）≠ brewing（酝酿，偏计划）
**词根**：simmer（文火酝酿）+ -ing → 即将沸腾

### 25. **insidious** — 潜在的，隐伏的；阴险的
**核心**：**不易察觉地危害**（潜在/阴险）
**搭配**：an insidious threat 潜在的危险 / insidious disease 潜伏的疾病 / insidious effects 潜移默化的影响
**辨析**：⚠️ insidious（隐伏危害）≠ subtle（微妙，中性）≠ sinister（邪恶，明显恶意）≠ sneaky（鬼祟，口语）
**词根**：in-（内）+ sid-（坐）+ -ious → 潜伏在里面；同根 reside, sediment

### 26. **an insidious threat** — 潜在的危险，隐伏的威胁
**核心**：**隐伏的威胁**（不易察觉；≈ a latent threat，≠ an imminent threat 迫近）
**搭配**：an insidious threat to health 对健康的潜在威胁 / guard against an insidious threat 防范隐伏威胁

## 十、生态与地理

### 27. **omnivore** — 杂食动物
**核心**：**什么都吃**的动物
**搭配**：omnivores such as bears and pigs 熊和猪等杂食动物 / an omnivore's diet 杂食性饮食
**辨析**：⚠️ omnivore（杂食）≠ carnivore（食肉）≠ herbivore（食草）≠ insectivore（食虫）
**词根**：omni-（全）+ vor-（吃）→ 全都吃；同根 devour 吞食, voracious 贪吃的

### 28. **swath** — 一长条，一大片（土地）
**核心**：**带状的一大片**（土地/森林/人群）
**搭配**：a swath of forest 一大片森林 / cut a swath through 大片摧毁 / a wide swath of the population 人口的很大一部分
**辨析**：⚠️ swath（带状大片）≠ strip（细长条）≠ stretch（一段/一片）≠ patch（一小块）
**词根**：古英语 swæð（割痕）→ 割下的一长条

### 29. **a swath of forest** — 一大片森林
**核心**：**连片的大森林**（量词用法；≈ a stretch of forest，≠ a grove 小片树林）
**搭配**：a vast swath of forest 广袤的森林地带 / clear a swath of forest 砍伐一大片森林

## 十一、足与行走

### 30. **bipedal** — 双足行走的
**核心**：**两足行走**（人类直立行走 bipedalism 是演化关键）
**搭配**：bipedal locomotion 双足运动 / a bipedal creature 双足行走的生物 / bipedal walking 直立行走
**辨析**：⚠️ bipedal（形容词）≠ biped（两足动物，名词）≠ quadrupedal（四足行走）
**词根**：bi-（二）+ ped-（足）+ -al；同根 pedal 踏板, pedestrian 行人, centipede 蜈蚣

### 31. **biped** — 两足动物
**核心**：**两足行走的动物**（名词），人类是 biped
**搭配**：humans are bipeds 人类是两足动物 / an upright biped 直立行走的两足动物
**辨析**：⚠️ biped（名词）≠ bipedal（形容词）≠ quadruped（四足动物，反义）
**词根**：bi-（二）+ ped-（足）→ 两足动物

## ⚠️ 形近词 / 近义词辨析（含场景偏好）

| 词对 | 区别（含使用场景偏好） |
|------|------|
| **absorption** vs **adsorption** | absorption = 吸收（吸入内部）；adsorption = 吸附（表面附着）⚠️ 原文 aborption 拼写错误 |
| **distill** vs **distil** | distill = 蒸馏（美式/标准，双 l）；distil = 英式拼写（单 l） |
| **atom** vs **molecule** | atom = 原子（不可再分）；molecule = 分子（多个原子组成） |
| **scandal** vs **gossip** vs **rumour** | scandal = 丑闻（社会事件）；gossip = 流言蜚语（日常八卦）；rumour = 谣言（未经证实） |
| **brutal** vs **cruel** vs **savage** | brutal = 残忍粗暴（无怜悯）；cruel = 残忍（通用）；savage = 野蛮残暴 |
| **consent** vs **agree** vs **approve** | consent = 同意/准许（正式，名词/动词）；agree = 同意（通用）；approve = 批准（官方） |
| **puppet** vs **doll** vs **marionette** | puppet = 木偶/傀儡（比喻受控者）；doll = 玩具娃娃；marionette = 提线木偶 |
| **culprit** vs **criminal** vs **suspect** | culprit = 肇事者/元凶（也指问题根源）；criminal = 罪犯（法律）；suspect = 嫌疑人（未定罪） |
| **blacksmith** vs **farrier** | blacksmith = 铁匠（打铁）；farrier = 蹄铁匠（钉马掌） |
| **overshawdow** → **overshadow** | 原文拼写错误；overshadow = 使黯然失色/蒙上阴影 |
| **status quo** vs **status** | status quo = 现状（拉丁语固定短语）；status = 地位/状态 |
| **language acquisition** vs **language learning** | acquisition = 语言习得（自然获得）；learning = 语言学习（有意识） |
| **ruling** vs **verdict** vs **judgement** | ruling = 裁决（法院/机构）；verdict = 判决（陪审团）；judgement = 判断/判决（法官） |
| **simmer** vs **simmering** | simmer = 动词"煨/酝酿"；simmering = 形容词"一触即发的"（原文词性混淆） |
| **omnivore** vs **carnivore** vs **herbivore** | omnivore = 杂食；carnivore = 食肉；herbivore = 食草 ⚠️ 同族三词 |
| **insidious** vs **subtle** vs **sinister** | insidious = 隐伏危害（不易察觉）；subtle = 微妙（中性）；sinister = 邪恶（明显恶意） |
| **swath** vs **strip** vs **patch** | swath = 一大片（带状）；strip = 细长条；patch = 一小块 |
| **biped** vs **bipedal** | biped = 两足动物（名词）；bipedal = 双足行走的（形容词） |
| **biped** vs **quadruped** | biped = 两足动物；quadruped = 四足动物（bi- 二 / quadru- 四） |
