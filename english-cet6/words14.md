### ⚠️ 形近词 / 近义词辨析

| 词对 | 区别 |
|------|------|
| **absorption** vs **adsorption** | absorption = 吸收（吸入内部）；adsorption = 吸附（表面附着）⚠️ 一字之差；原文 aborption 为拼写错误 |
| **distill** vs **distil** | distill = 蒸馏（美式/标准，双 l）；distil = 英式拼写（单 l） |
| **atom** vs **molecule** | atom = 原子（不可再分）；molecule = 分子（多个原子组成） |
| **scandal** vs **gossip** vs **rumour** | scandal = 丑闻（社会事件）；gossip = 流言蜚语（日常八卦）；rumour = 谣言（未经证实） |
| **brutal** vs **cruel** vs **savage** | brutal = 残忍粗暴（无怜悯）；cruel = 残忍（通用）；savage = 野蛮残暴 |
| **consent** vs **agree** vs **approve** | consent = 同意/准许（正式，名词/动词）；agree = 同意（通用）；approve = 批准（官方） |
| **puppet** vs **doll** vs **marionette** | puppet = 木偶/傀儡（比喻受控者）；doll = 娃娃（玩具）；marionette = 提线木偶 |
| **culprit** vs **criminal** vs **suspect** | culprit = 肇事者/元凶（也指问题根源）；criminal = 罪犯（法律）；suspect = 嫌疑人（未定罪） |
| **blacksmith** vs **farrier** | blacksmith = 铁匠（打铁）；farrier = 蹄铁匠（钉马掌） |
| **overshawdow** → **overshadow** | 原文拼写错误；overshadow = 使黯然失色/蒙上阴影 |
| **status quo** vs **status** | status quo = 现状（拉丁语固定短语）；status = 地位/状态 |
| **language acquisition** vs **language learning** | acquisition = 语言习得（自然获得）；learning = 语言学习（有意识） |
| **ruling** vs **verdict** vs **judgement** | ruling = 裁决（法院/机构）；verdict = 判决（陪审团）；judgement = 判断/判决（法官） |
| **simmer** vs **simmering** | simmer = 动词"煨/酝酿"；simmering = 形容词"一触即发的"（原文词性混淆） |
| **omnivore** vs **carnivore** vs **herbivore** | omnivore = 杂食；carnivore = 食肉；herbivore = 食草⚠️ 同族三词 |
| **insidious** vs **subtle** vs **sinister** | insidious = 隐伏危害（不易察觉）；subtle = 微妙（中性）；sinister = 邪恶（明显恶意） |
| **swath** vs **strip** vs **patch** | swath = 一大片（带状）；strip = 细长条；patch = 一小块 |
| **biped** vs **bipedal** | biped = 两足动物（名词）；bipedal = 双足行走的（形容词） |
| **biped** vs **quadruped** | biped = 两足动物；quadruped = 四足动物（bi- 二 / quadru- 四） |

### 🎯 高频考点速记

| 考点 | 说明 |
|------|------|
| **absorption 拼写** | 含 -s-（absorb → absorption）；原文 aborption 漏字母 |
