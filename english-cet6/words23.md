# 📚 CET-6 单词本 (23)

> 排版：每条单词 2-4 行解析，按优先级排列：核心 → 搭配 → 辨析 → 词根/记忆
> 标注：`⚠️` = 易混点/重点 | `⭐️` = 六级熟词僻义（配例句）| **加粗** = 核心要点

## 一、位置与空间

### 1. **adjacent** — 邻近的，毗邻的
**核心**：**紧挨着的**（地理上相邻，比 near 更强调"接壤"）
**搭配**：be adjacent to 与…邻近 / adjacent rooms 相邻的房间 / adjacent angles 邻角（数学）
**辨析**：⚠️ adjacent（紧邻接壤）≠ near（附近，距离近）≠ adjoining（相连，共用边界）≠ neighbouring（邻近的，指区域）
**词根**：ad-（向）+ jac- = lie（躺）+ -ent → 躺在旁边 → 邻近的；同根 eject 投出

### 2. **lateral** — 侧面的，横向的
**核心**：**从侧面/横向的**（相对纵向 vertical）
**搭配**：lateral movement 横向移动 / a lateral branch 侧枝 / lateral thinking 横向（发散）思维
**辨析**：⚠️ lateral（侧向）↔ vertical（纵向）；⚠️ 形近 **literal**（字面的）——勿混
**词根**：later- = side（边）+ -al；同根 bilateral 双边的, unilateral 单边的

## 二、数量与充足

### 3. **ample** — 充足的，足够的；宽敞的
**核心**：**富富有余**（比 enough 更强调"绰绰有余"）
**搭配**：ample time/space 充足的时间/空间 / ample evidence 充分的证据 / an ample figure 丰满的身材
**辨析**：⚠️ ample（充足有余）≠ adequate（刚好够，达标）≠ sufficient（足够，正式）≠ abundant（大量丰富）
**词根**：拉丁 amplus（大）；同根 amplify 放大, amplitude 振幅

### 4. **adequate** — 足够的；胜任的
**核心**：**刚好达到要求**（数量"够用"，质量"称职"）
**搭配**：be adequate for 足以应付… / adequate to the task 胜任该任务 / an adequate supply 充足的供应
**辨析**：⚠️ adequate（达标，中性，不强调多）≠ ample（富足有余）≠ sufficient（足够，多用于数量/证据）
**词根**：ad-（向）+ equ- = equal（相等）+ -ate → 与需求相当 → 足够；同根 equal 相等, equate 使等同

### 5. **underrepresentative** — 代表性不足的
**核心**：⚠️ 非标准词——规范形式应为 **unrepresentative**（不具代表性的）或 **underrepresented**（代表性不足的）
**搭配**：an unrepresentative sample 不具代表性的样本 / women are underrepresented in STEM 女性在理工领域占比过低
**辨析**：unrepresentative（不具代表性的，反义 representative）vs underrepresented（占比偏低，被动式）
**词根**：un-/under-（不足）+ represent（代表）+ -ative/-ed；同根 representative 代表

## 三、文艺与体裁

### 6. **genre** — 体裁，类型（尤指文艺作品）
**核心**：**（文学/艺术/音乐）体裁、门类**；⚠️ 原文 "a literal genre" 应为 **a literary genre**（文学体裁）
**搭配**：a genre of music 一种音乐类型 / a literary genre 文学体裁 / the detective genre 侦探小说类
**辨析**：genre（文艺体裁，正式）≠ category（类别，通用）≠ type/kind（类型，通用）
**词根**：拉丁 genus（种类）；同根 generic 通用的, generate 产生

### 7. **exquisite** — 精美的，精致的；剧烈的
**核心**：**极其精美**（工艺/品味）；也指感觉"**剧烈的**"（exquisite pain）
**搭配**：exquisite craftsmanship 精湛工艺 / an exquisite taste 高雅的品味 / exquisite pain 剧痛
**辨析**：⚠️ exquisite（精美绝伦，褒义）≠ elegant（优雅）≠ delicate（精致易碎）≠ refined（优雅考究）
**词根**：ex-（出）+ quis- = seek（寻求）+ -ite → 精心求出来的 → 精致的；同根 require, inquire

## 四、族群与社会身份

### 8. **race** — 种族，人种；⭐️ 比赛，竞速
**核心**：**种族/人种**（按生理特征划分）；⭐️ 熟词僻义：**比赛/竞速**
**搭配**：the human race 人类 / the race problem 种族问题 / a horse race 赛马
**辨析**：⚠️ race（生理/社会上的种族，宽泛）≠ ethnicity（文化、语言、习俗上的族群归属）
**词根**：古意大利语 razza（血统）；同根 racial 种族的, racism 种族主义

### 9. **ethnicity** — 民族，族群（文化归属）
**核心**：**基于文化/语言/习俗的族群身份**（非生理划分）
**搭配**：ethnic groups 族群 / people of different ethnicities 不同族裔的人 / ethnic minority 少数民族
**辨析**：⚠️ ethnicity（文化/血缘的族群）≠ race（生理/社会种族，更宽泛）≠ nationality（国籍）
**词根**：ethn- = nation/people（民族）+ -icity；同根 ethnic 民族的, ethnology 民族学

### 10. **inclusion** — 包容，接纳；包含
**核心**：**把不同群体纳入**（社会/组织）；也指"包含在内"
**搭配**：social inclusion 社会包容 / diversity and inclusion 多元与包容（D&I）/ the inclusion of ... 把…纳入
**辨析**：inclusion（接纳不同群体，褒义）↔ exclusion（排斥）
**词根**：in-（进入）+ clud- = close（关闭）+ -sion → 关进圈内 → 包含；同根 include 包括, exclude 排除

### 11. **breadwinner** — 养家糊口的人，家庭经济支柱
**核心**：⚠️ 拼写：**breadwinner**（原文 breadwinnner 多一个 n）；家中**挣钱养家**的人
**搭配**：the sole breadwinner 唯一养家的人 / the main breadwinner 主要经济来源
**记忆**：bread（面包）+ winner（挣得者）→ 挣面包的人 → 养家者

## 五、性情与身体

### 12. **disposition** — 性情，性格；倾向；布置
**核心**：**天生的性情**；也指"**倾向**"（disposition to do）和"排列布置"
**搭配**：a cheerful disposition 开朗的性情 / a disposition to do sth 做某事的倾向 / at sb's disposition 由某人支配
**辨析**：disposition（天生性情，正式）≈ temperament（气质，天生）≠ personality（个性，综合）≠ character（品格）
**词根**：dis-（分开）+ posit- = place（放）+ -ion → 分置 → 性情/安排；同根 dispose 处置, position 位置

### 13. **shiver** — 寒战，颤抖（因寒冷/恐惧）
**核心**：**（因冷或怕而）发抖**（比 tremble 更常因寒冷）
**搭配**：shiver with cold 冷得发抖 / a shiver ran down one's spine 脊背发凉 / send shivers 令人毛骨悚然
**辨析**：⚠️ shiver（寒冷/恐惧，轻颤）≠ tremble（因恐惧/激动而颤）≠ shudder（战栗，因厌恶/恐惧，更强烈）
**词根**：中古英语 chiveren；多指寒冷引起的抖动

### 14. **pant** — 喘气，气喘；渴望
**核心**：**急促喘气**（运动/闷热后）；口语 **pant for** = 渴望
**搭配**：pant for breath 上气不接下气 / a panting dog 伸舌喘气的狗 / pant for/after 渴望
**辨析**：pant（急促喘气）≠ gasp（因惊讶/窒息而猛吸一口气）≠ puff（喘息，也指抽烟）
**词根**：古法语 pantaisier（呼吸困难）；同根 pants 短裤（原指"透气裤"）

### 15. **neat freak** — 有洁癖的人，爱整洁成癖者
**核心**：⚠️ 规范写法 **neat freak**（名词，原文 neat freaky 词性有误）；口语指"强迫症般爱干净的人"
**搭配**：a real neat freak 超级洁癖 / neat-freak tendencies 洁癖倾向
**辨析**：neat freak（口语，略调侃）≈ clean freak；医学正式用 **mysophobia** 不洁恐惧症
**记忆**：neat（整洁）+ freak（痴迷者）→ 整洁狂

## 六、医疗与健康

### 16. **dosage** — （药物）剂量，用量
**核心**：**一次/一疗程的用药量**（医用术语）
**搭配**：the recommended dosage 建议剂量 / exceed the dosage 超过剂量 / dosage form 剂型
**辨析**：dosage（用药的剂量/方案，偏整体）≠ dose（一次服用的量，更具体可数）
**词根**：dose（剂量）+ -age；同根 dose 一剂

### 17. **hygiene** — 卫生，保健
**核心**：⚠️ 拼写：**hygiene**（原文 hyigene 字母错位）；**卫生/保健**（个人或公共卫生）
**搭配**：personal hygiene 个人卫生 / food hygiene 食品卫生 / dental hygiene 口腔卫生
**辨析**：hygiene（卫生，名词）≠ hygienic（卫生的，形容词）≠ sanitation（环境卫生设施，公共）
**词根**：Hygeia（希腊健康女神）+ -ene；同根 hygienic 卫生的, hygienist 卫生员

### 18. **burial** — 埋葬，葬礼
**核心**：n. **埋葬/葬礼**；⚠️ 原文"埋葬的"是形容词义——形容词应为 **buried**（被埋葬的）
**搭配**：a burial ground 墓地 / a burial service 葬礼 / burial customs 丧葬习俗
**辨析**：burial（名词，埋葬/葬礼）vs buried（形容词，被埋葬的）vs funeral（葬礼仪式）
**词根**：bury（埋葬）+ -al；同根 bury 埋藏

## 七、器物与工具

### 19. **scissors** — 剪刀
**核心**：**剪刀**；⚠️ 恒用复数——须说 **a pair of scissors**（不能 a scissors）
**搭配**：a pair of scissors 一把剪刀 / scissors and paste 剪刀和浆糊 / sharp scissors 锋利的剪刀
**词根**：拉丁 scindere（切）；同根 schism 分裂, rescind 废除

### 20. **locker** — 储物柜，锁柜
**核心**：**（公共场所）带锁的储物柜**；也指更衣室的柜子
**搭配**：a gym locker 健身房储物柜 / a locker room 更衣室 / leave sth in one's locker 放在柜里
**词根**：lock（锁）+ -er（工具/容器后缀）；同根 lock 锁, unlock 开锁

### 21. **fax** — 传真机；传真（文件）
**核心**：n. **传真机/传真件**；v. **发传真**
**搭配**：send a fax 发传真 / by fax 通过传真 / a fax machine 传真机
**辨析**：fax（传真）≠ email（电子邮件）；fax 现渐被 email 取代
**记忆**：fax 即 facsimile（摹真本）的缩略

### 22. **mould** — 模具；霉菌；塑造，发霉
**核心**：n. ①**模具**（浇铸用）②**霉菌**；v. **塑造/发霉**；⚠️ 英式 mould = 美式 **mold**
**搭配**：a layer of mould 一层霉菌 / a jelly mould 果冻模具 / mould sth into 把…塑造成
**辨析**：⚠️ mould 一词多义：模具（工业）vs 霉菌（生物）；拼写有英美差异
**词根**：拉丁 modulus（模数）；同根 module 模块, model 模型

## 八、职业与身份

### 23. **solicitor** — 事务律师（英式）；法务官
**核心**：**英式**（一般不出庭的）**事务律师**；⚠️ "推销员"义罕见，美式里指"法务官/募捐员"
**搭配**：a solicitor's office 律师事务所 / Solicitor General 副检察长
**辨析**：⚠️ solicitor（英式事务律师，不出庭）≠ barrister（英式出庭大律师）≠ attorney/lawyer（美式律师）
**词根**：拉丁 solicitare（solicit 恳求/招揽）→ 招揽业务的人；同根 solicit 征求, solicitous 关切的

### 24. **enrollee** — 入伍者，入学者；（美）参保人
**核心**：⚠️ 拼写：**enrollee**（原文 erollee 拼写错误）；**被招收/登记在册**的人
**搭配**：new enrollees 新入学者/新参保人 / college enrollees 大学新生
**词根**：enrol(l)（登记，英式 enrol / 美式 enroll）+ -ee（被…者）→ 被登记的人

## 九、动作与事件

### 25. **parade** — 游行，阅兵；展示，炫耀
**核心**：n. **游行/阅兵**；v. **游行**；引申"**炫耀地展示**"
**搭配**：hold a parade 举行游行 / a military parade 阅兵 / parade one's knowledge 炫耀知识
**辨析**：parade（游行/炫耀展示）≠ march（行进，抗议/行军）≠ procession（队伍，宗教/仪式行列）
**词根**：拉丁 parare（准备，布置，展示）；同根 prepare 准备, apparatus 器械

### 26. **blast** — 爆炸；气浪；一阵强风/巨响；爆破
**核心**：n. **爆炸/冲击波**；也指"一阵（强风、巨响）"；v. **炸毁**
**搭配**：a bomb blast 炸弹爆炸 / blast off 发射升空 / a blast of wind 一阵狂风 / at full blast 全力/最大音量
**辨析**：blast（爆炸/气浪，也表"一阵猛击"）≠ explosion（爆炸，通用）≠ gust（一阵风）≠ bang（砰的一声）
**词根**：古英语 blǣst（吹气）；同根 blow 吹

### 27. **omit** — 省略，遗漏；忘记做
**核心**：**漏掉/略去**（该做的没做、该有的没写）
**搭配**：omit sth from 从…中删去 / omit doing sth 忘记做过某事 / omit to do sth 疏漏去做某事
**辨析**：⚠️ omit（遗漏/省略）≈ leave out ≠ delete（主动删除）≠ neglect（疏忽，未尽义务）
**词根**：o-（=ob 向）+ mit- = send（送）→ 放过去 → 遗漏；同根 emit 发出, transmit 传送

## 十、方式与程度

### 28. **incidentally** — 顺便一提，偶然地，附带地
**核心**：**顺带地/偶然地**；也作插入语"**顺便说一句**"（= by the way）
**搭配**：incidentally, ... 顺便提一下 / quite incidentally 纯属偶然 / incidental costs 附带费用
**辨析**：⚠️ incidentally（副词，顺便/偶然）≠ accidentally（意外地，出于失误）；形近 **incident** 事件
**词根**：in-（进入）+ cid- = fall（落下）+ -ent + -ly → 落到身上 → 偶然发生；同根 incident 事件, accident 事故

### 29. **automatically** — 自动地；无意识地
**核心**：**自动地**（机器）；引申"**不假思索、习惯性地**"
**搭配**：automatically update 自动更新 / the door closes automatically 门自动关闭 / automatically assume 想当然地认为
**词根**：auto-（自己）+ mat- = move/think（动/思）+ -ically → 自己动 → 自动；同根 automatic 自动的, automation 自动化

### 30. **relentless** — 不停的，持续的；严苛的，无情的
**核心**：**毫不松懈、不肯罢休**的（不因困难或求情而停）
**搭配**：relentless effort 不懈的努力 / relentless pursuit 不懈追求 / relentless pressure 持续不断的压力
**辨析**：⚠️ relentless（不松懈，中性偏褒）≠ continuous（连续，中性）≠ ruthless（残忍无情，贬义）
**词根**：re-（再）+ lent- = soft（软）+ -less（无）→ 不软下来 → 毫不留情；同根 relent 变宽容

### 31. **thrift** — 节俭，节约
**核心**：**精打细算、不乱花钱**（褒义）；也指"节俭机构"（thrift institution）
**搭配**：thrift and industry 节俭与勤劳 / a thrift shop 二手商店 / practise thrift 厉行节约
**辨析**：⚠️ thrift（节俭，中性偏褒）≠ frugality（节俭，正式书面）≠ economy（节约，也指经济）≠ stinginess（吝啬，贬义）
**词根**：与 thrive（兴旺）同源 → 会持家才兴旺；同根 thrifty 节俭的

## ⚠️ 形近词 / 近义词辨析（含场景偏好）

| 词对 | 区别（含使用场景偏好） |
|------|------|
| **adjacent** vs **near** | adjacent = 紧邻、接壤（正式，含"边界相接"）；near = 附近（通用，只表距离近） |
| **ample** vs **adequate** vs **sufficient** | ample = 充足有余（褒，强调多）；adequate = 刚好够/达标（中性）；sufficient = 足够（正式，重数量/证据） |
| **race** vs **ethnicity** | race = 生理/社会种族（宽泛）；ethnicity = 文化、语言、习俗上的族群归属（阅读社会类高频） |
| **lateral** vs **literal** | 形近：lateral = 侧面的/横向的；literal = 字面的 —— 勿混 |
| **shiver** vs **tremble** vs **shudder** | shiver = 因冷而轻颤；tremble = 因恐惧/激动而颤；shudder = 战栗（因厌恶/恐惧，最强） |
| **pant** vs **gasp** | pant = 急促喘气（运动后）；gasp = 猛吸一口气（惊讶/窒息） |
| **dosage** vs **dose** | dosage = 用药剂量/方案（偏整体）；dose = 一次服用的量（具体可数） |
| **solicitor** vs **barrister** vs **lawyer** | solicitor = 英式事务律师（不出庭）；barrister = 英式出庭大律师；lawyer/attorney = 美式律师 |
| **omit** vs **delete** vs **neglect** | omit = 遗漏/省略（无意或有意）；delete = 主动删除；neglect = 疏忽（未尽职责） |
| **incidentally** vs **accidentally** | 形近：incidentally = 顺便地/偶然地；accidentally = 意外地（出于失误） |
| **mould** vs **mold** | 英美拼写差异：模具/霉菌 — 英式 mould，美式 mold |
| **proceed** vs **procession** vs **parade** | parade = 游行/炫耀；procession = 队伍（宗教/仪式）；march = 行进（抗议/行军） |
| **disposition** vs **temperament** vs **personality** | disposition = 天生性情（正式）；temperament = 气质（天生）；personality = 个性（综合） |
| **relentless** vs **ruthless** vs **continuous** | relentless = 不松懈（中性偏褒）；ruthless = 残忍无情（贬）；continuous = 连续（中性） |
| **thrift** vs **frugality** vs **stinginess** | thrift = 节俭（中性偏褒）；frugality = 节俭（正式书面）；stinginess = 吝啬（贬义） |
| **genre** vs **category** | genre = 文艺体裁（文学/音乐/电影）；category = 类别（通用） |

| **be adjacent to** | "与…邻近"，固定接 to（阅读/完型高频） |
| **diversity and inclusion (D&I)** | "多元与包容"，社会/职场类阅读高频；反义 exclusion |
| **race vs ethnicity** | 社会类阅读必考：race 重生理，ethnicity 重文化归属 |
| **at full blast** | "全力/以最大音量"，blast 的固定短语；blast off 发射升空 |
| **omit to do / omit doing** | omit to do sth（疏漏做某事）vs omit doing sth（忘记做过）——完型易混 |
| **incidentally vs accidentally** | 形近必辨：incidentally = 顺便/偶然；accidentally = 意外（失误） |
| **scissors 恒复数** | 只能 a pair of scissors，无 a scissors 用法 |
| **mould / mold 英美差异** | 模具、霉菌：英式 mould = 美式 mold |
| **-ee 后缀表"被…者"** | enrollee（被招收者）= enrol + -ee；对比 employer（施动者） |
| **solicitor 多义** | 英式 = 事务律师；勿误当"推销员"；与 barrister 区分庭内庭外 |
| **underrepresentative 非标准** | 规范用 unrepresentative（不具代表性）或 underrepresented（占比偏低） |
| **ample / adequate 程度** | ample 富足有余，adequate 仅达标——程度题、写作选词需辨 |
| **practise thrift** | "厉行节约"；名词 thrift 常与 industry 并列（thrift and industry） |
