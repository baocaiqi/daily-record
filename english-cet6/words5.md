# 📚 CET-6 单词本 (5)

> 排版：每条单词 2-4 行解析，按优先级排列：核心 → 搭配 → 辨析 → 词根/记忆
> 标注：`⚠️` = 易混点/重点 | **加粗** = 核心要点

## 一、健康·公共卫生

### 1. **quarantine** — 隔离期；检疫
**核心**：**隔离/检疫**（公共健康类阅读高频）
**搭配**：in quarantine 在隔离期 / self-quarantine 自我隔离 / put sb in quarantine 将某人隔离
**词根**：quar- = forty（意大利语 quaranta → 威尼斯曾要求船只隔离 40 天）
**记忆**：quar-（四十）→ 40 天隔离 → quarantine

### 2. **pneumonia** — 肺炎
**核心**：**肺炎**（医学/公共卫生阅读常见）
**词根**：pneumon- = lung（肺）→ 衍生 pneumatic 气动的
**记忆**：⚠️ 首字母 **p 不发音**！类似 psychology, pterodactyl

## 二、政治·法律·外交

### 3. **governor** — 州长；总督；理事
**核心**：**州长/总督**（人）；与 government（政府）区分
**搭配**：the Governor of New York 纽约州州长 / board of governors 理事会
**辨析**：⚠️ governor（人：州长/管理者）≠ government（机构：政府）
**词根**：govern- = steer（掌舵，管理）→ govern, government, governance

### 4. **diplomacy** — 外交；外交手腕
**核心**：**外交/外交手腕**（国际关系类阅读高频）
**搭配**：shuttle diplomacy 穿梭外交 / quiet diplomacy 秘密外交 / dollar diplomacy 金元外交
**词根**：diploma-（官方文件/文凭）→ diplomacy, diplomat, diplomatic

### 5. **legitimate** — 合法的；合理的；正统的
**核心**：**合法+正当**（强调正当性，法律/政治类阅读核心词）
**搭配**：legitimate heir 合法继承人 / legitimate concern 合理的担忧 / legitimate business 合法生意
**辨析**：⚠️ legitimate（合法+正统，强调正当性）≠ legal（法律上的，偏技术性）≠ lawful（依法的，偏古雅）
**词根**：leg- = law（法律）→ legal, legislate, legislature

### 6. **legislature** — 立法机关
**核心**：⚠️ **立法机关**（原文"司法机关"有误！三权分立话题必考）
**辨析**：⚠️ legislature（立法机关）≠ judiciary（司法机关）≠ executive（行政机关）
**词根**：legis-（法律）+ lat-（提出，bring forward）→ 提出法律的机构

### 7. **intervention** — 干涉，介入，干预
**核心**：**干预/介入**（政治、经济、医疗）
**搭配**：government intervention 政府干预 / military intervention 军事干预 / medical intervention 医疗干预
**词根**：inter-（之间）+ ven-（来）→ 来到中间 → 介入 → intervene, convene, prevent
**记忆**：inter（之间）+ vent（来）→ 走到中间来 → 干预

### 8. **conspiracy** — 阴谋，共谋
**核心**：**阴谋/共谋**（社科类阅读常见）
**搭配**：conspiracy theory 阴谋论
**词根**：con-（共同）+ spir-（呼吸）→ 一个鼻孔出气
**参考**：已见于 words1 #14

### 9. **conspire** — 密谋；共同导致
**核心**：**密谋**；引申"共同导致"（拟人用法）
**搭配**：conspire against sb 密谋反对某人 / conspire to do sth 合谋做某事 / events conspired to... 各种因素凑在一起… / events conspired against us 事事都不顺（命运作对，高级表达）

## 三、运动·趋势·条件

### 10. **pendulum** — 钟摆
**核心**：**钟摆**；比喻"舆论/趋势的摇摆"
**搭配**：pendulum clock 摆钟 / the swing of the pendulum 钟摆的摆动（比喻舆论/趋势的转变）
**词根**：pend- = hang（悬挂）→ depend, suspend, pending
**记忆**：the pendulum has swung (back) 风水轮流转，风向变了（议论文比喻）

### 11. **spiral** — n./v. 螺旋（式上升/下降）
**核心**：**螺旋**式升降、失控恶化（经济/社会类图表作文常用）
**搭配**：spiral out of control 失控地急剧上升（或恶化）/ downward spiral 恶性循环，每况愈下 / inflationary spiral 螺旋式通胀
**参考**：已见于 words1 #11

### 12. **contingent** — adj. 视情况而定的 / n. 代表团
**核心**：**视…而定的**；名词"代表团"
**搭配**：be contingent on/upon sth 取决于…，受…影响
**辨析**：⚠️ contingent（取决于…的）≠ continent（大陆）
**词根**：con-（共同）+ ting-/tact-（接触，touch）→ 因接触而关联 → contact, tangible
**记忆**：contact（接触）→ contingent（接触才发生 → 视情况而定）

## 四、包含·闯入·遭遇

### 13. **enclose** — 围住；随函附上
**核心**：**围住/封入**；信函"随函附上"（正式信函/商务英语常用语）
**搭配**：enclose a cheque 附上支票 / please find enclosed... 随函附上…请查收 / enclose a garden with a fence 用篱笆围住花园
**词根**：en-（使，进入）+ close（关闭）→ 关在里面

### 14. **encompass** — 包含，包括；围绕
**核心**：**包含/涵盖**（学术写作高频替换 include/cover）
**搭配**：encompass a wide range of 涵盖广泛的 / encompass all aspects of 涵盖…的方方面面
**词根**：en-（使进入）+ compass（范围，罗盘）→ 纳入范围之内 → 包含
**记忆**：compass 是罗盘/范围 → encompass 是把…圈进范围 → 包含

### 15. **encounter** — v./n. 遭遇；邂逅；经历
**核心**：**遭遇/邂逅**（较正式，含意外意味）
**搭配**：encounter difficulties/problems 遇到困难 / a chance encounter 偶遇，邂逅 / close encounter 近距离接触
**辨析**：⚠️ encounter（遭遇/邂逅，正式）≠ meet（遇见，最通用）

### 16. **intrude on/into** — 闯入；侵扰；打断
**核心**：**闯入/侵扰**（隐私、谈话），社会/伦理类阅读
**搭配**：intrude on one's privacy 侵犯隐私 / intrude into a conversation 打断谈话 / I don't mean to intrude 我不是有意打扰
**词根**：trud- = thrust（推，插入）→ intrude（往里推 → 闯入），extrude（往外推 → 挤出），protrude（往前推 → 突出）

## 五、港口·仪式·生死

### 17. **harbour** — n. 港口 / v. 庇护；心怀（情感）
**核心**：名词**港口**；动词**庇护/心怀（情感）**
**搭配**：safe harbour 避风港 / harbour a grudge 心怀怨恨 / harbour doubts 心怀疑虑 / harbour a criminal 窝藏罪犯
**辨析**：⚠️ harbour（英式）= harbor（美式）

### 18. **procession** — 队伍，行列
**核心**：**行进中的队伍**（仪式/送葬）
**搭配**：funeral procession 送葬队伍 / in procession 列队行进 / wedding procession 婚礼队伍
**辨析**：⚠️ procession（队列，仪式）≠ parade（游行/阅兵，偏庆祝）
**词根**：pro-（向前）+ cess-（走，go）→ 向前走 → process, proceed

### 19. **cemetery** — 公墓，墓地
**核心**：**公墓**（非教堂所属）
**辨析**：⚠️ cemetery（公墓，非教堂所属）≠ graveyard（教堂墓地）≠ tomb（坟墓单体）
**记忆**：⚠️ 拼写 ceme**t**ery，容易错写成 cemetary；里面全是 e（ce-m-e-t-e-ry，一个 a 都没有）

## 六、人·身份·表达

### 20. **chap** — 小伙子，家伙
**核心**：**家伙/小伙子**（英式英语日常口语高频，美式较少用）
**搭配**：old chap 老兄（英式口语）/ a decent chap 一个体面的小伙子 / poor chap 可怜的家伙
**辨析**：⚠️ chap（英式口语）≈ guy（美式口语），英式阅读常见人物称呼

### 21. **people of all stripes** — 各种类型的人，三教九流
**核心**：**形形色色的人**（of all stripes = of all kinds/types/backgrounds）
**搭配**：politicians of all stripes 各党派政治家 / people of all stripes and colors 形形色色的人
**记忆**：stripe（条纹）→ 不同条纹 → 不同类型/派别

### 22. **make one's debut** — 首次登场，首秀
**核心**：**首次亮相/首秀**
**搭配**：make one's debut 首次亮相 / debut album 首张专辑 / debut performance 首场演出 / debut novel 处女作
**记忆**：debut 源自法语 début（开始，开端）；make one's grand debut 盛大登场

### 23. **soil your hands** — 弄脏你的手
**核心**：**弄脏手**；比喻"参与不光彩之事"
**搭配**：soil one's hands (with sth) 弄脏手（也比喻参与不光彩之事）/ not soil one's hands 不愿弄脏手（不屑为伍）
**辨析**：⚠️ soil（弄脏，较正式/文学）≠ dirty（弄脏，口语通用）

### 24. **naked** — 裸体的；赤裸裸的
**核心**：**裸体的**；引申"赤裸裸的"（文学/描述性阅读常见）
**搭配**：naked eye 肉眼 / stark naked 一丝不挂 / the naked truth 赤裸裸的事实 / naked flame 明火
**辨析**：⚠️ naked（裸体，通用）≠ nude（裸体，偏艺术/正式/摄影）≠ bare（光秃的，如 bare foot 赤脚）

### 25. **headhunter** — 猎头；物色人才的人
**核心**：**猎头/挖人才的人**
**搭配**：corporate headhunter 企业猎头 / executive headhunter 高管猎头
**记忆**：head（头脑，人才）+ hunter（猎人）→ 猎人才的人 → 猎头；headhunt 作动词："I got headhunted by Google." 我被谷歌挖走了。

## 七、证据·解释

### 26. **anecdotal** — 轶事的，趣闻的；传闻的
**核心**：**传闻的/轶事的**（缺乏科学依据，批判性阅读术语）
**搭配**：anecdotal evidence 传闻性证据（不严谨的证据）
**词根**：an-（不，未）+ ec-/ex-（出）+ dot-（给，give）→ 未公开给出的（故事）→ anecdote 轶事 → anecdotal
**记忆**：anecdote（轶事，小故事）→ anecdotal（轶事的）；阅读中常表"不足为据"

### 27. **explicatory** — 解释的，说明的
**核心**：**解释性的**（较正式/学术）
**辨析**：⚠️ explicatory（解释性的，正式/学术）≈ explanatory（解释的，更常用）
**词根**：ex-（向外）+ plic-（折叠，fold）→ 向外展开 → 解释；同根 explicit 明确的, implicit 含蓄的, complicate 复杂的

## 八、金钱·生活

### 28. **lucrative** — 获利多的，赚钱的
**核心**：**有利可图的**（经济/商业类阅读高频）
**搭配**：a lucrative business/deal 有利可图的生意 / a lucrative career 高薪职业
**词根**：lucr- = gain/profit（利润）→ lucrative, lucre（钱财，贬义）
**记忆**：lucre（钱，谐音"路阔"有钱路才阔）→ lucrative 有利可图的

### 29. **purse** — 钱包（女式）
**核心**：**女式钱包**（英式：零钱包；美式：手提包/钱包）
**搭配**：tighten the purse strings 紧缩开支 / hold the purse strings 掌管财务 / coin purse 零钱包
**辨析**：⚠️ purse（女式钱包）≠ wallet（男士钱包）；the public purse 国库，公共资金

### 30. **penny** — 便士；美分
**核心**：**便士/美分**；复数 pence（英，金额）/ pennies（美，硬币个数）
**搭配**：not a penny 一文不名 / a penny for your thoughts 你在想什么呢？/ every penny counts 每一分钱都很重要
**记忆**：A penny saved is a penny earned. 省一分就是赚一分。（富兰克林名言）/ penny-wise, pound-foolish 小钱精明大钱糊涂

### 31. **shell** — n. 壳 / v. 剥壳
**核心**：**壳**；shell out 不情愿地掏大钱（惯用）
**搭配**：shell out (for sth) 付一大笔钱 / come out of one's shell 不再害羞，开始活跃 / turtle shell 乌龟壳 / shell corporation 空壳公司
**记忆**：shell out → 像剥壳一样"掏"出钱来

## 九、容器·器物·动作

### 32. **jug** — 壶，罐（带柄和嘴）
**核心**：**带柄和嘴的壶**（英式）
**搭配**：milk jug 牛奶壶 / a jug of water 一壶水 / measuring jug 量杯
**辨析**：⚠️ jug（带柄和嘴的壶）≠ jar（广口罐，储物用）≠ mug（杯子，喝水用）≠ pitcher（大水罐，美式）

### 33. **disc** — 磁盘；圆盘
**核心**：**圆盘/磁盘**
**搭配**：hard disc 硬盘 / disc drive 磁盘驱动器 / compact disc (CD) 光盘 / slipped disc 椎间盘突出
**辨析**：⚠️ disc（英式）= disk（美式）

### 34. **trunk** — 树干；象鼻；行李箱
**核心**：一词多义：**树干/象鼻/汽车后备箱**
**搭配**：tree trunk 树干 / swimming trunks 泳裤 / trunk call 长途电话（英式旧用法）
**辨析**：⚠️ trunk（汽车后备箱，美式）= boot（英式）
**记忆**：一根树干 → 大象鼻子像树干 → 行李箱也像树干一样粗大 → trunk 三义同一词

### 35. **vapour** — 蒸汽，水汽
**核心**：**水蒸气**（英式拼写）
**搭配**：water vapour 水蒸气
**辨析**：⚠️ vapour（英式）= vapor（美式）
**词根**：vap- = steam → vapour, evaporate（蒸发）, vapid（索然无味的，像蒸汽一样没味道）

### 36. **sift** — v. 筛；仔细审查
**核心**：**筛/仔细筛查**
**搭配**：sift through sth 仔细筛查 / sift flour 筛面粉 / sift out 筛除，筛选出
**记忆**：联想 sieve（筛子，名词）→ sift（筛的动作，动词）；sift through piles of documents 在成堆的文件中仔细翻找

## 十、动植物

### 37. **mosquito** — 蚊子
**核心**：**蚊子**
**搭配**：mosquito net 蚊帐 / mosquito repellent 驱蚊剂 / mosquito bite 蚊子叮咬
**记忆**：西班牙语 mosca（苍蝇）+ -ito（小后缀）→ 小苍蝇 → 蚊子

### 38. **pea** — 豌豆
**核心**：**豌豆**；常用复数 peas
**搭配**：green peas 青豌豆 / like two peas in a pod 一个模子里刻出来的，一模一样
**记忆**：pea soup 豌豆汤；"They are like two peas in a pod." 形容两人极其相似

### 39. **garlic** — 大蒜
**核心**：**大蒜**
**搭配**：garlic bread 蒜香面包 / a clove of garlic 一瓣蒜 / garlic press 压蒜器 / garlic breath 大蒜味口气
**记忆**：gar-（像矛 gar）+ lic（像韭 leek）→ 大蒜

### 40. **shrub** — 灌木
**核心**：**灌木**（单株可观赏）
**搭配**：evergreen shrub 常绿灌木 / flowering shrub 开花灌木
**辨析**：⚠️ shrub（灌木，单株）≠ bush（灌木丛，成片）≠ tree（树，有明显主干）≠ herb（草本植物）

### 41. **cattle** — 牛（总称，集合名词）
**核心**：⚠️ 牛的**集合名词**，不可数但谓语用复数：The cattle **are** grazing.
**搭配**：a herd of cattle 一群牛 / dairy cattle 奶牛 / beef cattle 肉牛
**辨析**：⚠️ cattle（总称）≠ cow（母牛/奶牛）≠ ox（阉公牛，干活用）≠ bull（公牛，斗牛用）

### 42. **ox** — 牛（阉公牛，用于劳作）
**核心**：**阉公牛**（干活的牛）；复数 oxen
**搭配**：as strong as an ox 像牛一样强壮
**辨析**：⚠️ ox（阉公牛，干活）≠ bull（未阉公牛，斗牛）≠ cow（母牛/奶牛）≠ cattle（牛的总称）

### 43. **goose** — 鹅
**核心**：**鹅**；复数 geese
**搭配**：roast goose 烤鹅 / wild goose chase 徒劳的追寻 / cook one's goose 毁掉某人的机会/前途
**记忆**："Your goose is cooked!" 你完蛋了！/ what's good for the goose is good for the gander 一碗水端平

### 44. **cock** — 公鸡
**核心**：**公鸡**（英式）
**搭配**：cock crow 公鸡打鸣 / cock fight 斗鸡
**辨析**：⚠️ cock（英式：公鸡；口语另有粗俗义，正式写作慎用）≠ rooster（美式：公鸡，安全通用）

### 45. **ape** — n. 猿 / v. 模仿
**核心**：名词**猿**（无尾）；动词**模仿**
**搭配**：go ape 发狂，暴跳如雷 / ape sb's style 模仿某人的风格
**辨析**：⚠️ ape（猿，无尾）≠ monkey（猴子，有尾）

## ⚠️ 形近词 / 近义词辨析（含场景偏好）

| 词对 | 区别（含使用场景偏好） |
|------|------|
| **contingent** vs **continent** | contingent = 取决于…的 / 代表团；continent = 大陆 |
| **governor** vs **government** | governor = 州长/管理者（人）；government = 政府（机构） |
| **legislature** vs **judiciary** vs **executive** | legislature = 立法机关；judiciary = 司法机关；executive = 行政机关 |
| **legitimate** vs **legal** vs **lawful** | legitimate = 合法+正统（强调正当性）；legal = 法律上的（偏技术）；lawful = 依法的（偏古雅/正式） |
| **cemetery** vs **graveyard** vs **tomb** | cemetery = 公墓（非教堂所属）；graveyard = 教堂墓地；tomb = 坟墓单体 |
| **naked** vs **nude** vs **bare** | naked = 裸体（通用，也比喻赤裸裸的）；nude = 裸体（艺术/摄影）；bare = 光秃的（bare foot 赤脚） |
| **jug** vs **jar** vs **mug** vs **pitcher** | jug = 带柄和嘴的壶（英式）；jar = 广口罐（储物）；mug = 杯子（喝水）；pitcher = 大水罐（美式）= jug（英式） |
| **purse** vs **wallet** | purse = 女式钱包/零钱包（英式）；wallet = 男士钱包 |
| **disc** vs **disk** | disc（英式）= disk（美式） |
| **vapour** vs **vapor** | vapour（英式）= vapor（美式） |
| **trunk** vs **boot** | trunk = 汽车后备箱（美式）；boot = 汽车后备箱（英式） |
| **ox** vs **bull** vs **cow** vs **cattle** | ox = 阉公牛（干活）；bull = 未阉公牛（斗牛）；cow = 母牛/奶牛；cattle = 牛的总称（不可数集合名词，谓语用复数） |
| **ape** vs **monkey** | ape = 猿（无尾）；monkey = 猴子（有尾） |
| **shrub** vs **bush** vs **tree** vs **herb** | shrub = 灌木（单株）；bush = 灌木丛；tree = 树（有主干）；herb = 草本植物 |
| **cock** vs **rooster** | cock = 公鸡（英式，口语另有粗俗义慎用）；rooster = 公鸡（美式，安全通用） |
| **explicatory** vs **explanatory** | explicatory = 解释的（正式/学术）≈ explanatory（更常用） |
| **procession** vs **parade** | procession = 队列（送葬/仪式）；parade = 游行/阅兵（庆祝） |
| **soil** vs **dirty** | soil = 弄脏（正式/文学）；dirty = 弄脏（口语通用） |
| **encounter** vs **meet** | encounter = 遭遇/邂逅（较正式，含意外意味）；meet = 遇见（最通用） |

## 🎯 高频考点速记

| 考点 | 说明 |
|------|------|
| **cattle 的谓一致** | cattle 不可数但谓语必用复数！例：Cattle **are** raised here. |
| **trunk 的英美差异** | 汽车后备箱：trunk（美）= boot（英）；泳裤：swimming trunks |
| **legislature ≠ judiciary** | 三权分立：legislature（立法）/ executive（行政）/ judiciary（司法） |
| **intrude 的词根 trud-** | 各种"推"：intrude 往里推（闯入），extrude 往外推（挤出），protrude 向前推（突出） |
| **plic- 词根家族** | explicit 展开的 → 明确的 / implicit 折里面的 → 含蓄的 / complicate 折一起 → 复杂的 |
| **pendulum 的比喻义** | the pendulum has swung = 舆论/趋势已转变（议论文万能表达） |
| **anecdotal evidence** | 阅读常见批判性论证术语 = "传闻证据，不足为据" |
| **pneumonia 发音** | 首字母 p 不发音（类似 psychology, pterodactyl），听力易错 |
| **harbour = harbor** | 英美拼写差异；harbour a grudge 心怀怨恨 |
