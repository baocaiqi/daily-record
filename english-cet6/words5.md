### ⚠️ 形近词 / 近义词辨析

| 词对 | 区别 |
|------|------|
| **contingent** vs **continent** | contingent = 取决于…的 / 代表团；continent = 大陆 |
| **governor** vs **government** | governor = 州长/管理者（人）；government = 政府（机构） |
| **legislature** vs **judiciary** vs **executive** | legislature = 立法机关；judiciary = 司法机关；executive = 行政机关 |
| **legitimate** vs **legal** vs **lawful** | legitimate = 合法+正统（强调正当性）；legal = 法律上的（偏技术）；lawful = 依法的（偏古雅/正式） |
| **cemetery** vs **graveyard** vs **tomb** | cemetery = 公墓（非教堂所属）；graveyard = 教堂墓地；tomb = 坟墓单体 |
| **naked** vs **nude** vs **bare** | naked = 裸体（通用，也比喻赤裸裸的）；nude = 裸体（艺术/摄影）；bare = 光秃的（bare foot 赤脚） |
| **jug** vs **jar** vs **mug** vs **pitcher** | jug = 带柄和嘴的壶（英式 pitcher）；jar = 广口罐（储物）；mug = 杯子（喝水）；pitcher = 大水罐（美式）= jug（英式） |
| **purse** vs **wallet** | purse = 女式钱包/零钱包（英式）；wallet = 男士钱包 |
| **disc** vs **disk** | disc（英式）= disk（美式） |
| **vapour** vs **vapor** | vapour（英式）= vapor（美式） |
| **trunk** vs **boot** | trunk = 汽车后备箱（美式）；boot = 汽车后备箱（英式） |
| **ox** vs **bull** vs **cow** vs **cattle** | ox = 阉公牛（干活）；bull = 未阉公牛（斗牛）；cow = 母牛/奶牛；cattle = 牛的总称（不可数集合名词，谓语用复数） |
| **ape** vs **monkey** | ape = 猿（无尾）；monkey = 猴子（有尾） |
| **shrub** vs **bush** vs **tree** vs **herb** | shrub = 灌木（单株）；bush = 灌木丛；tree = 树（有主干）；herb = 草本植物 |
| **cock** vs **rooster** | cock = 公鸡（英式，口语另有粗俗义慎用）；rooster = 公鸡（美式，安全通用） |
| **explicatory** vs **explanatory** | explicatory = 解释的（正式/学术）= explanatory（更常用） |
| **procession** vs **parade** | procession = 队列（送葬/仪式）；parade = 游行/阅兵（庆祝） |
| **soil** vs **dirty** | soil = 弄脏（正式/文学）；dirty = 弄脏（口语通用） |
| **encounter** vs **meet** | encounter = 遭遇/邂逅（较正式，含意外意味）；meet = 遇见（最通用） |

| 考点 | 说明 |

| **cattle 的谓一致** | cattle 不可数但谓语必用复数！例：Cattle **are** raised here. |

| **plic- 词根家族** | explicit 展开的 → 明确的 / implicit 折里面的 → 含蓄的 / complicate 折一起 → 复杂的 |
