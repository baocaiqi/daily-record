# 📚 CET-6 单词本 (7)

> 排版：每条单词 2-4 行解析，按优先级排列：核心 → 搭配 → 辨析 → 词根/记忆
> 标注：`⚠️` = 易混点/重点 | **加粗** = 核心要点

## 一、社会与政治

### 1. **activist** — 积极分子，活动家，激进分子
**核心**：参与**社会/政治运动**的活动家（社会运动/政治类阅读高频）
**搭配**：political activist 政治活动家 / human rights activist 人权活动人士 / environmental activist 环保活动人士 / student activist 学生积极分子
**辨析**：⚠️ activist（活动家，偏社会/政治运动）≠ extremist（极端分子，贬义）
**词根**：act- = 做/驱动 → act → active → activist

### 2. **unrest** — 动荡，骚乱，不安
**核心**：社会的**不安定/动荡**（集体层面，国际政治/社会类阅读关键词）
**搭配**：social unrest 社会动荡 / civil unrest 内乱 / labour unrest 劳工骚动 / growing unrest 日益加剧的不安
**辨析**：⚠️ unrest（社会/政治动荡，集体）≠ restlessness（个人的焦躁不安）
**词根**：un-（不）+ rest（安宁）→ 不安宁 → 动荡

### 3. **unification** — 统一，联合
**核心**：**统一**（政治/国家层面）
**搭配**：the unification of Germany 德国统一 / national unification 国家统一 / unification process 统一进程 / unification treaty 统一条约
**辨析**：⚠️ unification（统一）≠ reunification（重新统一）≠ unity（团结，抽象名词）≠ union（联盟，组织）
**词根**：uni- = 一 + fic- = 做 → 做成一个；记忆链 uni- → unite → unified → unification

### 4. **unification of a country** — 国家统一
**核心**：**国家统一**（政治/历史语境）
**搭配**：achieve the unification of a country 实现国家统一 / peaceful unification 和平统一
**场景**：政治/历史类阅读

### 5. **liberalize** — 使自由化，放宽限制
**核心**：让政策/制度**更自由**、放宽限制
**搭配**：liberalize trade 贸易自由化 / liberalize the economy 经济自由化 / liberalize immigration laws 放宽移民法
**辨析**：⚠️ liberalize（政策/制度层面自由化）≠ liberate（解放，使人获自由）
**词根**：liber- = 自由 → liberal → liberalize；同根 liberty 自由, liberal 开明的, liberate 解放

### 6. **misconduct** — 不端行为，失职 / 管理不当
**核心**：**不正当行为/失职**（正式用语，法律/职场/学术场景）
**搭配**：professional misconduct 职业不端行为 / sexual misconduct 性行为不端 / scientific misconduct 学术不端 / gross misconduct 严重渎职
**辨析**：⚠️ misconduct（不端行为，正式）≠ wrongdoing（坏事，通用）≠ malpractice（渎职，偏医疗/法律）
**词根**：mis-（错误）+ conduct（行为，管理）→ 错误行为

## 二、比例与相称

### 7. **disproportionate** — 不成比例的，不相称的
**核心**：⚠️ 原文"不合安排"有误，正确释义为**不成比例的**
**搭配**：disproportionate impact 不成比例的影响 / a disproportionate share 不成比例的份额 / disproportionate punishment 量刑过重
**辨析**：⚠️ disproportionate（不成比例，偏抽象/社会/法律）≠ disproportional（偏数学/统计）；前者使用更广
**词根**：dis-（不）+ proportion（比例）+ -ate → 比例不对的

### 8. **proportionate** — 成比例的，相称的
**核心**：**相称的、按比例的**（proportion → proportionate）
**搭配**：proportionate response 相称的回应 / proportionate increase 按比例增长 / be proportionate to 与…成比例
**辨析**：⚠️ proportionate（相称/均衡）≈ proportional（数学上的比例关系）≠ disproportionate（不成比例，反义）
**词根**：pro-（按照）+ port-（份）+ -ate → 按份分配的 → 成比例的

## 三、情绪与品格

### 9. **grieve** — 使悲伤；感到悲痛
**核心**：⚠️ 原文误标为"悲伤的"（形容词），grieve 是**动词**"悲痛"
**搭配**：grieve over sth 为某事悲痛 / grieve for sb 为某人哀悼 / grieve the loss of 为失去…而悲伤 / it grieves me to say 我很难过地说；惯用 "She is still grieving for her husband." 她仍在为丈夫悲痛
**辨析**：⚠️ grieve（动词）≠ grief（名词）≠ grieved / grievous / grieving（形容词）
**词根**：grav- = 重 → 心情沉重；同根 grave 坟墓, gravity 重力, aggravate 加重, grief 悲痛

### 10. **drained** — 精疲力尽的，耗尽的
**核心**：被"**抽干**"的 → 精疲力尽（身心俱疲）
**搭配**：feel drained 感到筋疲力尽 / emotionally drained 情感耗尽的 / financially drained 财力耗尽的
**惯用**："I feel completely drained after that meeting." 开完那个会后我完全精疲力尽了。
**词根**：drain（排水，耗尽）+ -ed → 被抽干；记忆：排水管 drain → 能量被排干

### 11. **dire** — 严重的，可怕的，极端的
**核心**：**极其严重/可怕**（灾难性语气）
**搭配**：dire consequences 严重后果 / dire straits 困境，绝境 / in dire need of 迫切需要… / dire poverty 赤贫
**辨析**：⚠️ dire（极端严重/可怕，偏灾难性）≠ serious（严肃，通用）≠ severe（严峻，程度重）≠ urgent（紧急的）
**惯用**："The country is in dire economic straits." 该国陷入了严重的经济困境。

### 12. **gracious** — 慈祥的，和蔼的；优雅的；仁慈的
**核心**：**亲切仁慈的**（上位者对下位者，褒义）
**搭配**：a gracious smile 慈祥的微笑 / a gracious host 亲切好客的主人 / gracious living 优雅的生活；惯用 "She was gracious enough to forgive me." 她宽宏大量地原谅了我
**辨析**：⚠️ gracious（仁慈亲切，态度）≠ graceful（优美，动作/形态）≠ grateful（感激）— 常见混淆词
**词根**：grac-/grat- = 愉悦/感恩 → grace → gracious；同根 graceful, grateful, gratitude

### 13. **inarticulate** — 不善言辞的；口齿不清的；难以言表的
**核心**：**说不清楚、表达不好**的（与 articulate 为反义词对）
**搭配**：inarticulate speaker 不善言辞的发言者 / inarticulate with rage 气得说不出话 / inarticulate speech 口齿不清的讲话
**辨析**：⚠️ inarticulate（表达能力差）≠ incoherent（语无伦次，逻辑乱）≠ mute（哑，生理）≠ taciturn（沉默寡言，性格）
**词根**：in-（不）+ articulate（清晰表达的）→ 不能清晰表达的

### 14. **unbiased** — 公平的，无偏见的，不偏袒的
**核心**：**没有偏见、客观中立**（描述评价/判断立场常用）
**搭配**：unbiased opinion 公正的意见 / an unbiased judge 不偏不倚的法官 / unbiased reporting 客观报道 / unbiased sample 无偏样本（统计术语）
**辨析**：⚠️ unbiased（无偏见，客观中立）≠ fair（公平，通用）≠ impartial（不偏不倚，正式/法律）≈ disinterested（无私心，无利益关系）
**词根**：un-（不）+ bias（偏见）+ -ed

## 四、动摇与不稳

### 15. **shaky** — 颤抖的；不稳定的，不可靠的
**核心**：**摇摇晃晃**的 → 不稳定、不可靠
**搭配**：a shaky hand 颤抖的手 / a shaky economy 不稳定的经济 / shaky evidence 不可靠的证据；惯用 "The company's finances are on very shaky ground." 该公司财务状况很不稳定
**辨析**：⚠️ shaky（不稳/不可靠）≈ unstable（不稳定）≠ steady（稳定，反义）
**词根**：shake（摇动）+ -y → 摇摇晃晃的

### 16. **a shaky economy** — 不稳定的经济
**核心**：**动荡不稳**的经济状况
**搭配**：suffer from a shaky economy 经济动荡 / revive a shaky economy 重振疲软经济

### 17. **on shaky ground** — 站不住脚，基础不稳
**核心**：**立场/基础不牢**（比喻义）
**搭配**：be on shaky ground 底气不足 / put sb on shaky ground 使某人陷入不利境地
**惯用**："Legally speaking, we're on shaky ground." 从法律上讲，我们的立场站不住脚。

## 五、文书与赌注

### 18. **filing** — 存档，归档；存档文件
**核心**：**归档/存档**（文件）
**搭配**：filing cabinet 文件柜 / filing system 归档系统 / court filing 法院备案 / patent filing 专利申请
**辨析**：⚠️ filing（归档/存档）≠ file（文件/文件夹）≠ filling（填充）— 一字之差
**词根**：fil- = 线 → 古时文件用线串起来 → file → filing

### 19. **a bankruptcy filing** — 破产申请（文件）
**核心**：向法院提交的**破产申请**
**搭配**：submit a bankruptcy filing 提交破产申请 / prepare a bankruptcy filing 准备破产文件
**场景**：法律/商业类阅读

### 20. **wager** — 打赌，赌注
**核心**：**打赌/赌注**（偏正式、文学）
**搭配**：make a wager 打个赌 / place a wager on 在…上下注 / a friendly wager 友好的打赌
**辨析**：⚠️ wager（打赌，正式/文学）≈ bet（口语中最常用）
**惯用**："I'll wager you a dinner that he shows up late." 我赌他一顿晚餐他肯定会迟到。

### 21. **make a wager** — 打赌
**核心**：**和人打赌**
**搭配**：make a wager with sb 和某人打赌 / make a wager on the outcome 在结果上下注

## 六、转变与永恒

### 22. **turnaround** — 周转时间；转变，好转
**核心**：**好转/逆转**（商业/经济类阅读高频）+ **周转时间**
**搭配**：a quick turnaround 快速周转 / economic turnaround 经济好转 / a dramatic turnaround 戏剧性的逆转 / turnaround time 周转时间
**辨析**：⚠️ turnaround（情况好转）≈ recovery（复苏）≠ downturn（衰退，反义）
**词根**：turn（转）+ around（回）→ 转回来 → 情况好转

### 23. **perpetuity** — 永恒，永久
**核心**：⚠️ 原文误标为"永恒的"（形容词），perpetuity 是**名词**"永久"
**搭配**：in perpetuity 永久地 / in perpetuity and forever 永永远远
**辨析**：⚠️ perpetuity（名词）≠ perpetual（形容词，永久的）
**词根**：per-（贯穿）+ pet-（追求）+ -uity → 一直追求下去 → 永恒；记忆：perpetual motion 永动机

## 七、人物与学术

### 24. **rector** — 教区牧师；（大学）校长，院长
**核心**：**（教区）牧师 / （大学）校长**
**搭配**：parish rector 教区牧师 / university rector 大学校长 / rector of the church 教堂牧师
**辨析**：⚠️ rector（英式大学校长/教区牧师）≠ president（美式大学校长）≠ principal（中小学校长）≠ chancellor（名誉校长）
**词根**：rect- = 统治/直 → rector 管理者；同根 direct 指引, correct 纠正, rectangle 矩形, rectify 矫正

### 25. **geneticist** — 基因学家，遗传学家
**核心**：研究**基因/遗传**的科学家
**搭配**：molecular geneticist 分子遗传学家 / a leading geneticist 顶尖遗传学家
**词根**：gen- = 出生/种类 → gene → genetics → geneticist；同根 generate 产生, generation 代, genesis 起源

### 26. **interdisciplinary** — 跨学科的
**核心**：⚠️ 原文拼写 interdisplinary 有误，正确为 **interdisciplinary**（学术/教育类阅读高频）
**搭配**：interdisciplinary research 跨学科研究 / interdisciplinary approach 跨学科方法 / interdisciplinary team 跨学科团队
**辨析**：⚠️ interdisciplinary（跨学科，学科间融合）≠ multidisciplinary（多学科参与但不融合）≠ transdisciplinary（超学科，超越学科界限）
**词根**：inter-（之间）+ discipline（学科）+ -ary

### 27. **diffusionism** — 传播论（人类学/文化传播理论）
**核心**：文化**向外传播扩散**的理论（人类学）
**搭配**：cultural diffusionism 文化传播论
**词根**：dif-/dis-（分开）+ fus-（流）+ -ism → 文化向四面八方流动；记忆链 diffuse → diffusion → diffusionism；同根 confuse 混淆, refuse 拒绝, fuse 融合

### 28. **biomass** — 生物量；生物质能
**核心**：**生物质**（总量/能源，环保/能源类阅读高频）
**搭配**：biomass energy 生物质能 / biomass fuel 生物燃料 / plant biomass 植物生物量 / above-ground biomass 地上生物量
**词根**：bio- = 生命 + mass（质量，物质）→ 生物的总质量

## 八、求偶与反射

### 29. **courtship** — 求偶期；求爱期；追求期
**核心**：⚠️ 原文拼写 coutership 有误，正确为 **courtship** — 求偶/求爱（期）
**搭配**：courtship ritual 求偶仪式 / courtship period 求偶期 / courtship display 求偶展示；惯用 "Their courtship lasted three years before they married." 他们的恋爱期持续了三年才结婚
**词根**：court（求爱）+ -ship（名词后缀）；注意 court 一词两义：法庭 / 求爱；同根 courtesy 礼貌

### 30. **a knee-jerk reflex** — 膝跳反射
**核心**：**膝跳反射**；引申"不假思索的本能反应"
**搭配**：test the knee-jerk reflex 检查膝跳反射 / knee-jerk reaction 本能反应（比喻义）
**惯用**："His opposition was just a knee-jerk reaction." 他的反对只是一种本能反应罢了。
**记忆**：knee（膝盖）+ jerk（猛的一动）→ 敲膝盖小腿一弹 → 膝跳反射

## 九、建筑与地理

### 31. **inn** — 小旅馆，客栈
**核心**：**乡村小客栈**（传统、温馨）
**搭配**：a country inn 乡村客栈 / holiday inn 假日酒店 / stay at an inn 住在客栈 / roadside inn 路边客栈
**辨析**：⚠️ inn（乡村小旅馆，传统温馨）≠ hotel（现代大型酒店）≠ motel（汽车旅馆，路边）≠ hostel（青年旅社）
**记忆**：inn 小而温馨，类似"隐"居地

### 32. **enclosure** — 围场，圈地；附件（邮件中）
**核心**：⚠️ 原文释为"围住"（动词），enclosure 是**名词**"围场/附件"
**搭配**：an enclosure for animals 动物围场 / see enclosure 见附件 / the enclosure movement 圈地运动
**辨析**：⚠️ enclosure（围场/附件）≠ enclose（动词，围住）≠ closure（关闭，名词）
**词根**：en-（使）+ clos-（关）+ -ure → 关起来的地方；考点："圈地运动"是英国历史背景知识点

### 33. **orb** — 球体，天体；宝球（王权象征）
**核心**：**球体/天体**；英国王权宝球
**搭配**：a golden orb 金色圆球 / the celestial orbs 天体（文学）/ orb of the sun 太阳天体 / the royal orb 王权宝球
**词根**：orb- = 圆/球 → orb → orbit（轨道）→ orbital；同根 orbit, exorbitant

### 34. **gravel** — 砾石，沙砾 / 用砾石铺路
**核心**：⚠️ 原文释为"沙粒"不够准确，gravel 是**砾石/碎石**（粒径 2-64mm，多棱角，铺路用）
**搭配**：gravel road 砾石路 / a gravel path 碎石小径 / gravel driveway 砾石车道 / gravel pit 采石场
**辨析**：⚠️ gravel（砾石，多棱角）≠ sand（沙粒，细）≠ pebble（鹅卵石，光滑）
**记忆**：gravel 走在上面 gravel gravel 响

## 十、动物与时尚

### 35. **ostrich** — 鸵鸟；逃避现实的人
**核心**：**鸵鸟**；比喻**逃避现实的人**
**搭配**：ostrich policy 鸵鸟政策（自欺欺人）/ bury one's head in the sand like an ostrich 像鸵鸟一样把头埋进沙里 / ostrich feather 鸵鸟羽毛
**惯用**："Stop being an ostrich and face reality!" 别当鸵鸟了，面对现实吧！
**记忆**：鸵鸟遇险把头埋进沙里 → 比喻逃避现实

### 36. **on-trend** — 时髦的，潮流的
**核心**：**当季潮流**的（时尚/消费语境）
**搭配**：on-trend fashion 时髦的时装 / on-trend colour 流行色 / stay on-trend 保持时尚
**辨析**：⚠️ on-trend（当季潮流，偏消费/时尚）≠ trendy（时髦，可带贬义"赶时髦"）≠ fashionable（时尚，最通用）≠ stylish（有格调，偏品味）
**场景**：时尚/消费类口语和文章

## 十一、逃避与余波

### 37. **elude** — 逃避，躲避；使不能达到
**核心**：**逃脱/躲开**；使（答案/睡意等）达不到
**搭配**：elude capture 逃避抓捕 / elude the police 躲避警察 / sleep eludes me 我无法入睡
**辨析**：⚠️ elude（逃避/使达不到）≠ allude（暗指）≠ delude（欺骗误导）— 同根词
**词根**：e-（出）+ lud-（玩）→ 玩到外面去 → 溜走；同根 allude, delude, illusion；惯用 "The exact meaning eludes me." 我琢磨不透确切含义

### 38. **elusive** — 难以获得（或达到/捕捉/描述）的；逃避的
**核心**：**难以捉摸、难以达到**的
**搭配**：an elusive goal 难以达到的目标 / elusive concept 难以理解的概念 / elusive criminal 在逃罪犯 / a most elusive quality 最难能可贵的品质
**辨析**：⚠️ elusive（难以捉摸）≠ illusive（幻觉的/虚假的，← illusion）— 同音形近
**词根**：e-（外）+ lud-（玩）+ -ive → 玩消失的 → 难以捉摸的；惯用 "Happiness can be an elusive thing." 幸福有时难以捉摸

### 39. **fallout** — 后果，余波；放射性沉降物
**核心**：**（负面）后果/余波**；放射性沉降物
**搭配**：political fallout 政治余波 / economic fallout 经济后果 / nuclear fallout 核沉降物 / the fallout from the scandal 丑闻的余波
**惯用**："The political fallout from the crisis was enormous." 这场危机的政治余波是巨大的。
**记忆**：fall（落下）+ out（向外）→ 从空中降落下来的东西 → 余波/沉降物

## ⚠️ 形近词 / 近义词辨析（含场景偏好）

| 词对 | 区别（含使用场景偏好） |
|------|------|
| **gracious** vs **graceful** | gracious = 仁慈亲切的（态度/性格，上位者对下位者）；graceful = 优美的（动作/形态）；⚠️ 常见混淆词 |
| **inarticulate** vs **incoherent** vs **taciturn** | inarticulate = 不善言辞（表达力差）；incoherent = 语无伦次（逻辑乱）；taciturn = 沉默寡言（性格） |
| **unbiased** vs **fair** vs **impartial** | unbiased = 无偏见（客观中立，强调没有预设偏见）；fair = 公平（通用）；impartial = 不偏不倚（正式/法律） |
| **inn** vs **hotel** vs **motel** vs **hostel** | inn = 乡村小客栈（传统温馨）；hotel = 大型酒店；motel = 汽车旅馆（路边）；hostel = 青年旅社（便宜） |
| **elude** vs **allude** vs **delude** | elude = 逃避/使达不到；allude = 暗指；delude = 欺骗误导；同根词 lud-（玩） |
| **elusive** vs **illusive** | elusive = 难以捉摸的；illusive = 幻觉的/虚假的（← illusion）；同音形近 |
| **filing** vs **filling** | filing = 存档（file 引申）；filling = 填充（fill 引申）；⚠️ 一字之差 |
| **enclosure** vs **closure** | enclosure = 围场/附件（en- 使 + close）；closure = 关闭/结束（close 名词） |
| **gravel** vs **sand** vs **pebble** | gravel = 砾石（2-64mm，多棱角）；sand = 沙粒（细）；pebble = 鹅卵石（光滑） |
| **on-trend** vs **trendy** vs **fashionable** | on-trend = 当季潮流（偏消费/时尚）；trendy = 时髦（可带贬义"赶时髦"）；fashionable = 时尚（通用） |
| **perpetuity** vs **perpetual** | perpetuity = 永恒（名词）；perpetual = 永恒的（形容词）；⚠️ 词性不同 |
| **grieve** vs **grief** | grieve = 感到悲痛（动词）；grief = 悲痛（名词）；⚠️ 词性不同！grave（坟墓/严重的）≠ grief（悲痛）≠ grieve（悲伤 v.） |

## 🎯 高频考点速记

| 考点 | 说明 |
|------|------|
| **grave / grieve / grief 三词辨析** | grave = 坟墓 n. / 严重的 adj.；grieve = 悲伤 v.；grief = 悲痛 n.；词根 grav- = 重，阅读中根据上下文判断 |
| **gracious vs graceful** | 阅读理解态度判断重点：gracious = 和蔼的/仁慈的（对人态度），graceful = 优美的（动作/形态） |
| **词根 lud- 系列** | elude 逃避, allude 暗指, delude 欺骗, illusion 幻觉, collude 勾结 → 阅读中根据前缀区分词义方向 |
| **enclosure 圈地运动** | 英语常涉及英国历史背景知识：the Enclosure Movement = 圈地运动（15-19 世纪英国土地私有化过程） |
| **interdisciplinary 拼写** | 高频拼写易错词！inter-（之间）+ disciplin-（学科）+ -ary = interdisciplinary，勿写成 interdisplinary |
| **courtship 拼写** | court（求爱）+ ship（名词后缀）= courtship，勿写成 coutership |
| **perpetuity 词性** | perpetuity 是名词"永恒"，perpetual 是形容词"永恒的"，写作中不能混用 |
| **unification / reunification** | unification = 统一（首次或泛指）；reunification = 重新统一（分裂后再合，如 German reunification） |
| **elusive 一词多场景翻译** | elusive 根据搭配翻译不同：elusive goal 难以达到的目标 / elusive concept 难以理解的概念 / elusive criminal 在逃罪犯 |
| **knee-jerk reaction 比喻义** | 阅读中 knee-jerk 常比喻"不假思索的本能反应"，非字面的"膝跳反射" |
| **ostrich 的比喻义** | ostrich policy / like an ostrich = 鸵鸟政策/逃避现实 → 阅读中识别比喻用法 |
