### ⚠️ 形近词 / 近义词辨析

| 词对 | 区别 |
|------|------|
| **hurl** vs **haul** | hurl = 猛扔（throw forcefully）；haul = 拖，拉（原文把 hurl 误作"拖，拉"） |
| **knob** vs **knot** | knob = 旋钮/球形把手；knot = 结（打结）；形近易混 |
| **defendant** vs **plaintiff** | defendant = 被告（被起诉方）；plaintiff = 原告（起诉方）⚠️ 法律术语反义对 |
| **hawk** vs **eagle** vs **falcon** | hawk = 鹰/隼；eagle = 雕（更大）；falcon = 隼（猎鹰） |
| **dove** vs **pigeon** | dove = 鸽子（和平意象/文学）；pigeon = 鸽子（广场常见，口语） |
| **crow** vs **raven** | crow = 乌鸦（较小）；raven = 渡鸦（更大，文学中常为不祥之兆） |
| **swan** vs **swam** | swan = 天鹅；swam = swim 的过去式（原文把天鹅误拼为 swam） |
| **rim** vs **brim** vs **edge** | rim = 圆形物体边缘/口（杯口、轮辋）；brim = 杯/帽的边缘；edge = 边缘（最通用） |
| **climax** vs **summit** vs **peak** | climax = 高潮/顶点（情节）；summit = 顶峰（山峰/峰会）；peak = 峰值（曲线最高点） |
| **utmost** vs **almost** | utmost = 极度的（ut- = out）；almost = 几乎（al- + most） |
| **accountable** vs **responsible** | accountable = 应负责的（强调可追责）；responsible = 负责的（更通用） |
| **snobbish** vs **arrogant** | snobbish = 势利的（看不起地位低的人）；arrogant = 傲慢的（自大） |
| **slaughter** vs **massacre** vs **assassinate** | slaughter = 屠杀/屠宰；massacre = 大屠杀（强调残忍）；assassinate = 暗杀（政治人物） |
| **impart** vs **convey** | impart = 传授（知识/品质，正式）；convey = 传达（信息/情感，通用） |
| **offset** vs **compensate** | offset = 抵消（两物相抵）；compensate = 补偿（给受损方） |
| **stalk** vs **stride** vs **sneak** | stalk = 潜行跟踪/高视阔步；stride = 大步走（正常）；sneak = 鬼鬼祟祟地走 |

### 🎯 高频考点速记

| 考点 | 说明 |
|------|------|
| **be accountable for + 事 / to + 人** | 原文 "be accoutable of sth/for sb" 搭配有误：for 接事、to 接人 |
| **fume with anger** | 介词 with 后接名词 anger，不接形容词 angry（原文 fume with angry 有误） |
| **do one's utmost to do** | "竭尽全力做某事"的正式表达，写作中优于 try one's best |
| **plaintiff vs defendant** | 法律术语对：原告起诉被告 = the plaintiff sued the defendant |
| **hawks and doves** | 政治用语：鹰派（主战）vs 鸽派（主和） |
| **as the crow flies** | 惯用语："直线距离"，阅读中常见 |
| **tie the knot** | 惯用语："结婚"（字面：打结） |
| **a flock of + 复数** | 量词 flock 用于鸟/羊群；"一群乌鸦"= a flock of crows（原文漏了复数 s） |
| **favourably / favorable 英美拼写** | 英式 favourably = 美式 favorably；-our / -or 互换 |
| **美制 vs 英制加仑** | 美制 gallon ≈ 3.785L，英制 gallon ≈ 4.546L |
| **政治光谱 left / center / right** | left-of-center 中间偏左 / right-of-center 中间偏右 / far-left 极左 |
| **swan song** | 惯用语："告别演出，绝唱" |
| **albeit = although** | 正式连词，后接短语（形容词/分词），阅读中识别为"尽管" |
| **stalker 跟踪骚扰者** | stalk 的动词义"跟踪骚扰"在新闻中高频，名词 stalker 常用 |
| **™ 注册商标** | trademark（商标）vs brand（品牌）vs logo（标识）三者区分 |
