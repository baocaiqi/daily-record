### ⚠️ 形近词 / 近义词辨析（含场景偏好）

| 词对 | 区别（含使用场景偏好） |
|------|------|
| **meteor** vs **meteoroid** vs **meteorite** | meteor = 流星（大气层中燃烧的现象，天文科普）；meteoroid = 流星体（太空中的碎片本体，专业术语）；meteorite = 陨石（落到地面，地质收藏语境）⚠️ 同一物三阶段 |
| **asteroid** vs **meteor** | asteroid = 小行星（绕太阳的大岩石，天文科普）；meteor = 流星（小碎片入大气燃烧的现象） |
| **acclaimed** vs **hyped** vs **touted** vs **vaunted** | acclaimed = 广受好评（褒义，凭实力，影评/书评）；hyped = 过度炒作（贬义，营销夸大，媒体评论）；touted = 被标榜（中性偏贬，be touted as，新闻）；vaunted = 被吹嘘（贬义带讽刺，much-vaunted，政论） |
| **much-vaunted** vs **sb's vaunted** vs **less-than-vaunted** | 三者均为 vaunted 的贬义变体：much-vaunted = 大肆吹嘘的（新闻讽刺）；sb's vaunted = 某人自夸的（所有格+讽刺）；less-than-vaunted = 名不副实的（委婉反讽） |
| **mitigate** vs **temper** vs **allay** | mitigate = 减轻严重性/风险（正式，法律/灾害语境，配抽象名词）；temper = 使温和（通用，配语气/力量，兼名词"脾气"）；allay = 消除恐惧疑虑（配负面情感名词，新闻/演讲） |
| **knock-on effect** vs **ripple effect** vs **domino effect** | knock-on effect = 连锁反应（英式新闻，中性）；ripple effect = 涟漪效应（扩散式，偏形象）；domino effect = 多米诺效应（一个接一个，贬义更强） |
| **critique** vs **criticism** vs **review** | critique = 评析（中性偏学术，系统分析，可作动词）；criticism = 批评（贬义，挑毛病）；review = 评论（通用，书影音） |
| **outskirts** vs **suburb** vs **downtown** | outskirts = 市郊边缘（on the outskirts of，地理描述）；suburb = 郊区住宅区（通勤圈）；downtown = 市中心（反义） |
| **disputable** vs **controversial** vs **debatable** | disputable = 可争议（学术，语气中性）；controversial = 引发争议（新闻，热度高）；debatable = 有待商榷（语气最轻） |
| **giggle** vs **chuckle** vs **snicker** | giggle = 咯咯傻笑（孩子气，略带贬义，口语）；chuckle = 低声轻笑（满足得意，褒义）；snicker = 窃笑（嘲笑他人，贬义） |
| **flash** vs **sparkle** vs **glitter** | flash = 闪光（短暂明亮，文学/警示）；sparkle = 闪耀（细碎愉悦，偏褒）；glitter = 闪闪发光（持续反光，可贬"浮华"） |
| **extraction** vs **refinement** vs **distillation** | extraction = 提取/开采（抽出，工业/化学/医学）；refinement = 精炼（提纯去杂）；distillation = 蒸馏（特定工艺） |
| **precedent-setting** vs **unprecedented** | precedent-setting = 开先例的（为将来立范例，法律新闻）；unprecedented = 史无前例的（以前没有过，强调首次） |
| **buy-in** vs **acceptance** vs **approval** | buy-in = 认可（组织内支持，商务口语）；acceptance = 接受（通用中性）；approval = 批准（官方正式） |
| **proofreader** vs **editor** vs **copy editor** | proofreader = 校对员（查拼写标点格式）；editor = 编辑（内容结构把关）；copy editor = 文字编辑（校对+润色） |
| **virtuous** vs **righteous** vs **moral** | virtuous = 品行端正（美德层面，书面）；righteous = 正直（宗教/道德优越感，可带贬义）；moral = 道德的（通用中性） |
| **commonality** vs **similarity** vs **overlap** | commonality = 共性（共有特征，学术）；similarity = 相似性（程度较弱）；overlap = 重叠（部分重合） |

### 🎯 高频考点速记

| 考点 | 说明 |
|------|------|
| **meteor / meteoroid / meteorite 三词** | 同一星体三个阶段：太空中的碎片 = meteoroid（流星体）；大气层燃烧 = meteor（流星）；落到地面 = meteorite（陨石），天文阅读必考辨析 |
| **acclaimed / hyped / touted / vaunted 褒贬** | 阅读态度题关键：acclaimed（褒）vs hyped（贬：炒作）vs touted（中性偏贬：标榜）vs vaunted（贬：吹嘘）；much-vaunted 带讽刺 |
| **mitigate / temper / allay 搭配对象** | mitigate 配风险/损害（法律/灾害）；temper 配语气/力量（调和）；allay 配恐惧/焦虑（情感词）；完型常考搭配 |
| **be independent of 介词** | 固定搭配用 of（be independent of sth），不是 from；反义 be dependent on 用 on；介词搭配是完型高频考点 |
| **a knock-on effect 单复数** | 单数 a knock-on effect；原文 a knock-on effects 单复数不一致为错误 |
| **virtuous 拼写** | virtue → virtuous（去 e + -ous）；原文 vituous 漏 r 为拼写错误，考研写作易错词 |
| **precedent-setting vs unprecedented** | 开先例（为将来立范例）≠ 史无前例（从未发生）；法律/新闻阅读中区分 |
| **critically acclaimed 固定搭配** | "口碑极佳的"，影评类阅读高频；acclaimed 前常接 critically / widely |
| **critique 一词两性** | critique 既可作名词"评论文章"也可作动词"评析"，名词形式区别于 criticism（批评） |
| **be touted as** | "被标榜为…"，新闻高频被动结构：be touted as the next...（下一个…） |
| **temper 一词多义** | 动词"使温和/回火" + 名词"脾气"（lose one's temper）；阅读中根据词性判断 |
| **on the outskirts of** | "在…市郊"，地理类阅读高频介词搭配 |
