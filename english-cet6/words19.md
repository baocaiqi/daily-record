# 📚 CET-6 单词本 (19)

> 排版：每条单词 2-4 行解析，按优先级排列：核心 → 搭配 → 辨析 → 词根/记忆
> 标注：`⚠️` = 易混点/重点 | **加粗** = 核心要点

## 一、田园与科技

### 1. **orchard** — 果园
**核心**：**成片果树**的园地（apple orchard 苹果园）
**搭配**：an apple orchard 苹果园 / work in the orchard 在果园劳作 / orchard fruits 果园水果
**辨析**：⚠️ orchard（果园，果树成片）≠ garden（花园，观赏/菜园）≠ plantation（种植园，大规模经济作物）
**词根**：古英语 ortgeard（ort 蔬菜 + geard 院子）→ 种果树的园子

### 2. **agro-technological** — 农业科技的，农业技术的
**核心**：**农业 + 科技**的复合形容词
**搭配**：agro-technological innovation 农业科技创新 / agro-technological advancement 农业技术进步
**词根**：agro-（农业，希腊语 agros 田地）+ technological（技术的）；同根 agriculture 农业, agronomy 农学

## 二、学术与科学

### 3. **geneticist** — 遗传学家，基因学家
**核心**：研究**基因/遗传**的科学家
**搭配**：a molecular geneticist 分子遗传学家 / a leading geneticist 顶尖遗传学家
**词根**：gen- = birth/kind（出生，种类）→ gene → genetic + -ist（人）；同根 generate 产生, generation 世代, genesis 起源
**参考**：已在 words7 整理，此处复习

### 4. **in-depth** — 深入的，全面的，深度的
**核心**：**深入彻底**的（研究/分析/采访）
**搭配**：an in-depth analysis 深入分析 / in-depth research 深度研究 / an in-depth interview 深度访谈
**辨析**：⚠️ in-depth（深入的，强调透彻）≠ thorough（彻底的，强调完整）≠ comprehensive（全面的，覆盖面广）
**参考**：已在 words9 整理，此处复习

### 5. **qualitative** — 定性的，性质上的
**核心**：关于**性质/质量**而非数量的
**搭配**：qualitative analysis 定性分析 / qualitative research 质性研究 / qualitative change 质变
**辨析**：⚠️ qualitative（定性的，质）≠ quantitative（定量的，量）— 考研完型高频反义对！
**词根**：qual- = 性质（quality）+ -itive（形容词后缀）；同根 quality 质量, qualify 使合格

### 6. **factoid** — 趣闻；伪事实，仿真叙述
**核心**：⚠️ 拼写：**factoid**（fact + -oid）；两个义项：有趣的**小知识** 或 貌似真实的**伪事实**
**搭配**：an interesting factoid 有趣的冷知识 / media factoids 媒体制造的伪事实
**辨析**：⚠️ factoid（趣闻/伪事实，含"像事实但不一定真"）≠ fact（事实，真实）≠ factual（真实的，形容词）
**词根**：fact-（事实）+ -oid（像…的）→ 像事实的东西；同根 factory, manufacture

### 7. **factual** — 真实的，事实的
**核心**：**以事实为依据**的，客观的
**搭配**：factual information 真实信息 / a factual account 客观陈述 / factual error 事实错误
**辨析**：⚠️ factual（真实的，基于事实）≠ true（真的，通用）≠ objective（客观的，无偏见）≠ fictional（虚构的，反义）
**词根**：fact-（事实，做）+ -ual（形容词）；同根 fact, factor, factoid

### 8. **presuppose** — 以…为前提，预先假定
**核心**：**默认前提**：暗含某假设才成立
**搭配**：presuppose the existence of 以…的存在为前提 / their plan presupposes cooperation 他们的计划以合作为前提
**辨析**：⚠️ presuppose（预先假定，正式）≈ assume（假设，通用）≈ presume（推测，有一定依据）≠ suppose（假设，口语）
**词根**：pre-（预先）+ suppose（假定）→ 先假定；同根 suppose, assumption, presumption

### 9. **biotic** — 生物的，生命的
**核心**：与**生命体/生物**相关的（生态学术语）
**搭配**：biotic factors 生物因素 / biotic environment 生物环境 / biotic resources 生物资源
**辨析**：⚠️ biotic（生物的，生态学）≠ biological（生物学的，学科）≠ organic（有机的，化学）
**词根**：bio- = life（生命）+ -tic；同根 biology 生物学, biography 传记, antibiotic 抗生素

## 三、阻碍与低迷

### 10. **hindrance** — 阻碍，妨碍；障碍物
**核心**：**拖后腿/妨碍**的事物（可指人或物）
**搭配**：a hindrance to progress 进步的障碍 / without hindrance 畅通无阻 / be a hindrance to sb 成为某人的绊脚石
**辨析**：⚠️ hindrance（阻碍，强调妨碍过程）≠ obstacle（障碍物，具体/抽象）≠ barrier（壁垒，屏障）≠ setback（挫折，暂时的）
**词根**：hind-（在后面）+ -rance → 在后面拖住 → 阻碍；同根 behind, hinder 妨碍, hindmost 最后面的

### 11. **a hindrance to** — …的障碍，对…的妨碍
**核心**：固定搭配 **a hindrance to sth/sb**（to 后接名词）
**搭配**：a hindrance to development 发展的障碍 / a hindrance to learning 学习的绊脚石
**辨析**：⚠️ 固定介词用 to（a hindrance to），不是 for/of；对比 obstacle to, barrier to 同用 to

### 12. **demoralization** — 士气低落，泄气，消沉
**核心**：**信心/士气**被摧毁的状态
**搭配**：the demoralization of the troops 部队士气低落 / widespread demoralization 普遍的士气消沉
**辨析**：⚠️ demoralization（士气受挫，群体）≠ discouragement（灰心，个人）≠ despair（绝望，程度最深）
**词根**：de-（去除）+ moral（士气，道德）→ 夺走士气；同根 moral 道德的, morale 士气, immoral 不道德的

### 13. **sigh** — 叹息，叹气（名词/动词）
**核心**：**叹气**（表达无奈/疲倦/放松）
**搭配**：heave a sigh of relief 松一口气 / sigh with relief 如释重负地叹气 / a deep sigh 深深叹息
**辨析**：⚠️ sigh（叹气，情感表达）≠ sob（啜泣）≠ moan（呻吟，抱怨）
**词根**：拟声词，模拟"呼——"的叹气声

## 四、领域与权贵

### 14. **realm** — 领域，范围；王国
**核心**：**抽象领域**（知识/想象/政治）；古义"王国"
**搭配**：the realm of science 科学领域 / in the realm of possibility 在可能的范围内 / the realm of fantasy 幻想世界
**辨析**：⚠️ realm（领域，正式/书面）≈ domain（领域，学术/网络）≈ field（领域，最通用）≠ kingdom（王国，具体政治实体）
**惯用**："It's not beyond the realm of possibility." 这不是不可能的事。

### 15. **presidential** — 总统的，总统制的
**核心**：与**总统/总统制**相关的
**搭配**：presidential election 总统大选 / presidential candidate 总统候选人 / presidential address 总统演讲
**辨析**：⚠️ presidential（总统的，国家元首）≠ prime ministerial（首相的，议会制）— 政体不同
**词根**：preside（主持，preside over 主持）+ -ential；同根 preside, president, presidency 总统任期

### 16. **entourage** — 随从，随行人员
**核心**：**要人身边**的随行团体（明星/政要）
**搭配**：the president's entourage 总统的随行人员 / travel with a large entourage 带着大批随从出行
**辨析**：⚠️ entourage（随行团体，法语借词）≠ escort（护卫队/陪同）≠ retinue（侍从，历史）
**词根**：法语 entourer（环绕，en- 里 + tour 转）→ 围在身边的人

## 五、勤奋与表达

### 17. **industry** — 工业；勤奋
**核心**：⚠️ 一词两义：**工业**（现代常用）+ **勤奋**（正式书面）
**搭配**：heavy industry 重工业 / the film industry 电影业 / his diligence and industry 他的勤勉（正式）
**辨析**：⚠️ industry（工业/勤奋，一词两义）≠ industrial（工业的，形容词）≠ industrious（勤奋的，形容词）
**词根**：拉丁语 industria（勤奋）→ 后引申"工业"；同根 industrial, industrious

### 18. **industriousness** — 勤奋，勤勉
**核心**：**勤奋的品质**（正式用语，新闻报道/文学作品）
**搭配**：admire sb's industriousness 钦佩某人的勤勉 / tireless industriousness 不知疲倦的勤奋
**辨析**：⚠️ ⚠️ 拼写：**industriousness**（原文 industriouness 漏 r）；industriousness（勤奋，名词）≠ industry（工业/勤奋）≠ diligence（勤勉，同义）
**词根**：industri-（勤奋）+ -ous（形容词）+ -ness（名词）→ 勤奋

### 19. **representational** — 具象的；代表性的
**核心**：⚠️ 拼写：**representational**（原文 repersentational 漏字母）；艺术"具象的"；"代表性的"
**搭配**：representational art 具象艺术（写实艺术）≠ abstract art 抽象艺术 / be representational of 代表…
**辨析**：⚠️ representational（具象/代表的，艺术+政治）≠ representative（代表性的/代表，通用）≠ abstract（抽象的，艺术反义）
**词根**：re-（再）+ present（呈现）+ -ational → 再次呈现的 → 具象的

### 20. **be representational of** — 代表…，是…的体现
**核心**：固定搭配 **be representational of sth**（正式）
**搭配**：be representational of the era 是那个时代的体现 / be representational of national culture 代表民族文化
**辨析**：⚠️ be representational of（正式，体现）≈ be representative of（通用，代表）≠ stand for（口语，代表）

## 六、动荡与僵局

### 21. **standoff** — 僵持，僵局；对峙
**核心**：双方**互不相让**的对峙状态
**搭配**：a standoff between the two sides 双方的对峙 / end in a standoff 以僵局收场 / nuclear standoff 核对抗
**辨析**：⚠️ standoff（僵持对峙，军事/谈判）≠ stalemate（僵局，棋类/谈判）≠ deadlock（僵局，正式）
**词根**：stand（站立）+ off（远离）→ 站着对峙互不退让

### 22. **turbulence** — 湍流；动荡，骚乱
**核心**：**剧烈动荡**（天气/政治/经济）；航空"湍流"
**搭配**：political turbulence 政治动荡 / economic turbulence 经济动荡 / clear-air turbulence 晴空湍流（航空）
**辨析**：⚠️ turbulence（湍流/动荡，物理+政治）≠ turmoil（混乱，社会）≠ chaos（混沌，完全无序）
**词根**：turb- = disturb（搅动）+ -ulence；同根 disturb 打扰, turbulent 动荡的, turbine 涡轮

## 七、杠杆与筹码

### 23. **leverage** — 杠杆作用；影响力，手段；充分利用（动词）
**核心**：**借力**：名词"影响力/杠杆"；动词"充分利用"
**搭配**：have leverage over sb 对…有影响力 / gain leverage 获得筹码 / leverage one's resources 充分利用资源 / financial leverage 财务杠杆
**辨析**：⚠️ leverage（影响力/杠杆，商务政治）≠ influence（影响，通用）≠ bargaining power（谈判筹码）
**词根**：lev- = raise（举起）+ -er + -age → 撬动重物的力 → 杠杆；同根 lever 杠杆, elevate 提升, levitate 悬浮

### 24. **the leverage of a lever** — 杠杆的杠杆作用
**核心**：**lever（杠杆）的 leverage（杠杆作用）**——同根词叠用，强调物理杠杆原理
**搭配**：the leverage of a lever amplifies force 杠杆的杠杆作用放大力量
**记忆**：lever（杠杆）→ leverage（杠杆作用）→ 引申"影响力"（用支点撬动他人）

### 25. **have leverage over sb** — 对某人有影响力/制约力
**核心**：掌握**制衡对方**的筹码
**搭配**：have leverage over the opponent 对对手有制约力 / use one's leverage over 利用对…的影响力
**辨析**：⚠️ have leverage over（有影响力，牵制）≠ have influence on（有影响，中性）≠ hold sway over（支配，正式）

### 26. **gain/get leverage** — 获得筹码，取得影响力
**核心**：**争取到**谈判/博弈的优势
**搭配**：gain leverage in negotiations 在谈判中获得筹码 / get leverage over competitors 取得对竞争对手的优势
**记忆**：gain/get（获得）+ leverage（筹码）→ 攒到撬动局势的力量

## 八、时间与杂项

### 27. **perpetuate** — 使持续，使长存（常含贬义）
**核心**：⚠️ 词性：**动词**"使（负面事物）持续下去"（原文标"持续不断的"是形容词，形容词为 perpetual）
**搭配**：perpetuate stereotypes 固化刻板印象 / perpetuate inequality 使不平等延续 / perpetuate the myth 使谣言长存
**辨析**：⚠️ perpetuate（使持续，动词，多为负面）≠ perpetual（永久的，形容词）≠ persist（持续存在，不及物）
**词根**：per-（贯穿）+ pet-（追求）+ -uate → 一直追求下去 → 使持久；同根 perpetual, petition, appetite

### 28. **an obscene phone call** — 色情骚扰电话
**核心**：**淫秽下流**的电话骚扰（obscene 详见 words18）
**搭配**：receive an obscene phone call 接到骚扰电话 / report an obscene phone call 举报骚扰电话
**记忆**：obscene（淫秽的）+ phone call（电话）→ 淫秽电话

### 29. **megalith** — 史前巨石（纪念碑）
**核心**：**史前巨大的石块**（如巨石阵 Stonehenge）
**搭配**：the megaliths of Stonehenge 巨石阵的巨石 / megalithic monument 巨石纪念碑
**辨析**：⚠️ megalith（史前巨石，考古）≠ monolith（独石柱/整体巨石）≠ menhir（竖石纪念碑）
**词根**：mega- = 巨大（希腊语 megas）+ lith- = 石头 → 巨石；同根 megaphone 扩音器, lithography 石版印刷

### 30. **bellyful** — 满腹，一肚子
**核心**：**满肚子的**（食物/怨气）；口语"受够了"
**搭配**：a bellyful of complaints 满腹牢骚 / have a bellyful of sth 受够了某事（口语）
**辨析**：⚠️ bellyful（满腹，口语，常含抱怨）≠ stomachful（一肚子，中性）≠ fill（填满，动词）
**词根**：belly（肚子）+ -ful（充满）；同根 belly 腹部, bellied 有腹的

### 31. **eightfold** — 八倍的，八倍地
**核心**：**八倍**（形容词/副词），数字 + fold 构词
**搭配**：an eightfold increase 八倍增长 / increase eightfold 增长八倍
**辨析**：⚠️ eightfold（八倍）≠ eighth（第八，序数）⚠️ 形近；fold 系列：twofold 两倍, threefold 三倍, manifold 多样的
**词根**：eight（八）+ fold（倍，折）；同根 twofold, manifold

## ⚠️ 形近词 / 近义词辨析（含场景偏好）

| 词对 | 区别（含使用场景偏好） |
|------|------|
| **qualitative** vs **quantitative** | qualitative = 定性的（性质，学术）；quantitative = 定量的（数量，统计）⚠️ 考研反义对 |
| **factoid** vs **factual** vs **fact** | factoid = 趣闻/伪事实（像事实不一定真）；factual = 真实的（形容词）；fact = 事实（名词） |
| **hindrance** vs **obstacle** vs **barrier** | hindrance = 妨碍（拖慢过程）；obstacle = 障碍物（具体/抽象）；barrier = 壁垒（屏障） |
| **demoralization** vs **discouragement** vs **despair** | demoralization = 士气受挫（群体）；discouragement = 灰心（个人）；despair = 绝望（最深） |
| **realm** vs **domain** vs **field** | realm = 领域（正式书面）；domain = 领域（学术/网络）；field = 领域（最通用口语） |
| **presidential** vs **prime ministerial** | presidential = 总统制（总统为国家元首）；prime ministerial = 议会制（首相） |
| **industry** vs **industrious** vs **industriousness** | industry = 工业/勤奋（一词两义）；industrious = 勤奋的（形容词）；industriousness = 勤奋（名词，正式） |
| **representational** vs **representative** | representational = 具象的/代表性的（艺术+正式）；representative = 代表的（通用） |
| **standoff** vs **stalemate** vs **deadlock** | standoff = 对峙（军事/谈判）；stalemate = 僵局（棋/谈判）；deadlock = 僵局（正式） |
| **turbulence** vs **turmoil** vs **chaos** | turbulence = 湍流/动荡（物理+政治）；turmoil = 混乱（社会）；chaos = 混沌（完全无序） |
| **leverage** vs **influence** | leverage = 影响力/杠杆（商务政治，借力）；influence = 影响（通用中性） |
| **perpetuate** vs **perpetual** vs **persist** | perpetuate = 使持续（动词，负面）；perpetual = 永久的（形容词）；persist = 持续存在（不及物） |
| **megalith** vs **monolith** vs **menhir** | megalith = 史前巨石（考古）；monolith = 独石柱；menhir = 竖石纪念碑 |
| **bellyful** vs **stomachful** | bellyful = 满腹（口语，常含抱怨）；stomachful = 一肚子（中性） |
| **eightfold** vs **eighth** | eightfold = 八倍；eighth = 第八 ⚠️ 形近易混 |
| **presuppose** vs **assume** vs **presume** | presuppose = 预先假定（正式）；assume = 假设（通用）；presume = 推测（有依据） |
| **orchard** vs **garden** vs **plantation** | orchard = 果园（果树）；garden = 花园（观赏/菜园）；plantation = 种植园（大规模经济作物） |

| **perpetuate 词性** | perpetuate 是动词"使持续"（多为负面）；perpetual 才是形容词"永久的" |
| **industry 一词两义** | 工业（现代常用）+ 勤奋（正式书面）；阅读中根据语境判断 |
| **leverage 一词多性** | 名词"影响力/杠杆" + 动词"充分利用"；商务/政治阅读高频 |
| **a hindrance to 介词** | 固定搭配 to（a hindrance to sth）；与 obstacle to / barrier to 同构 |
| **realm of** | "…领域"（正式）：the realm of science / beyond the realm of possibility |
| **turbulence 双领域** | 物理（湍流）+ 政治（动荡）；考研科技/时政阅读双高频 |
| **fold 构词** | twofold 两倍 / threefold 三倍 / eightfold 八倍 / manifold 多样的；数字+fold 表倍数 |
| **be representational of** | 正式固定搭配"代表…"，写作可替换 be representative of |
