# 📚 CET-6 单词本 (20)

> 排版：每条单词 2-4 行解析，按优先级排列：核心 → 搭配 → 辨析 → 词根/记忆
> 标注：`⚠️` = 易混点/重点 | **加粗** = 核心要点

## 一、政治与制度

### 1. **diffusionist** — 传播论者
**核心**：主张**文化传播论**（diffusionism）的学者
**搭配**：a diffusionist theory 传播论学说 / diffusionist approach 传播论视角
**词根**：dif-（分开）+ fus-（流）+ -ion + -ist（人）；同根 diffuse 扩散, fusion 融合
**参考**：diffusionism 已在 words7 整理

### 2. **magistrate** — 地方法官，治安法官；地方行政官
**核心**：**基层司法**官员（审理轻微案件，英式常用）
**搭配**：a local magistrate 地方法官 / appear before a magistrate 在地方法官面前出庭
**辨析**：⚠️ magistrate（地方法官，基层）≠ judge（法官，通用/上级法院）≠ mayor（市长，行政）
**词根**：magistr- = master（长官）+ -ate；同根 master, magistrate, magistracy

### 3. **unionist** — 工会会员，工会主义者；统一主义者
**核心**：**支持工会**的人；英国政治中"统一派"（反对北爱独立）
**搭配**：trade unionist 工会会员 / a staunch unionist 坚定的工会支持者
**词根**：uni- = one（一）+ -on + -ist；同根 union 工会/联盟, unite 联合, unity 团结

### 4. **constitutionality** — 合宪性，符合宪法
**核心**：⚠️ 拼写：**constitutionality**（原文 constiutationality 乱序）；"是否**符合宪法**"
**搭配**：the constitutionality of the law 该法律的合宪性 / challenge the constitutionality 质疑合宪性
**辨析**：⚠️ constitutionality（合宪性，名词）≠ constitutional（宪法的，形容词）≠ unconstitutional（违宪的，反义）
**词根**：con-（共同）+ stitut-（设立）+ -ion + -al + -ity；同根 constitute 构成, institution 制度

### 5. **constitutional law** — 宪法
**核心**：⚠️ 拼写：**constitutional law**（原文 constitutation law 错误）；规范国家根本制度的法律
**搭配**：a constitutional law professor 宪法学教授 / violate constitutional law 违反宪法
**辨析**：⚠️ constitutional law（宪法/宪法学）≠ civil law（民法）≠ criminal law（刑法）
**词根**：constitution（宪法）+ -al；同根 constitute, constitution

### 6. **legitimacy** — 合法性，正当性；合理性
**核心**：**合法/正当**的地位（政府/程序/要求）
**搭配**：the legitimacy of the government 政府的合法性 / challenge sb's legitimacy 质疑…的合法性 / question the legitimacy of 质疑…的正当性
**辨析**：⚠️ legitimacy（合法性/正当性，名词）≠ legality（合法性，偏法律条文）≠ legit（合法的，口语）
**词根**：legitim- = lawful（合法的，源自 lex 法律）+ -acy；同根 legal, legislation 立法, legitimate 合法的

### 7. **bureaucrat** — 官僚，官员
**核心**：**政府行政官员**（常含贬义"墨守成规"）
**搭配**：a government bureaucrat 政府官僚 / career bureaucrat 职业官僚
**辨析**：⚠️ bureaucrat（官僚，可贬义）≠ official（官员，中性）≠ civil servant（公务员，中性正式）
**词根**：bureau（办公桌/局）+ -crat（统治）；同根 bureaucracy 官僚制, bureaucratic 官僚的, autocrat 独裁者

### 8. **a state bureaucrat** — 国家官僚，政府官员
**核心**：**国家级行政**官僚
**搭配**：a high-ranking state bureaucrat 高级国家官员 / a state bureaucrat's red tape 官僚的繁文缛节
**记忆**：state（国家）+ bureaucrat（官僚）→ 国家官僚

### 9. **indictment** — 起诉书；控诉；谴责
**核心**：**正式起诉**；引申"对…的控诉/谴责"
**搭配**：face indictment 面临起诉 / a federal indictment 联邦起诉书 / an indictment of the system 对制度的控诉
**辨析**：⚠️ indictment（起诉/控诉，法律+引申）≠ accusation（指控，一般）≠ charge（控告，正式）
**词根**：in-（向）+ dict- = say（说）+ -ment → 正式陈词 → 起诉；同根 dictate, predict, verdict

### 10. **face indictment** — 面临起诉
**核心**：**面临刑事**起诉（新闻高频）
**搭配**：face indictment on corruption charges 面临腐败指控的起诉 / face indictment by a grand jury 面临大陪审团起诉
**记忆**：face（面对）+ indictment（起诉）→ 面对起诉

## 二、经济与就业

### 11. **compensatory** — 补偿的，赔偿的
**核心**：用于**补偿/赔偿**的
**搭配**：compensatory payment 补偿金 / compensatory damages 补偿性损害赔偿 / compensatory education 补偿教育
**辨析**：⚠️ compensatory（补偿性的）≠ complementary（互补的）⚠️ 形近一字！≠ supplementary（补充的）
**词根**：com-（共同）+ pens- = weigh/pay（称量，支付）+ -atory；同根 compensate 补偿, pension 养老金, expense 花费

### 12. **startup** — 初创公司；新创办的
**核心**：**新创企业**（科技创业常用）；形容词"初始的"
**搭配**：a tech startup 科技初创公司 / startup funding 创业资金 / startup phase 初创阶段
**辨析**：⚠️ startup（初创公司，创业语境）≠ start-up costs（启动成本）≠ enterprise（企业，泛指）
**词根**：start（启动）+ up（向上）→ 刚启动的公司

### 13. **recruiter** — 招聘者，招募者
**核心**：**负责招人**的人/机构
**搭配**：a headhunting recruiter 猎头 / military recruiter 征兵人员 / college recruiter 校园招聘专员
**辨析**：⚠️ recruiter（招聘者，招人方）≠ recruit（新兵/新成员，被招的人）⚠️ 一词两向！
**词根**：re-（再）+ cru-（生长）+ -it + -er；同根 recruit 招募, increase 增加, crescent 新月

### 14. **belt-tightening** — 紧缩的，节俭的
**核心**：⚠️ 拼写：**belt-tightening**（原文 belt-tighting 漏 en）；勒紧腰带 → **财政紧缩/节俭**
**搭配**：belt-tightening measures 紧缩措施 / a period of belt-tightening 一段紧缩期 / belt-tightening budget 紧缩预算
**辨析**：⚠️ belt-tightening（财政紧缩，经济新闻）≈ austerity（ austerity 紧缩，正式）≠ frugality（节俭，个人）
**记忆**：belt（腰带）+ tighten（勒紧）→ 勒紧腰带过紧日子

## 三、艺术与美学

### 15. **ornate** — 装饰华丽的，华美的；辞藻华丽的
**核心**：**繁复华丽**的装饰风格
**搭配**：an ornate ceiling 华丽的天花板 / ornate decoration 繁复装饰 / ornate language 辞藻华丽的语言
**辨析**：⚠️ ornate（装饰繁复华丽）≠ luxurious（奢华的，贵）≠ elaborate（精心制作的）≠ plain（朴素的，反义）
**词根**：orn- = decorate（装饰）+ -ate；同根 ornament 装饰品, ornamental 装饰性的

### 16. **originality** — 原创性，独创性
**核心**：⚠️ 拼写：**originality**（原文 orginality 漏 i）；"**独创性**"
**搭配**：show originality 展现独创性 / lack of originality 缺乏原创性 / the originality of the design 设计的独创性
**辨析**：⚠️ originality（原创性）≠ creativity（创造力）≠ novelty（新颖性，一时新奇）
**词根**：origin- = 起源（origo）+ -al + -ity；同根 origin 起源, original 原始的, originate 起源

### 17. **glamorous** — 迷人的，有魅力的，富有魅力的
**核心**：⚠️ 拼写：**glamorous**（原文 glamormous 拼错）；"**魅力四射**"的
**搭配**：a glamorous lifestyle 迷人的生活方式 / glamorous movie stars 魅力四射的电影明星
**辨析**：⚠️ glamorous（魅力迷人，光鲜）≠ charming（迷人，亲切）≠ attractive（有吸引力，通用）
**词根**：glamour（魅力，苏格兰语 grammar 变体，原指魔法）+ -ous；同根 glamour, glamorize

## 四、情感与特征

### 18. **wistful** — 伤感的，惆怅的；渴望的
**核心**：**怀念中带惆怅**的（对过去/得不到的事物）
**搭配**：a wistful smile 惆怅的微笑 / wistful longing 渴望 / look wistful 神情怅然
**辨析**：⚠️ wistful（惆怅+渴望，柔和）≠ nostalgic（怀旧的，想回到过去）≠ melancholy（忧郁的，程度重）
**词根**：wist-（= wish，古语"知道/渴望"）+ -ful → 满是渴望的

### 19. **foremost** — 最重要的，首要的；最著名的
**核心**：**排第一的**（地位/重要性）
**搭配**：first and foremost 首先，最重要的是 / the foremost expert 顶尖专家 / foremost among them 其中最重要的
**辨析**：⚠️ foremost（首要的，正式）≈ leading（领先的）≈ principal（主要的）≠ former（前者的）⚠️ 形近
**词根**：fore-（前面）+ most（最）→ 最前面的 → 首要的

### 20. **altruistic** — 利他的，无私的
**核心**：**为他人利益**的（无私）
**搭配**：altruistic behavior 利他行为 / altruistic motives 无私动机 / an altruistic act 利他之举
**辨析**：⚠️ altruistic（利他的，无私）≠ selfless（无私的，通用）≠ philanthropic（慈善的，捐钱）≠ selfish（自私的，反义）
**词根**：alter- = other（他人）+ -istic；同根 alter 改变, alternative 替代的（拉丁语 alter 另一个）

## 五、医学与身体

### 21. **pulse** — 脉搏；脉冲；活力
**核心**：**脉搏**；电子"脉冲"；引申"活力"
**搭配**：take one's pulse 把脉 / a weak pulse 微弱的脉搏 / pulse rate 脉率 / electric pulse 电脉冲
**辨析**：⚠️ pulse（脉搏/脉冲）≠ heartbeat（心跳）≠ rhythm（节奏，韵律）
**词根**：puls- = drive（推，驱）+ -e → 血液被推动 → 脉搏；同根 push 推, compel 强迫, impulse 冲动

### 22. **weak pulse** — 微弱的脉搏
**核心**：**脉象虚弱**（医学体征）
**搭配**：have a weak pulse 脉搏微弱 / a barely detectable weak pulse 几乎摸不到的微弱脉搏
**记忆**：weak（微弱）+ pulse（脉搏）→ 弱脉

### 23. **take one's pulse** — 把脉，测脉搏
**核心**：**测量脉搏**（医生/自我检查）
**搭配**：take the patient's pulse 给病人把脉 / take one's own pulse 自己测脉搏
**记忆**：take（测量）+ one's + pulse（脉搏）→ 把脉

### 24. **hyperactivity** — 多动症，活动过度
**核心**：**过度活跃**（ADHD 注意缺陷多动障碍核心症状）
**搭配**：attention deficit hyperactivity disorder (ADHD) 注意缺陷多动障碍 / child hyperactivity 儿童多动
**辨析**：⚠️ hyperactivity（多动，医学术语）≠ restlessness（坐立不安，一般）≠ agitation（焦躁）
**词根**：hyper-（过度）+ activity（活跃）；同根 hyperactive 多动的, hypersensitive 过敏的, hypertension 高血压

## 六、犯罪与欺骗

### 25. **discernible** — 可辨别的，可看出的
**核心**：**能看/察觉出来**的（细微但可察觉）
**搭配**：a discernible difference 可察觉的差异 / barely discernible 几乎看不出 / clearly discernible 清晰可辨
**辨析**：⚠️ discernible（可辨别的，可察觉）≠ distinguishable（可区分的，可分清）≠ visible（可见的，视觉）≠ perceptible（可感知的，正式）
**词根**：dis-（分开）+ cern- = separate（区分）+ -ible → 能分开看的 → 可辨别的；同根 discern 辨别, concern 关心, certain 确定的

### 26. **deduction** — 扣除，扣除额；推论，演绎
**核心**：⚠️ 原文 deductation 拼写错误；两个领域：**扣款**（财务）+ **演绎推理**（逻辑）
**搭配**：tax deduction 税收减免 / deduct from the salary 从工资中扣除 / make a deduction 作出推论 / deductive reasoning 演绎推理
**辨析**：⚠️ deduction（扣除/演绎）≠ deductible（可扣除的，形容词/保险自付额）≠ induction（归纳，逻辑反义）
**词根**：de-（向下）+ duct- = lead（引导）+ -ion → 引导下来 → 扣除/推导；同根 conduct 引导, product 产品, introduce 介绍

### 27. **misdeed** — 恶行，不端行为
**核心**：**错误/邪恶**的行为（书面）
**搭配**：commit a misdeed 犯下恶行 / pay for one's misdeeds 为恶行付出代价 / past misdeeds 前科
**辨析**：⚠️ misdeed（恶行，书面）≈ wrongdoing（坏事，通用）≠ crime（罪行，法律）
**词根**：mis-（错误）+ deed（行为）；同根 misbehave 行为不端, deed 行为

### 28. **thriller** — 惊悚小说/电影
**核心**：**惊险刺激**的文学/影视类型
**搭配**：a crime thriller 犯罪惊悚片 / a spy thriller 间谍惊悚片 / psychological thriller 心理惊悚
**辨析**：⚠️ thriller（惊悚，刺激紧张）≠ horror（恐怖，血腥吓人）≠ suspense（悬念，手法）
**词根**：thrill（兴奋，颤抖）+ -er；同根 thrill 使激动, thrilling 惊险的

### 29. **a crime thriller** — 犯罪惊悚小说/电影
**核心**：**犯罪题材**的惊悚作品
**搭配**：a bestselling crime thriller 畅销犯罪惊悚小说 / direct a crime thriller 执导犯罪惊悚片
**记忆**：crime（犯罪）+ thriller（惊悚）→ 犯罪惊悚

### 30. **deceptiveness** — 欺骗性，迷惑性
**核心**：⚠️ 拼写：**deceptiveness**（原文 deceiveness 漏 p）；"**具有欺骗/迷惑性**"
**搭配**：the deceptiveness of appearances 表象的迷惑性 / the deceptiveness of memory 记忆的欺骗性
**辨析**：⚠️ deceptiveness（欺骗性，名词）≠ deception（欺骗，行为）≠ deceit（欺骗，品质）≠ deceptive（欺骗的，形容词）
**词根**：de-（离开）+ cept- = take（拿）+ -ive + -ness；同根 deceive 欺骗, reception 接收, concept 概念

### 31. **falsehood** — 谎言，虚假；不实
**核心**：**虚假陈述**（书面语，比 lie 正式）
**搭配**：tell a falsehood 说谎 / a blatant falsehood 明目张胆的谎言 / expose the falsehood 揭穿谎言
**辨析**：⚠️ falsehood（虚假陈述，书面/正式）≈ lie（谎言，最通用）≈ untruth（假话，委婉）
**词根**：false（假的）+ -hood（状态）；同根 false, falsify 伪造, falsehood

### 32. **tell a falsehood** — 说谎，撒一个谎
**核心**：**说假话**（正式表达）
**搭配**：tell a deliberate falsehood 故意撒谎 / never tell a falsehood 从不说谎
**辨析**：⚠️ tell a falsehood（说假话，正式）≈ tell a lie（说谎，通用）≠ tell the truth（说真话，反义）

### 33. **trapper** — 设陷阱捕兽的人
**核心**：**捕兽者**（皮毛贸易/荒野求生）
**搭配**：a fur trapper 皮毛捕兽者 / mountain trapper 山地捕兽人
**辨析**：⚠️ trapper（设陷阱捕兽的人）≠ hunter（猎人，用枪/弓）——区分捕猎方式
**词根**：trap（陷阱）+ -er（人）；同根 trap, trapped, entrap 诱捕

## 七、可行与逻辑

### 34. **feasible** — 可行的，行得通的
**核心**：**可以实现的**（方案/计划）
**搭配**：a feasible plan 可行的计划 / technically feasible 技术上可行 / economically feasible 经济上可行
**辨析**：⚠️ feasible（可行，可实施）≈ viable（可行的，可持续的）≈ practicable（切实可行）≠ impossible（不可能，反义）
**词根**：feas- = do/make（做，拉丁语 facere）+ -ible（可…的）→ 做得成的

### 35. **unfeasible** — 行不通的，不可行的
**核心**：**无法实现**的（feasible 反义）
**搭配**：an unfeasible proposal 不可行的提案 / economically unfeasible 经济上不可行
**辨析**：⚠️ unfeasible（不可行）≈ infeasible（不可行，美式更常用）≠ impractical（不切实际）≠ unattainable（达不到）
**词根**：un-（不）+ feasible（可行）→ 不可行

### 36. **logicality** — 逻辑性，合理性
**核心**：**逻辑严密**的性质
**搭配**：the logicality of the argument 论证的逻辑性 / lack of logicality 缺乏逻辑性
**辨析**：⚠️ logicality（逻辑性）≠ logic（逻辑，学科/原理）≠ rationality（合理性，理性）
**词根**：log- = word/reason（词，理性）+ -ical + -ity；同根 logic, logical, illogical 不合逻辑的

### 37. **refute** — 反驳，驳斥
**核心**：**证明…错误**（用证据反驳）
**搭配**：refute an argument 驳倒论点 / refute a claim 反驳主张 / refute the theory 驳斥该理论
**辨析**：⚠️ refute（驳倒，证明错）≠ rebut（反驳，回应）≠ contradict（否认，说相反）≠ reject（拒绝，不接受）
**词根**：re-（回）+ fut- = beat（打）→ 打回去；同根 refute, refutable

### 38. **refutation** — 反驳，驳斥（名词）
**核心**：**驳斥的行为/言辞**
**搭配**：a refutation of the theory 对该理论的驳斥 / offer a refutation 提出反驳
**辨析**：⚠️ refutation（反驳，名词）≠ contradiction（矛盾/否认）≠ objection（反对，异议）
**词根**：re-（回）+ fut-（打）+ -ation → 打回去的行为

### 39. **irrefutable** — 无可辩驳的，铁证如山的
**核心**：⚠️ 拼写：**irrefutable**（原文 irrefuation 拼错）；"**无法反驳**的"
**搭配**：irrefutable evidence 铁证 / an irrefutable argument 无可辩驳的论证 / irrefutable proof 确凿证据
**辨析**：⚠️ irrefutable（无可辩驳，有证据）≠ undeniable（不可否认）≠ indisputable（无可争议）≠ refutable（可反驳的，反义）
**词根**：ir-（不）+ re-（回）+ fut-（打）+ -able → 打不回去的 → 无可辩驳

### 40. **instructive** — 有教益的，有启发性的
**核心**：**能教给人东西**的（有教育意义）
**搭配**：an instructive book 有教益的书 / an instructive experience 有启发性的经历 / instructive example 启发性例子
**辨析**：⚠️ instructive（有教益的）≈ educational（教育的）≠ informative（信息量大的）≠ instructive ≠ instructional（教学用的）
**词根**：in-（进入）+ struct- = build（建造）+ -ive → 建造心智的 → 有教益的；同根 instruct 教导, structure 结构

## 八、依赖与生态

### 41. **interdependence** — 相互依赖，互相依存
**核心**：⚠️ 原文"互相撑腰"不准确，interdependence = **相互依赖**（中性）
**搭配**：economic interdependence 经济相互依赖 / global interdependence 全球相互依存 / interdependence between nations 国家间相互依赖
**辨析**：⚠️ interdependence（相互依赖，中性）≠ codependence（共同依赖，负面，心理/不健康关系）≠ independence（独立，反义）
**词根**：inter-（相互）+ de-（下）+ pend-（悬挂）+ -ence → 相互悬挂依存；同根 depend 依赖, independent

### 42. **codependence** — 相互依赖，共同依赖（负面）
**核心**：**病态的相互依赖**（心理学，一方依赖另一方维持）
**搭配**：codependence in relationships 关系中的病态依赖 / break the cycle of codependence 打破共同依赖的循环
**辨析**：⚠️ codependence（病态共同依赖，心理学术语，负面）≠ interdependence（相互依赖，中性正面）≠ dependence（依赖，单向）
**词根**：co-（共同）+ depend（依赖）+ -ence → 共同依赖

### 43. **biophilia** — 亲生命性，热爱自然的本性
**核心**：人类**亲近自然生命**的天性（Edward O. Wilson 提出的假说）
**搭配**：the biophilia hypothesis 亲生命假说 / a sense of biophilia 亲自然之情
**词根**：bio- = life（生命）+ philia = love（爱）→ 爱生命；同根 biology 生物学, philanthropy 慈善（爱人类）, philosophy 哲学（爱智慧）

### 44. **forage** — 觅食；饲料（名词/动词）
**核心**：动物**四处觅食**；名词"饲料/草料"
**搭配**：forage for food 觅食 / forage in the woods 在林中觅食 / hay forage 干草饲料
**辨析**：⚠️ forage（觅食，动物/野外）≠ hunt（捕猎，肉食）≠ scavenge（捡食，腐食/垃圾）
**词根**：古法语 fourrage（饲料，源自古法语 fuerre 稻草）；同根 forage, forager

### 45. **forage for food** — 觅食
**核心**：⚠️ 原文 foraeg for food 拼写错误；**四处寻找食物**
**搭配**：animals foraging for food 觅食的动物 / forage for food in winter 冬天觅食
**辨析**：⚠️ forage for food（觅食，动物）≈ search for food（找食物，通用）≈ scavenge for food（捡食，贬义）

### 46. **folklore** — 民间传说，民俗
**核心**：⚠️ 原文"名俗"为错别字，正确 **民俗**；一个民族的**传统故事/风俗**
**搭配**：local folklore 当地民俗 / folklore studies 民俗研究 / a creature of folklore 民间传说中的生物
**辨析**：⚠️ folklore（民间传说/民俗，文化）≠ legend（传奇，英雄故事）≠ myth（神话，神的故事）
**词根**：folk（民间）+ lore（知识，传说）；同根 folk music 民谣, folk tale 民间故事

## 九、时间与科学

### 47. **timescale** — 时间尺度，时间段
**核心**：⚠️ 原文"时期"不准确，timescale = **时间跨度/尺度**（衡量长短的参照）
**搭配**：on a geological timescale 以地质时间尺度 / over a short timescale 在短期内 / a long timescale 长时间尺度
**辨析**：⚠️ timescale（时间尺度）≠ timeline（时间线）≠ period（时期，通用）
**词根**：time（时间）+ scale（刻度，尺度）→ 时间的刻度

### 48. **ventilation** — 通风；通风系统
**核心**：**空气流通**；建筑"通风设备"
**搭配**：ventilation system 通风系统 / good ventilation 通风良好 / lack of ventilation 通风不畅
**辨析**：⚠️ ventilation（通风，系统/过程）≠ air conditioning（空调，制冷）≠ aeration（曝气，水/土壤）
**词根**：vent- = wind（风，拉丁语 ventus）+ -ilation；同根 vent 通风口, ventilator 呼吸机, wind

### 49. **academia** — 学术界，学术圈
**核心**：**大学/科研**界（与 industry 相对）
**搭配**：work in academia 在学术界工作 / a career in academia 学术生涯 / links between academia and industry 学界与业界的联系
**辨析**：⚠️ academia（学术界，集合名词）≠ academic（学者/学术的）≠ university（大学，机构）
**词根**：academ-（柏拉图学园 Akademeia）+ -ia；同根 academic, academy 学院

### 50. **overburdened** — 负担过重的，超负荷的
**核心**：**负担太重**压垮的
**搭配**：overburdened teachers 负担过重的教师 / an overburdened healthcare system 超负荷的医疗系统
**辨析**：⚠️ overburdened（负担过重，压倒性）≠ overloaded（超载，负荷）≠ overworked（工作过度）
**词根**：over-（过度）+ burden（负担）+ -ed；同根 burden, burdensome 沉重的

### 51. **universality** — 普遍性，通用性
**核心**：⚠️ 原文"同一性"不准确，universality = **普遍性**（适用于所有情况）
**搭配**：the universality of human rights 人权的普遍性 / universality of the rules 规则的普适性
**辨析**：⚠️ universality（普遍性）≠ unity（统一性）≠ uniformity（一致性）≠ generality（普遍性，同义）
**词根**：uni- = one（一）+ vers-（转）+ -ality → 转到各处都一样 → 普遍；同根 universe 宇宙, universal 普遍的

### 52. **sustainability** — 可持续性
**核心**：⚠️ 词性：**名词**"可持续性"（原文"可持续的"是形容词 sustainable）
**搭配**：environmental sustainability 环境可持续性 / sustainability of development 发展的可持续性 / sustainability goals 可持续发展目标
**辨析**：⚠️ sustainability（可持续性，名词）≠ sustainable（可持续的，形容词）≠ viability（可行性/生存力）
**词根**：sus-（下）+ tain- = hold（握持）+ -ability → 能持续握持；同根 sustain 维持, sustainable, maintain

## 十、其他

### 53. **pharaoh** — 法老
**核心**：**古埃及国王**的称号
**搭配**：the pharaoh of ancient Egypt 古埃及法老 / Pharaoh's tomb 法老陵墓
**记忆**：法老 = 古埃及"国王"，谐音"发老"→ 老大的王

### 54. **drawn-out** — 冗长的，拖长的
**核心**：⚠️ 原文 drown-out 拼写错误（drown out 是"淹没声音"）！正确 **drawn-out** = 拖得很长的
**搭配**：a drawn-out process 漫长的过程 / a drawn-out war 旷日持久的战争 / drawn-out negotiations 冗长的谈判
**辨析**：⚠️ drawn-out（拖长的，冗长）≈ protracted（持久的，正式）≠ prolonged（延长的，中性）≠ concise（简洁的，反义）
**词根**：draw（拉）+ out（出）→ 拉得很长 → 拖长的

### 55. **prudently** — 谨慎地，明智地
**核心**：⚠️ 原文 prudentaliy 拼写错误；**谨慎明智地**（副词）
**搭配**：act prudently 谨慎行事 / prudently invest 谨慎投资 / prudently managed 管理得当的
**辨析**：⚠️ prudently（谨慎地，权衡）≈ cautiously（小心地）≈ wisely（明智地）≠ recklessly（鲁莽地，反义）
**词根**：prud- = foresee（预见）+ -ent + -ly；同根 prudent, prudence, providence（详见 words15）

### 56. **cross-cutting** — 跨领域的，贯穿性的
**核心**：**横跨多个领域**的（议题/主题）
**搭配**：cross-cutting issues 跨领域议题 / cross-cutting themes 贯穿性主题 / cross-cutting concerns 横切关注点（软件工程术语）
**辨析**：⚠️ cross-cutting（跨领域，贯穿多个）≠ interdisciplinary（跨学科的，学术）≠ overlapping（重叠的）
**词根**：cross（交叉）+ cut（切）+ -ing → 横切 → 贯穿多个领域

## ⚠️ 形近词 / 近义词辨析（含场景偏好）

| 词对 | 区别（含使用场景偏好） |
|------|------|
| **constitutionality** vs **constitutional** | constitutionality = 合宪性（名词，法律）；constitutional = 宪法的（形容词）⚠️ 原文拼写错误 |
| **legitimacy** vs **legality** | legitimacy = 合法性/正当性（道义+法律）；legality = 合法性（纯法律条文） |
| **bureaucrat** vs **official** vs **civil servant** | bureaucrat = 官僚（可贬义"僵化"）；official = 官员（中性）；civil servant = 公务员（正式中性） |
| **indictment** vs **accusation** vs **charge** | indictment = 起诉书（正式法律）；accusation = 指控（一般）；charge = 控告（警方/正式） |
| **compensatory** vs **complementary** vs **supplementary** | compensatory = 补偿性的；complementary = 互补的⚠️ 形近一字；supplementary = 补充的 |
| **recruiter** vs **recruit** | recruiter = 招聘者（招人方）；recruit = 新成员（被招方）⚠️ 一词两向 |
| **belt-tightening** vs **austerity** | belt-tightening = 紧缩（新闻常用，形象）；austerity = 紧缩（正式政策术语） |
| **ornate** vs **luxurious** vs **elaborate** | ornate = 装饰繁复华丽（风格）；luxurious = 奢华的（昂贵）；elaborate = 精心制作的（复杂） |
| **originality** vs **creativity** vs **novelty** | originality = 原创性（独立创造）；creativity = 创造力（能力）；novelty = 新颖性（一时新奇） |
| **glamorous** vs **charming** vs **attractive** | glamorous = 魅力光鲜（明星/生活方式）；charming = 迷人亲切；attractive = 有吸引力（通用） |
| **wistful** vs **nostalgic** vs **melancholy** | wistful = 惆怅渴望（柔和）；nostalgic = 怀旧（想回过去）；melancholy = 忧郁（程度重） |
| **foremost** vs **former** | foremost = 首要的（地位）；former = 前者的⚠️ 形近一字 |
| **altruistic** vs **selfless** vs **philanthropic** | altruistic = 利他的（动机）；selfless = 无私的（通用）；philanthropic = 慈善的（捐钱） |
| **pulse** vs **heartbeat** | pulse = 脉搏/脉冲（身体+电子）；heartbeat = 心跳（心脏跳动） |
| **hyperactivity** vs **restlessness** | hyperactivity = 多动（医学术语）；restlessness = 坐立不安（一般） |
| **thriller** vs **horror** | thriller = 惊悚（紧张刺激）；horror = 恐怖（血腥吓人） |
| **deceptiveness** vs **deception** vs **deceit** | deceptiveness = 欺骗性（性质）；deception = 欺骗（行为）；deceit = 欺骗（品质） |
| **falsehood** vs **lie** vs **untruth** | falsehood = 虚假陈述（书面正式）；lie = 谎言（最通用）；untruth = 假话（委婉） |
| **trapper** vs **hunter** | trapper = 设陷阱捕兽者；hunter = 猎人（用枪/弓） |
| **feasible** vs **viable** vs **practicable** | feasible = 可行（可实施）；viable = 可行（可持续/可生存）；practicable = 切实可行 |
| **refute** vs **rebut** vs **contradict** | refute = 驳倒（证明错）；rebut = 反驳（回应）；contradict = 否认（说相反） |
| **irrefutable** vs **undeniable** vs **indisputable** | irrefutable = 无可辩驳（有证据）；undeniable = 不可否认；indisputable = 无可争议 |
| **interdependence** vs **codependence** vs **dependence** | interdependence = 相互依赖（中性正面）；codependence = 病态共同依赖（心理学负面）；dependence = 依赖（单向） |
| **folklore** vs **legend** vs **myth** | folklore = 民间传说（文化风俗）；legend = 传奇（英雄）；myth = 神话（神的故事） |
| **timescale** vs **timeline** vs **period** | timescale = 时间尺度；timeline = 时间线；period = 时期（通用） |
| **universality** vs **unity** vs **uniformity** | universality = 普遍性；unity = 统一性；uniformity = 一致性 |
| **sustainability** vs **sustainable** | sustainability = 可持续性（名词）；sustainable = 可持续的（形容词） |
| **drawn-out** vs **protracted** vs **prolonged** | drawn-out = 拖长冗长（口语）；protracted = 持久的（正式）；prolonged = 延长的（中性）⚠️ 原文 drown-out 拼写错误 |
| **cross-cutting** vs **interdisciplinary** | cross-cutting = 跨领域议题（政策）；interdisciplinary = 跨学科（学术） |
