### ⚠️ 形近词 / 近义词辨析

| 词对 | 区别 |
|------|------|
| **scent** vs **odour** | scent = 香味（好闻的，如香水、花香）；odour = 难闻的气味（如霉味、体味） |
| **council** vs **counsel** vs **consul** | council = 委员会（一群人）；counsel = 劝告/律师（行为或人）；consul = 领事 |
| **consensus** vs **census** | consensus = 共识（共同感觉）；census = 人口普查（统计） |
| **ascent** vs **descent** vs **decent** | ascent = 上升；descent = 下降/血统；decent = 体面的；⚠️ descent vs decent 仅一字之差 |
| **ascend** vs **descend** vs **transcend** | ascend = 上升；descend = 下降；transcend = 超越（跨越往上） |
| **predecessor** vs **successor** vs **ancestor** | predecessor = 前任/前身（职位/产品）；successor = 继任者；ancestor = 祖先（血缘） |
| **property** vs **poverty** | property = 财产；poverty = 贫穷；⚠️ 反义词，仅一字之差 |
| **plant** vs **plot** vs **pilot** | plant = 植物；plot = 情节/阴谋；pilot = 飞行员 |
| **ally** vs **alloy** vs **alley** | ally = 盟友；alloy = 合金；alley = 小巷 |
| **grim** vs **grin** vs **grip** | grim = 阴森的/严酷的（🙁）；grin = 咧嘴笑（😁）；grip = 紧握 |
| **penal** vs **panel** vs **penalty** | penal = 刑罚的；panel = 小组/面板；penalty = 处罚 |
| **scar** vs **scare** vs **scarce** | scar = 伤疤；scare = 惊吓；scarce = 稀少的 |
| **sear** vs **scar** vs **shear** | sear = 灼烧；scar = 疤痕；shear = 剪切 |

| **deficiency** vs **defect** vs **deficit** | deficiency = 缺乏/不足（量上的短缺）；defect = 缺陷（质的毛病）；deficit = 赤字（财政不平衡） |
| **bundle** vs **bunch** vs **bale** | bundle = 捆（紧密捆扎）；bunch = 串/群（松散聚集）；bale = 大捆（打包货物） |
| **rebellion** vs **revolt** vs **revolution** | rebellion = 叛乱（持续久/较大规模）；revolt = 起义（群体/持续时间短）；revolution = 革命（彻底变革） |
| **elaborate** vs **elegant** | elaborate = 精心制作的（复杂精细）；elegant = 优雅的（简洁/高贵） |

### 🎯 高频考点速记

| 考点 | 说明 |
|------|------|
| **bound 的多义性** | be bound up with（密切相关）≠ bound for（前往）≠ be bound to do（一定会做），完型填空高频混淆项 |
| **ascend/descend/transcend 系列** | 同一词根 scend-：ascend 上升、descend 下降、transcend 超越、condescend 屈尊，阅读中根据前缀判断方向 |
| **consensus vs census** | 词汇题经典易混词：consensus = 共识（带 sens 感觉），census = 人口普查 |
| **council vs counsel** | council = 委员会（council meeting 理事会会议），counsel = 劝告/律师（legal counsel 法律顾问），常出现在完型中 |
| **Catholic vs catholic** | 大写 = 天主教的；小写 = 包罗万象的（a catholic taste），一词两义阅读拦路虎 |
| **scent vs odour 辨析** | scent = 香味（好闻），odour = 臭味（难闻），完型/阅读词汇题常考的近义词 |
| **explicitly vs implicitly** | explicitly = 明确地（明说），implicitly = 含蓄地（暗示），反义词对，阅读态度题关键 |
| **sophisticated vs complicated** | sophisticated = 精密的/老练的（褒义），complicated = 复杂的（偏贬义），阅读态度判断 |
| **tempo/pace/rhythm/speed** | tempo = 整体节奏（音乐/生活），pace = 步伐速度，rhythm = 韵律节拍，speed = 速度，搭配不同 |
| **acid vs sour** | acid = 化学酸/尖酸（acid rain 酸雨 / acid remark 尖酸话），sour = 口感酸/馊（sour milk 酸牛奶 / sour grapes 酸葡萄心理） |
| **pile/plot/pilot 三角易混** | plot = 情节/阴谋，pilot = 飞行员/试点，仅一字之差 |
| **property vs poverty** | 反义词形近：property = 财产，poverty = 贫穷，阅读中快速区分看前后文 |
| **yield 的多义性** | yield to = 屈服于；yield = 产量（名词）；yield = 产出（动词），阅读中根据上下文判断 |
