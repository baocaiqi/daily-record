# 📚 CET-6 单词本 (6)

> 排版：每条单词 2-4 行解析，按优先级排列：核心 → 搭配 → 辨析 → 词根/记忆
> 标注：`⚠️` = 易混点/重点 | **加粗** = 核心要点

## 一、宗教与神圣

### 1. **divine** — 神圣的；绝妙的 / v. 猜测
**核心**：**神圣的**，口语中夸张称赞"极好的"；也可作动词"猜测"
**搭配**：divine intervention 神的干预 / divine right 神授之权 / divine inspiration 神启 / "The chocolate mousse was simply divine!" 这巧克力慕斯简直绝了！
**词根**：div- = god（神）→ divine, divinity 神性, divination 占卜

### 2. **divine power** — 神力
**核心**：**神力**，宗教/文学类阅读高频
**搭配**：by divine power 凭借神力 / believe in divine power 信仰神力

### 3. **catholic** — 天主教的；广泛的，包罗万象的
**核心**：⚠️ 大小写决定词义：大写 **Catholic** = 天主教的；小写 catholic = **广泛的/包罗万象的**
**搭配**：a catholic taste in music 广泛的音乐品味 / Roman Catholic 罗马天主教 / the Catholic Church 天主教会
**辨析**：⚠️ Catholic（大写，天主教）≠ catholic（小写，普遍），大小写词义差异是词汇考点
**词根**：cata-（完全）+ hol-（整体）→ 普遍的 → catholic

### 4. **Catholic Church** — 天主教会
**核心**：**天主教会**（专有名词）
**搭配**：the Roman Catholic Church 罗马天主教会 / Catholic Church doctrines 天主教教义
**辨析**：⚠️ Catholic Church（天主教）≠ Protestant Church（新教）≠ Orthodox Church（东正教）

### 5. **pope** — 教皇
**核心**：**教皇**，罗马天主教的最高领袖
**搭配**：Pope Francis 教皇方济各 / the election of a new pope 新教皇选举
**词根**：源自拉丁语 papa（父亲）→ 精神之父 → 教皇

### 6. **temptation** — 诱惑
**核心**：**诱惑**，吸引力；抵制或屈服的对象
**搭配**：resist temptation 抵制诱惑 / yield to temptation 屈服于诱惑 / the temptation to do sth 做某事的诱惑
**词根**：tempt- = try/test（试探）→ tempt, attempt 尝试, contempt 蔑视
**记忆**："Lead us not into temptation." 不叫我们遇见试探（主祷文名句）

## 二、居所与空间

### 7. **hut** — 简陋的小屋，棚屋
**核心**：**简陋小屋/棚屋**，多指临时或简单搭建的
**搭配**：mud hut 土坯房 / beach hut 海滩小屋 / mountain hut 山间小屋
**辨析**：⚠️ hut（简陋小屋）≠ cabin（小木屋，度假/森林）≠ cottage（村舍，田园温馨）≠ shed（工具棚）

### 8. **compartment** — 隔间；（火车）车厢
**核心**：分隔出的**小空间/隔间**；（火车）车厢
**搭配**：glove compartment（汽车）手套箱 / engine compartment 引擎舱 / first-class compartment 头等车厢
**词根**：com-（一起）+ part-（分开）+ -ment → 分隔出来的空间；同根 part, apartment

### 9. **adjoin** — 毗邻，紧挨
**核心**：**毗邻，紧挨**，正式/建筑用语
**搭配**：adjoin the property 与房产毗邻 / adjoining rooms 相邻的房间
**辨析**：⚠️ adjoin（紧挨，正式）≠ adjacent（相邻，偏数学/方位）≠ neighbour（邻居，通用）
**词根**：ad-（向，靠近）+ join（连接）→ 靠近连接 → 毗邻

### 10. **watertight** — 防水的；严密的，无懈可击的
**核心**：**防水的**；比喻**严密无懈可击**（阅读高频）
**搭配**：watertight container 防水容器 / watertight alibi 无懈可击的不在场证明 / watertight case 铁案
**词根**：water + tight（紧的）→ 水进不来 → 防水 → 无懈可击

### 11. **alley** — 小巷，胡同
**核心**：**小巷/胡同**，窄窄的通道
**搭配**：back alley 后巷 / blind alley 死胡同（也喻没有出路的工作）/ alley cat 流浪猫 / bowling alley 保龄球馆
**辨析**：⚠️ be right up one's alley = be up one's street 正合某人的胃口/特长

## 三、气味五兄弟

### 12. **scent** — 气味（尤指香味）；线索 / v. 嗅到
**核心**：⚠️ 通常指**好闻的**气味（香水/花香），难闻的用 odour/stink；也指"线索"
**搭配**：the scent of roses 玫瑰的香味 / a scent of danger 危险的气息 / on the scent of 追踪 / throw sb off the scent 误导某人
**辨析**：⚠️ scent（香味）≠ odour（臭味）≠ smell（中性最通用）

### 13. **the scent of a fox** — 狐狸的气味（踪迹）
**核心**：**狐狸的气味/踪迹**，猎狐/追踪类文学描写
**搭配**：pick up the scent 嗅到踪迹 / lose the scent 失去线索

### 14. **odour** — 气味（常指难闻的）
**核心**：**气味**，常指**难闻的**（如霉味、体味）
**搭配**：body odour (BO) 体味 / a foul odour 恶臭 / a musty odour 霉味 / odourless 无味的
**辨析**：⚠️ odour（英式）= odor（美式）；odour 常指臭味 ≠ smell 中性 ≠ scent 香味 ≠ fragrance 芬芳 ≠ aroma（食物）香气，近义词辨析是词汇题难点

### 15. **a musty odour** — 霉味
**核心**：**霉味**（musty = 发霉、陈腐的）
**搭配**：a musty smell/odour 霉味 / musty old books 发霉的旧书 / a musty room 有霉味的房间
**辨析**：⚠️ musty 与 must（必须）无关，源自古英语"霉"，联想老书必有 musty smell

### 16. **a foul odour** — 恶臭
**核心**：**恶臭**，foul = 令人作呕的臭味
**搭配**：foul smell/odour 恶臭 / foul language 脏话 / foul play 犯规；谋杀嫌疑
**辨析**：⚠️ foul（恶臭作呕）≠ musty（霉味）≠ pungent（刺鼻）≠ stale（不新鲜变味）；"There's a foul smell coming from the fridge." 冰箱里飘出恶臭

## 四、关门声与猛撞

### 17. **slam** — 砰地关上；猛撞；猛烈抨击
**核心**：**砰地关上/猛撞**；引申"猛烈抨击"
**搭配**：slam the door 砰地关门 / slam on the brakes 猛踩刹车 / slam dunk 扣篮 / slam sb 抨击某人 / "He slammed the door in my face." 他当着我的面摔门
**辨析**：⚠️ slam（猛力砰地关）≠ bang（砰一声，不一定是门）≠ shut（关，中性）

### 18. **the slam of a door** — 关门声，摔门声
**核心**：**摔门声**（slam 作名词）
**搭配**：hear the slam of a door 听到摔门声 / the slam of the car door 汽车关门声
**记忆**：slam 是拟声词，模仿砰的关门声

## 五、bound 双雄

### 19. **be bound up with sth** — 与…密切相关
**核心**：与…**密切相关**（抽象联系）
**搭配**：be closely bound up with 与…紧密相连
**辨析**：⚠️ be bound up with（密切相关）≠ bound for（前往）≠ be bound to do（一定会做）
**词根**：bound = bind（捆绑）的过去分词 → 绑在一起的

### 20. **bound for** — 前往，驶往
**核心**：**开往，驶往**某地（具体方向）
**搭配**：a ship bound for New York 开往纽约的船 / homeward bound 回家的 / outward bound 出海的
**辨析**：⚠️ "Where are you bound?" 你去哪儿？（正式/文学用语）

## 六、琐事与让步

### 21. **trifle** — 琐事，小事；少量 / v. 怠慢，小看
**核心**：**琐事，小事**；a trifle = 一点点；⚠️ 与"辞职信"无关（原文混淆，那是 resignation）
**搭配**：a mere trifle 区区小事 / trifle with sb/sth 怠慢，小看 / "He's not a man to be trifled with." 他可不是好惹的
**词根**：tri-（三）+ -fle → 三个小东西 → 琐事

### 22. **notwithstanding** — 尽管，虽然
**核心**：**尽管，虽然**，正式/法律用语，阅读中作转折词识别
**搭配**：Notwithstanding the heavy rain, the match continued. 尽管大雨，比赛仍继续
**辨析**：⚠️ ≈ in spite of ≈ despite ≈ although ≈ albeit（正式程度递减）
**词根**：not + with + stand + -ing → 不用站着（反对）→ 尽管

## 七、关税与私刑

### 23. **tariff** — 关税；价目表
**核心**：**关税**（进口商品税），经济/贸易类阅读高频
**搭配**：impose a tariff 征收关税 / protective tariff 保护性关税 / tariff barrier 关税壁垒 / retaliatory tariff 报复性关税
**辨析**：⚠️ tariff（关税）≠ tax（税，通用）≠ duty（关税，偏英式）≠ levy（征收的税款）

### 24. **lynch** — 以私刑处死，绞杀
**核心**：**私刑处死**（不经法律审判），美国历史/社会类阅读话题
**搭配**：lynch mob 动用私刑的暴民 / be lynched by a mob 被暴民私刑处死
**辨析**：⚠️ lynch（私刑）≠ execute（依法处决）
**词根**：源自美国 Charles Lynch 上校 → lynch law 私刑

## 八、身份与职业

### 25. **privileged** — 有特权的；荣幸的
**核心**：**有特权的**；I feel privileged to... 很荣幸做…
**搭配**：a privileged position 特权地位 / privileged information 机密信息 / the privileged few 少数特权阶层
**词根**：privi-（私人）+ leg-（法律）→ 私有的法律权利 → privilege

### 26. **resignation** — 辞职；辞职信；顺从，听任
**核心**：⚠️ 核心义是**辞职行为**和"顺从，听任"（原文仅写"辞职信"不完整）
**搭配**：letter of resignation 辞职信 / hand in one's resignation 提交辞呈 / resignation to fate 听天由命
**词根**：re-（回）+ sign-（签字）→ 签回 → 辞职 → 放弃抵抗 → 顺从
**记忆**：with resignation 无奈地、顺从地："He accepted the decision with resignation."

### 27. **charitable** — 慈善的；宽厚的
**核心**：**慈善的**；引申"宽厚的，善意的"
**搭配**：charitable organization 慈善组织 / charitable donation 慈善捐款 / charitable interpretation 善意的解读
**词根**：char- = car- = dear/love（爱）→ charity → charitable

### 28. **operative** — 可操作的；有效的 / n. 操作工；特工
**核心**：**生效的，可操作的**；operative word = **关键词**
**搭配**：operative word 关键词 / become operative 生效 / factory operative 工厂操作工 / "The operative word here is 'maybe'." 这里的关键词是"也许"
**词根**：oper- = work（工作）→ operate, operation, operator, cooperate

## 九、健壮与突出

### 29. **sturdy** — 强壮的，结实的；坚定的
**核心**：**结实健壮**（侧重坚固耐用）；坚定的
**搭配**：a sturdy young man 健壮的年轻人 / sturdy furniture 结实的家具 / sturdy resistance 坚决抵抗
**辨析**：⚠️ sturdy（结实耐用）≠ robust（身体好/系统强健）≠ strong（最通用）
**记忆**：sturdy 联想 study → 又学习又锻炼 → 又聪明又强壮

### 30. **salient** — 显著的，突出的
**核心**：**显著的，突出的**，正式/学术写作高频
**搭配**：salient point 要点 / salient feature 显著特征 / salient example 突出例子
**辨析**：⚠️ salient（突出，学术）≠ prominent（显眼/有名）≠ conspicuous（扎眼）
**词根**：sal- = leap/jump（跳）→ 跳出来的 → 突出

### 31. **a salient point** — 要点，突出之处
**核心**：**要点，突出之处**
**搭配**：highlight a salient point 强调要点 / the most salient point 最突出的一点

## 十、简洁与蔓延

### 32. **brevity** — 简短，简洁
**核心**：**简洁，简短**
**搭配**：brevity is the soul of wit 简洁是智慧的灵魂（莎士比亚）/ for the sake of brevity 为简洁起见
**词根**：brev- = short（短）→ brief, abbreviate

### 33. **wordy** — 冗长的，啰嗦的
**核心**：**啰嗦冗长**（用词太多，偏负面）
**搭配**：a wordy explanation 冗长的解释 / wordy writing 啰嗦的文风
**辨析**：⚠️ wordy（口语，啰嗦）≠ verbose（正式/文学）≠ long-winded（口语化）≠ concise（简洁，反义词）
**词根**：word + -y（形容词后缀）→ 词太多 → 啰嗦

### 34. **rampant** — 猖獗的，泛滥的；疯长的
**核心**：**猖獗泛滥**（多指坏事）；疯长的
**搭配**：rampant inflation 恶性通胀 / rampant corruption 猖獗腐败 / the disease is rampant 疾病肆虐 / rampant weeds 疯长的杂草
**词根**：ramp- = climb（攀爬）→ 到处爬 → 蔓延/猖獗

### 35. **makeshift** — 临时凑合的，权宜的 / n. 临时替代品
**核心**：**临时凑合的，权宜的**（强调简陋应急）
**搭配**：a makeshift shelter 临时避难所 / makeshift solution 权宜之计 / makeshift camp 临时营地
**辨析**：⚠️ makeshift（简陋应急）≠ temporary（临时，中性）≠ provisional（正式，之后会换）
**词根**：make + shift（变换）→ 临时做了一个调整 → 权宜的

### 36. **shifting** — 不断变化的，流动的
**核心**：**不断变化的，流动的**
**搭配**：shifting sands 流沙（喻不稳定的局面）/ shifting priorities 不断变化的优先事项 / shifting population 流动人口
**词根**：shift- = change/move（变化）→ shift, shifting, shape-shifter

## 十一、相似与倾向

### 37. **akin** — 类似的，相似的
**核心**：**类似的**（性质上相似，正式）
**搭配**：be akin to sth 与…类似 / something akin to 有点像…的东西 / akin to despair 近乎绝望
**词根**：a-（= of）+ kin（亲属，家族）→ 同一家族的 → 相似的

### 38. **analogous** — 类似的，可类比的
**核心**：**可类比的**（逻辑/系统性相似，学术论证）
**搭配**：be analogous to 与…类似 / draw an analogy 作类比
**辨析**：⚠️ analogous（逻辑可类比）≠ akin（性质上相似）≠ similar（最通用）≠ identical（完全相同）
**词根**：ana-（按照）+ log-（说，推理）→ 按同样的方式推理

### 39. **be analogous to** — 和…类似，可与…类比
**核心**：与…**可类比**
**搭配**："The human heart is analogous to a pump." 人的心脏类似于一个水泵。

### 40. **inclination** — 倾向，意愿；爱好
**核心**：**倾向/意愿**（偏内在兴趣）
**搭配**：an inclination to do sth 做某事的倾向 / follow one's own inclinations 随心所欲 / artistic inclinations 艺术爱好
**辨析**：⚠️ inclination（意愿，主观）≠ tendency（客观规律）≠ preference（二选一偏好）
**词根**：in-（向）+ clin-（倾斜）→ 倾向；同根 incline, decline

### 41. **an inclination to** — 有意愿做…
**核心**：**做…的意愿/倾向**
**搭配**：show an inclination to 显示出…的倾向 / have an inclination to lie 有说谎的倾向

### 42. **be immune to sth** — 对…免疫；不受…影响
**核心**：对…**免疫**；不受…**影响**
**搭配**：be immune to criticism 不在乎批评 / be immune to the disease 对该疾病免疫 / immune system 免疫系统
**词根**：im-（不）+ mun-（服务，职责）→ 不用服务的 → 免疫的 → 不受影响

### 43. **temptation** — 见 #6（诱惑）
**核心**：⚠️ 与 #6 重复，见「一、宗教与神圣」第 6 条
**搭配**：resist temptation 抵制诱惑 / yield to temptation 屈服于诱惑

## 十二、思考与理想

### 44. **idealist** — 理想主义者
**核心**：**理想主义者**（追求理想的人）
**搭配**：a dreamy idealist 爱空想的理想主义者 / youthful idealist 年轻的理想主义者
**辨析**：⚠️ idealist（理想主义者）≠ realist（现实主义者）≠ pessimist（悲观主义者）≠ optimist（乐观主义者）
**词根**：idea（理念）→ ideal → idealist → idealism 理想主义

### 45. **unreflecting** — 不假思索的，缺乏思考的
**核心**：⚠️ 主要指**不加思考/缺乏反思的**（原文"不反射的"有误导；表"不反光"应说 non-reflective）
**搭配**：unreflecting obedience 盲从 / unreflecting acceptance 不加思考地接受
**词根**：un-（不）+ re-（回）+ flect-（弯曲，反射）→ 不回头想 → 缺乏思考
**记忆**：reflect（反思）→ unreflecting（不反思的）

## 十三、复杂与同质

### 46. **intricate** — 错综复杂的
**核心**：**错综复杂**（细节交织，复杂精细）
**搭配**：intricate patterns 复杂的图案 / an intricate plot 错综复杂的情节 / intricate details 繁复的细节
**辨析**：⚠️ intricate（细节交织）≠ complex（最通用）≠ complicated（复杂难懂，偏负面）
**词根**：in-（进入）+ tric-（琐事，纠缠）→ 纠缠不清 → intricate；同源 intrigue 阴谋

### 47. **intricacy** — 错综复杂；复杂精细之处
**核心**：**错综复杂**（名词）；复杂精细之处
**搭配**：the intricacy of the design 设计的精巧复杂 / understand the intricacies of 理解…的复杂之处 / legal intricacies 法律的复杂之处

### 48. **homogenization** — 同质化，均质化
**核心**：**同质化**（不同事物变得相同），全球化/文化类阅读话题
**搭配**：cultural homogenization 文化同质化 / milk homogenization 牛奶均质处理
**辨析**：⚠️ homogenization（变得相同）≠ standardization（按统一标准制作）
**词根**：homo-（相同）+ gen-（种类，产生）→ 同类化

## 十四、自然与生物

### 49. **herbivore** — 食草动物
**核心**：**食草动物**
**辨析**：⚠️ herbivore（食草）≠ carnivore（食肉）≠ omnivore（杂食）≠ insectivore（食虫）
**词根**：herb-（草）+ vor-（吃）→ 吃草的动物；同根 devour 狼吞虎咽, voracious 贪吃的

### 50. **antenna** — 触角；天线
**核心**：**触角/天线**；复数区分：昆虫触角 antennae，天线 antennas
**搭配**：TV antenna 电视天线 / satellite antenna 卫星天线 / insect antennae 昆虫触角

## ⚠️ 形近词 / 近义词辨析（含场景偏好）

| 词对 | 区别 |
|------|------|
| **scent** vs **odour** | scent = 香味（好闻，如香水、花香）；odour = 难闻的气味（如霉味、体味） |
| **council** vs **counsel** vs **consul** | council = 委员会（一群人）；counsel = 劝告/律师（行为或人）；consul = 领事 |
| **consensus** vs **census** | consensus = 共识（共同感觉）；census = 人口普查（统计） |
| **ascent** vs **descent** vs **decent** | ascent = 上升；descent = 下降/血统；decent = 体面的；⚠️ descent vs decent 仅一字之差 |
| **ascend** vs **descend** vs **transcend** | ascend = 上升；descend = 下降；transcend = 超越（跨越往上） |

## 🎯 高频考点速记

| 考点 | 说明 |
|------|------|
| **bound 的多义性** | be bound up with（密切相关）≠ bound for（前往）≠ be bound to do（一定会做），完型填空高频混淆项 |
| **ascend/descend/transcend 系列** | 同一词根 scend-：ascend 上升、descend 下降、transcend 超越、condescend 屈尊，阅读中根据前缀判断方向 |
| **consensus vs census** | 词汇题经典易混词：consensus = 共识（带 sens 感觉），census = 人口普查 |
| **council vs counsel** | council = 委员会（council meeting 理事会会议），counsel = 劝告/律师（legal counsel 法律顾问），常出现在完型中 |
| **Catholic vs catholic** | 大写 = 天主教的；小写 = 包罗万象的（a catholic taste），一词两义阅读拦路虎 |
| **scent vs odour 辨析** | scent = 香味（好闻），odour = 臭味（难闻），完型/阅读词汇题常考的近义词 |
| **explicitly vs implicitly** | explicitly = 明确地（明说），implicitly = 含蓄地（暗示），反义词对，阅读态度题关键 |
| **sophisticated vs complicated** | sophisticated = 精密的/老练的（褒义），complicated = 复杂的（偏贬义），阅读态度判断 |
| **tempo/pace/rhythm/speed** | tempo = 整体节奏（音乐/生活），pace = 步伐速度，rhythm = 韵律节拍，speed = 速度，搭配不同 |
| **acid vs sour** | acid = 化学酸/尖酸（acid rain 酸雨 / acid remark 尖酸话），sour = 口感酸/馊（sour milk 酸牛奶 / sour grapes 酸葡萄心理） |
| **plant/plot/pilot 三角易混** | plot = 情节/阴谋，pilot = 飞行员/试点，仅一字之差（原"pile"系笔误，应为 plant） |
| **property vs poverty** | 反义词形近：property = 财产，poverty = 贫穷，阅读中快速区分看前后文 |
| **yield 的多义性** | yield to = 屈服于；yield = 产量（名词）；yield = 产出（动词），阅读中根据上下文判断 |
