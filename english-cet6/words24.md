# 📚 CET-6 单词本 (24)

> 排版：每条单词 2-4 行解析，按优先级排列：核心 → 搭配 → 辨析 → 词根/记忆
> 标注：`⚠️` = 易混点/重点 | `⭐️` = 六级熟词僻义 | **加粗** = 核心要点

## 一、人与社会

### 1. **patron** — 赞助人；老主顾
**核心**：出钱**资助**艺术/事业的人；也指**老顾客**
**搭配**：a patron of the arts 艺术赞助人 / a regular patron 常客
**辨析**：patron（赞助人/老主顾）≠ sponsor（赞助商，多指企业出资）
**词根**：patr- = father（父亲，拉丁 pater）+ -on → 如父般庇护 → 资助人

### 2. **patronage** — 赞助；光顾；庇护
**核心**：**资助行为**；顾客的**惠顾**；也指提携、任人唯亲
**搭配**：under the patronage of 在…赞助下 / withdraw one's patronage 不再光顾
**辨析**：patronage（资助/惠顾，抽象名词）vs patron（资助人，具体的人）
**词根**：patron + -age（名词后缀）；同根 patronize 光顾/屈尊俯就

### 3. **fellowship** — 友谊；团体；奖学金
**核心**：**伙伴情谊**；学会/团体；研究生的**奖学金**
**搭配**：a sense of fellowship 同伴情谊 / a research fellowship 研究奖学金
**辨析**：fellowship（情谊/学术资助）vs friendship（友谊，通用）vs scholarship（奖学金，本科多）
**词根**：fellow（伙伴）+ -ship（状态/身份）

### 4. **bride** — 新娘
**核心**：**婚礼上的新娘**；新郎是 groom / bridegroom
**搭配**：bride and groom 新娘与新郎 / a bride-to-be 准新娘
**辨析**：bride（新娘）↔ bridegroom/groom（新郎）；bridal adj. 婚礼的
**词根**：古英语 bryd；同根 bridal 新娘的/婚礼的

### 5. **sibling** — 兄弟姐妹
**核心**：**同胞兄弟或姐妹**（不分性别；单数指其中一个）
**搭配**：sibling rivalry 手足之争 / younger siblings 弟弟妹妹
**辨析**：sibling（兄弟姐妹，正式）vs brother/sister（通用，区分性别）
**词根**：古英语 sibb（亲属）+ -ling（表人）→ 亲属

### 6. **steward** — 男乘务员；管家；干事
**核心**：**男乘务员**；大宅**管家**；赛事/组织的**干事**
**搭配**：a cabin steward 客舱乘务员 / the race steward 赛事干事
**辨析**：steward（男）↔ stewardess（女，旧称）；现代多用 flight attendant
**词根**：古英语 stiweard（厅堂看守人）；同根 stewardess 女乘务员

### 7. **stewardess** — 女乘务员
**核心**：**女性乘务员/空乘**（旧称，今多称 flight attendant）
**搭配**：an air stewardess 空姐 / a train stewardess 列车女乘务员
**辨析**：⚠️ stewardess 带性别色彩、渐被淘汰；中性说法 **flight attendant** 更通行
**词根**：steward + -ess（女性后缀）；同根 steward 男乘务员

### 8. **menace** — 威胁；危险人物，讨厌鬼
**核心**：n. **威胁/危险**；**危险人物/惹麻烦的人**（口语）；v. 威胁
**搭配**：a menace to society 社会公害 / a public menace 公害分子
**辨析**：⚠️ 原文"卑鄙小人，讨厌鬼"仅取口语引申义；核心义为**威胁**
**词根**：拉丁 minacia（威胁）；同根 menacing 险恶的

### 9. **nominate** — 提名，推荐；任命
**核心**：**提名**（候选人）；正式**任命/指定**
**搭配**：nominate sb for the award 提名某人获奖 / nominate sb as chairman 任命某人为主席
**辨析**：nominate（提名/任命）vs appoint（任命正式职务）vs designate（正式指定）
**词根**：nomin- = name（名字）+ -ate → 报上名字 → 提名；同根 nominal 名义上的

### 10. **nominee** — 被提名者，候选人
**核心**：**被提名的人**（-ee 表被动方）；奖项/职位候选人
**搭配**：the Oscar nominee 奥斯卡提名者 / a nominee for the post 该职位候选人
**辨析**：nominee（被提名者，被动）↔ nominator（提名者，主动）
**词根**：nomin-（名字）+ -ee（被…者）；同类 employee 雇员, appointee 被任命者

## 二、情感与境遇

### 11. **reluctant** — 不情愿的，勉强的
**核心**：**不愿做、勉强答应**（be reluctant to do）
**搭配**：be reluctant to do sth 不愿做某事 / a reluctant agreement 勉强的同意
**辨析**：reluctant（不情愿，多因不愿）vs unwilling（不愿意，更强硬）vs hesitant（犹豫，未定）
**词根**：re-（反）+ luct- = struggle（挣扎）→ 挣扎抗拒 → 不情愿；同根 reluctance 不情愿

### 12. **indignant** — 愤慨的，义愤的
**核心**：因**受委屈/不公**而愤怒的（正当义愤）
**搭配**：be indignant at/over sth 对…愤慨 / an indignant letter 义愤的抗议信
**辨析**：indignant（因不公而义愤，正当）vs angry（生气，通用）vs furious（暴怒，强烈）
**词根**：in-（不）+ dign- = worthy（值得）→ 觉得不配如此对待 → 愤慨；同根 dignity 尊严

### 13. **astonish** — 使惊讶，使震惊
**核心**：v. **使人极度惊讶**；⚠️ 原文"震惊的"是形容词 **astonished**
**搭配**：be astonished at/by 对…感到惊讶 / an astonishing result 惊人的结果
**辨析**：astonish（惊讶到发愣，程度强）vs surprise（使意外，通用）vs amaze（使惊叹）
**词根**：ex-（出）+ ton- = thunder（雷）→ 雷击般 → 震惊；同根 astonished 惊讶的

### 14. **humiliate** — 使羞辱，使丢脸
**核心**：**使人当众出丑、自尊受损**
**搭配**：humiliate sb in public 当众羞辱某人 / a humiliating defeat 丢脸的失败
**辨析**：humiliate（羞辱，伤自尊，重）vs embarrass（使尴尬，轻）vs shame（使羞愧，含道德）
**词根**：hum- = ground（地，拉丁 humus 土）→ 按到地上 → 羞辱；同根 humble 谦卑的

### 15. **brag** — 吹嘘，自夸
**核心**：v. **自吹自擂**（含贬义）；brag about/of sth
**搭配**：brag about one's success 吹嘘成就 / a bragging tone 自夸的口吻
**辨析**：brag（吹牛，贬义，口语）vs boast（夸耀，可中性）vs show off（炫耀，侧重展示）
**词根**：中古英语 braggen；口语色彩浓

### 16. **nagging** — 唠叨的；挥之不去的
**核心**：**不停叨扰/抱怨**的；也指**挥之不去的**（疑虑/疼痛）
**搭配**：a nagging wife 唠叨的妻子 / a nagging doubt 挥之不去的疑虑 / a nagging pain 隐痛
**辨析**：nagging（唠叨/纠缠，贬义）vs complaining（抱怨，中性）
**词根**：nag（v. 唠叨/不断烦扰）+ -ing

### 17. **dispute** — 争端，纠纷；争论
**核心**：n. **争执/纠纷**；v. 争论/对…质疑
**搭配**：a border dispute 边界争端 / beyond dispute 无可争议 / dispute the claim 质疑该主张
**辨析**：dispute（争端，正式，可指法律/国际）vs quarrel（口角，私人）vs argument（争论，通用）
**词根**：dis-（分开）+ put- = think（思考）→ 想法分歧 → 争论；同根 compute 计算

### 18. **sobering** — 令人警醒的，发人深省的
**核心**：⚠️ 原文"清醒的"有误——形容词 **sober** 才是"清醒的"；**sobering** = 使人清醒/警觉的
**搭配**：a sobering thought 令人警醒的想法 / sobering statistics 发人深省的数据
**辨析**：sobering（令人警醒，修饰事物）vs sober（清醒的/未醉的，形容人）
**词根**：sober（清醒）+ -ing；同根 sobriety 清醒/节制

### 19. **plight** — 困境，苦难处境
**核心**：**艰难不幸的境况**（尤指严重、值得同情）
**搭配**：the plight of refugees 难民的困境 / in a desperate plight 处于绝境
**辨析**：plight（严重困境，多含同情，正式）vs predicament（尴尬处境）vs dilemma（两难）
**词根**：源自古法语 plit（处境）；多用于新闻报道

### 20. **salvation** — 拯救，救赎
**核心**：**从危难/罪恶中得救**；宗教义"灵魂得救"
**搭配**：seek salvation 寻求救赎 / be sb's salvation 是某人的救星
**辨析**：salvation（救赎，宗教/重大，正式）vs rescue（营救，具体）vs redemption（赎罪/救赎）
**词根**：salv- = save（救）+ -ation；同根 save 拯救, salvage 抢救

## 三、言辞与说服

### 21. **stipulate** — 规定，明确要求
**核心**：v.（协议/合同）**明文规定**；stipulate that...
**搭配**：stipulate the terms 规定条款 / as stipulated in the contract 按合同规定
**辨析**：stipulate（合同明文规定，正式）vs specify（具体指明）vs require（要求，通用）
**词根**：stip- = press tight（压紧，拉丁 stipes 木桩）+ -ate → 钉死条款 → 规定；同根 stipulation 规定

### 22. **rhetoric** — 修辞（学）；花言巧语
**核心**：n. **修辞技巧**；常含贬义 = **华而不实的说辞**
**搭配**：political rhetoric 政治空话 / mere rhetoric 空话连篇 / the art of rhetoric 修辞艺术
**辨析**：⚠️ rhetoric 是**名词**；"修辞的/花言巧语的"形容词是 **rhetorical**
**词根**：rhetor- = orator（演说家）+ -ic；同根 rhetorical 修辞的

### 23. **doctrine** — 教义，学说；主义
**核心**：**成体系的信念/学说**（宗教、政治、法律）
**搭配**：Catholic doctrine 天主教教义 / the Monroe Doctrine 门罗主义 / legal doctrine 法律学说
**辨析**：doctrine（系统学说，中性/正式）vs dogma（教条，贬义，强调不容置疑）
**词根**：doc- = teach（教导，拉丁 docere）+ -trine；同根 doctor 博士, document 文件

### 24. **dogma** — 教条，信条
**核心**：**不容置疑的教义**（含贬义：僵化）
**搭配**：political dogma 政治教条 / party dogma 党的信条
**辨析**：⚠️ dogma（贬义：僵化教条）vs doctrine（中性：学说）——语气不同
**词根**：希腊 dogma（意见/信条）；同根 dogmatic 武断的/教条的

### 25. **testimony** — 证词，证言；证明
**核心**：**法庭证词**；引申"（有力）证明"
**搭配**：give testimony 作证 / bear testimony to sth 为…作证 / expert testimony 专家证词
**辨析**：testimony（证词，法律/正式）vs evidence（证据，物证/泛指）vs witness（证人）
**词根**：test- = witness（见证）+ -imony；同根 testify 作证, testament 证明

### 26. **provocative** — 挑衅的；煽动性的；引人深思的
**核心**：⚠️ 原文 provokative 拼写有误；**激起反应**的（愤怒或思考）
**搭配**：a provocative remark 挑衅性言论 / a provocative question 发人深省的问题
**辨析**：provocative（挑动/引发反应，褒贬皆可）vs offensive（冒犯的，贬义）
**词根**：pro-（向前）+ voc- = call（喊）+ -ative → 叫嚣引出 → 挑衅；同根 provoke 激怒

### 27. **stimulus** — 刺激（物）；激励；促进因素
**核心**：n. 复数 **stimuli**；**引发反应/促进发展**的因素
**搭配**：a stimulus to growth 增长的刺激因素 / sensory stimulus 感官刺激 / economic stimulus 经济刺激
**辨析**：stimulus（促进因素，中性/学术）vs stimulant（兴奋剂，物质）vs incentive（激励，侧重动机）
**词根**：stim- = goad（刺棒，拉丁 stimulare）+ -us；同根 stimulate 刺激

### 28. **appealing** — 有吸引力的，动人的
**核心**：**惹人喜爱/令人心动的**（比 attractive 更亲和）
**搭配**：an appealing smile 迷人的微笑 / appealing to the eye 赏心悦目
**辨析**：appealing（动人、招人喜欢）vs attractive（有吸引力，多指外貌）vs charming（有魅力，气质）
**词根**：ap-（向）+ peal- = drive（驱赶）→ 吸引过来；同根 appeal 吸引/上诉

### 29. **appeal** — ⭐️吸引力；呼吁；上诉
**核心**：n./v. **吸引力**（lose one's appeal 失去吸引力）；**呼吁**；**上诉**
**搭配**：lose your appeal 丧失吸引力 / appeal to sb 吸引某人/呼吁某人
**辨析**：⚠️ 一词多义：吸引（the appeal of…）/ 恳求（appeal for help）/ 上诉（appeal to a higher court）
**词根**：拉丁 appellare（呼叫）；同根 appealing 动人的

## 四、法律与治理

### 30. **sanction** — ⭐️制裁；批准，认可
**核心**：n. **制裁**（常用复数 sanctions）；⭐️ 熟词僻义 **批准/认可**（v./n.）；v. 批准
**搭配**：impose sanctions on 对…实施制裁 / official sanction 官方批准 / sanction the use of force 授权动武
**辨析**：⚠️ 一词两义相反：**制裁**（惩罚）vs **批准**（许可）——靠语境判断
**词根**：sanct- = holy（神圣，拉丁 sancire 批准）→ 批准；引申"制裁"；同根 sanctuary 圣所

### 31. **file an appeal** — 提出上诉，提交申诉
**核心**：**向法院递交上诉**；file 意为"正式提交"
**搭配**：file an appeal against the ruling 对裁决提出上诉 / file a lawsuit 提起诉讼
**辨析**：appeal（上诉，法律）vs plea（请求/抗辩）vs petition（请愿，联名）
**词根**：file（提交，源自"归档"）+ appeal（上诉）

### 32. **lay claim to sth** — 声称对…拥有权利
**核心**：**公开主张（所有权/资格）**；claim 作名词
**搭配**：lay claim to the throne 觊觎王位 / lay claim to the inheritance 主张继承权
**辨析**：lay claim to（主张权利，正式）vs claim（v. 声称，通用）vs demand（索要，强硬）
**词根**：lay（放置）+ claim（主张）；claim 同根 proclamation 公告

### 33. **in accordance with** — 依照，与…一致
**核心**：**按照（规定/法律）**，正式书面
**搭配**：in accordance with the law 依法 / in accordance with the contract 按合同
**辨析**：in accordance with（依照，正式）≈ according to（根据，通用）vs in line with（与…相符）
**词根**：accord（一致）+ -ance；同根 accord 一致

### 34. **safeguard** — 保护措施；保障；保护
**核心**：n. **防护措施/保障条款**；v. 保护（免受损害）
**搭配**：a safeguard against fraud 防欺诈措施 / legal safeguards 法律保障 / safeguard one's rights 保障权利
**辨析**：safeguard（预防性保护措施）vs protection（保护，通用）vs security（安全，状态）
**词根**：safe（安全）+ guard（守卫）→ 保障

### 35. **violate** — 违反；侵犯；亵渎
**核心**：**违背（法律/协议）**；**侵犯（权利/隐私）**；亵渎（圣地）
**搭配**：violate the law 违法 / violate sb's privacy 侵犯隐私 / violate a treaty 违反条约
**辨析**：⚠️ 原文"抵抗，忤逆"不准；violate = 违反/侵犯（非"抵抗"）；violation n. 违反/侵犯
**词根**：viol- = force（暴力，拉丁 violare）→ 强行破坏 → 违反；同根 violence 暴力

### 36. **unanimous** — 一致同意的，全体一致的
**核心**：⚠️ 原文"不一致的"**释义完全错误**；**unanimous = 全体一致同意**（反义 divided）
**搭配**：a unanimous decision 一致决定 / be unanimous in doing 一致同意做
**辨析**：unanimous（全体一致，强调无异议）；⚠️ 与"不一致"（inconsistent/not unanimous）相反
**词根**：un-（一）+ anim- = mind（心智，拉丁 animus）+ -ous → 同一心意 → 一致

### 37. **charitable** — 仁慈的，宽厚的；慈善的
**核心**：⚠️ 原文 chartiable 拼写有误；**慈善的**（组织/捐赠）；**宽厚的**（对他人评价）
**搭配**：a charitable organization 慈善机构 / a charitable donation 慈善捐款 / a charitable view 宽厚的看法
**辨析**：charitable（慈善的/宽厚的）vs benevolent（仁慈的，正式）vs generous（慷慨的）
**词根**：charit- = love（仁爱，拉丁 caritas）+ -able；同根 charity 慈善

### 38. **notwithstanding** — 尽管，虽然
**核心**：**尽管**（= despite），正式书面；可置于句首/句尾
**搭配**：notwithstanding the difficulties 尽管有困难 / notwithstanding that... 尽管…
**辨析**：notwithstanding（尽管，正式）≈ despite/in spite of；后接名词（除 notwithstanding that）
**词根**：not（不）+ withstanding（抵抗）→ 虽受阻力仍…→ 尽管

## 五、商业与经济

### 39. **transaction** — 交易；业务，事务
**核心**：**一笔交易/办理的业务**（买卖、转账等）
**搭配**：complete a transaction 完成一笔交易 / a business transaction 商业交易 / transaction costs 交易成本
**辨析**：transaction（单笔交易，正式）vs deal（交易，口语）vs business（生意，泛指）
**词根**：trans-（穿过）+ act- = do（做）+ -ion → 达成 → 交易；同根 act 行动

### 40. **commodity** — 商品，货物
**核心**：⚠️ 原文"商业"有误；**commodity = 商品/大宗货物**（可数）
**搭配**：a commodity market 商品市场 / commodities like oil 石油等大宗商品
**辨析**：commodity（商品/大宗货物，经济术语）vs goods（货物，通用）vs product（产品）
**词根**：com-（共同）+ mod- = measure（衡量）+ -ity → 按量交换之物 → 商品

### 41. **manufacture** — 制造；（the ~）制造业
**核心**：v. **（批量）制造**；n. **制造（业/品）**——⚠️ 指"制造业"整体多用 **manufacturing**
**搭配**：manufacture cars 制造汽车 / the manufacture of cloth 布匹制造 / manufacturing industry 制造业
**辨析**：manufacture（制造，动/名）vs manufacturing（制造业，名词）vs produce（生产，通用）
**词根**：manu- = hand（手）+ fact- = make（做）→ 用手做 → 制造；同根 factory 工厂, manual 手工的

### 42. **manufactory** — 制造厂，工厂（旧词）
**核心**：**制造厂/作坊**（旧用法，今多用 factory/mill）

**辨析**：inadequacy（不足/欠缺，可指自我感觉）vs insufficiency（不足，较客观）vs inferiority（自卑/劣势）
**词根**：in-（不）+ ad-（向）+ equ- = equal（相等）→ 不够相等 → 不足；同根 adequate 足够的

### 82. **hokey** — 做作的，虚情假意的；老套的
**核心**：⚠️ 原文"hockey"有误——**hockey 是曲棍球（运动）**；表"做作的"应是 **hokey**（美式口语）
**搭配**：a hokey ending 俗套的结局 / hokey sentimentality 虚情假意的煽情
**辨析**：hokey（做作/俗套，口语贬义）vs hockey（曲棍球，名词，同音不同义）
**词根**：美式口语 hokum（噱头）+ -y；同根 hokum 陈词滥调

### 83. **discrepancy** — 差异，不一致
**核心**：⚠️ 原文 discrepency 拼写有误；**（两事物间不应有的）出入/矛盾**
**搭配**：a discrepancy between the two accounts 两本账目间的出入 / price discrepancies 价格差异
**辨析**：discrepancy（不一致/出入，含"应有而无"义）vs difference（差异，中性）vs inconsistency（前后矛盾）
**词根**：dis-（分开）+ crep- = sound（响，拉丁 crepare）→ 声音不齐 → 不一致

## 十一、动作与变化

### 84. **cease** — 停止，终止
**核心**：v. **（正式）停止**（比 stop 书面）；cease to do / cease doing
**搭配**：cease fire 停火 / cease to exist 不复存在 / cease and desist 停止并终止（法律）
**辨析**：cease（停止，正式书面）vs stop（停止，口语通用）vs halt（暂停，尤行进）
**词根**：拉丁 cessare（停）；同根 cessation 停止, incessant 不断的

### 85. **destined to** — 注定要，命中注定
**核心**：**be destined to do/for** 命中注定（或被安排）要…
**搭配**：be destined to fail 注定失败 / be destined for greatness 注定不凡
**辨析**：destined（命中注定，含宿命感）vs doomed（注定失败/毁灭，贬义）vs bound to（必定，中性）
**词根**：de-（加强）+ stin- = fix（固定）→ 定下 → 注定；同根 destiny 命运, destination 目的地

### 86. **render** — 使成为；给予，提供；表达
**核心**：v. **使…变得**（render sb helpless）；**提供/给予**（服务、帮助）；"表达/翻译"
**搭配**：render sb helpless 使某人无助 / render assistance 提供帮助 / render sth into English 译成英文
**辨析**：render（使成为/正式给予）vs make（使得，通用）vs provide（提供，通用）
**词根**：re-（回）+ der- = give（给，拉丁 dare）→ 归还/给予；同根 surrender 投降

### 87. **fuel** — 助长，加剧；燃料；加油
**核心**：v. **刺激/加剧**（争论、情绪）；n. **燃料**
**搭配**：fuel speculation 助长猜测 / fuel inflation 加剧通胀 / fossil fuels 化石燃料
**辨析**：fuel（加剧/刺激，比喻）vs trigger（引发，瞬间）vs aggravate（使恶化）
**词根**：拉丁 focus（炉火）→ 燃料；同根 fueling 加油

### 88. **roam** — 漫游，闲逛
**核心**：v. **无目的地游荡/漫步**（over/through a place）
**搭配**：roam the streets 在街上闲逛 / roam around the world 周游世界
**辨析**：roam（漫游，范围较大）vs wander（漫步，可含迷路）vs stroll（悠闲散步，短距）
**记忆**：roam ≈ 大范围游荡；roaming charges 漫游费（手机）

### 89. **tangle** — 缠结；纠纷；使缠结
**核心**：v./n. **（使）缠结/纠结**；引申 **纠纷/混乱**（in a tangle）
**搭配**：tangle with sb 与某人起争执 / be tangled in 被卷入… / a tangle of wires 一团乱线
**辨析**：tangle（缠结/纠纷）vs twist（扭/曲解）vs knot（打结，节点）
**词根**：中古英语 tangilen；同根 tangled 纠缠的/错综复杂的

### 90. **dispense** — 分发，分配；配（药）
**核心**：v. **分发/施予**（物品）；**配药**（药剂师）
**搭配**：dispense medicine 配药 / dispense advice 给予忠告 / a dispensing machine 自动售货机
**辨析**：dispense（分发/配药）vs distribute（分发，范围广）vs administer（施予/管理）
**词根**：dis-（分开）+ pens- = weigh（称量，拉丁 pendere）→ 按量分出 → 分发；同根 compensate 补偿

### 91. **underlie** — 构成…的基础；潜藏于
**核心**：⚠️ 原文"强调"有误；**underlie = 位于…之下/是…的根源**（过去式 underlay）
**搭配**：the principles that underlie the policy 政策背后的原则 / underlying causes 根本原因
**辨析**：underlie（构成基础/潜藏）vs emphasize（强调）——原文误；underlying adj. 潜在的/根本的
**词根**：under（下面）+ lie（躺）→ 躺在下面 → 构成基础

## 十二、短语与句式

### 92. **dispense with** — 免除，省去；无须
**核心**：**不再需要/用不着**（dispense with sth），正式
**搭配**：dispense with formalities 省去礼节 / dispense with sb's services 解雇某人
**辨析**：⚠️ dispense with（省去/免除）≠ dispense（分发）——加 with 意义大不同
**词根**：dispense（分发）+ with → 把…分发掉 → 免除

### 93. **be geared to/towards** — 为…而设计；适应
**核心**：**按…的需要设计/调整**（be geared to sth/doing）
**搭配**：be geared to the needs of students 适应学生需求 / be geared towards export 面向出口
**辨析**：be geared to（为…设计/适应）vs be adapted to（适应，调整）vs be aimed at（旨在）
**词根**：gear（齿轮/调节）+ -ed → 调好档位 → 适应

### 94. **be bound up with** — 与…密切相关
**核心**：**与…紧密相连/不可分割**（be bound up with sth），正式
**搭配**：be bound up with economic growth 与经济增长密不可分 / be closely bound up with 与…息息相关
**辨析**：be bound up with（密切相关，正式）≈ be closely linked to vs be bound to（必定，另一义）
**词根**：bind（捆绑）+ up → 捆在一起 → 紧密相连

### 95. **give occasion to** — 引起，招致
**核心**：⚠️ 原文"有可能"有误；**give occasion to = 引起/成为…的缘由**（≈ give rise to）
**搭配**：give occasion to scandal 引发丑闻 / give occasion for complaint 招致抱怨
**辨析**：give occasion to（引起，正式）≈ give rise to（引起/导致）vs be likely to（有可能，另一义）
**词根**：occasion（时机/缘由）+ give；同根 occasional 偶尔的

### 96. **draw on** — 利用，动用；吸（烟）
**核心**：**凭借/动用**（资源、经验、资金）；趋近（时间）
**搭配**：draw on one's experience 凭借经验 / draw on reserves 动用储备 / draw on a cigarette 吸烟
**辨析**：draw on（利用资源/经验）vs rely on（依赖，靠）vs fall back on（退而求其次依赖）
**词根**：draw（拉取）+ on → 从中取用

### 97. **wear off** — 逐渐消失，逐渐减弱
**核心**：**（效果、感觉）渐渐消退**（wear 的过去式 wore）
**搭配**：the effect wore off 效果消退 / the novelty wears off 新鲜感渐消
**辨析**：wear off（逐渐消退）vs wear out（用坏/使疲惫）vs fade away（逐渐淡去）
**词根**：wear（磨损）+ off → 磨掉 → 消退

### 98. **catch up on** — 补做；了解（近况）
**核心**：**补上（耽误的事）**；**补看/追（新闻、剧集）**
**搭配**：catch up on sleep 补觉 / catch up on the news 补看新闻 / catch up on work 赶完工作
**辨析**：catch up on（补做/补看某事）vs catch up with（追上人/赶上进度）vs keep up with（跟上）
**词根**：catch（抓住）+ up on → 追赶补上

### 99. **at once** — ⭐️立刻；同时
**核心**：⭐️ 熟词僻义：**at once = 立刻/马上**；也可指 **同时**（at one and the same time）
**搭配**：do it at once 立刻去做 / all at once 突然；同时 / at once...and... 既…又…
**辨析**：⚠️ at once 两义：立刻（= immediately）与同时（= simultaneously）——靠语境判断
**词根**：at（在）+ once（一次）→ 一次性地 → 立刻/同时

### 100. **not that ... but (that) ...** — 不是因为…而是因为…
**核心**：⚠️ 原文"not perhaps that but 或许并非因为…而是"结构不清；规范结构 **not that A but (that) B** = 并非因为 A，而是因为 B
**搭配**：Not that I dislike it, but that I have no time. 不是我不喜欢，而是我没时间。
**辨析**：not that...but that...（释因句式）vs not...but...（不是…而是…，连接并列成分）
**词根**：not（不）+ that（引导原因从句）+ but（而是）

### 101. **swamped with** — 被…淹没/挤满；应付不过来
**核心**：⚠️ 原文"swaped with"拼写有误，疑为 **swamped with**（被大量事物淹没）或 **swarmed with**（挤满）
**搭配**：be swamped with work 被工作淹没 / be swamped with requests 请求应接不暇
**辨析**：swamped with（被淹没，忙不过来）vs swarmed with（被挤满，指人群/昆虫）vs flooded with（涌入）
**词根**：swamp（沼泽/淹没）+ -ed；同根 swamp 淹没

### 102. **slam dunk** — 灌篮；（口语）十拿九稳的事
**核心**：⚠️ 原文 slum dunk 拼写有误；篮球**灌篮**；引申 **轻而易举/板上钉钉的事**
**搭配**：a slam dunk 一记灌篮 / It's a slam dunk. 这事稳了。
**辨析**：slam dunk（灌篮/稳操胜券，口语）vs layup（上篮）vs three-pointer（三分球）
**词根**：slam（猛击）+ dunk（扣入）→ 猛扣入篮

## 十三、教育与学术

### 103. **syllabus** — 教学大纲，课程纲要
**核心**：n. **课程大纲**（列明教学内容的纲要）
**搭配**：the course syllabus 课程大纲 / on the syllabus 列入大纲
**辨析**：syllabus（课程大纲，单一课程）vs curriculum（课程体系，全部课程）vs outline（提纲）
**词根**：希腊 sittyba（标签）→ 纲要；复数 syllabi / syllabuses

### 104. **tuition** — 学费；教学，讲授
**核心**：n. **学费**（美式常用）；**教学/讲授**（英式）
**搭配**：tuition fees 学费 / pay tuition 交学费 / private tuition 私人辅导
**辨析**：tuition（学费/教学）vs fee（费用，泛指）vs scholarship（奖学金）
**词根**：tuit- = look after/guard（照看，拉丁 tueri）+ -ion → 照看/教导 → 教学/学费

### 105. **interpretation** — 解释，理解；口译；演绎
**核心**：n. **解读/阐释**；**口译**；对作品/数据的**诠释**
**搭配**：a strict interpretation 严格的解释 / simultaneous interpretation 同声传译 / artistic interpretation 艺术演绎
**辨析**：interpretation（解读/口译）vs explanation（解释，说明原因）vs translation（笔译）
**词根**：inter-（在…之间）+ pret-（价值/交易）→ 居中说明 → 解释；同根 interpret 解释/口译

|------|------|

| **indignant** vs **angry** | indignant = 因不公而义愤（正当、书面）；angry = 生气（通用） |
| **humiliate** vs **embarrass** | humiliate = 羞辱（伤自尊，重）；embarrass = 使尴尬（轻） |
| **brag** vs **boast** | brag = 吹牛（贬义，口语）；boast = 夸耀（可中性，也可 boastful） |
| **dispute** vs **quarrel** vs **argument** | dispute = 争端（正式，可指法律/国际）；quarrel = 口角（私人）；argument = 争论（通用） |
| **doctrine** vs **dogma** | doctrine = 系统学说（中性/正式）；dogma = 教条（贬义，不容置疑） |
| **rhetoric** vs **rhetorical** | rhetoric = 修辞/花言巧语（**名词**）；rhetorical = 修辞的/浮夸的（形容词） |
| **testimony** vs **evidence** | testimony = 证词（口述，法律）；evidence = 证据（物证/泛指） |
| **sanction（两义相反）** | 制裁（惩罚，经济/政治）；批准（许可，正式）——靠语境判断 |
| **violate** vs **breach** | violate = 违反法律/侵犯权利（正式）；breach = 违反合同/突破防线（法律/军事） |
| **commodity** vs **product** vs **goods** | commodity = 商品/大宗货物（经济术语）；product = 产品（制造品）；goods = 货物（通用） |
| **manufacture** vs **manufacturing** | manufacture = 制造（动/名，具体动作或制造品）；manufacturing = 制造业（部门/行业，整体） |
| **prospective** vs **promising** | prospective = 预期中的/未来的（潜在对象）；promising = 有前途的（褒义，评价） |
| **definitive** vs **definite** | 形近：definitive = 权威的/最终的；definite = 明确的/确定的 |
| **instantaneous** vs **instant** | instantaneous = 瞬时的（物理/科学，零延迟）；instant = 立即的（通用） |
| **novelty** vs **novel** | novelty = 新奇/新鲜感（名词）；novel = 新奇的（形容词）/ 小说（名词） |
| **hospitable** vs **hostile** | 形近：hospitable = 好客的/宜人的；hostile = 敌意的/敌对的——勿混 |
| **hokey** vs **hockey** | 同音不同义：hokey = 做作的/俗套的（口语）；hockey = 曲棍球（运动） |
| **inadequacy** vs **inferiority** | inadequacy = 不足/不胜任（能力或系统）；inferiority = 劣势/自卑（地位或心理） |
| **dispense** vs **dispense with** | dispense = 分发/配药；dispense with = 省去/免除——加 with 意义大变 |
| **at once（两义）** | 立刻（= immediately）；同时（= simultaneously）——同类易混 |
| **give occasion to** vs **give rise to** | 均表"引起"；occasion 更偏"成为缘由"；rise 更常用、语气更中性 |
| **swamped with** vs **swarmed with** | swamped = 被（事务）淹没/忙不过来；swarmed = 被（人群/昆虫）挤满 |

## 🎯 高频考点速记

| 考点 | 说明 |
|------|------|
| **sanction 双重含义** | 制裁（impose sanctions on）vs 批准（official sanction）——意思相反，阅读必辨 |
| **at once 熟词僻义** | "立刻"（= immediately）为六级常考义；勿只记"同时" |
| **appeal 一词多义** | 吸引（lose one's appeal）/ 呼吁（appeal for）/ 上诉（appeal to a higher court） |
| **dispense with** | "省去/免除"，正式；勿与 dispense（分发/配药）混 |
| **lay claim to sth** | "声称对…拥有权利"，正式书面（lay claim to the throne） |
| **in accordance with** | "依照…（法律/规定）"，写译高频；区别于 according to（根据，通用） |
| **be geared to/towards** | "为…而设计/适应"，常用被动（be geared to the needs of…） |
| **be bound up with** | "与…密切相关"，正式；区别于 be bound to（必定） |
| **give occasion to ≠ 有可能** | give occasion to = 引起/招致；"有可能"是 be likely to |
| **not that...but that...** | "不是因为…而是因为…"，释因句式（写作加分） |
| **draw on / wear off / catch up on** | 高频短语：draw on 利用；wear off 消退；catch up on 补做 |
| **unanimous 释义修正** | 意为"全体一致同意"，原文"不一致"错误；反义 divided |
| **slam dunk 引申义** | 名词"灌篮"→ 口语"十拿九稳的事"（It's a slam dunk.） |
| **拼写修正汇总** | extravagent → **extravagant**；instaneous → **instantaneous**；hosiptable → **hospitable**；inadquacy → **inadequacy**；discrepency → **discrepancy**；cholestrol → **cholesterol**；chartiable → **charitable**；provokative → **provocative**；naught → **naughty**；hockey → **hokey**；slum dunk → **slam dunk** |
