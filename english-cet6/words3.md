# 📚 CET-6 单词本 (3)

> 排版：每条单词 2-4 行解析，按优先级排列：核心 → 搭配 → 辨析 → 词根/记忆
> 标注：`⚠️` = 易混点/重点 | **加粗** = 核心要点

## 一、负面状态（脏·怒·多变·单调）

### 1. **foul** — 肮脏的；恶臭的；犯规的
**核心**：感官上的**恶臭/肮脏** + 体育**犯规**，一词多义（口语常用）
**搭配**：foul air 难闻的气味 / foul mood 坏心情 / foul weather 恶劣天气 / by fair means or foul 不择手段

### 2. **fury** — 暴怒，狂怒
**核心**：**极度愤怒**、近乎失控（程度强于 anger/rage）
**搭配**：fly into a fury 勃然大怒 / sound and fury 喧嚣与愤怒（出自莎士比亚）/ like fury 拼命地
**辨析**：⚠️ fury（暴怒，最强烈）≠ anger（生气，最通用）≠ rage（狂怒，居中）

### 3. **volatile** — 易挥发的；易变的，动荡的
**核心**：物质**易挥发** + 局势/市场**动荡易变**
**搭配**：volatile market 动荡的市场 / volatile substance 挥发性物质 / volatile temper 喜怒无常的脾气
**词根**：volat- = fly（飞）→ 源自拉丁语 volare；同根 volley, volitant

### 4. **monotonous** — 单调的，乏味的，一成不变的
**核心**：**单一音调** → 单调乏味
**搭配**：monotonous work 单调的工作 / monotonous voice 毫无起伏的声音
**词根**：mono-（单一）+ ton-（音调，tone）→ 一个调子；同根 monologue, monopoly

---

## 二、数量与活力

### 5. **innumerable** — 数不清的，无数的
**核心**：**多到数不清**（程度强于 many，偏书面）
**词根**：numer- = number → innumerable, numerous, enumerate, numeral

### 6. **vitality** — 生命力，活力，朝气
**核心**：**旺盛的生命力/活力**（人、组织皆可）
**词根**：vit-/viv- = life（生命）→ vital, revive, survive, vitamin, vivid

### 7. **exceedingly** — 极其，非常
**核心**：**极其**，程度强于 very，偏正式
**搭配**：exceedingly difficult 极其困难 / exceedingly rare 极其罕见
**辨析**：⚠️ exceedingly（正式、程度强）≠ very（口语、程度一般）

---

## 三、时间与方位

### 8. **temporary** — 暂时的，临时的
**核心**：**一时的/临时的**（与 permanent 相对）
**搭配**：temporary solution 临时解决方案 / spatial and temporary dimensions 空间与时间的维度
**词根**：temp- = time（时间）→ temporary, temporal, contemporary, tempo

### 9. **henceforth** — 从此以后，今后
**核心**：**从现在起往后**（正式/法律文体）
**辨析**：⚠️ henceforth（正式书面）≈ from now on（更口语化）

### 10. **ashore** — 在岸上，上岸
**核心**：**到岸上/在岸上**（船、人上岸）
**搭配**：come ashore 上岸 / go ashore 下船 / be washed ashore 被冲上岸
**词根**：a-（朝向）+ shore（岸）

---

## 四、管理与范式

### 11. **streamline** — 精简，使效率更高；流线型
**核心**：**精简流程提效**（管理/工程类阅读高频）
**搭配**：streamline the process 精简流程 / streamlined shape 流线型外形

### 12. **paradigm** — 范式，典范，模式
**核心**：**理论框架/思维范式**
**搭配**：paradigm shift 范式转移（科学发展史核心概念）/ a new paradigm 新范式
**辨析**：⚠️ paradigm（范式）≠ parameter（参数）

### 13. **dominance** — 主导地位，支配地位
**核心**：**占据支配/主导**的地位
**词根**：domin- = lord/master（主人，掌控）→ dominate, dominant, dominion, predominant

### 14. **auxiliary** — 辅助的；备用的
**核心**：**辅助/备用**的（装备、动词、电源）
**搭配**：auxiliary equipment 辅助设备 / auxiliary verb 助动词 / auxiliary power 备用电源
**词根**：auxil- = help（帮助）→ 源自拉丁语 auxilium

---

## 五、户外与生活（西部拓荒）

### 15. **wagon** — 马车；货车车厢
**核心**：**四轮运货车**（马车/铁路货车车厢）
**搭配**：covered wagon 有篷马车（美国西部拓荒史常见）/ station wagon 旅行车 / on the wagon 戒酒

### 16. **rifle** — 步枪；v. 搜寻，翻找
**核心**：名词**步枪**；动词**翻找**（rifle through）
**搭配**：rifle through sth 翻找某物 / assault rifle 突击步枪

### 17. **fur** — 皮毛，软毛
**核心**：动物**带毛的皮毛**（尤指软毛）
**搭配**：fur coat 皮草大衣 / make the fur fly 引起争吵
**辨析**：⚠️ fur（动物皮毛，带毛）≠ leather（皮革，去毛鞣制）≠ skin（皮肤）

### 18. **tobacco** — 烟草，烟叶
**核心**：**烟草**（公共健康/社会类阅读）
**搭配**：tobacco industry 烟草业 / tobacco control 控烟

## 六、社会·法律·关系

### 19. **franchise** — 特许经营权；选举权
**核心**：商业**加盟特许权**；政治**选举权**
**搭配**：franchise store 加盟店 / grant a franchise 授予特许经营权 / the Star Wars franchise 星球大战系列 IP

### 20. **witness** — 目击者；证人；见证
**核心**：名词**目击者/证人**；动词**见证**
**搭配**：witness to sth 某事的目击者 / bear witness 作证 / witness a change 见证变化

### 21. **nuisance** — 讨厌的人/事；妨害
**核心**：**令人讨厌的人/物**；法律上"妨害"
**搭配**：a real nuisance 真讨厌，真麻烦 / public nuisance 公害 / make a nuisance of oneself 惹人讨厌

### 22. **ally** — n. 盟友 / v. 与…结盟
**核心**：名词**盟友**；动词**结盟**（ally oneself with）
**搭配**：a close ally 亲密盟友 / ally oneself with sb 与某人结盟 / the Allies 同盟国（二战）

## 七、书与人

### 23. **introductory** — 序言的；入门的；引导的
**核心**：**入门/导论**性质的
**搭配**：introductory course 入门课程 / introductory remarks 开场白
**词根**：intro- = inward（向内）→ introduce, introvert, introspect

### 24. **preface** — 序言，前言
**核心**：**作者自序**（书的开头）
**搭配**：write a preface 写序言 / the preface to the book 本书序言
**辨析**：⚠️ preface（作者自序）≠ foreword（他人作序）≠ introduction（导论）
**词根**：pre-（前）+ face（= speak，说）→ 说在前面的话

### 25. **gaze** — 凝视，注视
**核心**：**长时间深情/专注地凝视**
**搭配**：gaze at sth 凝视某物 / steady gaze 目不转睛的注视 / gaze into the distance 凝视远方
**辨析**：⚠️ gaze（长时间凝视，含情感）≠ glance（一瞥）≠ stare（盯着看，可能不礼貌）

---

## 八、语气与强调

### 26. **have no idea whatsoever** — 毫无头绪，完全不知道
**核心**：**完全不知道**；whatsoever 在否定句中加强语气 ≈ at all
**搭配**：I have no idea whatsoever. 我完全不知道。

### 27. **albeit** — 尽管，虽然
**核心**：**尽管**（正式书面语，后接形容词/副词/介词短语）
**搭配**：a peaceful, albeit brief, moment 一段平静的（尽管短暂的）时光
**辨析**：⚠️ albeit（正式，接短语）≠ although（后接完整从句）

## ⚠️ 形近词 / 近义词辨析（含场景偏好）

| 词对 | 区别（含使用场景偏好） |
|------|------|
| **paradigm** vs **parameter** | paradigm = 范式/模式（理论框架）；parameter = 参数（可调节变量） |
| **fur** vs **leather** | fur = 动物皮毛（带毛）；leather = 皮革（去毛鞣制后） |
| **gaze** vs **stare** vs **glance** | gaze = 凝视（含情感，时间长）；stare = 盯着（可能不礼貌）；glance = 一瞥（快速扫过） |
| **preface** vs **foreword** vs **introduction** | preface = 作者自序；foreword = 他人作序/推荐序；introduction = 导论/引言 |
| **fury** vs **anger** vs **rage** | fury = 暴怒（最强烈，近乎失控）；rage = 狂怒；anger = 生气（最通用） |
| **henceforth** vs **from now on** | henceforth = 正式/法律用语；from now on = 日常口语 |
| **albeit** vs **although** | albeit = 正式，多接形容词/短语；although = 后接完整从句 |
