### ⚠️ 形近词 / 近义词辨析

| 词对 | 区别 |
|------|------|
| **successively** vs **successfully** | successively = 接连地/连续地（依次发生）；successfully = 成功地（达成目的）；⚠️ 一字之差，阅读高频混淆 |
| **diameter** vs **radius** vs **circumference** | diameter = 直径（过圆心的弦）；radius = 半径（一半）；circumference = 周长（绕圆一周） |
| **pamphlet** vs **leaflet** vs **brochure** | pamphlet = 小册子（多页装订）；leaflet = 传单（单页）；brochure = 宣传册（图文并茂） |
| **chrome** vs **chromium** | chrome = 铬合金/镀铬（日常用语）；chromium = 化学元素铬 Cr（专业术语） |
| **arbiter** vs **arbitrator** vs **referee** | arbiter = 权威裁决者/仲裁人；arbitrator = 正式法律仲裁员；referee = 体育裁判 |
| **glow** vs **gleam** vs **glitter** vs **shine** | glow = 柔和稳定的光/容光焕发；gleam = 闪现的光；glitter = 闪闪发光；shine = 照耀（最通用） |
| **gigantic** vs **huge** vs **colossal** | gigantic = 巨人般的巨大；huge = 巨大（最通用）；colossal = 巨像般夸张的巨大 |
| **factoid** vs **fact** vs **trivia** | factoid = 貌似事实的信息/趣闻（可真可假）；fact = 事实（真实）；trivia = 琐事/冷知识 |
| **tracking** vs **tracing** | tracking = 跟踪（跟着目标移动）；tracing = 追溯（寻找源头） |
| **ornate** vs **ornamental** vs **ornament** | ornate = 装饰华丽的（adj.）；ornamental = 装饰性的（adj.）；ornament = 装饰品（n.） |
| **private sector** vs **public sector** | private sector = 私营部门；public sector = 公共部门；经济类常成对出现 |
| **morphine** vs **heroin** | morphine = 吗啡（医用镇痛麻醉药）；heroin = 海洛因（非法毒品） |

### 🎯 高频考点速记

| 考点 | 说明 |
|------|------|
| **arbiter 拼写** | 易错拼写 artbiter → 正确为 arbiter；同根词 arbitrary（武断的）、arbitrate（仲裁） |
| **successively vs successfully** | 形近词：successively 接连地 / successfully 成功地；形容词 successive（连续的）/ successful（成功的） |
| **glowing 修饰评价** | glowing review / report / praise = 好评如潮、高度赞扬，阅读理解态度题高频 |
| **private vs public sector** | 经济类阅读高频对比：私营部门 vs 公共部门（public sector / third sector） |
| **theory of relativity** | 科普阅读：general relativity 广义相对论 / special relativity 狭义相对论 |
| **factoid 一词两义** | 原义"伪事实"（貌似真实的说法），现口语常指"有趣小知识"，阅读中按语境判断褒贬 |
| **atmospheric 双含义** | 科学义"大气（层）的"（atmospheric pressure 大气压）+ 引申义"有氛围的"（atmospheric music） |
| **juggle 熟词僻义** | 玩杂耍 → 兼顾多项（juggle work and family）→ 篡改（juggle the books 做假账） |
| **-oid 后缀** | -oid = 像……的：factoid 像事实的、android 人形机器人、asteroid 小行星 |
| **词根 lat- 系列** | 搬运/携带：relate, relative, relativity, translate, correlate → 阅读中根据前缀判断方向 |
