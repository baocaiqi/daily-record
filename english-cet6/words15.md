# 📚 CET-6 单词本 (15)

> 排版：每条单词 2-4 行解析，按优先级排列：核心 → 搭配 → 辨析 → 词根/记忆
> 标注：`⚠️` = 易混点/重点 | **加粗** = 核心要点

## 一、谨慎与沉着

### 1. **prudence** — 谨慎，慎重；精明
**核心**：**预见后果**再行动的谨慎，着眼长远、权衡利弊（褒义）
**搭配**：act with prudence 谨慎行事 / financial prudence 理财上的精明 / exercise prudence 保持谨慎
**辨析**：⚠️ prudence（慎思远虑）≠ caution（小心避风险）≠ discretion（言行不外露）
**词根**：prud-/provid- = foresee（预见）→ 有先见之明；同根 prudent, providence

### 2. **prudent measures** — 审慎的措施，预防性措施
**核心**：权衡利弊后采取的**审慎举措**（政策/财经语境）
**搭配**：take prudent measures 采取审慎措施 / prudent fiscal measures 审慎的财政措施
**辨析**：⚠️ prudent measures（权衡利弊）≠ preventive measures（防止发生）≠ precautionary measures（应对风险）
**场景**：政策/财经新闻阅读

### 3. **discreet** — 言行谨慎的，审慎的；不引人注目的
**核心**：**守口如瓶、不张扬**的谨慎（社交场合，说话办事留有余地）
**搭配**：a discreet silence 得体的沉默 / discreet inquiries 小心翼翼的打听 / at a discreet distance 隔着得体的距离
**辨析**：⚠️ discreet（言行不外露）≠ prudent（权衡利弊）≠ wary（警惕危险）
**词根**：dis-（分开）+ cret-（区分）→ 分得清该说不该说；同根 discretion, discrete

### 4. **wary** — 警惕的，谨慎的，小心翼翼的
**核心**：⚠️ 原文释为"担心"有误：wary = 对**风险保持警觉**，"担心"是 worry
**搭配**：be wary of sb/sth 对…保持警惕 / a wary glance 警惕的一瞥
**辨析**：⚠️ wary（警觉）≈ cautious（谨慎）≈ vigilant（警觉，正式）≠ worried（担心的）
**记忆**：aware（意识到）→ be wary（保持警觉）

### 5. **composure** — 沉着，镇静，泰然自若
**核心**：**压力下不失态**的沉着镇定
**搭配**：keep/lose one's composure 保持/失去镇定 / regain one's composure 恢复镇定
**辨析**：⚠️ composure（压力下不失态）≠ calmness（情绪平和）≠ equanimity（镇定，更正式）
**词根**：com-（共同）+ pos-（放）→ 把自己放稳；同根 compose, composed

### 6. **undistracted** — 全神贯注的，不分心的
**核心**：**不被干扰**地专注（强调排除外界打扰）
**搭配**：undistracted attention 全神贯注 / work undistracted by noise 不为噪音分心
**辨析**：⚠️ undistracted（不被干扰）≈ focused（目标明确）≈ concentrated（集中的）
**词根**：un-（不）+ dis-（分开）+ tract-（拉）→ 不被拉走；同根 distract, attract, extract

## 二、笨拙

### 7. **clumsy** — 笨拙的；不灵巧的；笨重的
**核心**：**动作不灵活**的笨拙，也可指处理问题拙劣
**搭配**：clumsy fingers 笨拙的手指 / a clumsy attempt 拙劣的尝试 / clumsy handling of the situation 笨拙地处理局面
**辨析**：⚠️ clumsy（动作笨拙）≠ awkward（尴尬/笨拙，社交体态）≠ inept（无能，能力差）
**记忆**：谐音"可拉米色"→ 连米色衣服都穿不利索 → 笨拙的

## 三、违反与背弃

### 8. **breach** — 违反，破坏；缺口 / v. 违反；突破
**核心**：**打破**规则/防线（正式，法律/信息安全高频），名词兼指"缺口"
**搭配**：breach of contract 违约 / a breach of security 安全漏洞 / breach the wall 冲破城墙
**辨析**：⚠️ breach（违反协议/信任，正式）≠ violate（违反法律/权利，通用）≠ break（打破，最通用）
**词根**：古英语 brecan（打破）→ break 同源词 → 打破规则/防线

### 9. **the breach of** — 违反，背弃（正式用语）
**核心**：**正式书面**表示"违反/背弃"（法律文书/新闻）
**搭配**：the breach of an agreement 违反协议 / the breach of a promise 背弃承诺 / the breach of discipline 违反纪律
**辨析**：⚠️ the breach of（正式）≈ the violation of（通用）≠ the breaking of（口语）

### 10. **data breach** — 数据泄露，数据外泄
**核心**：**黑客/管理漏洞**导致的数据泄露（网络安全阅读高频）
**搭配**：suffer a data breach 遭受数据泄露 / a massive data breach 大规模数据泄露
**辨析**：⚠️ data breach（系统性泄露）≠ data leak（无意/被动泄漏）≠ data theft（主动窃取）
**记忆**：data（数据）+ breach（缺口）→ 数据防线出现缺口

### 11. **breach the wall** — 冲破城墙，突破防线
**核心**：**攻破防线**（军事用法）
**搭配**：breach the city walls 攻破城墙 / breach the enemy's defences 突破敌军防线
**辨析**：⚠️ breach the wall（攻破）≈ break through the wall（突破，口语）≠ scale the wall（攀登翻越）

### 12. **breach of trust** — 背信弃义，违背信任
**核心**：**违背信任**（正式/法律用语）
**搭配**：commit a breach of trust 背信弃义 / a gross breach of trust 严重违背信任
**辨析**：⚠️ breach of trust（违背信任，正式）≠ betrayal（情感背叛）≠ infidelity（不忠，婚姻）

## 四、谴责与恳求

### 13. **deplore** — 谴责，强烈反对；痛惜，悲叹
**核心**：**谴责+痛惜**（正式书面，声明/新闻常用）
**搭配**：deplore violence 谴责暴力 / deplore the decision 强烈反对这一决定 / deplore the loss of 痛惜失去…
**辨析**：⚠️ deplore（谴责+痛惜，书面）≠ condemn（语气更强）≠ lament（哀悼悲叹）≠ denounce（公开谴责）
**词根**：de-（向下）+ plor-（哭）→ 悲叹到哭；同根 implore, explore

### 14. **implore** — 恳求，哀求，乞求
**核心**：⚠️ 原文 inplore 拼写有误，正确 **implore**（in- + plor-）
**搭配**：implore sb to do sth 恳求某人做某事 / implore for mercy 乞求怜悯 / implore forgiveness 乞求原谅
**辨析**：⚠️ implore（带强烈感情的恳求，正式）≈ beseech（文学）≈ beg（口语通用）≠ plead（法律辩护）
**词根**：in-（向内）+ plor-（哭）→ 哭着求；对比 deplore（谴责）

### 15. **deplore violence** — 谴责暴力
**核心**：**公开声明**谴责暴力（新闻/声明用语）
**搭配**：publicly deplore violence 公开谴责暴力 / deplore all forms of violence 谴责一切形式的暴力
**辨析**：⚠️ deplore violence（正式声明）≈ condemn violence（语气更重）≠ denounce violence（报刊用语）

## 五、赎回与补救

### 16. **redeem** — 赎回；补救，挽回；兑现
**核心**：**买回/补救**：金融"赎回"与道德"挽回"双义
**搭配**：redeem a coupon 兑换优惠券 / redeem one's reputation 挽回名誉 / redeem the situation 挽回局面
**辨析**：⚠️ redeem（赎回/补救）≠ retrieve（取回物品/数据）≠ recover（恢复健康/损失）
**词根**：re-（回）+ deem/em-（买）→ 买回来；同根 redemption 救赎, redeemable 可赎回的

### 17. **a redeeming feature** — 可取之处，弥补性的优点
**核心**：**弥补缺点**的优点（the only redeeming feature 唯一可取之处）
**搭配**：a redeeming feature of the film 这部电影的亮点 / the only redeeming feature 唯一可取之处
**辨析**：⚠️ redeeming feature（弥补缺点）≈ a saving grace（仅有的优点，习语）≠ a highlight（亮点，中性）

### 18. **redeem oneself** — 挽回声誉，将功补过
**核心**：⚠️ 原文"挽尊"为网络用语，规范表达 **redeem oneself** = 靠实际行动挽回形象
**搭配**：redeem oneself in sb's eyes 在某人眼中挽回形象 / redeem oneself with a good performance 用出色表现挽回颜面
**辨析**：⚠️ redeem oneself（挽回形象）≈ make amends（弥补过错）≈ restore one's reputation（恢复名誉）

## 六、节俭与理性

### 19. **thrift** — 节俭，节约；勤俭
**核心**：⚠️ 原文 thriftness 为非标准词，正确名词 **thrift**（或 thriftiness）
**搭配**：the virtue of thrift 节俭的美德 / practice thrift 厉行节约 / thrift shop 二手店
**辨析**：⚠️ thrift（节俭美德，褒）≈ frugality（朴素节约）≠ stinginess（吝啬，贬）
**词根**：thriv-/thrift- = prosper（兴旺）→ 会过日子而兴旺；同根 thrifty, thrive

### 20. **thrifty** — 节俭的，节约的
**核心**：**会过日子**的节俭（褒义），反义 wasteful 浪费的
**搭配**：a thrifty housewife 精打细算的主妇 / thrifty habits 节俭的习惯 / a thrifty use of resources 节约使用资源
**辨析**：⚠️ thrifty（会过日子，褒）≠ frugal（朴素清苦）≠ economical（划算，中性）≠ stingy/miserly（吝啬，贬）
**词根**：thrift（节俭）+ -y（形容词）→ 节俭的

### 21. **rationalization** — 合理化；理性化；文过饰非
**核心**：把不合理说成**合理**；含"找借口"贬义（为错误行为辩护）
**搭配**：the rationalization of production 生产合理化 / a rationalization for one's behaviour 为行为找的借口
**辨析**：⚠️ rationalization（合理化/找借口，可贬）≠ justification（辩解，中性/正式）≠ explanation（解释，最通用）
**词根**：ration-/reason- = 计算理性 → rational → rationalize；同根 rational, reason

### 22. **reasonableness** — 合理性；有道理；适度
**核心**：**公平适度**的合理性
**搭配**：the reasonableness of the request 请求的合理性 / question the reasonableness of 质疑…的合理性
**辨析**：⚠️ reasonableness（公平适度）≠ rationality（逻辑理性）≠ sensibility（明智判断力）
**词根**：reason（理性）+ -able + -ness → 合理性

## 七、过度与得当

### 23. **undue** — 过度的，不适当的；不当的
**核心**：**超出应有**的过度（法律术语 undue influence 不当影响）
**搭配**：undue influence 不当影响 / undue pressure 过大的压力 / without undue delay 无不当延误
**辨析**：⚠️ undue（超出应有）≠ excessive（超量）≠ improper（不合规范）
**词根**：un-（不）+ due（应得的）→ 超出应有的 → 过度的

### 24. **duly** — 正式地；按时地；适当地，恰当地
**核心**：⚠️ 原文仅释"正式的"偏窄，核心义为**按时地/按程序地**
**搭配**：duly arrive 准时到达 / duly noted 已知悉 / duly elected 正式当选
**辨析**：⚠️ duly（按程序/按时）≠ officially（官方地）≠ properly（恰当地）
**词根**：due（到期/应得）+ -ly → 按应有程序地

### 25. **duly arrive** — 准时到达，如期而至
**核心**：**按约定时间**到达（正式书面）
**搭配**：the guests duly arrived 客人们如期而至 / the package duly arrived the next day 包裹次日准时送达
**辨析**：⚠️ duly arrive（按时，正式）≈ arrive on time（通用）≠ arrive late（迟到）

### 26. **duly noted** — 已知悉，谨记（正式回应用语）
**核心**：公文/会议**套话**："已记录在案，已知悉"
**搭配**：your comments are duly noted 您的意见已记录在案 / duly noted, thank you 已悉知，谢谢
**辨析**：⚠️ duly noted（正式公文）≠ well noted（口语）≠ taken into account（已考虑在内）

### 27. **duly elected** — 正式当选，依法当选
**核心**：**依程序**当选（政治新闻高频）
**搭配**：the duly elected government 经正式选举产生的政府 / a duly elected representative 依法选出的代表
**辨析**：⚠️ duly elected（依法当选）≠ appointed（被任命，非选举）
**场景**：政治新闻：the duly elected president 正式当选的总统

## 八、整体观

### 28. **holistic** — 整体的，全面的；整体主义的
**核心**：**系统关联、不可分割**的整体观（医学/教育/管理高频）
**搭配**：a holistic approach 整体方法 / holistic medicine 整体医学 / a holistic view 全局观
**辨析**：⚠️ holistic（系统整体）≠ comprehensive（覆盖面广）≠ integral（不可或缺的）
**词根**：hol- = whole（整体）+ -istic → 整体的；同根 holism 整体论

### 29. **a holistic approach** — 整体方法，全面方法
**核心**：⚠️ 原文 apprach 漏字母，正确 **approach**；强调系统性
**搭配**：take a holistic approach to 采取整体方法处理… / adopt a holistic approach 采用整体思路
**辨析**：⚠️ a holistic approach（系统性）≠ a piecemeal approach（零敲碎打，反义）

## 九、气象与传播

### 30. **meteorology** — 气象学
**核心**：⚠️ 原文 meterology 漏 -eo-，正确 **meteorology**（词根 meteor）
**搭配**：meteorological station 气象站 / meteorology report 气象报告
**辨析**：⚠️ meteorology（气象学）≠ meteor（流星）≠ meteorite（陨石）
**词根**：meteor-（空中之物）+ -logy（学科）→ 研究大气现象的学科

### 31. **airborne** — 空气传播的；空运的，空降的
**核心**：**由空气携带**的：医学"空气传播" + 军事"空降"双义
**搭配**：airborne virus 空气传播的病毒 / airborne troops 空降部队 / become airborne 升空
**辨析**：⚠️ airborne（空气传播/空运）≠ aerial（空中的，摄影/天线）≠ flying（飞行的，通用）
**词根**：air（空气）+ borne（bear 被携带）→ 被空气携带的

### 32. **get airborne** — 起飞，升空
**核心**：**升入空中**；比喻"使项目启动"
**搭配**：the plane got airborne 飞机起飞了 / get the project airborne 使项目启动
**辨析**：⚠️ get airborne（升空）≈ take off（起飞，通用）≠ land（着陆，反义）

### 33. **propagation** — 繁殖；传播，宣传；蔓延
**核心**：**繁殖/传播**（生物+信息双义，科普阅读高频）
**搭配**：the propagation of plants 植物繁殖 / propagation of the virus 病毒传播 / the propagation of ideas 思想传播
**辨析**：⚠️ propagation（繁殖/传播）≈ reproduction（生殖）≠ dissemination（信息扩散，正式）≠ spread（最通用）
**词根**：pro-（向前）+ pag-（固定）+ -ation → 向前扩展；同根 propagate, propaganda（宣传）

## 十、倍数

### 34. **quadruple** — 四倍的 / 使成四倍 / 四倍
**核心**：动词"**增至四倍**"（quadruple the profits 利润翻两番）
**搭配**：a quadruple increase 四倍增长 / quadruple bypass surgery 心脏四重搭桥手术
**辨析**：⚠️ quadruple（四倍）≠ quarter（四分之一）；对比 double 两倍, triple 三倍
**词根**：quad- = four（四）+ -uple（倍数后缀）→ 四倍；同根 quadruplet 四胞胎

## 十一、生活器物

### 35. **tray** — 托盘，浅盘
**核心**：**端送物品**的浅盘
**搭配**：a tea tray 茶盘 / in-tray/out-tray 收/发件盘 / baking tray 烤盘
**辨析**：⚠️ tray（托盘）≠ plate（盛食物的盘子）≠ saucer（放茶杯的小碟）
**记忆**：谐音"垂"→ 端着托盘手臂下垂

### 36. **sling** — 吊带；投石器 / v. 抛，掷；吊挂
**核心**：名词**吊带** + 动词"甩、吊"，带"甩"的动作感
**搭配**：arm in a sling 手臂吊着绷带 / baby sling 婴儿背带 / sling a bag over one's shoulder 把包甩到肩上
**辨析**：⚠️ sling（甩/吊）≠ hurl（猛掷）≠ fling（随意甩）≠ throw（最通用）
**记忆**：sling 像"绳拎"→ 用绳吊着/甩出去

### 37. **cocktail** — 鸡尾酒；混合（物）
**核心**：**鸡尾酒**；比喻"混合物"（a cocktail of drugs 药物混合剂）
**搭配**：cocktail party 鸡尾酒会 / a cocktail of drugs 药物混合剂 / Molotov cocktail 燃烧瓶
**辨析**：⚠️ cocktail（配方混合）≠ mixed drink（泛称）≠ punch（潘趣酒）
**记忆**：公鸡尾巴（cocktail）五颜六色 → 色彩缤纷的混合酒

## 十二、市场与教育

### 38. **mass market** — 大众市场 / 面向大众市场的
**核心**：⚠️ 原文释"面向市场的"不完整：名词"**大众市场**"；作形容词用连字符 **mass-market**
**搭配**：the mass market for smartphones 智能手机的大众市场 / target the mass market 瞄准大众市场
**辨析**：⚠️ mass market（低价走量）≠ niche market（小众）≠ luxury market（奢侈品市场）
**记忆**：反义 niche market 小众市场

### 39. **well-educated** — 受过良好教育的，有教养的
**核心**：**教育背景好**（强调学历/教养）
**搭配**：a well-educated workforce 受过良好教育的劳动力 / well-educated professionals 高学历专业人士
**辨析**：⚠️ well-educated（教育背景）≠ knowledgeable（知识渊博）≠ well-read（博览群书）

| 词对 | 区别 |
|------|------|
| **prudent** vs **discreet** vs **wary** | prudent = 谨慎明智（权衡利弊/长远）；discreet = 言行谨慎（不张扬、守口如瓶，社交场合）；wary = 警惕的（对风险/危险保持警觉） |
| **wary** vs **worry** | wary = 警惕的/谨慎的（形容词，警觉）；worry = 担心/烦恼（动词/名词）；⚠️ 原文"担心"释义有误 |
| **deplore** vs **implore** vs **explore** | deplore = 谴责（de- 向下哭）；implore = 恳求（in- 向里哭）；explore = 探索（ex- 向外呼喊）；同词根 plor- |
| **deplore** vs **condemn** vs **denounce** | deplore = 谴责+痛惜（书面）；condemn = 谴责（语气更强）；denounce = 公开谴责（报刊用语） |
| **breach** vs **violate** vs **break** | breach = 违反（协议/信任/安全，正式）；violate = 违反（法律/权利，通用）；break = 打破（最通用） |
| **data breach** vs **data leak** vs **data theft** | data breach = 数据泄露（系统性事件）；data leak = 数据泄漏（无意/被动）；data theft = 数据窃取（主动窃取） |
| **redeem** vs **retrieve** vs **recover** | redeem = 赎回/补救（金融+道德）；retrieve = 取回（物品/数据）；recover = 恢复（健康/损失） |
| **thrift** vs **thriftiness** vs **stinginess** | thrift = 节俭（美德）；thriftiness = 节俭（名词形式）；stinginess = 吝啬（贬义）⚠️ thriftness 为非标准词 |
| **thrifty** vs **frugal** vs **economical** | thrifty = 节俭会过日子（褒义）；frugal = 朴素节省；economical = 经济的/划算（中性） |
| **rationalization** vs **justification** vs **explanation** | rationalization = 合理化（可含"找借口"贬义）；justification = 辩解（中性/正式）；explanation = 解释（最通用） |
| **undue** vs **excessive** vs **improper** | undue = 不当的/过度的（超出应有）；excessive = 过度的（超量）；improper = 不合适的（不合规范） |
| **holistic** vs **comprehensive** vs **integral** | holistic = 整体论的（系统关联）；comprehensive = 全面的（覆盖面广）；integral = 不可或缺的/整体的 |
| **airborne** vs **aerial** vs **flying** | airborne = 空气传播的/空运的（医学+军事）；aerial = 空中的（摄影/天线）；flying = 飞行的（通用） |
| **propagation** vs **reproduction** vs **dissemination** | propagation = 繁殖/传播（生物+信息）；reproduction = 生殖/复制（生物）；dissemination = 传播扩散（信息，正式） |
| **quadruple** vs **double** vs **triple** | quadruple = 四倍；double = 两倍；triple = 三倍；quad- 四 / di- 二 / tri- 三 |
| **composure** vs **calmness** vs **equanimity** | composure = 沉着（压力下不失态）；calmness = 平静（情绪平和）；equanimity = 镇定（情绪平稳，正式） |
| **tray** vs **plate** vs **saucer** | tray = 托盘（端送物品）；plate = 盘子（盛食物）；saucer = 小碟（放茶杯） |
| **mass market** vs **niche market** | mass market = 大众市场（低价走量）；niche market = 细分/小众市场（针对特定人群） |
| **well-educated** vs **knowledgeable** vs **well-read** | well-educated = 受过良好教育（教育背景）；knowledgeable = 知识渊博（知识储备）；well-read = 博览群书 |

## 🎯 高频考点速记

| 考点 | 说明 |
|------|------|
| **meteorology 拼写** | 正确为 meteorology（词根 meteor，含 -eo-）；原文 meterology 漏字母，勿与 meter（米/仪表）混淆 |
| **implore 拼写** | in- + plor- = implore；原文 inplore 有误；对比 deplore（谴责）/ explore（探索） |
| **deplore / implore / explore 词根** | 同词根 plor- = 哭/呼喊：de- 向下（悲叹谴责）、in- 向内（恳求）、ex- 向外（探索），完型/阅读词义推断 |
| **wary 词义** | wary = 警惕的/谨慎的（be wary of），不是"担心"；worry 才是担心；词汇题常设陷阱 |
| **breach 词族** | breach of contract 违约 / data breach 数据泄露 / breach of trust 背信弃义；法律+信息安全阅读高频 |
| **thrift 词性** | 名词 thrift（节俭）；形容词 thrifty；thriftness 是非标准词，写作慎用 |
| **undue influence** | 法律术语"不当影响"；undue = 过度的/不当的，完型中常与 excessive 辨析 |
| **duly 多义** | duly = 按时地/正式地/适当地：duly arrive 准时到达 / duly elected 正式当选 / duly noted 已知悉（公文套话） |
| **holistic approach 拼写** | approach 勿漏字母（apprach 错误）；a holistic approach to 是阅读高频搭配 |
| **airborne 双义** | 医学：airborne virus 空气传播病毒；军事：airborne troops 空降部队；一词两义阅读考点 |
| **propagation / propaganda 同源** | 同词根 pag-：propagate 繁殖/传播；propaganda 宣传（由中性词演变为贬义"洗脑式宣传"） |
| **quadruple 倍数表达** | double 两倍 / triple 三倍 / quadruple 四倍；阅读中 quadruple the profits = 增至四倍（翻两番） |
| **redeem oneself 搭配** | "挽回声誉/将功补过"，写作常用；redeeming feature 可取之处 |
| **mass market vs niche market** | 商业阅读：大众市场 vs 小众市场；作形容词时用连字符 mass-market |
