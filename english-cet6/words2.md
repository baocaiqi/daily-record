# 📚 CET-6 单词本 (2)

> 排版：每条单词 2-4 行解析，按优先级排列：核心 → 搭配 → 辨析 → 词根/记忆
> 标注：`⚠️` = 易混点/重点 | **加粗** = 核心要点

## 一、制度与凭证

### 1. **communism** — 共产主义
**核心**：**共产主义**（社会制度/思想体系，名词）
**搭配**：the Communist Party 共产党 / socialism and communism 社会主义与共产主义
**辨析**：⚠️ communism（n. 共产主义）≠ communist（adj. 共产主义的 / n. 共产主义者）

### 2. **credential** — 资格证书；凭证
**核心**：证明**资格/身份/学历**的凭证
**搭配**：academic credentials 学历资格 / press credential 记者证 / credentials check 证件核查
**词根**：cred- = believe/trust（相信，信任）→ 让人信服的凭证；同根 credit 信用, incredible 难以置信

### 3. **press credential** — 媒体资格证书
**核心**：记者参加**发布会/现场**采访的资格凭证
**搭配**：apply for a press credential 申请记者证 / present one's press credential 出示记者证
**场景**：新闻发布会等场合使用的记者凭证

## 二、罪与罚

### 4. **burglar** — 窃贼，入室盗贼
**核心**：**闯入室内**行窃的盗贼
**搭配**：a burglar alarm 防盗报警器 / burgle a house 入室盗窃（英式）
**辨析**：⚠️ burglar（入室行窃者）≠ thief（泛指小偷）≠ robber（强盗，多含暴力）

### 5. **cat burglar** — 飞贼；攀爬入室窃贼
**核心**：从**屋顶/窗户等高处**潜入的窃贼
**搭配**：a cat burglar struck last night 昨夜飞贼作案
**记忆**：像猫一样攀爬灵巧 → 飞贼

### 6. **convict** — v. 判罪 / n. 囚犯
**核心**：动词**判…有罪**；名词**已决犯/囚犯**
**搭配**：convict sb of sth 因…判处某人 / an escaped convict 越狱囚犯
**辨析**：⚠️ 发音随词性变：v. /kənˈvɪkt/，n. /ˈkɒnvɪkt/（名词重音前移）

### 7. **smuggle** — 走私，偷运
**核心**：**非法/秘密**运送（人或物）
**搭配**：smuggle drugs 走私毒品 / smuggle sb into a country 偷渡 / smuggle a glance 偷偷瞥一眼
**记忆**：联想"偷偷摸摸"运送 → 走私

## 三、残余与全景

### 8. **remnant** — 剩余部分，残余
**核心**：**残留下来**的部分
**搭配**：the remnants of lunch 残羹剩饭 / remnants of cloth 布头，零头布
**词根**：源自 remain（留下）+ -ant → 留下的东西
**辨析**：⚠️ remnant（残余）≠ remainder（剩余物，数学"余数"）≠ remains（遗迹/遗体）

### 9. **food remnant** — 残余食物
**核心**：**食物残渣/残留**（考古、环保语境）
**搭配**：food remnant analysis 食物残渣分析 / ancient food remnants 古代食物残留
**场景**：常见于环保/考古类阅读

### 10. **panorama** — 全景，全貌
**核心**：**一览无余的全景/全貌**
**搭配**：a panorama of the city 城市全景 / a panorama of modern life 现代生活全貌
**词根**：pan-（全）+ horama（景象）→ 全景
**记忆**：同词已见 words1（panorama 全景）

## 四、居家与手艺

### 11. **rack** — 支架，搁架
**核心**：**搁放物品的架子**
**搭配**：luggage rack 行李架 / display rack 展示架 / rack one's brains 绞尽脑汁
**辨析**：⚠️ rack（架子）≠ racket（球拍；吵闹）— 形近易混

### 12. **tile** — 瓷砖，瓦片
**核心**：铺**地面/墙面**的瓷砖、瓦片
**搭配**：tile a bathroom 给浴室贴瓷砖 / floor tile 地砖 / install a tile 贴砖
**辨析**：⚠️ tile（瓷砖/瓦）≠ brick（砖块，建筑承重）≠ slate（石板瓦）

### 13. **greeting card** — 贺卡
**核心**：节日/生日**表达问候**的卡片
**搭配**：send a greeting card 寄贺卡 / a Christmas greeting card 圣诞贺卡
**场景**：常见于节日/生日场景

### 14. **barber** — 男理发师
**核心**：专剪**男性**头发的理发师
**搭配**：barber's shop 理发店（英式）/ a barber's chair 理发椅
**辨析**：⚠️ barber（传统男理发师，只剪男发）≠ hairdresser（美发师，男女通用）

## 五、音乐与文学

### 15. **perform a symphony** — 演奏交响乐
**核心**：**演奏交响乐**（perform + 乐曲名）
**搭配**：perform a symphony by Beethoven 演奏贝多芬交响曲
**辨析**：⚠️ symphony = 交响乐 ≠ concerto（协奏曲）；音乐/艺术类阅读

### 16. **repertoire** — 全部曲目；全部技能
**核心**：**熟练掌握的全部曲目/技能储备**
**搭配**：a wide repertoire 广泛的曲目/技能 / in one's repertoire 在某人的拿手戏中
**场景**：音乐/表演类语境

### 17. **fiction** — 小说；虚构的事
**核心**：**虚构**的文学作品（小说）
**搭配**：science fiction 科幻小说 / non-fiction 非虚构类作品 / legal fiction 法律拟制
**辨析**：⚠️ fiction（虚构小说）≠ nonfiction（纪实文学）≠ fact（事实）

## 六、营养与医学

### 18. **nourish** — 滋养，养育；怀有（情感）
**核心**：**提供养分滋养**；**怀有**（希望/抱负）
**搭配**：nourish hope/ambition 怀有希望/抱负 / nourish the body 滋养身体
**词根**：nour-/nutri- = feed（喂养）；同根 nutrition 营养, nutrient 营养物, nurse 护士

### 19. **perish** — 死亡；毁灭；腐烂
**核心**：**死亡/毁灭/腐烂**（书面，语气重）
**搭配**：perish in the fire 葬身火海 / perish the thought! 千万别这么想！
**辨析**：⚠️ perish（书面/正式"死亡"）≠ die（口语通用）≠ kill（杀害，及物）

### 20. **perishable** — 易腐烂的；易消亡的
**核心**：容易**变质腐烂**的
**搭配**：perishable goods 易腐商品 / perishable food 易腐食品
**词根**：perish + -able（可…的，易…的）→ 易腐烂的
**场景**：食品/物流类阅读常见

### 21. **malignant** — 恶性的；恶意的
**核心**：**恶性**的（肿瘤）；**恶意**的
**搭配**：malignant tumor 恶性肿瘤 / a malignant plot 恶毒的阴谋
**词根**：mal- = bad/evil（坏的）；同根 malice 恶意, malfunction 故障, maltreat 虐待
**辨析**：⚠️ malignant（恶性的）≠ benign（良性的，反义）

### 22. **muscular** — 肌肉的；肌肉发达的
**核心**：与**肌肉**有关；**肌肉发达**的
**搭配**：muscular strength 肌肉力量 / a muscular build 强壮体格 / muscular dystrophy 肌肉萎缩症
**词根**：muscul- = muscle（肌肉）；同根 muscle 肌肉, musculature 肌肉系统

## 七、科学与度量

### 23. **centigrade** — 摄氏度的
**核心**：**摄氏**温标（0°冰点 / 100°沸点）
**搭配**：30 degrees centigrade 30摄氏度
**词根**：centi-（百）+ grade（度）→ 百分度
**辨析**：⚠️ centigrade = Celsius（℃），centigrade 较为老式，Celsius 更常用

### 24. **horizontal** — 水平的，横向的
**核心**：与地平线**平行**的
**搭配**：a horizontal line 水平线 / horizontal axis 横轴
**辨析**：⚠️ horizontal（水平）≠ vertical（垂直，反义）
**场景**：图表/数学/设计类阅读

### 25. **inverse** — 相反的，反向的；倒数
**核心**：**相反/倒转**的（关系、顺序）
**搭配**：inverse proportion 反比 / inverse relationship 反向关系 / in inverse order 以相反顺序
**辨析**：⚠️ inverse（反向，数学/抽象）≠ reverse（反转，通用）≠ opposite（相反，最通用）

### 26. **qualitative** — 定性的；质量的
**核心**：关于**性质/质量**而非数量的
**搭配**：qualitative analysis 定性分析 / qualitative research 质性研究
**辨析**：⚠️ qualitative（定性的）≠ quantitative（定量的，量性的）

### 27. **latent** — 潜在的，潜伏的
**核心**：**潜伏**、尚未显现的
**搭配**：latent period 潜伏期 / latent talent 潜在的才能 / latent demand 潜在需求
**辨析**：⚠️ latent（潜伏待发，尚未显现）≠ potential（潜在可能，通用）≈ dormant（休眠）

### 28. **radiant** — 容光焕发的；光芒四射的
**核心**：**光芒四射**；因喜悦而**容光焕发**
**搭配**：be radiant with joy/happiness 因喜悦而容光焕发 / a radiant smile 灿烂的笑容
**词根**：radi- = ray（光线）；同根 radiate 辐射, radius 半径

## 八、性格与状态

### 29. **solitary** — 单独的，独居的；唯一的
**核心**：**独自一人**的
**搭配**：solitary confinement 单独监禁 / a solitary life 独居生活 / not a solitary one 一个也没有
**词根**：sol- = alone（单独）；同根 sole 唯一的, solo 独奏, solitude 孤独

### 30. **strenuous** — 费力的，艰苦的；努力的
**核心**：需要**很大力气/精力**的
**搭配**：strenuous exercise 剧烈运动 / strenuous efforts 不懈努力 / strenuous objection 强烈反对
**记忆**：strenuous → 使(stren-)劲 → 费力的

### 31. **futile** — 徒劳的，无效的
**核心**：**白费力气**、注定失败的
**搭配**：a futile attempt/effort 徒劳的尝试 / it is futile to do sth 做某事是徒劳的
**记忆**：源自拉丁语"漏水的容器"→ 装了也漏 → 徒劳

### 32. **obsolete** — 过时的，已淘汰的
**核心**：**已淘汰**、不再使用的
**搭配**：become obsolete 变得过时 / obsolete technology 淘汰的技术
**辨析**：⚠️ obsolete（已淘汰，不再使用）≠ outdated（过时但尚可用）
**场景**：科技/设备类阅读高频词

### 33. **discreet** — 谨慎的，审慎的
**核心**：言行**谨慎不张扬**的
**搭配**：a discreet inquiry 谨慎的询问 / keep a discreet distance 保持适当距离
**辨析**：⚠️ discreet（谨慎的）≠ discrete（离散的，分开的）— 形近易混

### 34. **daunting** — 令人畏惧的；使人气馁的
**核心**：**令人望而生畏**的（任务/挑战）
**搭配**：a daunting task/challenge 令人望而生畏的任务/挑战
**辨析**：⚠️ daunting（令人畏难，有压力）≈ intimidating（令人胆怯）≠ discouraging（令人气馁）
**场景**：形容任务/挑战巨大

### 35. **daunt** — 使害怕，使胆怯；削弱勇气
**核心**：**使…胆怯/气馁**
**搭配**：be daunted by sth 被…吓住 / nothing daunted 毫不气馁
**记忆**：daunt（动词）→ daunting（形容词"令人畏惧的"）

### 36. **fantastical** — 奇异的，荒诞的
**核心**：**奇异荒诞**的（偏文学/古雅）
**搭配**：a fantastical tale 荒诞离奇的故事
**词根**：fantas- = imagine（想象）；同根 fantasy 幻想, fantastic 奇妙的
**辨析**：⚠️ fantastical = fantastic（同义），fantastical 更偏文学/古雅

## 九、行动与评价

### 37. **utilise** — 利用，使用
**核心**：**有效利用**（英式拼写）
**搭配**：utilise resources 利用资源 / fully utilise 充分利用
**词根**：ut-/us- = use（使用）；同根 utility 效用, utensil 器具, abuse 滥用
**辨析**：⚠️ utilise（英式拼法）= utilize（美式）

### 38. **eradicate** — 根除，铲除，消灭
**核心**：**彻底根除**（疾病/贫穷）
**搭配**：eradicate poverty/disease 消除贫困/疾病
**词根**：e-（出，向外）+ radic-（根）→ 连根拔起；同根 radical 激进的, radish 小萝卜
**辨析**：⚠️ eradicate（连根拔除，彻底）≠ eliminate（消除，一般）≠ remove（移除，最通用）

### 39. **inhabitant** — 居民，居住者
**核心**：某地的**常住居民**
**搭配**：local inhabitants 当地居民 / an inhabitant of 的居民
**词根**：habit- = dwell/live（居住）；同根 inhabit 居住, habitation 住所, habitat 栖息地
**辨析**：⚠️ inhabitant（居民，人）≠ habitat（栖息地，动植物）

### 40. **appraisal** — 评估，评价，鉴定
**核心**：对**价值/表现**的评估
**搭配**：property appraisal 房产评估 / performance appraisal 绩效评估 / critical appraisal 批判性评价
**词根**：ap-（向）+ prais-（价值）→ 估价；同根 appraise 估价, praise 称赞
**辨析**：⚠️ appraisal（评估价值/绩效）≠ evaluation（评估，学术/教育）≈ assessment（通用）

### 41. **coverage** — 新闻报道；覆盖范围
**核心**：**报道/覆盖**的范围和程度
**搭配**：media coverage 媒体报道 / insurance coverage 保险范围 / wide coverage 广泛覆盖
**辨析**：⚠️ coverage（报道/覆盖，名词）≠ cover（封面/覆盖，动词或名词）— 搭配不同

### 42. **shrug off** — 不把…当回事；摆脱
**核心**：**耸肩表示不屑**、不理会
**搭配**：shrug off criticism 对批评不屑一顾 / shrug off a cold 把感冒硬扛过去
**场景**：口语/新闻常用

### 43. **swear to God** — 对天发誓；向上帝发誓
**核心**：**郑重发誓**（口语强调）
**搭配**：I swear to God I didn't do it 我对天发誓我没做
**辨析**：⚠️ swear to God（发誓）≠ swear/curse（咒骂）— swear 一词两义
**场景**：口语/发誓场景

### 44. **scramble** — 攀爬；争抢；紧急起飞
**核心**：**手脚并用攀爬**；**争抢**；战机**紧急起飞**
**搭配**：scramble up the cliff 爬上悬崖 / scramble for sth 争抢某物 / scramble eggs 炒蛋
**辨析**：⚠️ scramble（乱爬乱抢）≠ climb（有目标地攀爬，正式）≠ crawl（匍匐爬行）

## ⚠️ 形近词 / 近义词辨析（含场景偏好）

| 词对 | 区别（含使用场景偏好） |
|------|------|
| **communism** vs **communist** | communism = 共产主义（制度/理念）；communist = 共产主义的 / 共产主义者 |
| **inhabitant** vs **habitat** | inhabitant = 居民，居住者；habitat = （动植物的）栖息地 |
| **symphony** vs **concerto** | symphony = 交响乐；concerto = 协奏曲 |
| **qualitative** vs **quantitative** | qualitative = 定性的；quantitative = 定量的，量性的 |
| **discreet** vs **discrete** | discreet = 谨慎的；discrete = 离散的，分开的（形近易混） |
| **barber** vs **hairdresser** | barber = 传统男理发师（只剪男发）；hairdresser = 通用美发师 |
| **centigrade** vs **Celsius** | 均指摄氏度，centigrade 较老式，Celsius 更常用 |
| **fantastical** vs **fantastic** | 同义，fantastical 更偏文学/古雅 |
| **burglar** vs **thief** vs **robber** | burglar = 入室窃贼；thief = 小偷（最通用）；robber = 强盗（多含暴力/威胁） |
| **malignant** vs **benign** | malignant = 恶性的；benign = 良性的（医学反义） |
| **obsolete** vs **outdated** | obsolete = 已淘汰不再使用；outdated = 过时但尚可用 |
