# 📖 阅读理解词汇积累 (3) — 精读 / 课外阅读

> 来源：阅读理解与课外阅读中积累的生词，按语义场景分组，服务六级阅读与写译
> 排版：每条 2-4 行解析，按优先级排列：核心 → 搭配 → 辨析 → 词根/记忆
> 标注：`⚠️` = 易错点/原文修正 | **加粗** = 核心要点

## 一、治理与决议

### 1. **regent** — 摄政者
**核心**：君主年幼/缺席时**代行统治**的人
**搭配**：the Prince Regent 摄政王 / a regency government 摄政政府
**辨析**：regent（代君主执政）≠ guardian（监护人，照管未成年人的法律身份）
**词根**：reg- = rule（统治）+ -ent（…的人）；同根 regal 帝王的, regime 政权, regulate 管理

### 2. **warrant** — 授权令；保证；使…有正当理由
**核心**：n.（逮捕/搜查）**令状**；v. **使…显得正当**（warrant attention 值得关注）
**搭配**：a search warrant 搜查令 / a death warrant 死刑执行令 / warrant attention 值得关注
**辨析**：warrant（n. 令状；v. 使正当，书面/法律）≠ guarantee（保证，通用）
**记忆**：与 guarantee 同源（古法语 guarantir"担保"）→ "担保、授权"

### 3. **finalize** — 最后敲定，定案
**核心**：完成**最后细节**使计划/协议定局
**搭配**：finalize a deal/an agreement 敲定交易/协议 / finalize the details 敲定细节
**词根**：final（最后的）+ -ize（使…）；同根 final 最后的, finale 终曲

### 4. **concurrence** — 同意，一致；同时发生
**核心**：n. **一致同意**（正式）；也指事件**同时发生**（词根本义）
**搭配**：with the concurrence of sb 经某人同意 / the concurrence of events 诸事同时发生
**辨析**：concurrence（同意，正式书面）≈ agreement（通用）；concurrent 同时发生的
**词根**：con-（共同）+ curr- = run（跑）+ -ence → 一起跑 → 同时/一致；同根 occur 发生, current 水流/当前的

### 5. **signify** — 表示，意味着；有重要性
**核心**：v. **表示/意味着**；正式用法中还指"**要紧**"
**搭配**：signify agreement 表示同意 / a nod signifies approval 点头表示认可 / it doesn't signify 这无关紧要（书面）
**词根**：sign- = mark（标记）+ -ify（使）→ 作标记表示；同根 signal 信号, significant 重要的

### 6. **opt in / opt out** — 加入 / 退出（主动选择）
**核心**：**选择参加 / 选择退出**——主动权在个人，非强制
**搭配**：opt in to the scheme 选择加入该计划 / opt out of the agreement 选择退出协议 / an opt-out clause 退出条款
**辨析**：⚠️ opt out（主动选择退出）≠ quit（退出，通用）；相对的是默认加入后 opt out
**词根**：opt- = choose（选择）+ in/out；同根 option 选择, adopt 采纳

## 二、品性与境遇

### 7. **servile** — 奴性的，卑躬屈膝的（贬义）
**核心**：⚠️ 原文"过分顺序从"为"过分顺从"笔误；**像奴隶般讨好顺从**
**搭配**：a servile attitude 奴颜婢膝的态度 / servile obedience 卑躬屈膝的服从
**辨析**：servile（奴性，贬义，指人格卑微）≠ obedient（服从，中性）≠ submissive（顺从，中性）
**词根**：serv- = slave（奴隶）+ -ile；同根 servant 仆人, serve 服务, servitude 奴役

### 8. **well-disposed** — 怀有好感的；乐意的
**核心**：**对…有好感/友好**（toward）；be well-disposed to do 乐意做
**搭配**：be well-disposed toward sb 对某人心存好感 / well-disposed to help 乐意帮忙
**辨析**：反义 **ill-disposed** 有敌意的；≈ favourable（赞同的，正式）
**词根**：well（好）+ disposed（有…倾向的，dispose 使倾向于）

### 9. **fawn** — 幼鹿；讨好奉承
**核心**：n. **幼鹿**（也指浅黄褐色）；v. **讨好**——fawn on/upon sb
**搭配**：a fawn 一头小鹿 / fawn on one's superiors 讨好上司
**辨析**：⚠️ 一词两性：动词 fawn on/upon = 奉承（贬义，源于狗摇尾）；名词 fawn = 幼鹿
**记忆**：与 spaniel 常同现——狗摇尾乞怜（fawn）如猎犬（spaniel）讨好主人

### 10. **spaniel** — 西班牙猎犬；善于讨好的人
**核心**：长毛垂耳、**温顺讨喜**的犬种；引申"卑躬屈膝讨好者"
**搭配**：a cocker spaniel 可卡犬 / fawn like a spaniel 像猎犬般摇尾乞怜
**词根**：← 古法语 espaigneul（西班牙的狗）；由犬性温顺引申"讨好人"

### 11. **lone** — 独自的，孤零零的
**核心**：**单独一个**的（只作定语，比 alone 书面）
**搭配**：a lone traveller 独行旅人 / a lone wolf 独来独往的人 / a lone voice 孤立的反对声
**辨析**：⚠️ lone（定语前置：a lone figure）≠ alone（表语：be alone）≠ lonely（孤独的，带感情色彩）
**记忆**：lone = alone 去掉 a，同源"单独"

### 12. **affinity** — 亲和力，密切关系，相似性
**核心**：**天然的亲近/共鸣**；affinity for / with / between
**搭配**：have an affinity for music 对音乐有天然好感 / the affinity between the two languages 两种语言的相似性
**辨析**：affinity（情感/天然上的亲近）≠ similarity（相似，客观比较）≠ rapport（默契，指人际关系）
**词根**：ad-（向）+ fin- = boundary（边界）+ -ity → 接壤 → 亲近；同根 confine 限制, infinite 无限的

### 13. **inertia** — 惯性；惰性，维持现状
**核心**：（物理）**惯性**；引申"**惰性、因循守旧**"——⚠️ 原文"维持现状"即此引申义
**搭配**：the law of inertia 惯性定律 / bureaucratic inertia 官僚惰性 / overcome inertia 克服惰性
**辨析**：inertia（惯性/体制惰性，中性偏贬）≠ laziness（懒惰，指人，贬义）
**词根**：in-（不）+ ert- = skill（技艺）→ 不使力 → 惰性；同根 inert 惰性的

### 14. **meanest** — 最卑微的，最简陋的
**核心**：mean 的最高级——（人）**最卑微贫穷的**；（物）**最简陋的**
**搭配**：the meanest labourer 最底层的劳动者（《国富论》）/ the meanest hut 最简陋的棚屋
**辨析**：⚠️ mean 多义：v. 意思是；adj. 吝啬的/刻薄的（美式口语）；adj. 卑微的（旧/书面）
**词根**：mean（卑微的，古义）+ -est 最高级；⚠️ 与"意思是"的 mean 不同源

### 15. **opulence** — 富裕，丰饶
**核心**：⚠️ 拼写：**opulence**（原文 oplence 缺字母）；极度富裕/丰饶（正式）
**搭配**：live in opulence 生活奢华 / an opulence of colours 色彩斑斓
**辨析**：opulence（极富，正式书面）≈ affluence（富足，正式）vs wealth（财富，通用）
**词根**：op- = rich/wealth（富有）+ -ulence；同根 opulent 富裕的

## 三、动作与状态

### 16. **bolster** — 支持，加强；长枕
**核心**：v. **支持/增强**（信心、论点、经济）；n. **长枕/垫枕**
**搭配**：bolster confidence 提振信心 / bolster one's argument 充实论点 / bolster the economy 振兴经济
**辨析**：bolster（支撑加固，使更稳固）≠ boost（提升水平/数量）≠ support（支持，通用）
**记忆**：像把枕头（bolster）垫高使人更稳 → 支撑

### 17. **intercept** — 拦截，截获，阻断
**核心**：**中途截住**（人/信号/传球），使其到不了目的地
**搭配**：intercept a pass 截断传球 / intercept a message 截获情报 / intercept smugglers 拦截走私犯
**辨析**：intercept（中途拦截）≠ interrupt（打断）≠ block（封锁，彻底阻断）
**词根**：inter-（中间）+ cept- = take（拿）→ 中途拿下；同根 accept 接受, concept 概念

### 18. **desert** — 抛弃；沙漠（一词多义）
**核心**：v. **抛弃/离弃**，读 /dɪˈzɜːt/；n. **沙漠/荒漠**，读 /ˈdezət/
**搭配**：desert one's family 抛弃家人 / desert a post 擅离职守（军事）/ the Sahara Desert 撒哈拉沙漠
**辨析**：⚠️ desert（抛弃/沙漠）≠ dessert（餐后甜点）——拼写只差一个 s
**记忆**：重音位置不同 → 词义不同；deserted 荒废的/被抛弃的

### 19. **procure** — 获得，设法取得
**核心**：（努力）**弄到、获得**——尤指不易得之物
**搭配**：procure supplies 采购补给 / procure a ticket 设法搞到票 / procurement 采购（名词，商务高频）
**辨析**：procure（设法获取，正式）≠ obtain（获得，中性）≠ acquire（习得/购得）
**词根**：pro-（向前）+ cur- = care（照看）→ 用心弄到手；同根 cure 治疗, curious 好奇的

### 20. **contract** — 契约；收缩；感染（一词多义）
**核心**：n. **合同/契约**；v. **收缩**（肌肉/金属）；**感染**（疾病）；⚠️ 原文"订阅"有误——订阅是 subscribe
**搭配**：sign a contract 签合同 / contract a disease 感染疾病 / metals contract when cold 金属遇冷收缩
**辨析**：⚠️ 阅读高频一词多义：经济义"契约"、物理义"收缩"、医学义"感染"
**词根**：con-（一起）+ tract- = draw（拉）→ 拉到一起 → 收缩/缔约；同根 attract 吸引, extract 提取

### 21. **mine** — 我的；矿；开采（一词多义）
**核心**：pron. **我的**；n. **矿（井）**；v. **开采**（矿石）；⚠️ 另指"地雷/水雷"
**搭配**：mine coal 采煤 / a coal mine 煤矿 / a landmine 地雷
**辨析**：mine（矿井/开采）vs ore（矿石）vs quarry（采石场）vs mineral（矿物，泛指）
**词根**：与 mineral（矿物）同源（拉丁 minera 矿）

### 22. **concert** — 音乐会；一致，协同
**核心**：n. **音乐会**（常见义）；⚠️ 熟词僻义：**in concert (with)** = 协同地/一致地
**搭配**：in concert with the police 与警方协同 / act in concert 行动一致 / a rock concert 摇滚音乐会
**辨析**：in concert（协同，正式书面）≈ in cooperation；**concerted** effort 齐心协力
**词根**：con-（一起）+ cert-（努力）→ 一起努力 → 协同；同根 concertedly 协力地

## 四、产业与分工（工匠·冶炼·交易）

### 23. **mason** — 石匠，泥瓦匠
**核心**：砌石/砖的**建筑工匠**
**搭配**：a stonemason 石匠 / mason's work 石工活 / masonry 砖石建筑（名词）
**记忆**：Freemason（共济会）由中世纪石匠行会演变而来

### 24. **smith** — 铁匠；…制造者
**核心**：**打铁/金属加工**的工匠；合成词表"…匠"
**搭配**：a blacksmith 铁匠 / a goldsmith 金匠 / a locksmith 锁匠
**辨析**：smith（金属工匠，泛指）vs blacksmith（铁匠，专指打铁）
**词根**：smith 本义"工匠"，加材料前缀成具体工种

### 25. **millwright** — 磨坊工匠
**核心**：**设计/建造/修理磨坊**（磨粉机、水轮/风车传动）的工匠
**搭配**：the millwright's trade 磨坊机械师的行当
**词根**：mill（磨坊）+ wright = maker（工匠）；同根 playwright 剧作家, wheelwright 车轮匠

### 26. **fuller** — 漂洗工（纺织）
**核心**：**漂洗（fulling）布匹**的工人——去油脂、使布致密厚实
**搭配**：fuller's earth 漂白土 / a cloth fuller 漂布工
**词根**：full（v. 漂洗/缩绒，纺织术语）+ -er；⚠️ 与形容词 full"满的"同形不同义

### 27. **carder** — 梳理工（纺织）
**核心**：**梳理（carding）羊毛/棉花**的工人——使纤维顺直，纺织首道工序
**搭配**：a wool carder 羊毛梳理工
**词根**：card（v. 梳理，用梳齿机）+ -er；⚠️ card 平时为"卡片"，纺织义为"梳理"

### 28. **smelting** — 熔炼（冶炼）
**核心**：⚠️ 原文"熔炉"有误——**smelting** = 高温熔化矿石提取金属的**过程**（"熔炉"是 smelter/furnace）
**搭配**：iron smelting 炼铁 / a smelting furnace 冶炼炉 / smelt copper ore 熔炼铜矿
**词根**：smelt（v. 熔炼）与 melt（熔化）同源 → 使矿石熔化以取金属

### 29. **charcoal** — 木炭
**核心**：木材**不完全燃烧**得到的燃料；也是绘画材料
**搭配**：a charcoal grill 木炭烤架 / a charcoal sketch 木炭素描 / activated charcoal 活性炭
**词根**：char（烧焦）+ coal（煤）→ 焦化之炭

### 30. **ore** — 矿石
**核心**：**含金属的矿石**，经冶炼提取金属
**搭配**：iron ore 铁矿石 / copper ore 铜矿石 / a rich ore deposit 富矿层
**辨析**：ore（原矿石，含金属）≠ mineral（矿物，泛指）≠ mine（矿井）

### 31. **coals** — 煤；煤块
**核心**：coal 的复数——**一块块煤**；文学中常指"燃烧的炭火/余烬"
**搭配**：carry coals to Newcastle 多此一举（谚语：往产煤地送煤）/ glowing coals 通红的炭火
**辨析**：coal（不可数：煤这种燃料）vs coals（可数：煤块/余烬）
**记忆**：谚语背景——纽卡斯尔是英国产煤港

### 32. **trucking** — 以物易物（交换）
**核心**：⚠️ 现代英语 trucking = **卡车货运**（美式）；《国富论》语境 truck = **以物易物/交换**（旧义）
**搭配**：the propensity to truck, barter, and exchange 以物易物与交换的天性（《国富论》名句）
**辨析**：barter（以物易物，现代仍用）vs truck（交换，旧义，读古典文本会遇到）
**词根**：truck（交换，古法语 troquer）→ 旧义渐废，现代转指卡车

## 五、生活器物与基建

### 33. **utensil** — 器具，器皿
**核心**：⚠️ 拼写：**utensil**（原文 utensile 多一个 e）；家用/厨房**小器具**
**搭配**：kitchen utensils 厨具 / cooking utensils 烹饪器具 / writing utensils 书写工具
**辨析**：utensil（小型家用器具）≠ appliance（电器/大件设备）≠ tool（工具，干活用）
**词根**：ut- = use（用）+ -ensil → 用的东西；同根 use 使用, utility 效用

### 34. **pewter** — 锡合金（白镴）
**核心**：**锡与铅/铜的合金**，色灰蓝，制餐具、酒器
**搭配**：a pewter mug 白镴酒杯 / pewter ware 锡镴器皿
**记忆**：中古英语 pewtre；材质名词，通常不可数

### 35. **victuals** — 食物，粮食（旧/书面）
**核心**：⚠️ n.（复数）**食物/口粮**，非"粮食的"；读音 /ˈvɪtlz/（t 不发音）
**搭配**：store up victuals 储备粮食 / ship's victuals 船上口粮
**辨析**：victuals（古旧用法）≈ provisions（供应品，现代）；口语旧拼写 vittles
**记忆**：拼写 victuals、读作 vittles——t 不发音的典型词

### 36. **dam** — 水坝；母兽
**核心**：n./v. **堤坝/筑坝拦水**；⚠️ 畜牧语境另一义：**母兽**（四足动物的母亲）
**搭配**：build a dam 筑坝 / dam up the river 拦河筑坝 / the sire and dam 公畜与母畜（育种术语）
**辨析**：dam（坝，拦水蓄水）≠ dyke/dike（堤，防水）≠ reservoir（水库，蓄水体）

### 37. **navigable** — 可航行的
**核心**：（河流/海域）**可通航**的
**搭配**：a navigable river 可通航河流 / keep the channel navigable 保持航道畅通
**词根**：nav- = ship（船）+ -ig- + -able（可…的）；同根 navy 海军, navigate 导航

### 38. **sea-coast** — 海岸，海滨
**核心**：⚠️ 拼写：**sea-coast**（原文 sea-coat 拼写错误，释义"海岸"已提示应为 coast）；海岸地带
**搭配**：along the sea-coast 沿海岸 / sea-coast trade 沿海贸易
**辨析**：coast（海岸线/沿海地区，通用）vs shore（岸边，湖海河皆可）vs beach（沙滩）

### 39. **requisite** — 必要的；必需品（requisites）
**核心**：adj. **必要的**（正式）；n. **必需品/要件**，⚠️ 原文 requisiter 应为 **requisites**
**搭配**：the requisite skills 必备技能 / requisites for success 成功的要件 / travel requisites 旅行用品
**辨析**：requisite（必要，正式）≠ requirement（要求，通用）≠ requisition（征用，军事/行政）
**词根**：re-（再）+ quis- = seek（求）+ -ite → 一再需要 → 必要；同根 require 要求, request 请求

## ⚠️ 形近词 / 近义词辨析（含场景偏好）

| 词对 | 区别（含使用场景偏好） |
|------|------|
| **desert** vs **dessert** | desert = 抛弃（v.，/dɪˈzɜːt/）/ 沙漠（n.，/ˈdezət/）；dessert = 餐后甜点——拼写差一个 s |
| **smelting** vs **smelter/furnace** | smelting = 熔炼过程（原文误注"熔炉"）；smelter/furnace = 熔炉（装置） |
| **sea-coast** vs **coast/shore/beach** | coast = 海岸线/沿海（大范围）；shore = 岸边（湖海河皆可）；beach = 沙滩（游玩场景） |
| **utensil** vs **appliance** vs **tool** | utensil = 家用小器具（kitchen utensils）；appliance = 电器/大件（household appliances）；tool = 工具（干活用） |
| **requisite** vs **requirement** vs **requisition** | requisite = 必要/必需品（正式）；requirement = 要求（通用）；requisition = 征用（军事/行政） |
| **lone** vs **alone** vs **lonely** | lone = 独自的（定语前置，书面）；alone = 单独（表语，客观）；lonely = 孤独的（带情感，贬义色彩） |
| **servile** vs **obedient** vs **submissive** | servile = 奴性（贬义，人格卑微）；obedient = 服从（中性，守规矩）；submissive = 顺从（中性偏贬，软弱） |
| **inertia** vs **laziness** | inertia = 惯性/体制惰性（中性偏贬，不特指人）；laziness = 懒惰（指人，贬义） |
| **procure** vs **obtain** vs **acquire** | procure = 设法获取（正式，需努力）；obtain = 获得（中性通用）；acquire = 习得/购得（技能、资产） |
| **opulence** vs **affluence** vs **wealth** | opulence = 极尽富裕（书面，奢华）；affluence = 富足（正式，生活宽裕）；wealth = 财富（通用，中性） |
| **contract 一词多义** | 契约（法律）/ 收缩（物理）/ 感染（医学）；"订阅"义不存在，订阅 = subscribe |
| **trucking 旧义 vs 现代义** | 现代 = 卡车货运（美式）；《国富论》旧义 = 以物易物/交换 |
