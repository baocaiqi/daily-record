### ⚠️ 形近词 / 近义词辨析

| 词对 | 区别 |
|------|------|
| **sorrow** vs **sorrowful** | sorrow = 悲伤（名词）；sorrowful = 悲伤的（形容词）；⚠️ 原文把 sorrow 误作形容词 |
| **stark** vs **strict** vs **starkly** | stark = 严峻的/赤裸裸的；strict = 严格的（"严谨的"应为 rigorous）；starkly = 副词"直白地/截然地" |
| **herb** vs **herd** | herb = 草本植物（herbal tea 花草茶）；herd = 兽群/人群（herd immunity 群体免疫）⚠️ 原文拼错 |
| **benefactor** vs **beneficiary** | benefactor = 捐助者/恩人（施惠方）；beneficiary = 受益人（受惠方）⚠️ 反义成对，仅差字母 |
| **sensual** vs **sensuous** vs **sensory** | sensual = 感官/肉欲的；sensuous = 感性的/审美的（褒义）；sensory = 感觉的（科学术语） |
| **stipulate** vs **specify** vs **regulate** | stipulate = 明文规定（正式/法律）；specify = 具体说明；regulate = 监管 |
| **telling** vs **convincing** | telling = 有说服力的/说明问题的（a telling detail）；convincing = 令人信服的 |
| **understandably** vs **understandable** | understandably = 可以理解地（副词）；understandable = 可以理解的（形容词）⚠️ 原文词性误标 |
| **accountability** vs **responsibility** | accountability = 问责制（强调可追责）；responsibility = 责任（通用） |
| **illiquidity** vs **liquidity** | illiquidity = 非流动性（资产难变现）；liquidity = 流动性；形容词 illiquid / liquid |
| **overrate** vs **overestimate** vs **underrate** | overrate = 评价过高；overestimate = 估计过高（数量）；underrate = 低估（反义） |
| **abruptly** vs **suddenly** | abruptly = 突然且唐突（含无预兆/不礼貌）；suddenly = 突然（中性） |
| **uncanny** vs **mysterious** vs **weird** | uncanny = 离奇/超常（超出常理）；mysterious = 神秘的（有谜团）；weird = 怪异的（口语） |
| **immunity** vs **impunity** | immunity = 免疫力/豁免权；impunity = 免罚（with impunity 不受惩罚）⚠️ 形近易混 |
| **fauna** vs **flora** | fauna = 动物群；flora = 植物群；flora and fauna 固定搭配"动植物" |
| **lineage-specific** vs **species-specific** | lineage-specific = 谱系特异的；species-specific = 物种特异的 |
| **decentralise** vs **centralise** | decentralise = 下放/分散（英式 -ise）；centralise = 集权（反义）；美式拼写 -ize |
| **capuchin** vs **cappuccino** | capuchin = 卷尾猴/嘉布遣修士；cappuccino = 卡布奇诺咖啡（同源"带风帽"） |

### 🎯 高频考点速记

| 考点 | 说明 |
|------|------|
| **herd immunity 群体免疫** | herd（兽群）≠ herb（草本植物）；公共卫生阅读高频，⚠️ 拼写易混 |
| **sorrow 词性** | 名词"悲伤"，形容词是 sorrowful；勿把 sorrow 当形容词 |
| **stipulate 用法** | 动词，常接 that 从句：The law stipulates that...；名词 stipulation |
| **the law stipulates 主谓一致** | 主语 the law 单数 → 谓语加 -s（原文 law stipulate 漏了 s） |
| **accountable / accountability 词性** | accountability 名词"问责"；hold sb accountable for sth 追究责任 |
| **flora and fauna** | 固定搭配"动植物"，环保/生物阅读高频 |
| **swift 熟词僻义** | 形容词"迅速的" + 名词"雨燕"（雨燕飞得快，一词两义） |
| **benefactor vs beneficiary** | 施惠者 vs 受益人，反义成对，阅读中常考 |
| **proceedings 常用复数** | legal proceedings 诉讼 / conference proceedings 会议论文集 |
| **lineage 谱系** | 发育生物学高频词；lineage-specific 谱系特异的 |
| **decentralise 英美拼写** | 英式 -ise = 美式 -ize；decentralise/decentralize |
| **nonverbal communication** | 非言语交流 = 肢体语言（body language），心理学/传播学阅读 |
| **immunity 双领域** | 医学：herd immunity；法律：diplomatic immunity 外交豁免权 |
| **longline fishing 误捕** | 延绳钓对海鸟/海龟 bycatch 是生态环保类阅读热点 |
| **-ception / self-deception** | decep-（骗）：deception 欺骗 / self-deception 自我欺骗 / deceive 动词 |
