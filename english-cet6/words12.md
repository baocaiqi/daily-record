# 📚 CET-6 单词本 (12)

> 排版：每条单词 2-4 行解析，按优先级排列：核心 → 搭配 → 辨析 → 词根/记忆
> 标注：`⚠️` = 易混点/重点 | **加粗** = 核心要点

## 一、细粒度与细节

### 1. **fine-grained** — 细粒度的；细致的，精密的
**核心**：**颗粒/纹理很细**，引申为精细的（计算机/材料学/学术写作）
**搭配**：fine-grained structure 细粒度结构 / fine-grained analysis 精细分析 / fine-grained control 精细化控制
**辨析**：⚠️ fine-grained（强调颗粒/纹理细）≠ detailed（详细的）≠ fine（精细，单字）
**词根**：fine（精细）+ grain（颗粒）+ -ed → 颗粒很细 → 细粒度

## 二、节日与情绪

### 2. **Easter** — 复活节
**核心**：⚠️ 纪念**耶稣复活**的节日，专有名词**首字母大写**（勿写 easter）
**搭配**：Easter Sunday 复活节主日 / Easter egg 复活节彩蛋 / Easter holiday 复活节假期
**辨析**：⚠️ Easter（复活节）≠ Christmas（圣诞节）≠ Good Friday（受难日，复活节前周五）
**词根**：古英语 Ēastre（春之女神名）→ 复活节；复活节彩蛋是西方经典文化符号

### 3. **sorrow** — 悲伤，悲痛
**核心**：⚠️ **名词**"悲伤"（原文误作"悲伤的"），形容词是 sorrowful
**搭配**：deep sorrow 深深的悲伤 / to one's sorrow 令某人悲伤的是 / drown one's sorrows 借酒浇愁
**辨析**：⚠️ sorrow（深层悲痛）≠ sadness（悲伤，通用）≠ grief（因失去而哀伤）
**记忆**：sor-（痛）+ row → 心里"熬"着痛 → 悲伤

## 三、拯救与满足

### 4. **salvation** — 拯救，救赎；解救办法
**核心**：**灵魂/处境上的救赎**（宗教或比喻），可指"救命稻草"
**搭配**：the salvation of sb 对某人的拯救 / work out one's own salvation 自寻出路 / salvation army 救世军
**辨析**：⚠️ salvation（救赎/解救办法）≠ rescue（营救，具体行动）≠ remedy（补救办法）
**词根**：salv- = 安全/健康 → 把…带到安全处 → 拯救；同根 salvage 打捞, salubrious 有益健康的

### 5. **gratify** — 使满足，使高兴
**核心**：**使愉悦满足**（正式，带愉悦感）
**搭配**：gratify one's curiosity 满足好奇心 / be gratified at/by 对…感到欣慰
**辨析**：⚠️ gratify（使满足，正式带愉悦感）≠ satisfy（满足，最通用）≠ indulge（放纵迁就）
**词根**：grat- = 愉悦/感谢；同根 grateful 感激的, gratitude 感激, congratulate 祝贺

### 6. **gratify one's curiosity** — 满足某人的好奇心
**核心**：**满足好奇**（正式），比 satisfy one's curiosity 更书面
**搭配**：gratify one's curiosity about 满足对…的好奇心 / out of curiosity 出于好奇

### 7. **benefactor** — 捐助者，恩人
**核心**：**做好事的人**（施惠方）
**搭配**：anonymous benefactor 匿名捐助者 / generous benefactor 慷慨的捐助者 / the benefactor of the school 学校捐助人
**辨析**：⚠️ benefactor（施惠者）≠ beneficiary（受益人）——反义成对，仅差一个字母
**词根**：bene-（好）+ fact-（做）+ -or → 做好事的人；同根 benefit, beneficial, beneficiary

## 四、感官体验

### 8. **sensual** — 感官的；肉欲的
**核心**：**刺激感官的**，偏肉体快感
**搭配**：sensual pleasure 感官愉悦 / sensual experience 感官体验 / sensual lips 性感的嘴唇
**辨析**：⚠️ sensual（感官/肉欲）≠ sensuous（感性审美，褒义）≠ sensory（感觉的，科学术语）
**词根**：sens- = 感觉；同根 sense, sensation, sensitive

### 9. **the sensual pleasure** — 感官愉悦
**核心**：**感官享受**（偏肉体快感；中性说 sensory pleasure，智识说 intellectual pleasure）
**搭配**：the sensual pleasure of music 音乐的感官愉悦 / the sensual pleasures of life 生活中的感官享受

## 五、数字与语法

### 10. **plural** — 复数的；复数（形式）
**核心**：⚠️ **复数**，反义词 singular 单数；≠ plus（加，介词）
**搭配**：plural form 复数形式 / plural noun 复数名词 / in the plural 用复数形式
**词根**：plur- = 更多 + -al → 多于一个 → 复数；不规则复数 child→children, mouse→mice, criterion→criteria

### 11. **arithmetic** — 算术；算术的
**核心**：**基础四则运算**的算术
**搭配**：arithmetic mean 算术平均数 / mental arithmetic 心算 / arithmetic operations 算术运算
**辨析**：⚠️ arithmetic（算术）≠ mathematics（数学，总称）≠ algebra（代数）≠ geometry（几何）
**词根**：希腊语 arithmos = 数；同根 logarithm 对数

## 六、论证与表达

### 12. **telling** — 有力的，有说服力的；说明问题的
**核心**：**能说明问题**的、有说服力的
**搭配**：a telling argument 有力的论证 / a telling detail 说明问题的细节 / most telling of all 最能说明问题的是
**辨析**：⚠️ telling（说明问题的）≠ convincing（令人信服的）
**词根**：tell（说明）+ -ing → 能"说明"问题的 → 有力的

### 13. **understandably** — 可以理解地，合乎情理地
**核心**：⚠️ **副词**"可以理解地"（原文误作形容词），形容词是 understandable
**搭配**：understandably upset 可以理解地难过 / understandably reluctant 可以理解地不情愿
**词根**：under-（下）+ stand（站）+ -ably → 站得住的 → 可理解的

## 七、突然与严酷

### 14. **abruptly** — 突然地，唐突地
**核心**：**突然且唐突**，含"无预兆/不礼貌"
**搭配**：end abruptly 突然结束 / stop abruptly 戛然而止 / speak abruptly 说话唐突
**辨析**：⚠️ abruptly（突然且不礼貌）≠ suddenly（突然，中性）≠ unexpectedly（出人意料）
**词根**：ab-（离开）+ rupt-（断裂）+ -ly → 像绳子断了一样 → 突然；同根 rupture, erupt, disrupt

### 15. **stark** — 严峻的；赤裸裸的，鲜明的
**核心**：⚠️ **严峻的/赤裸裸的**（原文误作"严谨的"，"严谨的"是 rigorous / strict）
**搭配**：stark contrast 鲜明的对比 / stark reality 严峻的现实 / in stark terms 毫不掩饰地说
**记忆**：联想"死 tack"→ 又硬又冷 → 严酷的

### 16. **starkly** — 赤裸裸地，直白地；截然地
**核心**：**stark 的副词**，表示直白/截然
**搭配**：starkly different 截然不同 / starkly contrasted 形成鲜明对比 / put it starkly 直白地说
**辨析**：⚠️ starkly（副词）≠ stark（形容词）≠ strictly（严格地）形近易混
**词根**：stark + -ly → 副词形式

## 八、离奇与自欺

### 17. **uncanny** — 离奇的，难以解释的；惊人的
**核心**：**超出正常理解**的怪异/超常
**搭配**：uncanny resemblance 惊人的相似 / uncanny ability 超常的能力 / an uncanny feeling 说不出的怪异感
**辨析**：⚠️ uncanny（超出常理）≠ mysterious（神秘有谜团）≠ weird（怪异，口语）≠ supernatural（超自然）
**词根**：un-（不）+ canny（精明）→ 精明得不正常 → 离奇

### 18. **self-deception** — 自我欺骗，自欺欺人
**核心**：**自己骗自己**（多无意识），社科阅读常与认知偏差关联
**搭配**：engage in self-deception 自欺欺人 / a form of self-deception 一种自我欺骗
**辨析**：⚠️ self-deception（无意识自欺）≠ lying（有意识骗他人）≠ self-delusion（自欺幻觉）
**词根**：self + de-（向下）+ ceiv-（取）+ -tion → 自己骗自己

## 九、非言语与交流

### 19. **nonverbal** — 非言语的，非语言的
**核心**：**不用言语的**（手势/表情等），nonverbal communication = 肢体语言
**搭配**：nonverbal communication 非言语交流 / nonverbal cues 非言语线索 / nonverbal signals 非言语信号
**辨析**：⚠️ nonverbal（非言语）≠ verbal（言语的）≠ vocal（发声的）
**词根**：non-（非）+ verb-（词）+ -al → 不用词的

## 十、法律与责任

### 20. **proceedings** — 诉讼程序；会议记录；（复数）论文集
**核心**：⚠️ 常用**复数**：法律诉讼 / 会议记录 / 论文集
**搭配**：legal proceedings 法律诉讼 / start proceedings against 对…提起诉讼 / conference proceedings 会议论文集
**辨析**：⚠️ proceedings（诉讼/会议记录）≠ procedure（程序，步骤）≠ process（过程）
**词根**：pro-（向前）+ ceed-（走）+ -ings → 向前走的过程 → 诉讼程序

### 21. **stipulate** — 规定，明确要求
**核心**：⚠️ **动词**"明文规定"（正式/法律；原文误作名词），名词是 stipulation
**搭配**：stipulate that... 规定… / as stipulated in the contract 按合同规定 / stipulate a deadline 明确规定截止日期
**辨析**：⚠️ stipulate（明文规定，正式/法律）≠ regulate（监管，动词）≠ specify（具体说明）
**词根**：stipul- = 约定 + -ate → 约定条件 → 规定

### 22. **the law stipulates** — 法律明确规定
**核心**：⚠️ **主谓一致**：主语 the law 单数 → 谓语用 stipulates（原文 law stipulate 漏 -s）
**搭配**：the law stipulates that... 法律规定… / as the law stipulates 按法律规定

### 23. **accountability** — 责任，问责制
**核心**：⚠️ **名词**"问责"（原文误作形容词），形容词是 accountable
**搭配**：hold sb accountable for sth 追究某人对…的责任 / accountability system 问责制度 / public accountability 对公众负责
**辨析**：⚠️ accountability（问责，制度/抽象）≠ responsibility（责任，通用）
**词根**：ac-（向）+ count（说明）+ -ability → 要能"报账" → 问责

## 十一、金融与评价

### 24. **illiquidity** — 非流动性；（资产）难以变现
**核心**：⚠️ **名词**"难变现"（原文误作形容词），形容词是 illiquid
**搭配**：asset illiquidity 资产流动性差 / illiquidity risk 流动性风险 / the illiquidity of real estate 房地产难变现
**辨析**：⚠️ illiquidity（非流动性）≠ liquidity（流动性）≠ insolvency（破产，资不抵债）
**词根**：il-（不）+ liquid（流动）+ -ity → 不流动 → 难变现

### 25. **overrate** — 高估，评价过高
**核心**：⚠️ **动词**"评价过高"（原文误作形容词）
**搭配**：overrate one's ability 高估自己的能力 / be overrated 被高估 / overrated vs underrated 高估 vs 低估
**辨析**：⚠️ overrate（评价过高）≈ overestimate（估计过高，偏数量）≠ underrate / underestimate（低估）
**词根**：over-（过度）+ rate（打分）→ 分数打过头 → 高估

## 十二、迅捷与血缘

### 26. **swift** — 迅速的，敏捷的；雨燕
**核心**：⚠️ 熟词僻义：形容词"**迅速**"（正式/书面）+ 名词"**雨燕**"
**搭配**：swift response 迅速的反应 / swift action 果断的行动 / a swift recovery 迅速康复 / swift (bird) 雨燕
**辨析**：⚠️ swift（迅速，书面）≈ rapid ≈ quick（口语）≠ slow
**记忆**：雨燕 swift 飞得 swift → 一词两义相通

### 27. **kinship** — 亲属关系；相似性，共鸣
**核心**：**亲属纽带** + 抽象的**亲近感/共鸣**
**搭配**：kinship ties 亲属纽带 / a sense of kinship 亲切感 / kinship with 与…的相似性
**辨析**：⚠️ kinship（亲属关系/共鸣，抽象）≠ relationship（关系，通用）≠ relative（亲戚，具体的人）
**词根**：kin- = 亲属；同根 kin, kindred 同族的

## 十三、森林与生态

### 28. **forested** — 森林覆盖的，林木繁茂的
**核心**：**长满森林的**
**搭配**：forested area 森林覆盖区 / densely forested 林木茂密的 / forested hills 树木葱茏的山丘
**辨析**：⚠️ forested（形容词）≠ forestry（林业，名词）≠ forest（森林，名词）
**词根**：forest + -ed → 有森林的

### 29. **forestry** — 林业，森林管理
**核心**：**与森林相关的行业/学科**
**搭配**：forestry industry 林业产业 / forestry management 森林管理 / forestry worker 林业工人
**辨析**：⚠️ forestry（林业产业）≠ forest（森林）≠ deforestation（砍伐）≠ afforestation（造林）
**词根**：forest + -ry（行业后缀）→ 林业

### 30. **lineage-specific** — 谱系特异的（生物学）
**核心**：**特定谱系才有的**（发育生物学）
**搭配**：lineage-specific genes 谱系特异基因 / lineage-specific expression 谱系特异性表达
**辨析**：⚠️ lineage-specific（谱系特异）≠ species-specific（物种特异）≠ tissue-specific（组织特异）
**词根**：lineage（谱系）+ specific（特异的）；line-（线）→ 谱系

### 31. **capuchin** — 卷尾猴；（天主教）嘉布遣会修士
**核心**：**头上有像风帽毛发**的卷尾猴（动物/科普阅读）
**搭配**：capuchin monkey 卷尾猴 / white-faced capuchin 白面卷尾猴
**辨析**：⚠️ capuchin（卷尾猴）≠ chimpanzee（黑猩猩）≠ macaque（猕猴）≠ cappuccino（卡布奇诺）形近
**词根**：意大利语 cappuccino（带风帽）→ 毛发像戴风帽

### 32. **fauna** — 动物群，动物区系
**核心**：**动物总称**（与 flora 植物群成对出现）
**搭配**：flora and fauna 动植物 / native fauna 本地动物群 / marine fauna 海洋动物群
**辨析**：⚠️ fauna（动物群，总称）≠ flora（植物群）；≠ animal（单个动物）
**词根**：罗马神话农牧神 Faunus → 动物

### 33. **flora and fauna** — 动植物
**核心**：**动植物总称**（flora 植物群 ≠ fauna 动物群；环保/生物阅读高频）
**搭配**：the flora and fauna of the region 该地区的动植物 / protect flora and fauna 保护动植物

## 十四、免疫与疾控

### 34. **immunity** — 免疫力；豁免权
**核心**：**医学免疫 + 法律豁免**双领域
**搭配**：immunity to disease 对疾病的免疫力 / herd immunity 群体免疫 / diplomatic immunity 外交豁免权 / immunity from prosecution 免于起诉
**辨析**：⚠️ immunity（免疫/豁免）≠ impunity（免罚，with impunity 不受惩罚）形近
**词根**：im-（不）+ mun-（职责）→ 不承担病痛 → 免疫；同根 immune, immunize

### 35. **herd immunity** — 群体免疫
**核心**：⚠️ herd（兽群/人群）≠ herb（草本植物）——原文拼错；**群体免疫**
**搭配**：achieve herd immunity 实现群体免疫 / herd immunity threshold 群体免疫阈值

## 十五、组织与渔业

### 36. **decentralise** — 分散，下放（权力）；使非中心化
**核心**：⚠️ **动词**"去中心化"（原文误作形容词）；英式 -ise = 美式 -ize
**搭配**：decentralise power 下放权力 / a decentralised system 分散式系统 / decentralise management 分散管理
**辨析**：⚠️ decentralise（下放/分散）≠ centralise（集权，反义）≠ disperse（散开，物理）
**词根**：de-（去掉）+ centr-（中心）→ 去中心化；同根 central, concentrate

### 37. **longline** — 延绳钓（深海长线捕鱼法）
**核心**：**几公里长的深海钓线**捕鱼（环保阅读：误捕 bycatch 热点）
**搭配**：longline fishing 延绳钓捕鱼 / longline fishery 延绳渔业 / a longline vessel 延绳钓渔船
**辨析**：longline（延绳钓，渔业）≠ long line（长线，一般）≠ long-haul（长途）
**词根**：long（长）+ line（线）→ 长长的钓线 → 延绳

## ⚠️ 形近词 / 近义词辨析（含场景偏好）

| 词对 | 区别（含使用场景偏好） |
|------|------|
| **sorrow** vs **sorrowful** | sorrow = 悲伤（名词）；sorrowful = 悲伤的（形容词）；⚠️ 原文把 sorrow 误作形容词 |
| **stark** vs **strict** vs **starkly** | stark = 严峻的/赤裸裸的；strict = 严格的（"严谨的"应为 rigorous）；starkly = 副词"直白地/截然地" |
| **herb** vs **herd** | herb = 草本植物（herbal tea 花草茶）；herd = 兽群/人群（herd immunity 群体免疫）⚠️ 原文拼错 |
| **benefactor** vs **beneficiary** | benefactor = 捐助者/恩人（施惠方）；beneficiary = 受益人（受惠方）⚠️ 反义成对 |
| **sensual** vs **sensuous** vs **sensory** | sensual = 感官/肉欲（偏肉体）；sensuous = 感性审美（褒）；sensory = 感觉的（科学术语） |
| **stipulate** vs **specify** vs **regulate** | stipulate = 明文规定（正式/法律）；specify = 具体说明；regulate = 监管 |
| **telling** vs **convincing** | telling = 说明问题的（a telling detail）；convincing = 令人信服的 |
| **understandably** vs **understandable** | understandably = 可以理解地（副词）；understandable = 可以理解的（形容词）⚠️ 原文词性误标 |
| **accountability** vs **responsibility** | accountability = 问责制（强调可追责）；responsibility = 责任（通用） |
| **illiquidity** vs **liquidity** | illiquidity = 非流动性（资产难变现）；liquidity = 流动性；形容词 illiquid / liquid |
| **overrate** vs **overestimate** vs **underrate** | overrate = 评价过高；overestimate = 估计过高（数量）；underrate = 低估（反义） |
| **abruptly** vs **suddenly** | abruptly = 突然且唐突（无预兆/不礼貌）；suddenly = 突然（中性） |
| **uncanny** vs **mysterious** vs **weird** | uncanny = 离奇/超常（超出常理）；mysterious = 神秘（有谜团）；weird = 怪异（口语） |
| **immunity** vs **impunity** | immunity = 免疫力/豁免权；impunity = 免罚（with impunity 不受惩罚）⚠️ 形近 |
| **fauna** vs **flora** | fauna = 动物群；flora = 植物群；flora and fauna 固定搭配"动植物" |
| **lineage-specific** vs **species-specific** | lineage-specific = 谱系特异的；species-specific = 物种特异的 |
| **decentralise** vs **centralise** | decentralise = 下放/分散（英式 -ise）；centralise = 集权（反义）；美式拼写 -ize |
| **capuchin** vs **cappuccino** | capuchin = 卷尾猴/嘉布遣修士；cappuccino = 卡布奇诺咖啡（同源"带风帽"） |

## 🎯 高频考点速记

| 考点 | 说明 |
|------|------|
| **herd immunity 群体免疫** | herd（兽群）≠ herb（草本植物）；公共卫生阅读高频，⚠️ 拼写易混 |
| **sorrow 词性** | 名词"悲伤"，形容词是 sorrowful；勿把 sorrow 当形容词 |
| **stipulate 用法** | 动词，常接 that 从句：The law stipulates that...；名词 stipulation |
| **the law stipulates 主谓一致** | 主语 the law 单数 → 谓语加 -s（原文 law stipulate 漏 s） |
| **accountable / accountability 词性** | accountability 名词"问责"；hold sb accountable for sth 追究责任 |
| **flora and fauna** | 固定搭配"动植物"，环保/生物阅读高频 |
| **swift 熟词僻义** | 形容词"迅速的" + 名词"雨燕"（雨燕飞得快，一词两义） |
| **benefactor vs beneficiary** | 施惠者 vs 受益人，反义成对，阅读中常考 |
| **proceedings 常用复数** | legal proceedings 诉讼 / conference proceedings 会议论文集 |
| **lineage 谱系** | 发育生物学高频词；lineage-specific 谱系特异的 |
| **decentralise 英美拼写** | 英式 -ise = 美式 -ize；decentralise/decentralize |
| **nonverbal communication** | 非言语交流 = 肢体语言（body language），心理学/传播学阅读 |
| **immunity 双领域** | 医学：herd immunity；法律：diplomatic immunity 外交豁免权 |

| **self-deception / 认知偏差** | self-deception 与 cognitive bias 关联，心理/社科阅读 |
