# 📚 CET-6 单词本 (10)

> 排版：每条单词 2-4 行解析，按优先级排列：核心 → 搭配 → 辨析 → 词根/记忆
> 标注：`⚠️` = 易混点/重点 | **加粗** = 核心要点

## 一、手的动作

### 1. **clasp** — n. 扣子，钩子；紧握 / v. 握紧，抱紧
**核心**：**紧紧握住/抱住**，也指扣子；强调抓得牢
**搭配**：clasp hands 握手 / clasp sth in one's hands 双手紧握 / clasp one's hands 十指交叉相握 / a gold clasp 金扣子；惯用 She clasped the baby to her chest 把婴儿紧抱胸前
**辨析**：⚠️ clasp（紧握/抱紧）≈ grip（紧握）≈ clutch（急切地抓）≠ grasp（抓住/理解）
**记忆**：clasp 像扣子"咔哒"一声扣上

### 2. **clasp hands** — 握紧双手；握手
**核心**：**紧握**对方的手（强调紧握不放），也可指握手
**搭配**：clasp each other's hands 互相握住对方的手 / with clasped hands 双手紧握
**辨析**：⚠️ clasp hands（强调紧握）≠ shake hands（握手，礼仪动作）

## 二、电信与生物科技

### 3. **telecom** — n. 电信（业），电信公司
**核心**：telecommunications 的**缩写**，电信（业）/电信公司（口语常用）
**搭配**：a telecom company 电信公司 / the telecom industry 电信业 / telecom operators 电信运营商 / telecom giants 电信巨头（科技经济阅读高频）
**辨析**：⚠️ telecom（缩写，口语化）≠ telecommunication（正式，多用复数 telecommunications）
**词根**：tele- = 远 + communication 通信 → 远程通信；同根 telephone 电话, television 电视, telegraph 电报

### 4. **genetics** — n. 遗传学
**核心**：**遗传学**（研究基因的学科）
**搭配**：molecular genetics 分子遗传学 / genetics research 遗传学研究 / genetic engineering 基因工程 / genetically modified（GM）转基因的
**辨析**：⚠️ genetics（遗传学，学科）≠ genetic（遗传的，形容词）≠ genealogy（家谱学）
**词根**：gene（基因）+ -tics（学科后缀）→ 遗传学；同根 gene, genetic, genome, genetically

### 5. **mitochondrial** — adj. 线粒体的
**核心**：**线粒体的**；mtDNA（线粒体 DNA）为**母系遗传**，生物科普热门考点
**搭配**：mitochondrial DNA 线粒体 DNA / mitochondrial disease 线粒体疾病 / mitochondrial inheritance 线粒体遗传
**辨析**：⚠️ mitochondrial（线粒体的）≠ chromosome（染色体）≠ nucleus（细胞核）
**词根**：mito- = 线 + chondr- = 颗粒 + -al → "线+粒"状的细胞器；同根 mitochondria（复）, mitochondrion（单）

### 6. **econometric** — adj. 计量经济学的
**核心**：**计量经济学的**（用数学模型"测量"经济）
**搭配**：econometric models 计量经济模型 / econometric analysis 计量经济分析 / econometric methods 计量经济学方法
**辨析**：⚠️ 三兄弟形近易混：econometric（计量经济学的，模型）≠ economic（经济的，宏观）≠ economical（节约的，省钱）
**词根**：eco-（经济）+ metr- = 测量 + -ic → 用度量模型研究经济；同根 econometrics, economy, metric

## 三、水景与航运

### 7. **creek** — n. 小溪，小河；（美）支流
**核心**：**小溪，小河**；美语也可指支流
**搭配**：a mountain creek 山间小溪 / up the creek 陷入困境（俚语）/ up the creek without a paddle 无计可施
**辨析**：⚠️ creek（小溪/小湾）≈ stream（溪流）≠ river（河，更大）≠ brook（细流，更小）
**记忆**：creek 谐音"溪口"→ 小溪的入口

### 8. **cascade** — n. 小瀑布；一连串 / v. 倾泻，流下
**核心**：名词**小瀑布/一连串**，动词**倾泻流下**；喻"级联"
**搭配**：a cascade of water 倾泻的水流 / a cascade of events 一连串事件 / cascade effect 级联效应
**辨析**：⚠️ cascade（小瀑布/一连串）≈ waterfall（瀑布，更大）≠ rapids（急流）；惯用 The collapse set off a cascade of failures 倒闭引发连锁失败
**词根**：cas- = 落下 + -ade → 落下的水；同根 case 情况, casual 偶然的

### 9. **a cascade of curls** — 瀑布般的卷发
**核心**：**瀑布般垂落**的卷发（强调"倾泻而下"）
**搭配**：a cascade of blonde curls 瀑布般的金色卷发 / her hair fell in cascades 她的头发如瀑布般垂落
**辨析**：⚠️ a cascade of curls（垂落）≈ wavy hair（波浪发）≠ straight hair（直发）

### 10. **riverboat** — n. 内河船，江轮
**核心**：**内河船，江轮**（在河上行驶的船）
**搭配**：a Mississippi riverboat 密西西比河上的内河船 / riverboat gambling 船上赌博
**辨析**：⚠️ riverboat（内河船）≠ ferry（渡轮）≠ cruise ship（远洋邮轮）
**记忆**：river（河）+ boat（船）→ 在河里开的船

## 四、控制与垄断

### 11. **stranglehold** — n. 压制，扼杀；垄断，控制
**核心**：**垄断/压制**，字面"掐住咽喉的控制"（比喻义为主）
**搭配**：have a stranglehold on sth 对…实行垄断/控制 / break the stranglehold of 打破…的垄断
**辨析**：⚠️ stranglehold（卡脖子式垄断，比喻）≈ monopoly（垄断，正式）≈ chokehold（锁喉）；惯用 The company has a stranglehold on the market 垄断市场
**词根**：strangle（扼杀）+ hold（控制）→ 掐住咽喉的控制；同根 strangle 扼死, hold 控制

## 五、身份与绰号

### 12. **epithet** — n. 绰号，称号；（贬）辱骂之词
**核心**：**绰号/称号**，也指（贬）辱骂之词
**搭配**：a racial epithet 种族辱骂语 / an insulting epithet 侮辱性绰号
**辨析**：⚠️ epithet（绰号，中性/贬）≈ nickname（昵称，亲昵）≠ alias（化名，隐瞒身份）≠ title（头衔，正式）
**词根**：epi- = 在…上 + thet- = 放 → 贴在名字上的称呼；同根 thesis 论点, synthetic 合成的

### 13. **taxpayer** — n. 纳税人
**核心**：**纳税人**（交税的人）
**搭配**：taxpayer money 纳税人的钱 / hard-working taxpayers 辛勤的纳税人 / a taxpayer-funded project 纳税人出资的项目
**辨析**：⚠️ taxpayer（纳税人）≠ tax collector（收税人）≠ taxable（应征税的）；惯用 Taxpayers' money should not be wasted 纳税人的钱不该被浪费
**词根**：tax（税）+ pay + -er → 交税的人；同根 tax, taxation, tax-free, income tax

### 14. **puritan** — n. 清教徒 / adj. 清教徒式的，严格朴素的
**核心**：**清教徒**（追求"纯净"教义的新教徒）；⚠️ 原文"苦行僧"不准确，清教徒 ≠ 苦行僧
**搭配**：the Puritans 清教徒（16-17 世纪新教派别）/ puritan values 清教徒式价值观 / a puritan attitude to pleasure 对享乐的清教徒式态度
**辨析**：⚠️ puritan（历史宗教派别）≠ ascetic（苦行者，禁欲者）≠ hermit（隐士）
**词根**：pur- = 纯净 + -itan（表人）→ 主张"净化"教会者；同根 pure, purity, purify

## 六、衣着与软垫

### 15. **overdressed** — adj. 穿得过于正式/花哨的
**核心**：**穿得过于正式/花哨**（在某个场合"过头"）
**搭配**：be overdressed for the occasion 在场合中穿得太正式 / feel overdressed 觉得太隆重
**辨析**：⚠️ 反义成对：overdressed（太正式/花哨）≠ underdressed（太随意/不够正式）；惯用 I felt overdressed in a suit at the casual party 休闲派对上穿西装太隆重
**记忆**：over-（过度）+ dressed（穿衣）→ 穿过头了；对比 underdressed

### 16. **upholstered** — adj. 装有软垫的，有衬垫的（家具）
**核心**：**装有软垫的**（家具），用填充物"包"起来
**搭配**：an upholstered chair 软垫椅 / upholstered furniture 软垫家具 / a richly upholstered sofa 衬垫厚实的沙发
**辨析**：⚠️ upholstered（软垫家具）≈ cushioned（有坐垫的）≈ padded（加衬垫的，通用）
**词根**：up- + holster（包裹）+ -ed → 用填充物"包"起来；同根 upholster 装软垫, upholstery 软垫/装饰

### 17. **an upholstered chair** — 软垫椅
**核心**：**软垫椅**（包布/皮座椅）
**搭配**：a leather-upholstered chair 真皮软垫椅
**辨析**：⚠️ an upholstered chair（软垫椅）≠ a wooden chair（木椅，无软垫）≈ an armchair（扶手椅，常带软垫）

## 七、情绪与气质

### 18. **enraged** — adj. 愤怒的，被激怒的
**核心**：**暴怒的，被激怒的**（程度强）
**搭配**：be enraged at/by sth 因…而暴怒 / an enraged crowd 愤怒的人群 / enraged customers 愤怒的顾客
**辨析**：⚠️ enraged（暴怒，程度最强）> angry（生气，通用）≈ furious（狂怒）≠ irritated（恼怒，程度轻）
**词根**：en-（使）+ rage（暴怒）+ -ed → 使暴怒的；同根 rage, enrage, raging

### 19. **stressed-out** — adj. 压力过大的，焦虑不安的
**核心**：**压力过大、焦虑不安**的（形容人）
**搭配**：feel stressed-out 感到压力山大 / a stressed-out worker 压力过大的员工
**辨析**：⚠️ 易混：stressed-out/stressed（感到压力，修饰人）vs stressful（令人有压力的，修饰事）；≈ overwhelmed 不堪重负
**记忆**：stress（压力）+ out → 压力都"溢出"了 → 焦虑不安

### 20. **decisiveness** — n. 果断，决断力
**核心**：**决断力，果断**（名词）
**搭配**：act with decisiveness 果断行事 / show decisiveness 表现出决断力 / lack of decisiveness 缺乏决断
**辨析**：⚠️ decisiveness（决断力，名词）≠ decision（决定）≠ decisive（果断的，形容词）；惯用 Leadership requires decisiveness 领导力需要决断力
**词根**：de-（加强）+ cis- = 切 + -ive + -ness → 一刀切下去做决定；同根 decide, decision, decisive, incisive

## 八、财务与财政

### 21. **recoup** — v. 收回（成本），弥补（损失）
**核心**：**收回成本/弥补损失**（财务语境）
**搭配**：recoup one's losses 弥补损失 / recoup the cost 收回成本 / recoup investments 收回投资
**辨析**：⚠️ recoup（收回/弥补，财务）≈ recover（恢复/收回，通用）≈ reclaim（取回，主张权利）；惯用 It will take years to recoup the initial investment 收回初期投资需数年
**词根**：re-（回）+ coup- = 打/切 → 打回来；同根 coup 政变/妙举, coupon 优惠券

### 22. **toll** — n. 通行费；代价，伤亡人数 / v. 敲钟
**核心**：**通行费**；熟词僻义**代价/伤亡人数**；v. 敲钟
**搭配**：toll road 收费公路 / death toll 死亡人数 / take a toll on 对…造成损害 / toll the bell 敲钟
**辨析**：⚠️ toll（通行费/代价）≠ tax（税，强制征收）≠ fee（服务费）；惯用 The long hours took a toll on her health 长时间工作损害健康
**记忆**：收费站的兔子（toll）要交过路费；death toll = 死亡人数"计费表"

### 23. **exchequer** — n. 国库，财源；（英国）财政部
**核心**：**国库/财源**；（英国）财政部（英式）
**搭配**：the Exchequer（英国）财政部 / Chancellor of the Exchequer（英国）财政大臣 / public exchequer 国库
**辨析**：⚠️ exchequer（英国财政部，英式）≠ treasury（国库/财政部，通用）≠ the Treasury（美国财政部）
**记忆**：谐音"一撕拆款"→ 从国库里撕钱出来

### 24. **treasury** — n. 国库；财政部；国债（treasuries）
**核心**：**国库；财政部**；treasuries 国债
**搭配**：the Treasury 财政部 / treasury bonds 国债 / treasury bills 短期国库券（经济阅读高频）
**辨析**：⚠️ treasury（国库/财政部，通用）≈ exchequer（英国财政部）≠ treasure（财宝，具体物）
**词根**：treas- = 财宝 + -ury（地点）→ 存财宝处；同根 treasure, treasurer 司库

## 九、积压事务

### 25. **backlog** — n. 积压的事务，待办事项
**核心**：**积压未处理的事务/待办事项**（⚠️ 原文"代办事物"为错别字，正确为"待办事项"）
**搭配**：a backlog of work 积压的工作 / clear the backlog 清理积压 / reduce the backlog 减少积压；惯用 There's a huge backlog of orders 订单大量积压
**辨析**：⚠️ backlog（堆积未处理）≠ to-do list（待办清单，前瞻性）≠ log（日志）
**记忆**：back（后面）+ log（木头）→ 木头堆在后面 → 积压

### 26. **a backlog of mail** — 积压的邮件
**核心**：**积压（未处理）的邮件**
**搭配**：a backlog of unanswered mail 积压未回的邮件
**辨析**：⚠️ a backlog of mail（积压未处理）≠ junk mail（垃圾邮件）≠ a pile of mail（一堆邮件，中性）

## 十、营养与延续

### 27. **under-nutrition** — n. 营养不良（undernutrition 常连写）
**核心**：**营养不足**（量不足；常连写 undernutrition）
**搭配**：child undernutrition 儿童营养不良 / chronic undernutrition 长期营养不良
**辨析**：⚠️ undernutrition（量不足）≈ malnutrition（营养不良，广义，含不均衡）≠ overnutrition（营养过剩）
**词根**：under-（不足）+ nutrition（营养）→ 营养不足；同根 nutrition, nutritious, malnutrition

### 28. **perpetuate** — v. 使持续，使长存（多指负面事物）
**核心**：**使持续/长存**（多指负面事物，动词；⚠️ 原文"持续不断的"为形容词义，perpetuate 是动词）
**搭配**：perpetuate a myth 使谬论长存 / perpetuate inequality 使不平等持续 / perpetuate stereotypes 固化刻板印象
**辨析**：⚠️ perpetuate（使坏事延续，常带贬义）≠ maintain（维持，中性）≠ sustain（维持/支撑）；惯用 The media perpetuate stereotypes 媒体固化刻板印象
**词根**：per-（完全）+ petu- = 追求 + -ate → 一直追求下去；同根 perpetual 永久的, perpetuity 永恒

## 十一、促成与过失

### 29. **contributory** — adj. 促成的，起作用的，有贡献的
**核心**：**促成的，起作用的**（⚠️ 原文"促进"不完整，应为"促成的"）
**搭配**：a contributory factor 促成因素 / contributory negligence 共同过失（法律）
**辨析**：⚠️ contributory（促成的）≈ contributing（起作用的）≠ attributable（可归因于…的）
**词根**：con-（共同）+ tribut- = 给予 + -ory → 共同"给予"的；同根 contribute, contribution, tributary, distribute

### 30. **contributory factor** — 促成因素
**核心**：**促成因素**（间接因素之一）
**搭配**：a contributory factor to/in sth 某事的促成因素 / be a contributory factor in the accident 事故的促成因素之一
**辨析**：⚠️ contributory factor（促成因素，间接）≠ cause（原因，直接）≠ determinant（决定性因素）；惯用 Lack of sleep was a contributory factor in the crash 睡眠不足是事故的促成因素之一

### 31. **contributory negligence** — 共同过失，混合过失（法律术语）
**核心**：**共同过失**（法律术语：受害人自身也有过错，责任按比例分担）
**搭配**：the doctrine of contributory negligence 共同过失原则 / claim contributory negligence 主张共同过失
**辨析**：⚠️ contributory negligence（受害方也有过错）≠ negligence（单纯过失）
**词根**：contributory（促成的）+ negligence（过失）；同根 negligence, negligent, neglect

## 十二、司法与权力结构

### 32. **judiciary** — n. 司法部门，司法机关；（总称）法官
**核心**：**司法部门/司法机关**（法官总称）
**搭配**：the judiciary 司法部门 / an independent judiciary 独立的司法部门 / judicial system 司法体系
**辨析**：⚠️ 三权分立必考：judiciary（司法）≠ legislature（立法）≠ executive（行政）
**词根**：jud- = 判断 + -iciary → 做"判断"的机构；同根 judge, judicial, judgment, prejudice

### 33. **top-down** — adj./adv. 自上而下的（地）
**核心**：**自上而下**的（集权式管理/加工方式）
**搭配**：a top-down approach 自上而下的方法 / top-down management 自上而下的管理 / top-down processing 自上而下加工
**辨析**：⚠️ 反义成对：top-down（自上而下，集权式）≠ bottom-up（自下而上，民主式）；管理/心理阅读常成对出现
**记忆**：top + down → 从顶层往下推；对比 bottom-up

## 十三、争论与构想

### 34. **contention** — n. 争论；论点，主张
**核心**：**争论/论点，主张**（正式）
**搭配**：a point of contention 争论的焦点 / the main contention 主要论点 / a bone of contention 争论焦点（习语）
**辨析**：⚠️ contention（论点/争论，正式）≈ dispute（争端）≠ argument（争吵/论证）；惯用 The main contention is that education should be free 主要论点是教育应免费
**词根**：con-（共同）+ tend- = 伸展 + -ion → 双方"拉扯"同一件事；同根 contend, contender, tension

### 35. **a point of contention** — 争论的焦点
**核心**：**争论的焦点**（双方僵持不下）
**搭配**：the point of contention between A and B A 与 B 间的争论焦点 / a bone of contention 争议点（习语）
**辨析**：⚠️ 反义 a point of agreement（共识点）；≈ a bone of contention（同义习语）

### 36. **conceive** — v. 构想，设想；怀孕
**核心**：**构想/设想**；也指**怀孕**；conceive of 设想
**搭配**：conceive of doing sth 设想做某事（后接动名词）/ conceive a plan 构想计划 / conceive a child 怀孕
**辨析**：⚠️ ceiv- 家族：conceive（构想/怀孕）≠ perceive（感知）≠ deceive（欺骗）≠ receive（接收）；惯用 I can't conceive of living without the internet
**词根**：con-（一起）+ ceiv- = 拿取 → 脑中"拿取"意象；同根 concept, conception

### 37. **conceivably** — adv. 可以想象地，可能地
**核心**：**可以想象地，可能地**（⚠️ 原文拼写 conceiveably 有误，正确为 conceivably）
**搭配**：conceivably possible 理论上可能 / could conceivably happen 有可能发生
**辨析**：⚠️ conceivably（可以想象地，可能）≈ possibly（可能）≠ presumably（推测起来）；惯用 The plan could conceivably fail
**词根**：con- + ceiv-（拿取）+ -ably → 可以"想得到"地；同根 conceivable 可想象的, inconceivable 不可想象的

## 十四、附带与无争议

### 38. **incidental** — adj. 附带的，次要的；伴随的
**核心**：**附带的，次要的**；伴随的
**搭配**：incidental expenses 杂费 / incidental damage 附带损害 / be incidental to sth 伴随…而来；惯用 The extra costs are incidental to the main project 额外费用是主项目的附带支出
**辨析**：⚠️ incidental（附带/次要）≠ accidental（意外的）— 前者强调"伴随次要"，后者强调"偶然发生"
**词根**：in- + cid- = 落下 + -ent + -al → 偶然"落到"你身上的；同根 incident, accident, coincide

### 39. **be incidental to sth** — 伴随……而来的，对……是次要的
**核心**：**伴随…而来的**，对…是次要的
**搭配**：risks incidental to the job 工作附带的风险 / problems incidental to urban life 城市生活伴随的问题
**辨析**：⚠️ 反义 be essential to（必不可少）≈ accompany（伴随，动词）

### 40. **noncontroversial** — adj. 毫无争议的
**核心**：**毫无争议的**
**搭配**：a noncontroversial topic 毫无争议的话题 / a noncontroversial decision 无争议的决定
**辨析**：⚠️ 同义：noncontroversial ≈ uncontroversial（更常用）
**词根**：non-（不）+ contra-（相反）+ vers- = 转 + -ial → 不引起"翻转对立"；同根 controversial, controversy, invert, convert

## 十五、活力、基准与迁移

### 41. **vibrant** — adj. 充满活力的，生机勃勃的；鲜艳的
**核心**：**充满活力的，生机勃勃的**；鲜艳的
**搭配**：a vibrant city 充满活力的城市 / vibrant colors 鲜艳的色彩 / vibrant economy 繁荣的经济 / vibrant community 有生气的社区
**辨析**：⚠️ vibrant（有活力，城市/色彩）≈ lively（活泼）≈ dynamic（动态有活力）≠ vivid（生动，指描写/记忆清晰）
**词根**：vibr- = 振动 + -ant → 像在"振动"般有活力；同根 vibrate, vibration；心跳"振动"不停 → 充满活力

### 42. **benchmark** — n. 基准，基准点；标杆
**核心**：**基准，标杆**（可衡量对比的标准）
**搭配**：benchmark index 基准指数 / a benchmark for success 成功的基准 / benchmark against 以…为基准 / industry benchmark 行业基准
**辨析**：⚠️ benchmark（对比标准）≈ standard（标准）≠ baseline（基线，起点水平）；惯用 The S&P 500 is a benchmark for the US stock market
**词根**：bench（工作台）+ mark（标记）→ 刻在工作台上的标准记号；经济/科技阅读常与 performance, index 搭配

### 43. **relocate** — v. 迁移，搬迁，重新安置
**核心**：**迁移，搬迁**（正式，多指公司/工厂/住所）
**搭配**：relocate to another city 迁往另一城市 / relocate employees 重新安置员工 / relocate the factory 搬迁工厂
**辨析**：⚠️ relocate（迁移，正式）≈ move（搬家，通用）≈ transfer（调任/转移，职务或物品）；惯用 The company decided to relocate its headquarters to Shanghai 公司决定把总部迁到上海
**词根**：re-（再）+ loc- = 地点 + -ate → 换个地方；同根 locate, location, local, allocate

## 十六、欢呼三兄弟

### 44. **hooray** — int. 好极了，万岁
**核心**：**好极了，万岁**（欢呼声，拟声词）
**搭配**：hooray for sb/sth 为…喝彩 / hip hip hooray! 加油！；惯用 Hooray! We won the game!
**辨析**：⚠️ hooray / hurrah / hurray 三拼写同义，均为"万岁/好极了"
**记忆**：拟声词，欢呼声"呼啦"

### 45. **hurrah** — int. 好极了，万岁（hooray 的变体）
**核心**：**好极了，万岁**（hooray 的变体；⚠️ 原文拼写 hurran 有误，正确为 hurrah）
**搭配**：the last hurrah 最后一次亮相/绝唱 / hip hip hurrah! 万岁！；惯用 Hip hip hurrah!
**记忆**：与 hooray / hurray 同义，记一个即可

### 46. **hurray** — int. 好极了，万岁（hooray 的变体）
**核心**：**好极了，万岁**（hooray 的变体）
**搭配**：hurray for the holidays 为假期欢呼
**辨析**：⚠️ hooray / hurrah / hurray 三胞胎同义（欢呼声），无正式/口语之分

## 十七、方式副词

### 47. **symbolically** — adv. 象征性地，象征意义上地
**核心**：**象征性地**，象征意义上地
**搭配**：symbolically significant 具有象征意义的 / act symbolically 象征性地行动
**辨析**：⚠️ symbolically（象征性地）≠ literally（字面上地，反义）≠ symbolic（象征的，形容词）；惯用 The gesture was symbolically important
**词根**：sym-（共同）+ bol- = 抛 + -ical + -ly → 把两件事"抛"在一起；同根 symbol, symbolic, symbolism

### 48. **crushingly** — adv. 极其，惨重地（多修饰负面）
**核心**：**极其，惨重地**（多修饰负面，压倒性程度）
**搭配**：crushingly disappointing 令人极度失望 / crushingly defeated 惨败
**辨析**：⚠️ crushingly（压倒性的负面程度）≈ overwhelmingly（压倒性地）≠ crushing（压碎性的，形容词）；惯用 The news was crushingly disappointing
**记忆**：crush（压碎）+ -ingly → 像泰山压顶 → 极其惨重

### 49. **inescapably** — adv. 不可避免地，无可逃避地
**核心**：**不可避免地，无可逃避地**（⚠️ 原文拼写 inescapbly 有误，正确为 inescapably）
**搭配**：inescapably linked 密不可分 / inescapably true 千真万确
**辨析**：⚠️ inescapably（无可逃避）≈ inevitably（不可避免）≈ unavoidably（无法避免）；惯用 The two issues are inescapably linked
**词根**：in-（不）+ escape（逃避）+ -ably → 逃不掉地；同根 escape, inescapable

## 十八、流泪者与流血者（文学化）

### 50. **shedder** — n. 流泪者，流血者（文学化表达，非词典常用词）
**核心**：**流泪者/流血者**（文学性派生；词典中 shedder 常指"蜕壳的蟹"）
**搭配**：a shedder of tears 流泪者 / a shedder of blood 杀人者，刽子手
**辨析**：⚠️ shedder（使流出者，罕见文学词）≠ shed（流出，动词）
**词根**：shed（流出）+ -er → 使…流出的人；同根 shed tears 流泪, shed blood 流血

## ⚠️ 形近词 / 近义词辨析（含场景偏好）

| 词对 | 区别 |
|------|------|
| **exchequer** vs **treasury** vs **treasure** | exchequer = （英）财政部/国库（英式）；treasury = 国库/财政部（通用）；treasure = 财宝（具体物） |
| **stranglehold** vs **monopoly** | stranglehold = 卡脖子式垄断/压制（比喻）；monopoly = 垄断（正式术语） |
| **epithet** vs **nickname** vs **alias** | epithet = 绰号/称号（中性或贬义）；nickname = 昵称（亲昵）；alias = 化名（隐瞒身份） |
| **overdressed** vs **underdressed** | overdressed = 穿得太正式/花哨；underdressed = 穿得太随意；反义成对 |
| **stressed** vs **stressful** | ⚠️ stressed = 感到压力的（修饰人）；stressful = 令人有压力的（修饰事物） |
| **enraged** vs **angry** vs **furious** | enraged = 暴怒（程度最强）；angry = 生气（通用）；furious = 狂怒 |
| **recoup** vs **recover** | recoup = 收回成本/弥补损失（财务语境）；recover = 恢复/收回（通用） |
| **backlog** vs **to-do list** | backlog = 积压未处理的事务；to-do list = 待办清单（前瞻性） |
| **toll** vs **tax** vs **fee** | toll = 通行费/代价；tax = 税（强制征收）；fee = 服务费 |
| **under-nutrition** vs **malnutrition** | under-nutrition = 营养不足（量不足）；malnutrition = 营养不良（广义，含营养不均衡） |
| **perpetuate** vs **maintain** | perpetuate = 使（坏事）持续（贬义倾向）；maintain = 维持（中性） |
| **contributory factor** vs **cause** | contributory factor = 促成因素（间接因素之一）；cause = 直接原因 |
| **judiciary** vs **legislature** vs **executive** | 三权分立：judiciary 司法 / legislature 立法 / executive 行政 |
| **top-down** vs **bottom-up** | top-down = 自上而下（集权式）；bottom-up = 自下而上（民主式） |
| **contention** vs **dispute** vs **argument** | contention = 论点/争论（正式）；dispute = 争端；argument = 争吵/论证 |
| **conceive** vs **perceive** vs **deceive** | ⚠️ ceiv- 词根：conceive 构想/怀孕；perceive 感知；deceive 欺骗 |
| **noncontroversial** vs **uncontroversial** | 同义：均"无争议的"，un- 更常用 |
| **incidental** vs **accidental** | incidental = 附带的/次要的；accidental = 意外的 |
| **vibrant** vs **vivid** | vibrant = 有活力的（城市/色彩）；vivid = 生动的（描写/记忆） |
| **benchmark** vs **baseline** | benchmark = 基准（对比标准）；baseline = 基线（起点水平） |
| **relocate** vs **transfer** | relocate = 迁移（公司/住所）；transfer = 调任/转移（职务/物品） |
| **econometric** vs **economic** vs **economical** | ⚠️ 计量经济学的（模型）/ 经济的（宏观）/ 节约的（省钱） |
| **hooray** vs **hurrah** vs **hurray** | 同义异拼：好极了/万岁；⚠️ 原文 hurran 拼写有误 |
| **puritan** vs **ascetic** | puritan = 清教徒（历史宗教派别）；ascetic = 苦行者（禁欲者） |
| **undershed**（原文） | 非标准词，词典中不存在且无释义，已删除；疑为 undershirt 汗衫 / underside 底面 / undersized 偏小 之误 |

## 🎯 高频考点速记

| 考点 | 说明 |
|------|------|
| **economic / economical / econometric** | 三兄弟辨析：economic 经济的（宏观）/ economical 节约的（省钱）/ econometric 计量经济学的（模型） |
| **三权分立三词** | legislature（立法）/ executive（行政）/ judiciary（司法）成组记忆 |
| **top-down vs bottom-up** | 管理/心理阅读高频对比：自上而下 vs 自下而上 |
| **stressed vs stressful** | 修饰人 vs 修饰事物：stressed 感到压力的；stressful 令人有压力的 |
| **take a toll on / death toll** | 熟词僻义：对……造成损害 / 死亡人数 |
| **conceive of + 动名词** | conceive of（设想）后接动名词：I can't conceive of living without ... |
| **ceiv- 词根系列** | receive（接收）/ deceive（欺骗）/ perceive（感知）/ conceive（构想），前缀定方向 |
| **perpetuate 的贬义倾向** | 常接负面事物：perpetuate poverty / inequality / stereotypes |
| **contributory negligence** | 法律术语"共同过失"：受害人自身也有过错，责任按比例分担 |
