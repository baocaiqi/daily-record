| 33 | **spot-on** | adj. 完全正确的，恰到好处的 | `[词根]` spot（点，正中目标）+ on（在…上）→ 正中靶心 → 完全正确；`[短语]` spot-on advice 中肯的建议 / spot-on prediction 精准的预测 / your answer was spot-on 你的回答完全正确；`[辨]` spot-on（完全正确，英式口语）≈ exactly right（完全正确）≈ on the money（分毫不差，美式）；`[惯用]` "Your analysis was spot-on." 你的分析非常精准。`[记忆]` spot（点）+ on（在点上）→ 正中要害 → 完全正确 |

### ⚠️ 形近词 / 近义词辨析

| 词对 | 区别 |
|------|------|
| **flour** vs **flower** | flour = 面粉；flower = 花；同音异形 /flaʊər/ |
| **prophet** vs **profit** | prophet = 先知/预言家；profit = 利润；同音异形 ⚠️ 阅读/听力易混 |
| **afflict** vs **inflict** | afflict = 使受痛苦（be afflicted with）；inflict = 施加（痛苦/惩罚）给别人（inflict on） |
| **captive** vs **hostage** vs **prisoner** | captive = 俘虏/被俘的；hostage = 人质（勒索）；prisoner = 囚犯（监狱） |
| **reconcil** → **reconcile** | 原文拼写错误；reconcile = 使和解/调和（reconcile A with B） |
| **envisage** vs **imagine** vs **envision** | envisage = 设想（英式，后接 doing）；envision = 设想（美式）；imagine = 想象（通用） |
| **endorse** vs **support** vs **sponsor** | endorse = 支持/代言/背书；support = 支持（通用）；sponsor = 赞助（出钱） |
| **naturalization** vs **immigration** | naturalization = 入籍/归化；immigration = 移民（移入） |
| **anthropologist** vs **archaeologist** | anthropologist = 人类学家（研究人类社会）；archaeologist = 考古学家（研究遗迹） |
| **maternal** vs **paternal** | maternal = 母亲的/母系的（mater-）；paternal = 父亲的/父系的（pater-）⚠️ 反义成对 |
| **transmissiable** → **transmissible** | 原文拼写错误；transmissible = 可传播的（transmissible disease 传染病） |
| **fourfold** vs **quadruple** | fourfold = 四倍（adj./adv.，作定语/状语）；quadruple = 翻两番（动词/形容词） |
| **forester** vs **forestry** vs **ranger** | forester = 护林员；forestry = 林业（学科）；ranger = 公园管理员（美式） |
| **fournightly** → **fortnightly** | 原文拼写错误；fortnightly = 每两周一次的（fortnight = fourteen nights） |
| **breadth** vs **breath** vs **width** | breadth = 广度/宽度；breath = 呼吸（-ea-）；width = 宽度（具体尺寸）⚠️ 形近易混 |
| **meterologist** → **meteorologist** | 原文拼写错误；meteorologist = 气象学家（meteor- 气象，勿漏 -o-） |
| **skyrocket** vs **soar** vs **plummet** | skyrocket = 猛涨（火箭式）；soar = 飙升；plummet/plunge = 暴跌（反义） |
| **upscale** vs **upmarket** vs **high-end** | upscale = 高档的（美式）；upmarket = 高档的（英式）；high-end = 高端（通用） |
| **procreation** vs **reproduction** | procreation = 生育/繁衍（正式）；reproduction = 繁殖（通用） |

### 🎯 高频考点速记

| 考点 | 说明 |
|------|------|
| **be afflicted with/by** | 受…折磨，阅读高频被动结构；afflict（折磨）≠ inflict（施加） |
| **envisage doing sth** | 设想做某事，后接动名词不接 to do（英式） |
| **prophet / profit 同音词** | 先知 vs 利润，听力/阅读易混 |
| **endorse 一词多义** | 支持 / 代言 / （票据）背书；celebrity endorsement 名人代言 |
| **reconcile A with B** | 使…与…一致；reconcile work with family 兼顾工作与家庭 |
| **naturalization 入籍** | 政治/法律阅读；英式拼写 naturalisation |
| **maternal vs paternal** | 母系 vs 父系；maternal inheritance 母系遗传（遗传学阅读） |
| **transmissible disease** | 传染病（= communicable disease），医学阅读 |
| **increase fourfold 倍数表达** | 增至 4 倍；double/triple/quadruple/fourfold 数据类阅读高频 |
| **fortnightly 每两周** | fortnight = fourteen nights（英式），每两周一次 |
| **procreation 繁衍** | 生物/社会阅读：human procreation 人类繁衍 |
| **breadth and depth** | 广度与深度，议论文写作常用表达 |
| **the length and breadth of** | 遍及…各个角落，阅读中识别 |
| **soar / skyrocket / surge 上涨组** | 经济阅读高频上涨词；plummet/plunge 暴跌为反义 |
| **upscale vs upmarket 英美差异** | upscale（美式）/ upmarket（英式）= 高档的 |
| **run of the mill** | 熟词僻义：平平无奇的（mill 磨坊引申） |
| **forester / forestry 词族** | 护林员 / 林业 / 森林，环保类阅读常见 |
