# 📚 CET-6 单词本 (9)

> 排版：每条单词 2-4 行解析，按优先级排列：核心 → 搭配 → 辨析 → 词根/记忆
> 标注：`⚠️` = 易混点/重点 | **加粗** = 核心要点

## 一、地质与矿产

### 1. **ore** — 矿石，矿砂
**核心**：⚠️ 原文"砂石"不准确，应为**矿石**（含金属的岩石）
**搭配**：iron ore 铁矿石 / ore deposits 矿床 / rich ore 富矿
**辨析**：⚠️ ore（矿石，含金属的岩石）≠ mine（矿山/矿藏）≠ mineral（矿物，泛称）
**词根**：ore（古英语"未加工的金属"）；考点：iron ore 常与 coal, oil 并列出现

### 2. **seam** — 接缝；煤层；缝隙
**核心**：**接缝/缝隙**；煤层
**搭配**：a seam in the dress 裙子上的接缝 / a coal seam 煤层 / burst at the seams 胀破接缝（人满为患）；惯用 "The room was bursting at the seams." 房间挤得水泄不通
**辨析**：⚠️ seam（接缝，名词）≠ seem（似乎，动词）— 形近易混
**记忆**：衣服缝线 = seam；透过"缝"看 = seem

## 二、自然地貌

### 3. **gulf** — 海湾；鸿沟，巨大分歧
**核心**：⚠️ 熟词僻义：**海湾** + **鸿沟/巨大分歧**（a gulf between the rich and poor）
**搭配**：the Gulf of Mexico 墨西哥湾 / the Gulf War 海湾战争 / a widening gulf between A and B A 与 B 之间日益扩大的鸿沟
**辨析**：⚠️ gulf（大海湾/鸿沟）≠ bay（海湾，较小）≠ strait（海峡）
**词根**：源自希腊 kolpos（海湾）；同源 Gulf Stream 墨西哥湾暖流；记忆：海水"凹"进去 → 裂开一道"鸿沟"

### 4. **meadow** — 草地，牧场
**核心**：**草场**（供放牧/割草）
**搭配**：a flowery meadow 开满鲜花的草地 / meadow grassland 草甸草原
**辨析**：⚠️ meadow（草场，可放牧/割草）≠ pasture（牧场，专供放牧）≠ grassland（草原，泛指）≠ lawn（草坪，人工修剪）
**记忆**：meadow 谐音"麦多"→ 草地上草多得像麦子

## 三、动物与仿生

### 5. **beaver** — 海狸；（口语）勤奋工作的人 / beaver away 埋头苦干
**核心**：**海狸**；口语喻**勤奋工作者**
**搭配**：busy as a beaver 忙个不停 / beaver away at sth 埋头苦干做某事；惯用 "She beavered away all weekend on the report." 她整个周末埋头写报告
**辨析**：⚠️ beaver（海狸/勤快人）≠ otter（水獭）≠ muskrat（麝鼠）
**记忆**：海狸是动物界"劳模"，不停筑坝 → 引申"勤奋工作者"

### 6. **drone** — 无人机；雄蜂；嗡嗡声 / 嗡嗡作响
**核心**：**无人机**（科技类阅读高频）；原义雄蜂（只会嗡嗡飞）
**搭配**：a military drone 军用无人机 / drone strikes 无人机空袭 / drone on about sth 絮叨某事
**辨析**：⚠️ drone（无人机/嗡嗡声）≈ buzz（嗡嗡，更常用）≠ hum（低鸣/哼唱）≠ murmur（低语）
**记忆**：雄蜂 drone 只会"嗡嗡"飞 → 无人机也"嗡嗡"飞；考点：drone delivery 无人机配送 / drone photography 航拍

## 四、冲击与起伏

### 7. **lash** — 睫毛；鞭子 / 抽打；抨击
**核心**：一词多义：**睫毛** / **鞭子** / 抽打、抨击
**搭配**：eyelash 睫毛 / a lash of rain 一阵急雨 / lash out at 猛烈抨击；惯用 "She lashed out at the government's policy." 她猛烈抨击政府的政策
**辨析**：⚠️ lash（抽打/抨击）≈ whip（鞭打）≈ flog（鞭笞，正式）；lash out（怒斥）为固定短语
**记忆**：睫毛 eyelash 像眼睑上挂着的一束束小"鞭子"

### 8. **ebb** — 退潮 / 退潮；衰退
**核心**：**退潮**；引申**衰退**（渐进减弱）
**搭配**：ebb and flow 潮起潮落/起伏 / at a low ebb 处于低谷 / the ebb of life 生命的衰退
**辨析**：⚠️ ebb（退潮/衰退，渐进减弱）≠ wane（月亏/势力衰微）≠ recede（后退，水退/发际线）
**记忆**：ebb 像潮水"一退再退" → 退潮；经济/情绪类阅读：at a low ebb 处于低谷期

### 9. **the ebb tide** — 退潮（期）
**核心**：**退潮**
**搭配**：the ebb and flow of the tide 潮水的涨落 / against the ebb tide 逆着退潮
**辨析**：⚠️ ebb tide（退潮）≠ flood tide（涨潮）
**记忆**：ebb（退）+ tide（潮）；与 flood tide（涨潮）成对记忆

## 五、身体与医学

### 10. **appendix** — 附录；阑尾
**核心**：一词两义：**附录**（写作引用 see the appendix）/ **阑尾**（医学）
**搭配**：see appendix 见附录 / appendix A 附录 A / a burst appendix 阑尾穿孔
**辨析**：⚠️ appendix（附录/阑尾）≠ attachment（邮件附件）≠ supplement（增刊/补充）
**词根**：ap-/ad-（向，靠近）+ pend-（悬挂）+ -ix → 悬挂在主体后面的东西；同根 append 附加, pendant 吊坠, depend 依赖

### 11. **anatomy** — 解剖学；身体构造；剖析
**核心**：⚠️ 原文"解刨学"为错别字，正确为**解剖学**
**搭配**：human anatomy 人体解剖学 / the anatomy of a crisis 对危机的剖析
**辨析**：⚠️ anatomy（解剖学/构造，学科）≠ dissection（解剖，具体动作）≈ structure（结构）
**词根**：ana-（向上，分开）+ tom-（切）+ -y → 切开研究；同根 atom 原子, tome 大部头书

### 12. **corrode** — 腐蚀，侵蚀
**核心**：⚠️ 原文"侵蚀的"为形容词义，corrode 是**动词**"腐蚀"
**搭配**：corrode metal 腐蚀金属 / acid corrodes iron 酸腐蚀铁 / corroded pipes 被腐蚀的管道
**辨析**：⚠️ corrode（化学腐蚀）≠ erode（风/水冲刷侵蚀，更常用）≈ rust（生锈，特指铁）
**词根**：cor-（加强）+ rod-（啃咬）+ -e → 一点一点"啃掉"；同根 erode 侵蚀, rodent 啮齿动物

## 六、人物与职业

### 13. **spokesperson** — 发言人，代言人
**核心**：⚠️ 原文拼写 spokeserson 有误，正确为 **spokesperson**"发言人"
**搭配**：a government spokesperson 政府发言人 / a company spokesperson 公司代言人
**辨析**：⚠️ spokesperson（中性，最规范）≠ spokesman（男发言人）≠ spokeswoman（女发言人）≠ representative（代表，泛指）
**词根**：spoke + s + person → 替别人说话的人；惯用 "A spokesperson for the company declined to comment." 公司发言人拒绝置评

### 14. **retiree** — 退休人员
**核心**：**退休者**（指人；社会类阅读：aging population / retirees 老龄化高频）
**搭配**：a retired teacher 退休教师 / retirement age 退休年龄 / a retiree's pension 退休金
**辨析**：⚠️ retiree（退休者，指人）≠ retired（退休的，指状态）— 词性不同
**词根**：re-（回）+ tir-（拉）+ -ee（被…的人）→ 被"拉回"工作岗位之外；同根 retire, retirement

### 15. **wholesaler** — 批发商
**核心**：**批发商**（整批出售）
**搭配**：a wholesale market 批发市场 / wholesale price 批发价 / buy wholesale 整批购买
**辨析**：⚠️ wholesaler（批发商）≠ retailer（零售商）≠ vendor（小贩/供应商）
**词根**：whole（整个）+ sale（卖）+ -er → 整批出售的人；记忆：retail = re-（再）+ tail（切）→ 拆开零卖；考点：wholesale vs retail 成对出现

### 16. **laureate** — 获奖者；桂冠诗人
**核心**：⚠️ 原文拼写 laurate 有误，正确为 **laureate**"获奖者/桂冠诗人"
**搭配**：a Nobel laureate 诺贝尔奖得主 / Poet Laureate 桂冠诗人
**辨析**：⚠️ laureate（桂冠荣誉获奖者）≠ winner（通用获胜者）≠ prizewinner（得奖者）
**词根**：laur- = 月桂 + -ate → 头戴月桂冠的人；同根 laurel 月桂/桂冠；记忆：古希腊给胜利者戴月桂冠

## 七、自我中心

### 17. **self-centered** — 以自我为中心的，自私的
**核心**：**以自我为中心**（偏中性描述）
**搭配**：a self-centered person 以自我为中心的人 / self-centered behavior 自私的行为；惯用 "He's too self-centered to care about others." 他太以自我为中心，不关心别人
**辨析**：⚠️ self-centered（自我中心，中性）≈ selfish（自私，贬义更强）≠ selfless（无私，反义）
**词根**：self（自己）+ center（中心）+ -ed → 自己是世界的中心

### 18. **self-interest** — 自身利益，私利
**核心**：⚠️ 原文"自私自利的"为形容词义，self-interest 是**名词**"自身利益"
**搭配**：act out of self-interest 出于私利行事 / in one's own self-interest 符合自身利益 / enlightened self-interest 开明的利己主义
**辨析**：⚠️ self-interest（自身利益，中性名词）≠ selfishness（自私，贬义）
**词根**：self + interest → 自己的利益；同根 selfish 自私的, selfless 无私的

## 八、神态与歪斜

### 19. **wistful** — 惆怅的，渴望的，若有所思的
**核心**：⚠️ 原文"悲伤的"过重，wistful 是**惆怅中带渴望**（向往而不得）
**搭配**：a wistful smile 惆怅的微笑 / wistful eyes 渴望的眼神 / feel wistful about 对…感到惆怅
**辨析**：⚠️ wistful（惆怅渴望）≠ nostalgic（怀旧，怀念过去）≠ melancholy（忧郁，更沉重）≠ sad（悲伤，最通用）
**词根**：源自 wish（愿望）+ -ful → 充满渴望的；惯用 "She gave a wistful look at the old photo." 她惆怅地看着老照片

### 20. **lopsided** — 倾斜的，不对称的，一边倒的
**核心**：**一边歪/不对称**；比分"一边倒"
**搭配**：a lopsided smile 歪嘴笑 / a lopsided victory 一边倒的胜利 / a lopsided score 悬殊的比分
**辨析**：⚠️ lopsided（不对称/一边倒）≈ unbalanced（不平衡）≠ uneven（不平坦/参差）
**词根**：lop（耷拉）+ side（边）+ -ed → 一边耷拉下来；惯用 "The final score was lopsided: 5–0." 最终比分一边倒：5 比 0

### 21. **a lopsided mouth** — 撇嘴，歪嘴
**核心**：**歪嘴/撇嘴**（不对称的嘴型）
**搭配**：with a lopsided mouth 歪着嘴 / a lopsided grin 歪嘴咧嘴笑
**辨析**：⚠️ a lopsided mouth（撇嘴，不对称嘴型）≠ a pursed mouth（抿嘴，紧闭嘴唇）≠ a pout（撅嘴，不高兴）
**记忆**：lopsided（歪的）+ mouth（嘴）

## 九、潦草难辨

### 22. **crabbed** — 潦草的，难辨认的；（脾气）暴躁的
**核心**：**字迹潦草难辨**；（脾气）暴躁的
**搭配**：crabbed handwriting 潦草的字迹 / a crabbed old man 脾气古怪的老头 / crabbed style 晦涩的文风
**辨析**：⚠️ crabbed（潦草/脾气坏）≈ illegible（难以辨认）≠ crabby（暴躁，口语）≠ scribbled（乱涂）
**词根**：源自 crab（螃蟹）→ 像螃蟹一样横行/古怪；记忆：字迹像螃蟹爬的 → 潦草难认

### 23. **crabbed handwriting** — 潦草的字迹
**核心**：**潦草难辨的字迹**（阅读中 crabbed 常修饰 handwriting）
**搭配**：illegible crabbed handwriting 难以辨认的潦草字迹
**辨析**：⚠️ crabbed handwriting（潦草难辨）≈ scribble（乱写乱画）≠ cursive handwriting（连笔书法，正规书写体）
**记忆**：像螃蟹（crab）爬出来的字

## 十、收养与哲学

### 24. **adoptive** — 收养的，有收养关系的
**核心**：⚠️ 易错点：adoptive 修饰**收养方**（adoptive parents 养父母），adopted 修饰**被收养方**（adopted child）
**搭配**：adoptive parents 养父母 / an adoptive family 收养家庭
**辨析**：⚠️ adoptive（收养方：父母/家庭）≠ adopted（被收养方：孩子）— 语法易错点
**词根**：ad-（向）+ opt-（选择）+ -ive → 主动"选择"孩子的；同根 adopt 收养/采纳, adoption, option 选择

### 25. **metaphysical** — 形而上学的，玄学的；抽象的
**核心**：**形而上学的**（哲学，超越自然/物理）
**搭配**：metaphysical questions 形而上学问题 / metaphysical poetry 玄学派诗歌
**辨析**：⚠️ metaphysical（形而上学）≠ metaphorical（隐喻的）— 形近易混
**词根**：meta-（超越）+ phys-（自然）+ -ical → 超越自然的学问；同根 physics 物理学, physical 物理的, metaphysics；记忆：亚里士多德著作排在《物理学》之后而得名

## 十一、推理与深度

### 26. **reasoning** — 推理，论证，推论
**核心**：**推理/论证过程**（阅读/写作高频）
**搭配**：logical reasoning 逻辑推理 / a flaw in the reasoning 推理中的漏洞 / deductive reasoning 演绎推理
**辨析**：⚠️ reasoning（推理过程）≠ reason（理由，名词）≠ rationale（基本原理）≠ rational（理性的，形容词）
**词根**：reason（理性）+ -ing；同根 reasonable 合理的, unreasonable 不合理的；考点：the reasoning behind sth 某事背后的逻辑

### 27. **a line of reasoning** — 推理思路，论证线索
**核心**：⚠️ 原文"解决问题的方法"不准确，应为**推理思路/论证线索**
**搭配**：follow a line of reasoning 沿着一条推理思路 / a flawed line of reasoning 有缺陷的推理
**惯用**："I can't follow your line of reasoning." 我跟不上你的推理思路。
**记忆**：line（线索）+ reasoning（推理）→ 一条推理的"线"

### 28. **in-depth** — 深入的，彻底的，全面的
**核心**：⚠️ 原文"完全的，深的"不准确，in-depth 是**深入全面**的（新闻/学术高频）
**搭配**：an in-depth interview 深度访谈 / in-depth research 深入研究 / an in-depth report 深度报道
**辨析**：⚠️ in-depth（深入系统）≠ deep（深，最通用）≠ thorough（彻底，强调细致）
**词根**：in-（进入）+ depth（深度）→ 深入内部；同根 depth 深度, deep 深的, deepen 加深；惯用 "The newspaper ran an in-depth analysis of the crisis." 报纸对危机做了深度分析

### 29. **an in-depth analysis** — 深度分析
**核心**：**深入全面的分析**
**搭配**：conduct an in-depth analysis 进行深度分析 / an in-depth analysis of the market 对市场的深度分析
**辨析**：⚠️ an in-depth analysis（深入全面）≈ a thorough analysis（彻底）≠ a superficial analysis（肤浅，反义）
**记忆**：in-depth（深入的）+ analysis（分析）

## 十二、价廉与叛乱

### 30. **dirt cheap** — 非常便宜的，贱价的
**核心**：**极其便宜**（口语）
**搭配**：dirt-cheap prices 超低价格 / buy sth dirt cheap 以极低价买到某物；惯用 "I got this jacket dirt cheap at the flea market." 我在跳蚤市场超低价买到这件夹克
**辨析**：⚠️ dirt cheap（极便宜）≈ a bargain（划算）≠ dirt poor（一贫如洗）— 形近易混
**记忆**：比泥土还便宜 → dirt cheap；对比 dirt poor（穷得叮当响）

### 31. **sedition** — 煽动叛乱的言论/行为
**核心**：**煽动叛乱**（针对政府，言论层面）
**搭配**：charges of sedition 煽动叛乱罪 / seditious speech 煽动性言论
**辨析**：⚠️ sedition（煽动叛乱，言论）≠ treason（叛国投敌，罪更重）≠ rebellion（武装叛乱，行为层面）
**词根**：se-（分开）+ it-（走）+ -ion → 蛊惑人心"走"向分裂；同根 seditious 煽动性的, itinerary 旅程, circuit 环行

## 十三、机缘巧合

### 32. **quirk** — 怪癖；怪事；偶然的巧合
**核心**：**怪癖/怪事**；机缘巧合（中性偏趣）
**搭配**：a quirk of human nature 人性的怪癖 / a personality quirk 性格怪癖 / by a quirk of fate 因命运的捉弄
**辨析**：⚠️ quirk（怪癖，中性偏趣）≈ eccentricity（古怪行为，偏学术）≠ oddity（古怪的事物）≠ habit（习惯，中性）
**记忆**：quirk 谐音"缺壳"→ 怪人缺"外壳" → 有怪癖；惯用 "By a quirk of fate, we ended up in the same class." 机缘巧合，我们进了同一个班

### 33. **a quirk of fate** — 机缘巧合，命运的捉弄
**核心**：**机缘巧合**（命运的捉弄）
**搭配**：by a quirk of fate 出于机缘巧合 / through a quirk of fate 因命运的安排
**惯用**："By a quirk of fate, we were seated next to each other." 机缘巧合，我们被安排坐在了一起。
**记忆**：quirk（怪事）+ fate（命运）→ 命运开的"小玩笑"

## ⚠️ 形近词 / 近义词辨析（含场景偏好）

| 词对 | 区别（含使用场景偏好） |
|------|------|
| **spokesperson** vs **spokesman/spokeswoman** | spokesperson = 发言人（中性通用）；spokesman/spokeswoman 区分性别；⚠️ 原文拼写 spokeserson 有误 |
| **seam** vs **seem** | seam = 接缝（名词）；seem = 似乎（动词）；形近易混 |
| **laureate** vs **winner** | laureate = 桂冠获奖者（Nobel laureate）；winner = 通用获胜者；⚠️ 原文拼写 laurate 有误 |
| **gulf** vs **bay** vs **strait** | gulf = 大海湾/鸿沟；bay = 小海湾；strait = 海峡 |
| **meadow** vs **pasture** vs **lawn** | meadow = 草场（可割草/放牧）；pasture = 牧场（专供放牧）；lawn = 人工草坪 |
| **ebb** vs **wane** vs **recede** | ebb = 退潮/衰退；wane = 月亏/减弱（wax and wane）；recede = 后退（水/发际线） |
| **corrode** vs **erode** | corrode = 化学腐蚀；erode = 风/水冲刷侵蚀（更常用） |
| **appendix** vs **attachment** | appendix = 书末附录/阑尾；attachment = 邮件附件 |
| **anatomy** vs **dissection** | anatomy = 解剖学（学科）；dissection = 解剖（动作）；⚠️ 原文"解刨"为错别字 |
| **crabbed** vs **illegible** | crabbed = 潦草难辨（字）+ 脾气坏；illegible = 难以辨认的（通用） |
| **adoptive** vs **adopted** | ⚠️ adoptive = 收养方（adoptive parents 养父母）；adopted = 被收养方（adopted child 养子女） |

| **self-interest** vs **selfishness** | self-interest = 自身利益（中性名词）；selfishness = 自私（贬义） |
| **wistful** vs **nostalgic** | wistful = 惆怅渴望（向往而不得）；nostalgic = 怀旧的（怀念过去） |
| **lopsided** vs **uneven** | lopsided = 不对称/一边倒；uneven = 不平坦/参差 |
| **sedition** vs **treason** | sedition = 煽动叛乱（言论）；treason = 叛国（行为，罪更重） |
| **wholesaler** vs **retailer** | wholesaler = 批发商（整批）；retailer = 零售商（零卖） |
| **in-depth** vs **thorough** | in-depth = 深入的；thorough = 彻底的（强调细致） |
| **dirt cheap** vs **dirt poor** | dirt cheap = 极其便宜；dirt poor = 一贫如洗；形近易混 |

## 🎯 高频考点速记

| 考点 | 说明 |
|------|------|
| **拼写修正** | spokeserson→spokesperson；laurate→laureate；解刨学→解剖学；"代办事物"→待办事项 |
| **adoptive vs adopted** | adoptive 修饰收养方（adoptive parents 养父母）；adopted 修饰被收养方（adopted child）；语法易错点 |
| **metaphysical vs metaphorical** | 形近词：形而上学的（哲学）vs 隐喻的（修辞） |
| **gulf 熟词僻义** | 海湾 → 鸿沟/巨大分歧（a gulf between the rich and poor） |
| **ebb 系列** | ebb and flow 潮起潮落 / at a low ebb 处于低谷，经济与情绪类阅读高频 |
| **wholesale vs retail** | 批发 vs 零售，经济类阅读成对出现 |
| **appendix 双义** | 附录（写作引用 see the appendix）/ 阑尾（医学） |
| **Nobel laureate** | 诺奖得主，新闻/科普阅读高频 |
| **self-interest vs selfish** | self-interest 名词"自身利益"；selfish 形容词"自私的"，注意词性 |
| **dirt cheap / dirt poor** | 口语习语：极其便宜 / 一贫如洗 |
