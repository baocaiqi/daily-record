## 三、阶段一：打地基（4-6 周）

### 地基 = 三根柱子

1. **数学直觉**：线代、概率、微积分在 DL 里的实际用途（梯度、矩阵求导、期望/方差）
2. **核心机制**：反向传播、优化器、初始化、正则化、归一化——每个都要能回答"为什么这样设计"
3. **从零实现**：不靠框架写出前向/反向传播，用数值梯度验证正确性

### 周计划

| 周次 | 任务 | 产出 |
|---|---|---|
| 第 1 周 | 用 numpy 从零写 MLP（前向+反向+训练，不用 PyTorch） | 可运行的 mlp_numpy.py |
| 第 2 周 | 手推两层网络反向传播（标量→向量形式）；写**梯度检查** | 推导笔记 + gradient_check.py |
| 第 3 周 | 优化器对比实验：SGD / Momentum / Adam / 学习率调度 | 收敛曲线对比图 |
| 第 4 周 | 正则化+初始化+归一化实验：L2 / Dropout / BatchNorm / Xavier | 过拟合 vs 缓解对比图 |
| 第 5-6 周 | 从零实现 CNN；精读 5 篇地基论文 | cnn_numpy.py + 论文笔记 |

### 地基论文精读清单（配李沐《论文精读》视频）

1. Backprop（LeCun 89）——反向传播的起源
2. AlexNet（NIPS 2012）——深度学习的引爆点
3. BatchNorm（ICML 2015）——归一化的力量
4. ResNet（CVPR 2016）——残差连接解决退化
5. Attention Is All You Need（NIPS 2017）——Transformer

### 自测标准（5 问，答得出才算过关）

1. 能否徒手写出两层网络的反向传播（含矩阵形式）？
2. 能否讲清 Adam 的"动量 + 自适应学习率"各解决什么问题，及与 RMSProp 的区别？
3. 能否给出 BatchNorm 有效的两种解释（内部协变量偏移 vs 平滑损失面），并说清哪个更有说服力？
4. 能否用数学解释梯度消失的成因，以及 ResNet / LSTM / 归一化各自的缓解原理？
5. 能否不看框架 API，用 numpy 写 softmax + cross-entropy 及其梯度？

## 六、build-your-own-x 使用方法（重要）

### 它是什么

**不是工具/软件，而是一份"教程索引"**：一个 README 文件里按主题分类整理了 30+ 类技术、每类若干篇外部教程链接（GitHub 仓库、博客、视频）。

### 怎么用（4 步）

```bash
cd ~/github/build-your-own-x
# 1. 打开 README.md，按目录找主题分类
#    例如：AI Model / Database / Git / Operating System / Web Server ...
grep "Build your own" README.md | head -20   # 快速看有哪些主题

# 2. 找到感兴趣条目，复制链接（教程在外部，不在本仓库）
#    例如 "Build your own Neural Network" → https://...（GitHub 仓库/博客）

# 3. 在本地建一个练习目录，跟着教程一步步写代码
mkdir -p ~/projects/build-own && cd ~/projects/build-own

# 4. 用自己的语言重写，跑通、改改、加注释 → 写进 GitHub 个人仓库
```

### 关键提醒

- **本仓库只有链接索引，没有教程正文**——克隆下来的 320KB 就是一个 README
- 挑选标准：看语言（Python 优先）+ 看口碑（README 里列的都是精选）
- 用法精髓：**照着教程从零实现一遍**，别只"看"——费曼名言 "What I cannot create, I do not understand"
- 配合学习：第 1-2 周手写 MLP、第 5-6 周手写 CNN 时，可参考其中 Neural Network 类教程（不要照抄）
- CV 阶段选项目：分类里的 "Visual Recognition System"（从零做人脸识别）、"3D Renderer"（图形学，对 3D CV/NeRF 有用，后期再看）
