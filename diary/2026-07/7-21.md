### 今日知识点+总结

**今日状态**

- 今天的效率不是很高，写 dp 的时候卡了很久，对一些没见过的 dp 题型不会更好的变通

**AI 工具：Skill 配置**

- 正文部分尽可能精简（写清楚脚本的参数、用途），具体执行放在脚本（最好提供 -h，显示详尽的用法说明，若出现异常，写明原因）
- 参考文档作为附属资源，可以更加节省 token
- Skill 是三段渐进式加载的：
  1. 元数据加载：让 agent 识别、规划所有可用技能
  2. 执行壳加载：代码进入内存
  3. 运行资源完备加载：如本地重资源

**AI 工具：常用命令**

- /goal <condition>、/goal clear、/goal active、hook 等命令：goal 是用户设定命令，在模型交付大任务前会确认是否完成，没有完成会继续任务；若用户设立的任务不可能完成，用 impossible 兜底
- sub agent 的上下文管理：一般 model 会自己开 sub agent，用户也可以手动开；sub agent 是完全空白的 message 数组，不会依托父 agent
- 若需要父 agent 的上下文，可以 fork agent；对于 fork agent 的请求是完全命中主对话建立好的 cache，不会很消耗 token
- /btw <question>：不中断模型的同时提出问题
- allowed-tools 指定跳过操作的确认（如 Bash(git *)：所有对 git 的操作不需要用户确认）
- disable-model-inovation 禁止 model 自行触发的 skill，只能手动 /name 启动

**深度学习：集成学习的主要流派**

- voting：soft voting、hard voting
- soft voting 权重的三种计算方法：手动归一、网格搜索、堆叠（让模型学出权重）
- bagging：有放回抽样 bootstrap，并行训练
- adaboost：串行训练，调整样本权重
- gradient boosting：拟合前序树的残差
- svm 以及 RBF
