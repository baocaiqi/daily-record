### 今日知识点+总结

```

bootstrap vs 卡特蒙洛cv: 
正态近似（平滑）：平均准确率+-波动幅度（t分布代替近似分布，算出的区间会更加宽一点）*标准差
分位数在计算严重偏斜的数据时更加准确，而正态近似可能有荒谬的结果
单棵树的悲观偏差通过森林中树的增加而平均掉了
OOB bootstrap 的数据同源带来的乐观偏差是微弱的
单次留出法明显悲观，而k-fold,OOB bootstrap 几乎无偏
由于OOB bootstrap 没有独立测试集且使用同源数据测试，会过度乐观
632 bootstrap 通过把训练集的悲观和测试机的乐观通过加权中和，更为准确（适用于小数据，简单模型，在复杂模型会严重乐观）
632 + bootstrap 根据模型的真实拟合程度动态调整权重
引入R相对拟合率（越大拟合越严重）： w=0.632/(1-0.368*R) 
632+ bootstrap 是深度学习，决策树的首选
泛化性能评估：
数据大：2-way留出法，用正态近似算出置信区间
数据小：llo(leave one out每次只留一个当验证集，用剩下的N-1个样本重复训练N次，高方差，计算量大)，632+bootstrap
选模型或者调参：
数据大：3-way 留出
数据小： k-fold,没有独立测试集


```
