## 一、集成学习与树模型

### 2026-07-21 集成学习的主要流派

- **Voting**：soft voting、hard voting
  - soft voting 权重的三种计算方法：手动归一、网格搜索、堆叠（让模型学出权重）
- **Bagging**：有放回抽样（bootstrap），并行训练
- **AdaBoost**：串行训练，调整样本权重
- **Gradient Boosting**：拟合前序树的残差
- **SVM** 以及 RBF 核

### 2026-07-22 XGBoost 与 LightGBM

- XGBoost、LightGBM 两种模型的优势与正则化：
  - **XGBoost**（精度高，工业界和各类竞赛都较为常用）：
    1. 显式正则化项：在目标函数中直接加入正则项控制模型复杂度（L1 叶子节点正则、L2 叶子权重正则）
    2. 随机列抽样：只考虑部分特征，降低方差、加快速度
    3. 缺失值自动处理
    4. 预排序 + 分位数近似
  - **LightGBM**：
    1. 直方图算法：将连续特征离散为固定数量的桶，内存和计算量大幅下降
    2. leaf-wise 生长策略：每次选叶子分裂中增益最大的一个进行生长
    3. 高效并行
    4. 正则化：在 XGBoost 基础上增加了最大深度限制、最小数据量限制
- LightGBM 如何做到速度提升几十倍而精度不降？
  - **GOSS（基于梯度的单边采样）**：保留梯度（反映该样本在当前模型下的"被关注程度"）绝对值大的样本，对梯度小的样本按照一定比例随机采样——训练数据大幅减少，但不漏掉重要样本
  - **EFB（互斥特征捆绑）**：将互斥的稀疏特征绑在一起，提高计算效率

### 2026-07-23 集成学习的应用与调参

- 集成学习几个模型的应用和调参：随机森林工业界更广泛，Gradient Boosting 更偏竞赛
- 集成模型的方差主要取决于单棵树的方差与树与树之间的相关系数（集成方差 ≈ 平均相关系数 × 单棵树方差）
- 纯 bagging 时树间相关系数趋于 1，方差降低的增益较小；在每个特征分裂点引入随机特征子集，能有效降低相关系数
- 一般分类问题，`max_features` = 总特征数开根；回归则取 1/3 左右

### 2026-07-23 随机森林

- 随机森林的标准：bagging + 特征子集。森林欠拟合则增加特征子集大小，反之减小
- 标准随机森林是同质模型，默认用硬投票（同质树输出的概率是极不稳定的噪声、方差极大，因为叶子节点样本量较少），若强行对概率平均反而拉低精度
- XGBoost 默认采用累加分数形式，本质上属于软投票
- 随机森林泛化能力上界（Breiman）可解释这一点：泛化误差 ≤ (平均相关系数 × (1 − 单棵树强度的平方)) / 单棵树强度的平方，其中"强度"（strength）指单棵树的分类间隔（margin）期望，可粗略理解为单棵树准确率

### 2026-07-29 树模型复习（ID3 → C4.5 → CART）

| 维度 | ID3 | C4.5 | CART |
|------|-----|------|------|
| 结构 | 多叉树 | 多叉树 | 二叉树 |
| 特征选择 | 信息增益 | 信息增益率 | 基尼系数 / MSE |
| 处理连续值 | 否 | 是（离散化） | 是（二分） |
| 处理缺失值 | 否 | 是 | 是 |
| 剪枝策略 | 否 | 是（悲观剪枝） | 是（代价复杂度剪枝） |
| 主要用途 | 分类 | 分类 | 分类 / 回归 |

### 2026-07-29 树模型的正则化（惩罚树的物理结构）

- 惩罚叶子数量：叶子节点样本太少的直接不要
- 惩罚叶子输出值：输出差距不要太大，保持平滑
- 惩罚弱叶子：树很小、对结果无太大贡献的归 0

### 2026-07-30 复习：C4.5

- C4.5：信息增益率，处理连续值，引入悲观剪枝，但已被 CART 取代

## 二、模型评估与验证

### 2026-07-24 模型评估：偏差与方差

- 高方差即模型预测不稳定，是过拟合的表现；高偏差即是欠拟合的表现
- 一般应对过拟合，可以通过加大数据集来改善，强迫模型学习共性而不是死记硬背

### 2026-07-24 数据泄漏问题

- 归一化、缺失值填充等所有预处理必须在数据切分（留出法、交叉验证等）之后，且在训练集上完成拟合，再应用到验证/测试集上

### 2026-07-24 整体误差与偏差-方差的关系

- 随着模型复杂度增加，总误差呈"先降后升"的 U 型趋势（前期偏差下降主导，后期方差上升主导）
- 其数学根源在于：整体误差 = 偏差的平方 + 方差（推导中交叉项为 0）

### 2026-07-26 0-1 损失与偏差-方差

- 0-1 损失：主预测（聚合预测）取众数（硬投票），本质上衡量的是误分类率（即 1 − 准确率）
- 在 0-1 损失下（Domingos 分解），总损失可表达为 Loss = Bias − Variance（忽略噪声项）
- 其核心内涵是：当主流意见（众数）错误时，适当增大基学习器之间的分歧（方差）可以使部分预测"蒙对"，从而降低整体的误分类率

### 2026-07-26 统计偏差 vs 归纳偏置

- 需要严格区分"统计偏差"与"归纳偏置"
- 在通常的机器学习语境（如偏差-方差分解）中，"偏差"一般特指统计偏差（即平均预测值偏离真实值的程度）
- 归纳偏置是算法自身携带的"先验偏好"，例如决策树算法在训练数据能被小树和大树同时完美分类时，会优先选择更简单的小树（遵循奥卡姆剃刀原则：如无必要，勿增实体）
- 归纳偏置过强会限制模型的表达能力，导致模型过于死板（容易导致高统计偏差/欠拟合）

### 2026-07-26 公平性偏见

- 指模型在决策时，因个体的固有或后天属性（如种族、性别等），而产生系统性的不公平、歧视或偏见
- 主要源于：历史数据本身带有的偏见（社会偏见）；数据收集与预处理过程引入的偏见（如采样偏差、报告偏差）；以及模型设计/优化目标不当而放大的偏见

### 2026-07-26 置信区间与模型评估

- 置信区间：用同样的方法重复抽样并构建区间，会有约 95%（依置信水平而定）的区间覆盖真实的模型性能（真实值是固定的，区间是波动的）
- 通过重采样（如 K-Fold 交叉验证、Bootstrap 自助法）可以估计出置信区间。区间越窄，说明模型评估结果越稳定（低方差），模型越稳健
- 重复留出法：随机切分很多次，取多次评估指标的平均值，以降低单次留出法的评估方差

### 2026-07-26 模型选择 / 算法选择

- 在决策树与逻辑回归之间做选择时，可用交叉验证（CV）对比它们的平均表现（这属于模型选择）
- 在 XGBoost 与 SVM 等不同流派的算法之间做抉择时，同样可以用交叉验证（CV）来辅助决策（这属于算法选择）

### 2026-07-27 留出法 vs K-Fold CV

- 在留出法中，会因训练集过少（通常仅占 70% 左右）而导致悲观偏差（即训练数据代表性不足，系统性低估了模型的真实泛化能力）
- 而通过更改多次随机种子、取平均值的方式（即重复留出法），可以降低评估方差（减小单次切分带来的"手抖"），但无法完全根治悲观偏差（根治需靠增加单次训练集的比例，如使用 K-Fold）
- 更优解是使用 K-Fold CV（预定义轮换，每次用 K−1 折训练，比例更大，如 5 折用 80%，数据利用率更高，能有效缓解悲观偏差）

### 2026-07-27 蒙特卡洛 CV（重复留出法）

- 相较于 K-Fold CV（固定轮换），重复留出法（蒙特卡洛 CV）是完全随机切分（每次独立重采样，允许同一份样本出现在不同测试集中，重叠率不固定）

### 2026-07-27 关键角色区分

- K-Fold CV 一般用于模型选择与超参数调优（因其无偏性更好，公平对比不同模型）
- 蒙特卡洛 CV（重复留出法）更常用于评估模型稳定性与计算经验置信区间（通过大量随机模拟来估计预测分数的波动范围）

### 2026-07-27 标准误差与置信区间

- 标准误差 SE（Standard Error）= √(准确率 × (1 − 准确率) / 样本数)（衡量由随机抽样导致的单次评估结果与真实期望之间的平均偏差）
- 使用正态近似计算置信区间（理论依据为中心极限定理 CLT：当测试样本量 n 足够大时，二项分布会逼近正态分布）：
  - 置信区间计算公式：准确率 ± z（正态分布分位数，如 95% 对应 1.96）× SE
  - 但此法极其脆弱（严重依赖大样本假设），在小数据集（n < 100）或准确率极端（接近 0% 或 100%）时，置信区间可能超出 [0, 1] 的物理边界而失效

### 2026-07-28 Bootstrap vs 蒙特卡洛 CV

- 正态近似（平滑）：平均准确率 ± 波动幅度（用 t 分布代替近似分布，算出的区间会更宽一点）× 标准差
- 分位数在计算严重偏斜的数据时更加准确，而正态近似可能有荒谬的结果

### 2026-07-28 偏差分析

- 单棵树的悲观偏差通过森林中树的增加而平均掉了
- OOB bootstrap 的数据同源带来的乐观偏差是微弱的
- 单次留出法明显悲观，而 K-Fold、OOB bootstrap 几乎无偏
- 由于 OOB bootstrap 没有独立测试集且使用同源数据测试，会过度乐观

### 2026-07-28 632 bootstrap 与 632+ bootstrap

- 632 bootstrap 通过把训练集的悲观和测试集的乐观加权中和，更为准确（适用于小数据、简单模型，在复杂模型会严重乐观）
- 632+ bootstrap 根据模型的真实拟合程度动态调整权重
- 引入 R 相对拟合率（越大拟合越严重）：w = 0.632 / (1 − 0.368 × R)
- 632+ bootstrap 是深度学习、决策树的首选

### 2026-07-28 泛化性能评估 / 选模型调参

- 泛化性能评估：
  - 数据大：2-way 留出法，用正态近似算出置信区间
  - 数据小：LOO（leave-one-out，每次只留一个当验证集，用剩下的 N−1 个样本重复训练 N 次，高方差、计算量大）、632+ bootstrap
- 选模型或调参：
  - 数据大：3-way 留出
  - 数据小：K-Fold，没有独立测试集

### 2026-07-29 K-Fold 交叉验证

- K-Fold 权衡方差和偏差，较为合适的 k 为 5、10

## 三、统计检验与模型比较

### 2026-07-31 分类器性能比较的统计检验（重点：McNemar 检验）

比较两个分类器在相同测试集上的性能，不能只看准确率高低，还要看差异是否具有统计学意义。常用方法：

1. **McNemar 检验** — 衡量两个分类器在相同测试集上的性能差异
   - 构造 2×2 列联表：

     |            | B correct | B wrong |
     |------------|-----------|---------|
     | A correct  | a         | b       |
     | A wrong    | c         | d       |

     - a：两个模型都预测正确的样本数
     - b：Model A 正确、Model B 错误的样本数
     - c：Model A 错误、Model B 正确的样本数
     - d：两个模型都预测错误的样本数

   - 卡方值计算公式（含连续性校正，提高小样本情况下的准确性）：

     **χ² = (|b−c|−1)² / (b+c)**

   - 卡方值：衡量实际观测数据与理论期望数据之间的差异程度

2. **Cochran's Q 检验** — 检验多个分类器之间的显著差异（McNemar 检验的多分类器推广）
3. **5×2 CV F 检验** — 更可靠的算法差异检测方法：结合五次二折交叉验证（数据集被分成两个子集，每个子集轮流作为测试集，重复五次）

### 2026-07-31 p 值 / 卡方值 / 自由度

- **p 值**：在原假设成立的前提下，出现当前样本结果以及更极端结果的概率。p 越小，说明该结果越不可能是偶然发生的
- p 值 < 显著性水平（α）→ 拒绝原假设，认为结果具有统计学意义（不是偶然）
- p 值 ≥ 显著性水平（α）→ 不拒绝原假设，认为结果不具有统计学意义（可能是偶然）
- 卡方值和 p 值密切相关：**卡方值越大，p 越小**
- **自由度**：统计计算中能够自由取值的变量个数 = 样本数量 − 约束条件数量；在卡方检验中，自由度决定卡方分布的形状，从而影响 p 值的计算

### 2026-08-02 多重假设检验（Multiple Hypothesis Testing）

- 显著性水平即每次检验允许的犯错水平，一般是 5%
- 待比较模型有 k 个时，两两成对比较的次数 m = k(k−1)/2；若直接用 α = 0.05 做 10 次成对比较，至少犯一次"假阳性"（把没差异的模型判定为有差异）的概率会急剧上升到约 40%

**第一步：全局检验（Omnibus test）**

- 在原假设「所有模型的分类准确率之间没有差异」下，进行全局的联合检验（使用 Q 检验）

**第二步：事后成对检验（Pairwise post hoc test）**

- 如果第一步的全局检验拒绝了原假设，则接着在两两模型之间进行成对检验（McNemar）
- 并对多重比较进行校正（Bonferroni 校正：显著性水平调整为 α/m，m 为成对比较次数）
- 主要是为了严格控制"假阳性"，即把没差异的模型判定为有差异
- 但由于过于保守，主要用于学术界，工业界较少使用

**为什么不能直接两两比较？**

- 正确流程：先全局检验，看是否存在一个模型和其他模型的准确率不一样；再做两两比较 + 校正，确定出显著的模型

## 四、模型调参与超参数搜索

### 2026-07-30 调参两大件

- `GridSearchCV`：组合少时用，全量跑完
- `RandomizedSearchCV`：参数多时首选，`n_iter` 控制预算就行

### 2026-07-30 随机搜索的灵魂是 scipy.stats 分布

- `expon` 指数分布：偏向小值采样，非常适合学习率这种常在 0.01~0.1 区间的参数
- `randint`：整数均匀分布，注意 high 取不到边界值，比如 high=10 最大只到 9
- `uniform` 连续均匀分布：在指定区间内等概率抽浮点数

### 2026-07-30 调参大坑

- Bootstrap OOB 别用来做 `GridSearch`（200 轮 × 14 组 = 2800 次训练，比 K 折慢 20 倍，且每次只用 63% 独特数据训练导致高偏差，调参还得看 K 折）
- 交叉验证分数（`best_score_`）只是模拟考成绩，最终泛化能力必须用封存的独立测试集（`X_test`）来判

### 2026-07-30 进阶提取技巧

- `cv_results_` 里存了每轮验证分数，可提取冠军组的 200 轮分数用 `np.percentile` 算 2.5% 和 97.5% 分位数（分位数法不依赖正态假设，偏斜数据更稳）

### 2026-07-30 1-SE 法则（模型选择策略）

- 先找交叉验证最高分冠军，算出它的标准误差（SE）
- 划门槛：冠军分 − SE
- 在门槛内选最简单的模型（对应奥卡姆剃刀，工业界比纯峰值更稳）

### 2026-08-02 Nested CV 嵌套交叉验证

- 外层循环负责测试集的切分 + 内层循环训练、调参
- 内层做标准的 `GridSearchCV` 或 `RandomizedSearchCV`，跑出这组数据下的最佳超参数，用这组超参数在外层训练集上测试

### 2026-08-03 GridSearchCV + Pipeline 在 MNIST 上做 5 折交叉验证（五个主流算法对比）

- **哪些算法要嵌套 StandardScaler**：逻辑回归、KNN、SVM 的 pipeline 里都嵌了标准化；决策树、随机森林没有
  - 原因：逻辑回归靠梯度下降、SVM 用 RBF 核、KNN 算欧几里得距离，都依赖低方差的数据分布 → 必须归一化
  - 树的分裂只看阈值，特征尺度不影响 → 不需要标准化
- **GridSearchCV 的 refit 参数**：用内层 5 折交叉验证里分数最高的那组最佳参数，在 `X_train` 上再训练一遍，得到最终模型
- **scoring 怎么选**：
  - `accuracy`：整体正确率
  - `f1_macro`：对每个类别分别算 F1 再取算术平均（类别不平衡时更客观）
  - `f1_weighted`：按每个类别的样本量加权平均，适合类别数量不均的情况
- **逻辑回归求解器怎么选**（本场景：5000 条样本、10 分类、L2 正则）：
  - `newton-cg` 和 `lbfgs` 都能胜任：都支持多分类、收敛极快；newton-cg 在多类别时迭代次数略少，lbfgs 是 sklearn 默认选项、更通用
  - 数据量极大（数十万行以上）→ 换 `saga`：支持大规模数据 + 多分类，而且是唯一支持 L1 正则（做特征选择）的多分类求解器
  - `liblinear` 虽然快，但不支持多分类
- **结果**：SVM 最高（最擅长高维像素数据的"核方法"），随机森林次高（集成学习在多分类上表现好）

## 五、分类与评估指标

### 2026-07-22 模型评判标准

- 带阈值的 F1-score，无阈值的 NDCG、AUC
- AUC 对不平衡的数据具有鲁棒性，衡量两个类别分布的重叠程度
- NDCG 是可多元的（支持多级相关性），AUC 是二元的，但对实现公式还没有深入理解

### 2026-07-30 复习：AUC

- AUC（随机正负样本排队的正确率，不依赖阈值）

### 2026-08-03 复习混淆矩阵 + 新知识点：灵敏度、特异度、宏平均、MCC

- 混淆矩阵：

  |          | 预测正类 | 预测负类 |
  |----------|----------|----------|
  | 实际正类 | TP       | FN       |
  | 实际负类 | FP       | TN       |

- **灵敏度**（Sensitivity / Recall / TPR）= TP / (TP + FN)：正类里抓出来多少
- **特异度**（Specificity / TNR）= TN / (TN + FP)：负类里认对多少
- **宏平均**（Macro-average）：对每个类别分别算召回率（或正确率），再取算术平均 → 剥夺多数类的优势，类别不平衡时比整体 accuracy 更客观公正
- **MCC（Matthews Correlation Coefficient，马修斯相关系数）**：

  MCC = (TP × TN − FP × FN) / √[(TP + FP)(TP + FN)(TN + FP)(TN + FN)]

  - 取值 [−1, 1]：+1 完美预测，0 等于瞎猜，−1 完全反着预测
  - 和 F1 的区别：F1 只看正类抓得全不全（只涉及 TP、FP、FN），MCC 是"双向"的，要求 TP 和 TN 同时大，混淆矩阵四个格子全用上
  - 类别不平衡时比 F1 更可靠

### 2026-08-04 多分类策略：一对多（OvR / OvA）

- 思路：K 元分类就训练 K 个二元分类器，每个分类器只把当前类当正类、其余所有类当负类
- 预测时：每个分类器输出一个置信度分数（比如逻辑回归的概率），最后取分数最高的类作为结果
- 特点：一个分类器吃全部训练数据，K 个分类器彼此独立，简单直接

### 2026-08-04 AUC（ROC 曲线下面积）

- ROC 曲线：横轴是 FPR（假正率）= FP / (FP + TN)，纵轴是 TPR（真正率/召回率）= TP / (TP + FN)
- AUC 就是 ROC 曲线下的面积，越高模型能力越强
- 直觉含义：随机抽一个正样本和一个负样本，模型把正样本排在负样本前面的概率
- 取值：0.5 = 纯随机瞎猜，1 = 完美分类，小于 0.5 说明比随机还差（可能是标签标反了）
- 优势：不依赖分类阈值，类别不平衡时比 accuracy 更可靠

## 六、神经网络基础与正则化

### 2026-07-24 正则化

- 一般正则化分为岭回归（L2）和套索（L1）（总损失 = 原始损失 + L1/L2 惩罚项）
- L2（平方惩罚）会让权重向 0 收缩（缩小但不直接归零）
- L1（绝对值惩罚）则通过"软阈值截断"，将太小的权重直接砍成 0，让不重要的特征彻底停止学习
- 在树结构（XGBoost / LightGBM）上：通过 gamma 惩罚叶子数量（只有分裂增益大于惩罚阈值才会分裂），并通过 lambda 惩罚叶子输出值（强迫每棵树只贡献一点点，配合学习率让整体模型更加平缓），从而有效防止过拟合

### 2026-08-05 训练与调参要点（理论依据）

- **batch_size（32/64/128）**：过小则梯度估计方差大、训练不稳定；过大则内存开销大、收敛到尖锐极小值、泛化性能下降
- **通道数翻倍**：池化使特征图空间分辨率逐级减半，通道翻倍用于保留信息容量（空间维度↓、通道维度↑）
- **Dropout**：训练时以概率 p 随机置零神经元输出，等效于多个子网络的集成，抑制过拟合；0.5 为常用默认值
- **ReLU**：计算代价低，正区间梯度恒为 1，缓解深层网络的梯度消失
- **权重初始化不能全零**：全零初始化会导致对称性问题——所有神经元接收相同梯度、参数同步更新，无法分化出不同特征；随机初始化可以打破对称性

### 2026-08-06 学习率调度：ReduceLROnPlateau

- **机制**：监控指定指标（如验证损失），当该指标连续若干个 epoch 不再改善（进入平台期）时，按设定因子自动降低学习率
- **作用**：帮助模型越过平台期进一步收敛，是常用的学习率自适应策略

### 2026-08-17 复习：LeakyReLU

- LeakyReLU(0.01)：ReLU 将小于 0 的输入直接置为 0，而 LeakyReLU 是 0.01·x，避免死神经元问题

### 2026-08-18 复习：sigmoid 与 softmax

- **sigmoid**：σ(x) = 1 / (1 + e^(−x))
  - 输出范围 (0, 1)，可解释为概率，常用于二分类输出层
  - 导数形式好记：σ′(x) = σ(x)·(1 − σ(x))
  - 缺点：输入绝对值大时梯度趋近 0（梯度消失）；输出全为正，收敛较慢
- **softmax**：softmax(z)_i = e^(z_i) / Σⱼ e^(z_j)
  - 把一组实数变成"和为 1 的概率分布"，用于多分类输出层
  - 计算技巧：分子分母同减最大值 max(z) 防止溢出（结果不变）
  - 关系：二分类时 softmax 是 sigmoid 的推广（多分类必须用 softmax，保证各类概率和为 1 且互斥）

### 2026-08-19 Adam 优化器

- 代码：`optimizer = torch.optim.Adam(model.parameters(), lr=LEARNING_RATE)`
- 优化点：
  1. **动量法**：加速收敛、减少震荡（像小球滚下山，积累历史梯度方向）
  2. **自适应学习率**：根据历史梯度大小自动缩放更新步长（类似 AdaGrad/RMSProp 的思路）——每个参数有自己的学习率：梯度大的参数步长小，梯度小的参数步长大

## 七、卷积神经网络（CNN）基础

### 2026-08-04 补充点：池化层的作用

- 通过压缩长宽（空间尺寸），为后面的卷积层减少计算量
- 同时起到降维、提取局部主要特征的作用，还能减少过拟合

### 2026-08-06 卷积层基础与输出尺寸

- **输出特征图尺寸**：由输入尺寸、卷积核尺寸、填充（padding）与步长（stride）共同决定，计算公式为 (输入尺寸 − 卷积核尺寸 + 2×填充) / 步长 + 1，结果向下取整
- **卷积 vs 交叉相关**：数学上的卷积运算需先将核翻转再做滑动点积；深度学习中的"卷积层"实际执行的是交叉相关（核不翻转，直接滑动点积）。由于核权重由训练学习得到，是否翻转可被权重吸收，不影响模型的表达能力

### 2026-08-19 转置卷积（上采样）输出尺寸

- 计算公式：输出 = (输入 − 1) × stride − 2 × padding + kernel_size
- 在转置卷积中，padding 指在计算等效的常规卷积之前，从输入特征图外围裁剪掉的像素数
- 例：输入 4、stride 2、padding 1、kernel 4 → 输出 = (4−1)×2 − 2×1 + 4 = 8（尺寸翻倍上采样）
- 用途：上采样（如 VAE 解码器把潜在向量还原为图片），与池化/步长卷积的"可学习下采样"对应

### 2026-08-06 平移等变性与平移不变性

- **平移等变性**（translation equivariance）：卷积层由局部感受野与权重共享实现——输入发生平移时，特征图同步平移，特征本身不变
- **平移不变性**（translation invariance）：主要来源于池化/下采样——池化只保留局部区域内的最大（或平均）响应强度，忽略特征的精确位置，因此输入小幅平移时输出基本不变
- **池化（下采样）的作用**：丢弃精确位置信息（换取不变性）、扩大感受野、降低计算量

### 2026-08-06 卷积核权重的梯度与反向传播

- **权重的梯度**：由于权重共享，卷积核中每个权重 w 的梯度等于所有滑窗位置上（对应输入像素值 × 该位置反向传播梯度）的累加和——权重的更新由全部空间位置的贡献共同决定
- **反向传播**：利用链式法则从输出层向输入层逐层计算损失对每个参数的梯度，再据此更新权重

### 2026-08-06 数据增强

- **原理**：对训练样本施加随机变换（平移、旋转、翻转、裁剪、缩放等），生成更多训练样本，扩大训练集规模
- **作用**：提高模型泛化能力、抑制过拟合，并增强模型对位置、尺度等变化的不变性

## 八、经典 CNN 架构

### 2026-08-04 VGG16 网络结构

- 16 个带权重的层：13 个卷积层 + 3 个全连接层
- 全部只用 3×3 的小卷积核（stride=1、padding=1），不用大卷积核
  - 两个 3×3 堆叠 ≈ 一个 5×5 的感受野，三个 3×3 ≈ 7×7，但参数更少、非线性更强
- 总体结构分五大组，非常规整：每组卷积若干次、池化一次（2×2 最大池化）
  - 卷积核通道数逐组翻倍：64 → 64，128 → 128，256 → 256 → 256，512 → 512 → 512，512 → 512 → 512
- 参数总量约 1.38 亿，绝大部分集中在全连接层

### 2026-08-05 VGG16 的 PyTorch 搭建流程

- **定义卷积块**：`Conv2d(kernel_size=3, padding=1)` + `BatchNorm2d` + `ReLU`（VGG 原始结构无 BN，现代实现常加 BN 以加速收敛、稳定训练）
- **构建特征提取器**：按通道配置 `cfg=[64, 64, 128, 128, 256, 256, 256, 512, 512, 512, 512, 512, 512]` 循环堆叠卷积块，每个阶段结束后插入 `MaxPool2d(2,2)`
- **构建分类器**：`AdaptiveAvgPool2d(1)`（或 `Flatten`）将特征图 (512, H, W) 展平 → 三层 `Linear(512→4096→4096→num_classes)`，全连接层之间插入 `Dropout(0.5)` 正则化
- **权重初始化**：卷积层与全连接层采用 Kaiming uniform（配合 ReLU）或 Xavier 初始化，缓解梯度消失/爆炸
- **前向传播流程**：输入 (N, 3, 224, 224) → 特征提取 → 全局平均池化 → 展平 → 全连接分类，输出 (N, num_classes) 类别分数

### 2026-08-06 AlexNet（首个取得突破的深度 CNN）

- **定位**：首个在 ImageNet 大规模图像识别竞赛（ILSVRC 2012）中取得突破性成绩的深度卷积神经网络
- **架构**：5 个卷积层 + 3 个全连接层（共 8 层带权重层），更深的网络能学习更抽象、更复杂的特征表示
- **关键技术**：深度架构 + ReLU 激活（加速收敛、缓解梯度饱和）+ Dropout 正则化 + 多 GPU 并行训练 + 数据增强
- **特征提取流程**：卷积 → ReLU → 池化堆叠构成特征提取器，最终将特征图展平（flatten）为一维向量输入全连接层分类
- **卷积核与特征**：卷积核的权重（数值）决定其检测的特征类型（如边缘、纹理），由训练自动学习得到

### 2026-08-08 CNN 架构发展

- **AlexNet**：早期经典，计算量小，准确率低
- **ResNet**（ResNet-18 → ResNet-152）：准确率随着计算量增加而显著提升（70% ~ 80%），深度 + 残差
- **VGG**：计算量大，但提升有限（约 75%）
- **Inception 系列**：计算量中等，准确率可达 80%（多分支卷积，平衡了性能和效率）
- **ResNet 的核心（恒等映射 + 残差映射）**：F(x) = 目标映射 − x，即 F(x) 只需要学习目标与输入的差值；通过一条恒等映射的"快速通道"（shortcut）可以让信息无损地跨层流动，输出为 ReLU(x + F(x))

### 2026-08-08 关于激活函数与全卷积网络

- MaxPooling 放在激活函数之后，是常规下采样，保留平滑信息；所有卷积层之后接全局平均池化
- 全卷积网络：用步长卷积代替最大池化——步长卷积是可学习的卷积操作，通过卷积核的移动权重，自己学习如何下采样
- 全卷积网络追求简洁：所有层都使用卷积操作，没有池化层

## 九、生成式对抗网络（GAN）

### 2026-08-05 GAN

- GAN 属于隐式密度模型：不显式建模数据分布，由生成器 G 将低维噪声 z 映射为样本，判别器 D 区分真实与生成样本，两者对抗训练使生成分布逼近真实分布
- 训练目标为 Minimax 形式：判别器最大化其判别准确率，生成器最小化判别器对生成样本的判别得分，两者交替更新——固定 G 更新 D（真实样本标签 1、生成样本标签 0），固定 D 更新 G（使 D 对生成样本输出趋近 1）；G 不接触真实样本，仅通过 D 的梯度信号学习；训练初期 D 易判别导致 G 梯度消失、收敛困难
- cGAN 将条件信息 c 同时拼接进 G、D 的输入（(z, c) 与 (x, c)），实现可控生成（如指定类别）；后续 DCGAN 结合卷积架构提升训练稳定性与生成质量

### 2026-08-21 训练 GAN 的过程（D、G 交替更新）

- **一、训练判别器 D（此时给 G 完全冻结）**
  1. 随机采样真样本，喂给 D，让 D 学会给真样本高分
  2. 随机采样假样本，喂给 D，让 D 学会辨别假样本、给低分
- **二、训练生成器 G**
  1. 随机采样噪声，喂给 G，让 G 生成假样本
  2. 假样本喂给 D，只打分，不更新权重
  3. （关键点）反向传播计算损失，梯度到达 D 但不更新 D，穿过 D 的所有层变成一张"像素调整图"流回 G，更新 G 的权重
- 循环以上步骤，关键点：**G、D 交替更新**（不是同时更新，防止一方把另一方带偏）

### 2026-08-21 GAN 的纳什均衡点（衡量 GAN 的训练质量）

1. 生成器的分布完全等于真实分布（G 生成的样本以假乱真）
2. 判别器对于任意输入恒等于 0.5（D 完全无法区分真假，只能瞎猜）

- 为什么这是均衡点：G 稍微偏离真实分布，D 就能抓住破绽打出偏离 0.5 的分，让 G 的损失上升（逼 G 学得更像）；D 只要偏离 0.5，G 用该偏见生成图，D 的损失也会上升（逼 D 恢复公平打分）
- 互相牵制：谁偏离均衡，谁的损失就上升，因此双方都被"拉"回均衡点

### 2026-08-21 GAN 的损失公式（补全）

- **符号约定**：x 真实样本；z 随机噪声（如标准正态分布）；p_data(x) 真实数据分布；p_z(z) 噪声先验分布；G(z) 生成样本；D(x) 判别器打分 ∈ (0,1)；E[...] 期望（对一批样本求均值）
- **判别器损失（二分类交叉熵）**：

  L_D = −E_{x~p_data(x)}[log D(x)] − E_{z~p_z(z)}[log(1 − D(G(z)))]

  - 第一项 −E[log D(x)]：对真实样本，D 打分越高损失越小 → 逼 D 给真样本打高分
  - 第二项 −E[log(1 − D(G(z)))]：对假样本，D 打分越低损失越小 → 逼 D 给假样本打低分
- **生成器损失（非饱和形式，现代 GAN 常用）**：

  L_G = −E_{z~p_z(z)}[log D(G(z))]

  - G 想让 D 对假样本打高分（趋近 1），即最大化 log D(G(z))，加负号变成最小化
  - 一旦 D 识破假图（D(G(z)) 低），L_G 上升
  - 两种形式：原始论文 L_G = E[log(1 − D(G(z)))]（D 太强时梯度接近 0、G 学不动）；非饱和形式梯度更稳定
- **整体 min-max 目标**：

  min_G max_D V(D, G) = E_{x~p_data(x)}[log D(x)] + E_{z~p_z(z)}[log(1 − D(G(z)))]

  - max_D：固定 G，D 最大化 V（真样本高分、假样本低分）
  - min_G：固定 D，G 最小化 V（骗过 D）
  - 达到纳什均衡时 D(x) = D(G(z)) = 0.5，V = log 0.5 + log 0.5 = −2·log 2 ≈ −1.386（博弈的理论终值）
- **训练循环对应**：训练 D（G 冻结）只更新 D，用 L_D；训练 G（D 冻结）只更新 G，用 L_G；交替循环对应 min_G max_D V(D, G)

## 十、自动编码器与变分自动编码器（AE / VAE）

### 2026-08-17 自动编码器（Autoencoder）

- 本质是无监督学习的神经网络
- 学会把输入数据压缩成低维表示，再从低维表示重建出原始输入
- 变体：
  - 去噪自动编码器：输入数据添加噪声
  - 稀疏自动编码器
  - 变分自动编码器：不是学习一个固定的中间向量，而是学习一个范围（分布），解码器在该范围内随机采样，生成新的、合理的图片
- 应用：降维、去噪、异常检测、特征提取、生成新数据

### 2026-08-17 PCA 降维 vs 自动编码器

PCA 步骤：

1. 找到数据方差最大的方向（第一主成分）
2. 找到与它正交且方差次大的方向（第二主成分）
3. 保留前几个主成分，把数据投影到它们张成的低维空间

| 维度 | PCA | 自动编码器 |
|------|-----|-----------|
| 降维方式 | 线性投影 | 神经网络编码，非线性激活 |
| 训练目标 | 最大化投影后的方差 | 最小化重构误差 |

- 线性编码器约等于 PCA

### 2026-08-18 稀疏自动编码器（中间层的平均激活度很低）

- 通过在损失函数中加"惩罚项"实现稀疏：总损失 = 重构误差 + 稀疏惩罚项
1. **L1 正则**：对隐藏层激活值 a 加 L1 惩罚，惩罚项 = λ·Σ|a_j|（对每个神经元求和）
   - 为什么能稀疏：L1 会把权重持续"推"向 0，让大部分激活值变成 0（L2 只会压缩幅度，不产生严格的 0）
2. **KL 散度惩罚**：设定很小的期望激活率 ρ（如 0.05），统计每个神经元的平均实际激活率
   - 实际平均激活率：ρ̂_j = (1/m)·Σ a_j(x⁽ⁱ⁾)（对 m 个样本求平均）
   - 惩罚项：KL(ρ ‖ ρ̂_j) = ρ·log(ρ/ρ̂_j) + (1−ρ)·log((1−ρ)/(1−ρ̂_j))，把所有神经元加起来
   - 直觉：ρ̂ 偏离 ρ 越远，惩罚越大，把每个神经元的激活率"拉"回 ρ

**为什么要稀疏？**

1. 特征解耦：每个隐藏神经元只对一类特定模式响应（如边缘、角落）
2. 更好的泛化：迫使模型学习更本质的特征，丢弃冗余和噪声
3. 每个激活神经元对应明确的语义特征，更易解释

**应用**

- 预训练深度神经网络、提取初始有用特征（后被更简单的 ReLU + 随机初始化代替）；特征提取、异常检测、降维

### 2026-08-18 变分自动编码器（VAE，强制潜在空间分布为标准正态）

**普通 AE 的缺陷：**

1. 潜在空间不连续：相似的样本，z 的输出可能相差很大
2. 无法生成新样本

**流程**：输入 x → 编码器 → 均值、方差 → 采样 → 解码器 → 重构

- VAE 的 z 每次都不同（普通 AE 对同一输入 z 是一致的）；z 对一个样本的输出服从一个分布（以均值为中心、方差为半径的范围）
- **重参数技巧**：随机采样无法求导，改为通过均值、方差、随机采样的固定噪声一起计算，使梯度可回传
- **log-var trick**：编码器输出方差必须非负，而神经网络输出实数可正可负；让网络输出 log(方差) 再取指数，既保证非负又更平滑、鲁棒
- **计算公式**：z = μ + exp(½·log σ²)·ε = μ + σ·ε，其中 ε ~ N(0, 1)

**VAE 训练过程：**

1. 前向传播：计算均值、方差 → 从标准正态分布采样噪声 → 用重参数技巧得到 z → 解码器重构出图片
2. 计算 loss（黑白图用交叉熵，彩色图用 MSE）：总体误差 = 重构误差 + KL 散度
   - KL 散度衡量编码器输出分布与标准正态分布的差异（D_kl(p‖q)）
   - 两个正态分布之间的 KL 散度有闭合解（不用积分，直接代公式）：KL = −½·Σ(1 + log σ_k² − μ_k² − σ_k²)
3. 反向传播更新参数

### 2026-08-18 补充：概率质量函数（PMF）与概率密度函数（PDF）

- **PMF**（Probability Mass Function）：适用于离散随机变量，P(X = x_i) = p_i，且 Σp_i = 1（如掷骰子每面概率 1/6）
- **PDF**（Probability Density Function）：适用于连续随机变量
  - "密度"即单位长度的概率质量；曲线本身的高度不是概率，曲线下方的面积才是概率
  - P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx，且 ∫f(x)dx = 1（归一化）
  - 注意：f(x) 本身不是概率（可能大于 1）

### 2026-08-19 CNN 变分自动编码器：超参与数据加载

- `get_dataloaders_mnist(batch_size, num_workers, validation_fraction)`
  - **validation_fraction**：从训练集划分多少作为验证集（如 0.1 = 抽 10% 做验证）
  - **num_workers**：DataLoader 用多个子进程并行加载数据，值越大加载越快（但占内存）
- **VAE 的 validation 通常设为 0**：VAE 是无监督学习，训练目标是最小化重构误差 + KL 散度，不需要标签来验证分类准确率
- `skip-epoch-stats=true`：跳过每个 epoch 的统计，不在每个 epoch 后用验证集算误差，加快训练
- 补充：下采样让特征图尺寸减半时通道数往往翻倍，补偿空间信息的损失，用更多通道存储不同类型的抽象特征（与 08-05 "通道数翻倍"同源）

### 2026-08-19 重参数化的代码实现

```python
eps = torch.randn_like(z_mu).to(z_mu.device)
z = z_mu + eps * torch.exp(z_log_var / 2.)
```

- `torch.randn_like(z_mu)`：生成与 z_mu 同形状的标准正态噪声（z_mu 是潜在变量的均值向量）
- 公式：z = μ + ε·exp(log σ² / 2) = μ + ε·σ（与标准正态噪声 ε 逐元素相乘后加到均值上）
- 好处：随机性只来自 ε（与参数无关），梯度可以正常回传到 μ 和 σ

### 2026-08-19 操纵潜在空间生成人脸（平均脸与微笑方向向量）

- 数据预处理流水线：`Compose` 按顺序组合多个变换；`CenterCrop` 以图片中心为基准裁剪统一尺寸（128×128）；`ToTensor` 把 PIL 图像转张量并归一化到 [0, 1]（`Normalize` 可选，标准化到 [−1, 1]）
- `encoding-fn = None`：直接在像素空间得到平均脸（不经过编码器）
- 分别计算所有微笑脸和非微笑脸平均脸的潜在空间向量并**作差**，得到"纯微笑方向向量"
- 公式：**Z_new = Z_neutral + a × (Z_smile − Z_non_smile)**
  - Z_neutral：中性脸的潜在向量
  - (Z_smile − Z_non_smile)：微笑方向向量（两类均值差，即"微笑"这一属性的方向）
  - a：缩放系数，控制微笑强度（a 越大微笑越明显）
- 本质：在潜在空间里沿"微笑方向"移动，解码器就能生成带微笑的人脸——这正是 VAE 潜在空间"连续、可操纵"的体现

## 十一、迁移学习

### 2026-08-10 预训练与迁移学习

- 预训练：用很大、易获得的数据集训练一个模型，该阶段主要是让模型学会通用的底层特征
- 迁移学习：把源任务学到的"知识"迁移到目标任务上，在小规模的目标数据上微调——可选择冻结前面层、只训练新层，或让模型用极低的学习率调整

**迁移学习的三种方式**

1. 特征提取器迁移：预训练模型作为特征提取器，不再更新权重
2. 多任务学习：共享底层参数，同时学习几个相关任务
3. 域适应：源域有大量标注数据的训练环境，而目标域几乎无标注但需部署的环境

- 普通迁移学习（预训练 + 微调）：通常假设源数据和目标数据分布近似
- 域适应：面对更加极端的情况

### 2026-08-28 迁移学习谱系：预训练 → 微调 → 少样本 → 零样本

- 按"所需标注/示例数据量"从多到少排列：预训练 → 微调 → 少样本 → 零样本
- **全量微调（Fine-tuning）**：在预训练模型基础上，用目标任务数据更新参数（可全部或部分更新）
- **少量样本（Few-shot）**：只给少量示例（几个到几十个），模型即可适应新任务
- **零样本（Zero-shot）**：不给任何示例，直接凭预训练知识完成任务
- **上下文学习（In-Context Learning）**：推理时把示例放进提示词（prompt），模型**不更新参数**，靠上下文理解完成任务

## 十二、循环神经网络（RNN）

### 2026-08-10 RNN 基础

- 传统的前馈网络没有"记忆上下文"功能：输入词向量 → 输出预测
- RNN 当前的隐藏单元接受：上一步的隐藏状态 + 这一步的输入值作为输入 → 有了记忆功能

**序列任务的类型**

1. one → many：如输入一张图片，生成文字描述
2. many → one：输入电影评论，判断是负面还是正面评论
3. many → many：语言翻译、视频字幕生成

**RNN 中的三组权重（同一时刻共享）**

- W(输入 → 隐藏)：被每个时刻利用
- W(隐藏 → 隐藏)：决定如何把旧状态融入新状态，每个时刻利用
- W(隐藏 → 输出)：只在最后输出计算，不回传

### 2026-08-10 RNN 困境：梯度爆炸 / 消失

- RNN 困境：反向传播时，大量的连乘导致梯度爆炸/消失

**补充知识点：雅可比矩阵、奇异值、条件数**

- 雅可比矩阵：向量对向量的导数，描述输入空间的微小扰动如何全方位地改变输出空间（反向传播的梯度需要乘上雅可比矩阵）
- 奇异值：矩阵在各个方向上的增益或缩放尺度
- 若某个雅可比矩阵的奇异值全部大于 1，梯度爆炸；全部小于 1，梯度消失
- 条件数：系统对输入误差的敏感度（= 雅可比矩阵最大奇异值 / 最小奇异值）
  - 条件数 = 1：雅可比矩阵完美正交，各个方向同等缩放，梯度此时下降最快
  - 条件数很大：极度拉伸，对误差很敏感
  - 无穷大：矩阵不可逆，某个方向被压缩为 0
  - 在线性回归时，若输入数据的特征矩阵条件数很大，说明数据存在严重的共线性，所以数据输入需要标准化
  - 权重矩阵的条件数决定了前向传播时信号在不同方向上的缩放差异；某层的条件数太大，在多层的累积下，不同方向的信号强度会指数级分化，这就是梯度消失/爆炸的对应
- Hessian 矩阵（每个元素是损失 L 对参数变量的二阶偏导）：标量损失对参数向量的二阶导数，反映损失地形的曲率
  - 损失函数（Hessian）矩阵条件数 = 1：SGD 在最快的方向下降；条件数很大：收敛很慢

**RNN 梯度问题解决办法**

- 梯度裁剪：使用阈值裁剪解决梯度爆炸问题，但无法解决梯度消失问题
- TBPTT（截断式 BPTT）：强行切断反向传播计算图，缩短求导链长度，缓解梯度消失问题；是有偏估计，无法真正建模超长序列
- 目前主流的做法：层归一化（把方差拉回标准范围）+ 残差连接（跨层直接相加，为梯度提供"捷径"）
- LSTM（长短期记忆）：遗忘门、输入门、输出门（结构复杂、输出慢，但可以解决长期依赖）
  - LSTM 的记忆细胞与遗忘门做**逐元素相乘**（element-wise），当遗忘门接近 1 时，梯度可无损地沿时间轴反向传播
- GRU：重置门（决定是否忽略前面信息），更新门（同时决定是否忘记和记住）

### 2026-08-17 LSTM 实战：many-to-one 情感分类器

- 基于 LSTM 实现的 many-to-one 分类器：判断电影评论是正面还是负面
- **NLTK 库**：Python 中经典的自然语言处理工具包，提供分词、词性标注、情感分析、命名实体识别等功能
- **VADER 情感词典**：针对社交媒体短文本优化过的情感分析工具
- **punkt**：预训练好的无监督句子切分器，也可用于词切分
- `np.bincount()`：统计一个非负整数数组中每个数字出现的次数

### 2026-08-28 LSTM 源码与参数详解（nn.LSTM）

**hidden_size（隐藏状态大小）**

- 隐藏状态是 LSTM 的"记忆容量"，决定 h 输出和 c 细胞状态的维度
- 越大拟合能力越强，但过拟合风险越高
- 隐藏状态不是一个词：每个维度都在告诉下游"当前得到的是哪种类型/语法的信息"

**num_layers（堆叠层数）**

- 默认 1，处理原始输入序列；设为 2 时，第二层把第一层的输出作为输入
- 可提取更抽象的时间特征；层数越多越容易梯度消失

**batch_first**

- 切记显式设置为 `True`；默认 `False` 时输入形状为 `(seq_len, batch, input_size)`
- 设为 `True` 可与后续 Linear 层的张量对齐，减少转置操作

**dropout**

- 除堆叠层的最后一层外，其余层都要加

**bidirectional（双向）**

- `True` 时网络正反各扫描一遍，hidden 维度翻倍，将前后 hidden 拼接
- 一般 NLP 注重上下文（语音识别也会设置双向）
- 时间序列预测（股票、天气）必须 `False`，否则就是信息泄漏

**序列建模 bug 排查要点：detach 切计算图**

- 一个批次完成后必须 `detach()`：切掉计算图，否则梯度沿整条序列回传，导致显存爆炸

### 2026-08-28 自然语言生成：温度采样（temperature sampling）

- NLP 生成时的超参数，决定模型输出的保守倾向
- 对下一个预测词：原始分数 ÷ 温度后，再做指数放大（softmax）
- 温度 < 1：除以温度后分数差距被放大 → 模型更倾向分数更大的词 → 输出更保守、确定

## 十四、注意力机制与 Transformer

### 2026-08-28 RNN 中的注意力机制（Bahdanau / Luong）

- 思想：解码器生成当前词时，不只依赖最后的隐藏状态，而是"回看"编码器的所有词
- 步骤：
  1. 编码器处理完句子，保存每个词的隐藏状态
  2. 解码器生成当前词时，用自己的隐藏状态与编码器的隐藏状态加权求和：先计算相关性分数，再对所有分数 softmax 得到注意力权重
- **Bahdanau attention（加性注意力）**：用全连接前馈网络计算注意力分数，可学习更复杂的对齐关系，适合长文本
- **Luong attention（乘法/点积注意力）**：直接用向量点积计算分数，计算效率更高

### 2026-08-28 自注意力机制

- 革命性：输入序列的每个词都可**同时**作为查询者、被查询者、内容提供者，并行关注，不需要等待编码器处理完所有时间步
- Q（Query）关注谁 / K（Key）被关注的内容 / V（Value）实际输入内容
- 公式：Attention(Q, K, V) = softmax(QKᵀ / √d_k) · V
- **多头注意力（Multi-Head Attention）**：将 Q、K、V 投影到多个低维空间，从不同维度提取信息（如同义词、语法、指代关系），最后将多个头拼接，再过一个线性层输出
- **为什么要除以缩放因子 √d_k**：softmax 对输入极其敏感，值过大会导致概率极端集中、大部分词的梯度消失；除以缩放因子把分布拉回正态区间，更平滑

### 2026-08-28 Transformer 家族：BERT / GPT / BART

- **BERT**（Bidirectional Encoder Representations from Transformers）：只用 Transformer 的编码器部分，擅长理解；预训练：掩码语言模型（完形填空）+ 下一句预测（判断句间关系、理解整体逻辑）
- **GPT**（Generative Pre-trained Transformer）：单向，只看左边，只用解码器；自回归语言模型，做生成式任务；预训练：因果掩码——用前一个词预测后一个词
- **BART**（Bidirectional and Auto-Regression Transformer）：编码器 + 解码器，理解 + 生成；预训练：文本去噪——打乱、删词、mask 后让模型还原
