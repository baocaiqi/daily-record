#### 稀疏自动编码器（中间层的平均激活度很低）

通过在损失函数中加"惩罚项"实现稀疏：

总损失 = 重构误差 + 稀疏惩罚项

1. **L1 正则**
   - 对隐藏层激活值 a 加 L1 惩罚：惩罚项 = λ · Σ|a_j|（对每个神经元求和）
   - 为什么能稀疏：L1 会把权重持续"推"向 0，让大部分激活值变成 0（L2 只会压缩幅度，不产生严格的 0）

2. **KL 散度惩罚**：设定很小的期望激活率 ρ（如 0.05），计算平均的实际激活率，对每个神经元统计频率
   - 神经元 j 的实际平均激活率：ρ̂_j = (1/m) · Σ a_j(x⁽ⁱ⁾)（对 m 个样本求平均）
   - 惩罚项：KL(ρ ‖ ρ̂_j) = ρ·log(ρ/ρ̂_j) + (1−ρ)·log((1−ρ)/(1−ρ̂_j))，把所有神经元加起来
   - 直觉：ρ̂ 偏离 ρ 越远，惩罚越大，把每个神经元的激活率"拉"回 ρ

**为什么要稀疏？**

1. 特征解耦：每个隐藏的神经元只对一类特定的模式响应，如边缘，角落
2. 更好的泛化：迫使模型学习更本质的特征，丢弃冗余和噪声
3. 每个激活神经元对应一个明确的语义概率，更易理解稀疏特征

**应用**

- 预训练深度神经网络的，提取初始有用的特征，后被更加简单的 ReLu + 随机初始化代替
- 特征提取，异常检测，降维

#### 变分自动编码器（强制将潜在空间分布为标准正态分布）

**普通 AE 的缺陷：**

1. 潜在空间不连续，相似的样本，z 的输出可能相差很大
2. 无法生成新样本

**流程**：输入 x → 编码器 → 均值，方差 → 采样 → 解码器 → 重构

- VAE 的 z 每次都不同（和普通 AE 的差别，AE 对于一个输入，z 是一致的），z 对于一个样本的输出是服从一个分布的
- z 的取值是以均值为中心，方差为半径的范围内，通过重参数技巧、log-var 技巧计算的

**重参数技巧**：随机采样无法求导，通过均值、方差、随机采样一个固定噪声一起计算得到

**log-var trick**：编码器输出方差，但必须是非负的，而神经网络输出的实数可正可负，让网络输出的方差为非负数，且更加平滑具有鲁棒性

**计算公式**：

- z = 均值 + exp(log(方差)/2) × 噪声
- 即：z = μ + exp(½·log σ²) · ε = μ + σ · ε，其中 ε ~ N(0, 1)（标准正态随机噪声）

**VAE 训练过程：**

1. 前向传播：
   - 计算均值，方差
   - 从标准正态分布中，采样随机噪声
   - 用重参数技巧得到潜在向量 z
   - 解码器用 z 重构出图片
2. 计算 loss（黑白图用交叉熵，彩色图用 MSE）
   - 总体误差 = 重构误差 + KL 散度
   - KL 散度衡量编码器输出的分布与标准的正态分布的差异（D_kl(p‖q)，p 相对于 q 的差异）
   - 两个正态分布之间的 KL 散度有闭合解（不用积分，直接代公式）：KL = −½ · Σ(1 + log σ_k² − μ_k² − σ_k²)
3. 反向传播更新参数

**补充：**

- **概率质量函数（PMF，Probability Mass Function）**：适用于离散随机变量 X
  - 如掷一个骰子每一面的概率是 1/6
  - 公式：P(X = x_i) = p_i，且 Σp_i = 1（所有概率加起来等于 1）
- **概率密度函数（PDF，Probability Density Function）**：适用于连续随机变量
  - "密度"即单位长度的概率质量，某点密度大，说明随机变量在该点附近的概率高，曲线本身的高度不是概率，曲线下方的面积是概率
  - PDF 给每个点的概率需要做积分：P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx，且 ∫f(x)dx = 1（归一化）
  - 注意：f(x) 本身不是概率（可能大于 1），概率是曲线下的面积

**复习：**

1. **sigmoid**
   - 公式：σ(x) = 1 / (1 + e^(−x))
   - 输出范围 (0, 1)，可解释为概率，常用于二分类输出层
   - 导数形式好记：σ′(x) = σ(x)·(1 − σ(x))
   - 缺点：输入绝对值大时梯度趋近 0（梯度消失）；输出全为正，收敛较慢
2. **softmax**
   - 公式：softmax(z)_i = e^(z_i) / Σⱼ e^(z_j)
   - 把一组实数变成"和为 1 的概率分布"，用于多分类输出层
   - 计算技巧：分子分母同减最大值 max(z) 防止溢出（结果不变）
   - 关系：二分类时 softmax 就是 sigmoid 的推广（多分类必须用 softmax，因为要保证各类概率和为 1 且互斥）
