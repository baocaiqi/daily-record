#### 一、稀疏自动编码器（Sparse Autoencoder, SAE）

**核心思想**：强制隐藏层"大多数神经元保持沉默"，即平均激活度很低（如目标激活率 ρ ≈ 0.05），只有少数神经元对输入响应。这样学到的特征更稀疏、更本质，避免恒等映射式的冗余编码。

**实现方式：在损失函数中加入稀疏性惩罚项**

总损失 = 重构损失 + λ · 稀疏惩罚项

1. **L1 正则（L1 Regularization）**
   - 对隐藏层激活值 a 施加 L1 范数惩罚：
     $$L_{sparse} = \lambda \sum_{j} |a_j|$$
   - 为什么有效：L1 范数在零点不可导，其梯度恒为 ±λ，会持续把权重"推"向 0，使大部分激活值趋于 0，从而获得稀疏解（对比 L2 只压缩幅度、不产生严格的零）。

2. **KL 散度惩罚（KL Divergence Penalty）**
   - 设定一个很小的目标激活率 ρ（如 0.05），惩罚实际平均激活率 ρ̂ 与 ρ 的偏离。
   - 神经元 j 在 m 个训练样本上的平均激活率：
     $$\hat{\rho}_j = \frac{1}{m} \sum_{i=1}^{m} a_j(\boldsymbol{x}^{(i)})$$
   - 稀疏性惩罚项（对全部隐藏神经元求和）：
     $$\Omega_{sparse} = \sum_{j} \mathrm{KL}(\rho \,\|\, \hat{\rho}_j) = \sum_{j} \left[ \rho \log \frac{\rho}{\hat{\rho}_j} + (1 - \rho) \log \frac{1 - \rho}{1 - \hat{\rho}_j} \right]$$
   - 直觉：KL 散度衡量两个分布之间的差异。当 ρ̂_j = ρ 时 KL = 0（无惩罚）；ρ̂_j 偏离 ρ 越远，惩罚越大，从而把每个神经元的激活率"拉"回 ρ。

**为什么要稀疏**
1. **特征解耦**：每个隐藏神经元只对一类特定模式响应（如边缘、角落），互不纠缠；
2. **更好的泛化**：迫使模型学习更本质、可迁移的特征，丢弃冗余与噪声；
3. **可解释性**：激活的神经元对应明确的语义（特征），特征更易被人类理解。

**应用**：早期用于预训练深度网络以提取初始特征（后被"ReLU + 随机初始化"的更简单方案取代）；现仍用于特征提取、异常检测、降维等场景。

#### 二、变分自动编码器（Variational Autoencoder, VAE）

**普通 AE 的两大缺陷**
1. **潜在空间不连续**：相似样本可能被编码到相距很远的 z，中间区域无意义；
2. **无法生成新样本**：只能重构输入，无法从潜在空间随机采样生成新数据。

**VAE 的改进**：强制潜在变量 z 服从（近似）**标准正态分布** N(0, I)，使潜在空间连续、可采样、可生成。

**前向流程**
$$\boldsymbol{x} \xrightarrow{\text{编码器}} (\boldsymbol{\mu}, \log \boldsymbol{\sigma}^2) \xrightarrow{\text{采样}} \boldsymbol{z} \xrightarrow{\text{解码器}} \hat{\boldsymbol{x}}$$

关键区别：普通 AE 中 z 是**确定性**的（同一输入 z 唯一）；VAE 中 z 是**随机**的，服从 z ~ N(μ, σ²)，每次采样结果不同——z 以 μ 为中心、σ 为半径随机取值。

1. **重参数化技巧（Reparameterization Trick）**
   - 问题：从 N(μ, σ²) 直接采样 z 是随机操作，**不可求导**，梯度无法回传；
   - 解法：先采样固定噪声 ε ~ N(0, I)（与参数无关），再做确定性变换：
     $$\boldsymbol{z} = \boldsymbol{\mu} + \boldsymbol{\sigma} \odot \boldsymbol{\varepsilon}, \quad \boldsymbol{\varepsilon} \sim \mathcal{N}(0, \boldsymbol{I})$$
   - 效果：随机性被"隔离"在 ε 中，梯度可沿 μ 和 σ 正常回传（⊙ 表示逐元素相乘）。

2. **log-var trick（对数方差技巧）**
   - 问题：方差 σ² 必须非负，而神经网络输出是任意实数；
   - 解法：让网络输出 **log σ²**（可正可负），再取指数还原，并代入重参数公式：
     $$\boldsymbol{z} = \boldsymbol{\mu} + \exp\!\big(\tfrac{1}{2}\log\boldsymbol{\sigma}^2\big) \odot \boldsymbol{\varepsilon}$$
   - 好处：非负性天然满足；数值范围更平滑，训练更稳定、更具鲁棒性。

**VAE 训练过程**
1. **前向传播**：编码器输出 μ 与 log σ² → 从标准正态采样 ε → 重参数化得 z → 解码器重构出 x̂；
2. **计算损失**：
   $$\mathcal{L} = \underbrace{\mathbb{E}_{q(\boldsymbol{z}|\boldsymbol{x})}\left[-\log p(\boldsymbol{x}|\boldsymbol{z})\right]}_{\text{重构误差（负对数似然）}} + \underbrace{\mathrm{KL}\big(\mathcal{N}(\boldsymbol{\mu}, \boldsymbol{\sigma}^2)\,\big\|\, \mathcal{N}(0, \boldsymbol{I})\big)}_{\text{KL 散度（潜在空间正则项）}}$$
   - 重构误差：衡量解码重建质量。黑白图（二值输出）用**交叉熵**，彩色图（连续像素）用 **MSE（均方误差）**；
   - KL 散度：衡量编码器输出分布与标准正态分布的差异，具有**闭合解**（无需积分，可直接计算）：
     $$\mathrm{KL}\big(\mathcal{N}(\mu, \sigma^2)\,\big\|\, \mathcal{N}(0, 1)\big) = -\frac{1}{2} \sum_{k} \left( 1 + \log \sigma_k^2 - \mu_k^2 - \sigma_k^2 \right)$$
     其中 k 遍历潜在向量的每个维度。
3. **反向传播**：对总损失求梯度，更新编码器与解码器参数。

> 本质：VAE 的优化目标是最小化 **负 ELBO（证据下界，Evidence Lower Bound）**：
> $$\mathcal{L} = -\underbrace{\mathbb{E}_{q(\boldsymbol{z}|\boldsymbol{x})}\left[\log p(\boldsymbol{x}|\boldsymbol{z})\right]}_{\text{重构项}} + \underbrace{\mathrm{KL}\big(q(\boldsymbol{z}|\boldsymbol{x})\,\|\, p(\boldsymbol{z})\big)}_{\text{正则项}}$$
> 第一项保证重构质量，第二项保证潜在空间规则（贴近先验 N(0, I)）。

#### 三、概率质量函数（PMF）与概率密度函数（PDF）

**PMF（Probability Mass Function，概率质量函数）—— 适用于离散随机变量**
- 定义：$$P(X = x_i) = p_i, \quad p_i \geq 0, \quad \sum_i p_i = 1$$
- 例：掷一枚均匀骰子，P(X = 1) = ⋯ = P(X = 6) = 1/6；
- 直觉：概率"质量"集中在一个个离散点上，每个点直接给出概率值。

**PDF（Probability Density Function，概率密度函数）—— 适用于连续随机变量**
- 定义：非负函数 f(x)，满足归一化条件：
  $$\int_{-\infty}^{+\infty} f(x)\, dx = 1, \quad P(a \leq X \leq b) = \int_a^b f(x)\, dx$$
- 关键理解："密度" = 单位长度上的概率质量。某点 f(x) 大，说明随机变量在该点**附近**取值的概率高；
- ⚠️ 易错点：f(x) 本身**不是概率**（甚至可能 > 1），概率是曲线下方的**面积**，必须通过积分求得；
- 类比：PMF 像"一堆离散的砝码"，PDF 像"连续铺开的沙层"——单点无质量，必须取一段区域（积分）才有概率。

#### 四、复习：激活函数（附计算公式）

**1. sigmoid（逻辑斯蒂函数）**
$$\sigma(x) = \frac{1}{1 + e^{-x}}$$
- 输出范围 **(0, 1)**，可解释为概率，常用于二分类输出层、门控结构；
- 性质：σ(0) = 0.5，单调递增，处处可导；导数可写成自身形式 σ′(x) = σ(x)(1 − σ(x))，便于反向传播；
- ⚠️ 缺点：两端梯度饱和（|x| 大时导数趋近 0，导致**梯度消失**）；输出非零中心（全正），会使后层梯度更新呈"锯齿状"（zig-zag），收敛变慢。

**2. softmax（归一化指数函数）**
$$\mathrm{softmax}(\boldsymbol{z})_i = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}, \quad i = 1, \dots, K$$
- 将 K 维实数向量映射为**概率分布**：每个分量 ∈ (0, 1)，且全部分量之和 = 1；
- 用于**多分类**输出层，与交叉熵损失天然搭配（数值稳定，反向传播梯度简洁）；
- 数值稳定性技巧：分子分母同减最大值 max(z)，即 e^{z_i − max(z)} / Σ e^{z_j − max(z)}，防止 e^{大数} 溢出（softmax 值不变，因为整体除以常数 e^{−max}）。

**3. sigmoid vs softmax 对比**
- sigmoid 是"二分类版的 softmax"：softmax(K=2) 退化为两个 sigmoid 的关系（softmax(z₁, z₂) = σ(z₁ − z₂)）；
- 多分类**必须**用 softmax 而不是多个 sigmoid：sigmoid 各输出独立（和不一定为 1），softmax 强制互斥、和为 1，符合"样本只能属于一个类别"的语义。
