#### CNN 变分自动编码器

**超参的学习：**

- `get_dataloaders_mnist(batch_size, num_workers, validation_fraction)`
  - **validation_fraction**：从训练集划分多少出来作为验证集（如 0.1 = 抽 10% 做验证）
  - **num_workers**：DataLoader 使用多个子进程并行加载数据，值越大加载越快（但会占内存）

- **VAE 的 validation 通常设置为 0**，因为 VAE 是无监督学习，训练目标是最小化重构误差 + KL 散度，不需要标签来验证分类准确率

**补充：**

- 每当下采样让特征图尺寸减半，通道数往往翻倍，是为了补偿空间信息的损失，用更多的通道数来存储不同类型的抽象特征
- `skip-epoch-stats=true`：跳过每轮次统计，加快训练速度，不在每个 epoch 后用验证集算误差

**重参数化：**

```python
eps = torch.randn_like(z_mu).to(z_mu.device)
z = z_mu + eps * torch.exp(z_log_var / 2.)
```

- `torch.randn_like(z_mu)`：生成与 z_mu 同样形状的标准正态分布噪声（z_mu 是潜在变量的均值向量）
- 公式：z = μ + ε · exp(log σ² / 2) = μ + ε · σ（与标准正态噪声 ε 逐元素相乘后加到均值上）
- 好处：随机性只来自 ε（与参数无关），梯度可以正常回传到 μ 和 σ

**转置卷积输出尺寸：**

- 计算公式：输出 = (输入 − 1) × stride − 2 × padding + kernel_size
- 在转置卷积中的 padding 是指在计算等效的常规卷积之前，从输入特征图外围裁剪掉的像素数
- 例：输入 4、stride 2、padding 1、kernel 4 → 输出 = (4−1)×2 − 2×1 + 4 = 8（尺寸翻倍上采样）

**Adam 优化器：**

```python
optimizer = torch.optim.Adam(model.parameters(), lr=LEARNING_RATE)
```


**Adam 的优化点：**

1. **动量法**：加速收敛，减少震荡，更新方向（像小球滚下山，积累历史梯度方向）
2. **自适应学习率**（根据历史梯度大小自动缩放）：更新步长，各参数尺度不统一，统计学习率不适用
   - 每个参数有自己的学习率：梯度大的参数步长小，梯度小的参数步长大（类似 AdaGrad/RMSProp 的思路）

#### 通过操纵潜在空间生成逼真的人脸图片（代码学习）

```python
custom_transforms = torchvision.transforms.Compose([
    torchvision.transforms.CenterCrop((128, 128)),
    torchvision.transforms.ToTensor(),
    # torchvision.transforms.Normalize((0.5, 0.5, 0.5), (0.5, 0.5, 0.5))
])
```

- **数据预处理流水线**：`Compose` 把多个变换按顺序组合成一个整体
- **CenterCrop**：以图片中心为基准，裁剪出统一的图片尺寸（128×128）
- **ToTensor**：把 PIL 图像转成张量，像素值归一化到 [0, 1]
- （注释掉的 Normalize 若启用，会把像素值标准化到 [−1, 1]，以均值为中心）

**平均脸与微笑方向向量：**

- `encoding-fn = None`：直接在像素空间得到平均脸（不经过编码器）
- 通过分别计算所有微笑脸平均脸的潜在空间向量和非微笑脸潜在空间向量，**作差**，得到纯微笑方向向量
- 公式：**Z_new = Z_neutral + a × (Z_smile − Z_non_smile)**
  - Z_neutral：中性脸的潜在向量
  - (Z_smile − Z_non_smile)：微笑方向向量（两种脸的均值差，即"微笑"这一属性的方向）
  - a：缩放系数（控制微笑强度，a 越大微笑越明显）
- 本质：在潜在空间里沿"微笑方向"移动，解码器就能生成带微笑的人脸——这正是 VAE 潜在空间"连续、可操纵"的体现
