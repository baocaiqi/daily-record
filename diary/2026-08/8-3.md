### 今日知识点+总结

**GridSearchCV + Pipeline 在 MNIST 上做 5 折交叉验证（五个主流算法对比）**

- **哪些算法要嵌套 StandardScaler**：逻辑回归、KNN、SVM 的 pipeline 里都嵌了标准化；决策树、随机森林没有
  - 原因：逻辑回归靠梯度下降、SVM 用 RBF 核、KNN 算欧几里得距离，都依赖低方差的数据分布 → 必须归一化
  - 树的分裂只看阈值，特征尺度不影响 → 不需要标准化
- **GridSearchCV 的 refit 参数**：用内层 5 折交叉验证里分数最高的那组最佳参数，在 X_train 上再训练一遍，得到最终模型
- **scoring 怎么选**：
  - `accuracy`：整体正确率
  - `f1_macro`：对每个类别分别算 F1 再取算术平均（类别不平衡时更客观）
  - `f1_weighted`：按每个类别的样本量加权平均，适合类别数量不均的情况
- **逻辑回归求解器怎么选**（本场景：5000 条样本、10 分类、L2 正则）：
  - `newton-cg` 和 `lbfgs` 都能胜任：都支持多分类、收敛极快；newton-cg 在多类别时迭代次数略少，lbfgs 是 sklearn 默认选项、更通用
  - 数据量极大（数十万行以上）→ 换 `saga`：支持大规模数据 + 多分类，而且是唯一支持 L1 正则（做特征选择）的多分类求解器
  - `liblinear` 虽然快，但不支持多分类
- **结果**：SVM 最高（最擅长高维像素数据的"核方法"），随机森林次高（集成学习在多分类上表现好）

**复习混淆矩阵 + 新知识点：灵敏度、特异度、宏平均、MCC**

- 混淆矩阵：

  |      | 预测正类 | 预测负类 |
  |------|----------|----------|
  | 实际正类 | TP | FN |
  | 实际负类 | FP | TN |

- **灵敏度**（Sensitivity / Recall / TPR）= TP / (TP + FN)：正类里抓出来多少
- **特异度**（Specificity / TNR）= TN / (TN + FP)：负类里认对多少
- **宏平均**（Macro-average APC/ACC）：对每个类别分别算召回率（或正确率），再取算术平均 → 剥夺多数类的优势，类别不平衡时比整体 accuracy 更客观公正
- **MCC（Matthews Correlation Coefficient，马修斯相关系数）**：

  MCC = (TP × TN − FP × FN) / √[(TP + FP)(TP + FN)(TN + FP)(TN + FN)]

  - 取值 [-1, 1]：+1 完美预测，0 等于瞎猜，−1 完全反着预测
  - 和 F1 的区别：F1 只看正类抓得全不全（只涉及 TP、FP、FN），MCC 是"双向"的，要求 TP 和 TN 同时大，混淆矩阵四个格子全用上
  - 类别不平衡时比 F1 更可靠
