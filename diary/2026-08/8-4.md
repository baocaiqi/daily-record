### 今日知识点+总结

**多分类策略：一对多（OvR / OvA）**

- 思路：K 元分类就训练 K 个二元分类器，每个分类器只把当前类当正类、其余所有类当负类
- 预测时：每个分类器输出一个置信度分数（比如逻辑回归的概率），最后取分数最高的类作为结果
- 特点：一个分类器吃全部训练数据，K 个分类器彼此独立，简单直接

**AUC（ROC 曲线下面积）**

- ROC 曲线：横轴是 FPR（假正率）= FP / (FP + TN)，纵轴是 TPR（真正率/召回率）= TP / (TP + FN)
- AUC 就是 ROC 曲线下的面积，越高模型能力越强
- 直觉含义：随机抽一个正样本和一个负样本，模型把正样本排在负样本前面的概率
- 取值：0.5 = 纯随机瞎猜，1 = 完美分类，小于 0.5 说明比随机还差（可能是标签标反了）
- 优势：不依赖分类阈值，类别不平衡时比 accuracy 更可靠

**VGG16 网络结构**

- 16 个带权重的层：13 个卷积层 + 3 个全连接层
- 全部只用 3×3 的小卷积核（stride=1、padding=1），不用大卷积核
  - 两个 3×3 堆叠 ≈ 一个 5×5 的感受野，三个 3×3 ≈ 7×7，但参数更少、非线性更强
- 总体结构分五大组，非常规整：每组卷几次、池化一次（2×2 最大池化）
  - 卷积核通道数逐组翻倍：64 → 64，128 → 128，256 → 256 → 256，512 → 512 → 512，512 → 512 → 512
- 参数总量约 1.38 亿，绝大部分集中在全连接层

**补充点：池化层的作用**

- 通过压缩长宽（空间尺寸），为后面的卷积层减少计算量
- 同时起到降维、提取局部主要特征的作用，还能减少过拟合
