# 整理 CET-6 单词 Skill

当用户说"整理今天的单词"或类似的表达时，按照以下格式整理用户提供的单词。

## 适用触发词
- "整理今天的单词"
- "整理单词"
- "优化单词"
- "按格式整理"
- 任何表示要把原始单词列表整理成格式化单词本的请求

## 目标文件
在 `/home/baocai/daily-record/english-cet6/` 目录下，根据已有文件序号递增创建新文件（如 words6.md, words7.md...），或更新用户指定的文件。

## 格式规范

### 文件头
```markdown
# 📚 CET-6 单词本 (N)

> 标注说明：`[词根]` = 词根/词缀注释 | `[短语]` = 固定搭配 | `[辨]` = 辨析 | `[场景]` = 场景偏好 | `[考点]` = 高频考点 | `[惯用]` = Native Speaker 惯用表达 | `[记忆]` = 记忆技巧
```

### 单词表格
```markdown
| # | 单词/短语 | 释义 | 备注 |
|---|-----------|------|------|
| 1 | **word** | 释义 | `[词根]` ... `[短语]` ... `[辨]` ... `[考点]` ... `[惯用]` ... `[记忆]` ... |
```

### 备注栏要求
每个单词/短语的备注栏必须包含以下**至少 3 项**（越多越好）：

1. **`[词根]`** — 词根/词缀拆解，标注含义并列出同根词
2. **`[短语]`** — 常用固定搭配，每个搭配附中文释义
3. **`[辨]`** — 形近词/近义词辨析（⚠️ 标注易混点）
4. **`[场景]`** — 适用场景（阅读/口语/正式写作等）
5. **`[考点]`** — 高频考点：谓一致、英美差异、阅读常见话题等
6. **`[惯用]`** — Native Speaker 惯用表达，地道的英语说法
7. **`[记忆]`** — 记忆技巧：联想、谐音、词源故事、趣味记忆法
8. **`[参考]`** — 如果该词在前面文件中已出现，标注参考

### 分组规则
- 将语义相关的单词排列在一起（如动物类、政治类、动作类）
- 主词条和其短语放在相邻位置

### 近义词场景偏好解析（必做）
单词表中**意思相近**的词，必须在 `[辨]` / `[场景]` 备注及结尾辨析表格中解析各自的使用场景偏好，给出选择依据。解析维度：
- **语域**：正式（学术/法律/公文）vs 非正式（口语/日常）
- **情感色彩**：褒义 vs 贬义 vs 中性
- **适用语境**：新闻、学术、文学、商务、医学、法律等
- **语气强弱**：强烈 vs 温和 vs 委婉
- **搭配对象**：人 / 物 / 抽象概念

示例：acclaimed（褒义：凭实力广受好评，critically acclaimed）vs hyped（贬义：宣传夸大实际）vs touted（中性偏贬：被标榜吹捧）vs vaunted（贬义：自夸过度）

### 结尾三大板块（必须包含）

#### 1. 📌 词根小结
提取本文中出现 ≥2 次的词根，列成表格：
```markdown
| 词根 | 含义 | 例词 |
|------|------|------|
| **xxx-** | 含义 | word1, word2, word3 |
```

#### 2. ⚠️ 形近词 / 近义词辨析（含场景偏好）
提取本文中易混词对，列表格（每行必须写明各词的**使用场景偏好**）：
```markdown
| 词对 | 区别（含使用场景偏好） |
|------|------|
| **A** vs **B** | A = ...（场景：正式/学术，褒义）；B = ...（场景：口语，贬义） |
```

#### 3. 🎯 高频考点速记
提炼文中相关的语法/用法考点：
```markdown
| 考点 | 说明 |
|------|------|
| **考点名** | 简要说明 |
```

## 关键原则
- 备注信息要**丰富但准确**，不要编造
- 英文拼写要核对无误，特别注意英美差异标注
- 对原文中明显的拼写/释义错误要纠正并标注
- 词根分析要可靠，不要强行拆解
- 联想记忆法要自然好记，不要牵强
- 短语和惯用表达要地道、实用
