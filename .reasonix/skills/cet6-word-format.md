# 整理 CET-6 单词 Skill

当用户说"整理今天的单词"或类似的表达时，按照以下格式整理用户提供的单词。

## 适用触发词
- "整理今天的单词"
- "整理单词"
- "优化单词"
- "按格式整理"
- "排列整齐"
- 任何表示要把原始单词列表整理成格式化单词本的请求

## 目标文件
在 `/home/baocai/daily-record/english-cet6/` 目录下，根据已有文件序号递增创建新文件（如 words7.md, words8.md...），或更新用户指定的文件。

## 格式规范

### 文件头
```markdown
# 📚 CET-6 单词本 (N)

> 排版：每条单词 2-4 行解析，按优先级排列：核心 → 搭配 → 辨析 → 词根/记忆
> 标注：`⚠️` = 易混点/重点 | **加粗** = 核心要点
```

### 单词区块
每个单词/短语一个标题块，解析**分条排列、不挤在一行**：

```markdown
## 一、组名（语义分组）

### 1. **word** — 释义
**核心**：...
**搭配**：...
**辨析**：⚠️ ...
**词根**：...
```

- 标题：`### 序号. **单词** — 释义`
- 解析行 2-4 行，按**优先级递减**：
  1. **核心**（最重要：高频义/用法要点，可加粗关键词）
  2. **搭配**（最常用固定搭配，斜杠分隔）
  3. **辨析**（⚠️ 易混词 + 使用场景偏好）
  4. **词根/记忆**（词根拆解 + 记忆技巧，可合并成一行）
- 没有对应内容的行可省略（如没有辨析就不写辨析行）
- 每条解析**一句话**，简明直白，不堆砌

### 分组规则
- 将语义相关的单词排列在一起（如动物类、政治类、动作类）
- 主词条和其短语放在相邻位置
- 组间用 `---` 分隔

### 近义词场景偏好解析（必做）
单词表中**意思相近**的词，必须在辨析行及结尾辨析表格中解析各自的使用场景偏好：
- **语域**：正式（学术/法律/公文）vs 非正式（口语/日常）
- **情感色彩**：褒义 vs 贬义 vs 中性
- **适用语境**：新闻、学术、文学、商务、医学、法律等
- **语气强弱**：强烈 vs 温和 vs 委婉
- **搭配对象**：人 / 物 / 抽象概念

示例：acclaimed（褒义：凭实力广受好评）vs hyped（贬义：宣传夸大）vs touted（中性偏贬：被标榜）vs vaunted（贬义：自夸过度）

### 结尾三大板块（必须包含）

#### 1. 📌 词根小结
提取本文中出现 ≥2 次的词根，列成表格：
```markdown
| 词根 | 含义 | 例词 |
|------|------|------|
| **xxx-** | 含义 | word1, word2 |
```

#### 2. ⚠️ 形近词 / 近义词辨析（含场景偏好）
提取本文中易混词对，列表格（每行写明各词使用场景偏好）：
```markdown
| 词对 | 区别（含使用场景偏好） |
|------|------|
| **A** vs **B** | A = ...（正式/褒义）；B = ...（口语/贬义） |
```

#### 3. 🎯 高频考点速记
提炼文中相关的语法/用法考点：
```markdown
| 考点 | 说明 |
|------|------|
| **考点名** | 简要说明 |
```

## 关键原则
- 解析**分条排列**，绝不把多个维度挤进一行/一个单元格
- 优先级固定：核心 → 搭配 → 辨析 → 词根/记忆
- 重点突出：核心要点加粗，易混点用 ⚠️
- 每条解析一句话，简明直白，不堆砌冗余
- 备注信息要**丰富但准确**，不要编造
- 英文拼写要核对无误，特别注意英美差异标注
- 对原文中明显的拼写/释义错误要纠正并标注
- 词根分析要可靠，不要强行拆解
- 联想记忆法要自然好记，不要牵强
- 短语和惯用表达要地道、实用
